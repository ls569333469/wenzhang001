## 一、平台规格（关键发现）

> [!CAUTION]
> 当前代码硬编码 max=900 字是**错误的**！实际帖子限制是 **2100 字符**。

| 内容类型 | 字符上限 | 支持格式 | 适用场景 |
|---------|---------|---------|---------|
| **帖子 (Posts)** | **2,100 字符** | 文本 + 表情 + 图片 + 交易组件 | 快速更新、市场点评 |
| **文章 (Articles)** | 80,000 字符 | 富文本编辑、大量图文 | 深度分析、教程 |
| **视频 (Videos)** | — | 视频上传 | 动态内容分享 |
| **直播 (Live)** | — | 实时语音 + 红包 | 互动答疑 |

**我们的模式应对标"帖子 (Posts)"**，实际上限 2100 字符 ≈ 约 **700-1050 中文字**（按中文1字=2-3字符估算）。

## 二、内容规则（合规红线）

### 🔴 严禁行为（违反可导致封号）

| 类别 | 具体规则 |
|------|---------|
| **外部引流** | 禁止引导用户访问第三方平台、分享外部联系方式或私人频道链接 |
| **第三方推广** | 禁止推广付费服务或请求付款，禁止未经核实的 Telegram 链接/机器人 |
| **虚假信息** | 禁止发布虚假上市新闻、未经验证的声明 |
| **高风险链接** | 禁止分享非官方赠品链接、钓鱼链接 |
| **乞讨行为** | 禁止乞求资金、打赏 |
| **欺诈行为** | 禁止金融诈骗、仿冒、钓鱼 |
| **骚扰/不当内容** | 禁止霸凌、骚扰、露骨内容 |
| **知识产权** | 禁止未经授权的复制/搬运 |
| **垃圾信息** | 禁止重复、无关或纯扰动性帖子 |

### 处罚措施
- 首次违规：警告 + 流量限制
- 再次违规：临时暂停（最长7天）
- 严重/多次：永久撤销内容创建权限 + 可能法律追究
