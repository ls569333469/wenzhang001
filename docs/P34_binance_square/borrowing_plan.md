# 广场提示词借鉴清单

> 场景：写项目内容完成创作者任务（如 Mira 活动），900字以内，不用表情符号。
> 必须包含 #项目标签 和 $代币标签，内容与项目相关。

---

## 策略师借鉴 3 项

### ① 思维工具箱 → 直接复用

```
短篇原文（直接搬）：
- 换结构：原文的重点如果变成背景、背景变成重点，会不会更有意思？
- 换主体：换一个相关方来看这件事，TA会怎么说？
- 换尺度：拉远看（行业/历史）或拉近看（一个人/一个细节）
- 找矛盾：当事方说的和做的一致吗？表面和本质一样吗？
- 反过来想：如果这件事没发生，意味着什么？主流观点的反面成立吗？
- 类比：完全不同领域有没有类似的事？
```

### ② 约束正反例 → 改写为广场场景

| 短篇原文 | 广场改写 |
|---------|---------|
| hook是像在X上随手发出的开场白（✅ "所有人都在问她为什么去VC"） | hook要让广场用户停下来（✅ "$MIRA 的验证共识机制，本质上是给AI装了个去中心化测谎仪"） |
| 不是分析报告的开头（❌ "从技术角度分析其合理性"） | 不是新闻稿（❌ "近日Mira Network宣布完成融资…"） |
| 至少1个版本不以"散户"为假设读者 | 至少1个版本面向**开发者/建设者**而非散户投资者 |

### ③ 差异化强制 → 直接复用

```
短篇原文（直接搬）：
- 3个版本必须从明显不同的角度切入同一素材
- 3个版本的 logic_pattern 必须不同
- angle 必须针对这篇素材的具体内容，不能是通用方法论
```

---

## 写手借鉴 4 项

### ④ 节奏规则 → 直接复用

```
短篇原文（直接搬）：
## 节奏（重要！）
- 大部分句子8-22字，但每篇必须包含1-2个30-50字的复合长句作为段落支撑
- 长句和短句交替出现，像人在思考，想到哪说到哪，偶尔绕一下再拉回来
- 段落以1-3句为主，但允许偶尔出现一个4-5句的密集段
- 绝对禁止全篇都是整齐划一的碎片短句，这是最明显的AI指纹
```

### ⑤ 人味要求 → 微调措辞

| 短篇原文 | 广场改写 |
|---------|---------|
| 偶尔承认不确定 | 保留 |
| 允许一处自己修正自己的说法 | 保留 |
| 不需要每句话都斩钉截铁，允许一处观点灰度 | 保留 |
| 信息密度不均匀：可以有1处只是顺嘴感慨，不必每段都有干货 | 改为：可以有1处加入个人使用体感 |
| 全篇情绪要有起伏变化，不要从头到尾一个调 | 保留 |

### ⑥ 禁用词体系 → 直接复用 + 补充广场专属

```
短篇原文（直接搬）：
标点：破折号「——」、分号「；」
AI词（出现即不合格）：赛道、生态、布局、底层逻辑、核心竞争力、破局、赋能、差异化
AI比喻词（出现即不合格）：筹码、牌桌、战场、猎杀、阵地
屏蔽词：庄哥、庄家、币圈、韭菜、割韭菜
事实：虚构场景/编造数据/给人物加戏/所有内容必须源自素材

广场专属补充：
- 禁止投资建议（"建议买入/卖出/抄底"）
- 禁止外部链接/联系方式
- 禁止第三方推广
```

### ⑦ 角色设定3层 → 改写为广场场景

| 层 | 短篇原文 | 广场改写 |
|---|---------|---------|
| 身份 | 你是一个在X上写作的自媒体作者 | 你是币安广场的项目内容创作者 |
| 能力 | 你擅长把复杂信息用精准的语言重新表达，让读者觉得通透 | 你擅长将项目技术/机制用清晰语言讲透，让交易者理解价值 |
| 读者 | 你的读者不需要被科普，他们想看的是你怎么想 | 你的读者是活跃交易者，他们想知道这个项目值不值得关注 |

## 评论家借鉴 1 项

### ⑧ 独立 Critic 模板 → 以短篇为骨架改写

```
短篇骨架（保留结构，替换内容）：
├── REWRITE条件（4条） → 改为广场场景
├── REFINE条件（4条） → 加入 tone/logic_pattern 回查
├── 策略官字段回查 → {{ tone }} + {{ logic_pattern }}
├── 字数检查 → {{ word_count }} vs 900上限
└── 输出JSON → {verdict, reason, suggestions}
```

## 不借鉴的部分

| 短篇有，广场不需要 | 原因 |
|---|---|
| context_card 事件脉络 | 广场写项目内容，不区分爆发性/快讯 |
| emotion_arc 情感走向 | 广场偏专业教育向，不需要戏剧性情绪弧 |
| ending_style 六选一收尾 | 广场统一用互动提问或个人总结收尾 |
| custom_prompts 前端覆盖 | 后续可加，非优先 |
| 比喻要求 | 项目内容偏技术解读，比喻需求低 |

| 独有功能 | 说明 |
|---------|------|
| voice_anchors | Chroma 声调锚定 |
| Chroma 自动存储 | published_posts + content_history |

| skip_polisher | 短内容不需要润色 |
