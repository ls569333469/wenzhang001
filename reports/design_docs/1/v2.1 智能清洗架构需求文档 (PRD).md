📘 文档一：v2.1 智能清洗架构需求文档 (PRD)
1. 项目背景 & 痛点
在导入长文本（如 18KB 的 mimeng2.txt）到 v1.0 系统时，遇到了三个致命问题：

截断崩溃 (Truncation)：文件过大导致 LLM 输出超过 4096 Tokens 上限，JSON 格式被切断 (Unterminated string)，程序抛出异常。

数据烂尾 (Partial Failure)：单线程处理导致一旦报错，后续内容全部丢失（如只处理了 57%）。

垃圾入库 (Data Pollution)：缺乏质量过滤器，导致大量低分废话（如“PS”、“接广告”）被写入 Lark 数据库。

2. 升级目标
构建一个**“全局统筹、智能切分、质量门控”**的工业级清洗工具。

3. 技术规格 (Technical Specs)
A. 核心模块：智能规划器 (Smart Planner)
全局扫描：在调用 LLM 前，先读取文件总字符数。

动态分块：

安全阈值 (Safe Limit)：设定为 2500 字符（Input）。

计算公式：Total_Chunks = Ceil(Total_Chars / 2500)。

语义边界：切分时必须优先保留句子完整性（优先按 \n 换行符切分），严禁在句子中间硬切。

B. 核心模块：质量门控 (Quality Gate)
评分过滤：LLM 返回的 quality_score 低于 4 分 的素材，在代码层面直接丢弃，不进行数据库写入。

去名化：强制要求 LLM 将作者名（如“咪蒙”）替换为通用代词。

C. 核心模块：鲁棒性 (Robustness)
JSON 修复：增加对 Markdown 代码块（````json ... `````）的自动剥离逻辑。

容错机制：单片失败不影响整体，只打印警告并继续处理下一片。

🧠 文档二：架构思维演进逻辑 (The Logic Trace)
这是我们从报错到现在完美方案的思维推演路径，供您复盘：

阶段 1：发现“输入输出不对等” (The Bottleneck)
现象：为什么 18KB 的文件会让支持 128k 上下文的模型报错？

洞察：模型的输入可以很大，但输出（Generation）通常限制在 4096 tokens。

结论：我们不能一次性把 18KB 喂给 AI，因为 AI 写不完输出结果就会被强制掐断。

阶段 2：确定“黄金切分点” (The Sweet Spot)
问题：切多大合适？

切太小（<1000字）：逻辑破碎，浪费 Prompt Token 成本。

切太大（>4000字）：输出再次截断。

决策：设定 2500 字 为阈值。

榨汁机理论：输入 2500 字（水果） -> 提炼后输出约 1000 字（果汁）。这完全在 4096 tokens 的安全区内。

阶段 3：从“盲人摸象”到“上帝视角” (The Map)
优化：旧方案是读一点切一点（While Loop），容易卡死且无进度感。

决策：v2.1 Smart Planner。

先看一眼全貌（Total Length），算好要切几刀（Chunks Count），然后再动手。

这带来了精确的进度条和极高的稳定性。

class LLMProvider:
    def __init__(self, provider_name: str):
        self.name = provider_name
        self.client = None
        self.model_name = ""

    def connect(self):
        if self.name == "doubao":
            api_key = os.getenv("VOLC_API_KEY")
            base_url = "https://ark.cn-beijing.volces.com/api/v3"
            self.model_name = os.getenv("VOLC_MODEL_ENDPOINT") 
            self.client = OpenAI(api_key=api_key, base_url=base_url)
        elif self.name == "deepseek":
            api_key = os.getenv("DEEPSEEK_API_KEY")
            base_url = "https://api.deepseek.com"
            self.model_name = "deepseek-chat"
            self.client = OpenAI(api_key=api_key, base_url=base_url)
        elif self.name == "gemini":
            api_key = os.getenv("GOOGLE_API_KEY")
            base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
            self.model_name = "gemini-1.5-flash"
            self.client = OpenAI(api_key=api_key, base_url=base_url)
        else:
            raise ValueError(f"不支持的模型提供商: {self.name}")

        if not self.client.api_key:
            raise ValueError(f"未找到 {self.name} 的 API Key，请检查 .env 文件")
        
        return self.client, self.model_name

# 3. v2.1 智能规划切分器 (Smart Planner)
# ==========================================

def smart_plan_and_split(text: str, safe_limit: int = 2500) -> List[str]:
    """
    v2.1 智能统筹切分算法：先全局规划，再按语义边界切分。
    """
    total_chars = len(text)
    
    # 极速模式：小文件直接返回
    if total_chars <= safe_limit:
        return [text]

    # 统筹规划
    estimated_chunks = math.ceil(total_chars / safe_limit)
    console.print(f"[bold cyan]🔍 预处理分析:[/bold cyan] 检测到 {total_chars} 字符，计划切分为 [bold yellow]~{estimated_chunks}[/bold yellow] 个任务块...")

    chunks = []
    current_chunk = ""
    lines = text.split('\n')
    
    for line in lines:
        # 预判：如果加上这一行会超标
        if len(current_chunk) + len(line) > safe_limit:
            if current_chunk:
                chunks.append(current_chunk)
                current_chunk = "" # 清空手牌
        
        # 极端情况处理：单行超长
        if len(line) > safe_limit:
            while len(line) > safe_limit:
                chunks.append(line[:safe_limit])
                line = line[safe_limit:]
            current_chunk += line + "\n"
        else:
            current_chunk += line + "\n"
    
    if current_chunk.strip():
        chunks.append(current_chunk)

    console.print(f"[dim]   ✅ 实际切分结果: {len(chunks)} 块[/dim]")
    return chunks

def call_llm_single_chunk(text_chunk: str, author: str, client: OpenAI, model_name: str) -> List[CleanedSnippet]:
    prompt = f"""
    你是一个专业的数据清洗专家。请阅读以下文本片段（作者：{author}），提取【Web3写作素材】。
    
    【清洗规则】
    1. **去名化**：将"{author}"或具体人名替换为通用代词。
    2. **Schema**：输出 JSON，包含 snippet_type, logic_pattern, emotional_valence, quality_score (1-5)。
    3. **过滤**：只提取有价值的内容。
    
    【待处理文本】
    {text_chunk}
    """

    try:
        response = client.chat.completions.create(
            model=model_name,
            messages=[
                {"role": "system", "content": "You are a JSON extractor. Output valid JSON only."},
                {"role": "user", "content": prompt}
            ],
            response_format={"type": "json_object"},
            temperature=0.7
        )
        content = response.choices[0].message.content
        if content.startswith("```"):
            content = content.replace("```json", "").replace("```", "")
        data = json.loads(content)
        
        snippets_data = data.get("snippets", data)
        # 兼容列表或字典返回
        if isinstance(snippets_data, dict): snippets_data = [snippets_data]
            
        return [CleanedSnippet(**item) for item in snippets_data]
    except Exception as e:
        console.print(f"[yellow]⚠️ 片段处理失败: {e}[/yellow]")
        return []

def extract_structure_from_text(text: str, author: str, provider: str) -> List[CleanedSnippet]:
    llm_setup = LLMProvider(provider)
    client, model_name = llm_setup.connect()
    
    # 调用规划器
    chunks = smart_plan_and_split(text, safe_limit=2500)
    all_snippets = []
    
    # 进度条显示
    for chunk in track(chunks, description=f"🤖 AI 正在清洗 {author} 的数据..."):
        snippets = call_llm_single_chunk(chunk, author, client, model_name)
        all_snippets.extend(snippets)
        
    return all_snippets

@app.command()
def clean(
    folder: str = typer.Option(..., help="TXT文件夹路径"),
    author: str = typer.Option(..., help="作者名"),
    provider: str = typer.Option("doubao", help="模型: doubao, deepseek, gemini"),
    min_score: int = typer.Option(4, help="最低入库评分，低于此分数的素材将被丢弃")
):
    console.print(f"[bold green]🚀 启动 v2.1 智能清洗 (Model: {provider} | Min Score: {min_score})[/bold green]")
    
    if not os.path.exists(folder):
        console.print(f"[red]错误: 文件夹 {folder} 不存在[/red]")
        return

    files = [f for f in os.listdir(folder) if f.endswith(".txt")]
    
    for filename in files:
        file_path = os.path.join(folder, filename)
        with open(file_path, "r", encoding="utf-8") as f:
            text = f.read()

        console.print(f"\n[cyan]📄 正在处理文件: {filename}[/cyan]")
        snippets = extract_structure_from_text(text, author, provider)
        
        valid_count = 0
        for s in snippets:
            if s.quality_score >= min_score:
                if upload_to_lark(s, author):
                    valid_count += 1
        
        console.print(f"[green]✅ {filename} 完成: 提取 {len(snippets)} 条 -> 入库 {valid_count} 条 (已过滤 {len(snippets)-valid_count} 条低分内容)[/green]")
