## 🔍 排查步骤

### Step 1: 检查 LLM 响应质量

**目的**: 确认 LLM 是否正确返回 JSON，是否提取了足够的 snippets

**方法**:
1. 添加详细日志，记录每个分片的 LLM 原始响应
2. 统计：成功响应数、失败响应数、平均每响应提取条数

**执行**:
```python
# 在 process_single_chunk 中添加日志
console.print(f"[dim]LLM返回: {len(snippets_data)} 条[/dim]")
```

---

### Step 2: 检查 Prompt 限制

**目的**: 评估 Prompt 是否过于严格导致 LLM 判定大部分内容无价值

**检查点**:
- [ ] 时效性过滤规则是否过严
- [ ] PS 降权规则是否误杀正常内容
- [ ] 去名化规则是否影响提取

**验证方法**:
临时使用简化版 Prompt 测试提取率

---

### Step 3: 检查分片质量

**目的**: 确认 chunk_text 是否正确切分，分片内容是否完整

**方法**:
1. 输出前 3 个分片的内容预览
2. 检查是否存在切分破坏语义的情况

---

### Step 4: 检查超时和错误处理

**目的**: 统计有多少分片因超时/错误被丢弃

**方法**:
添加统计变量追踪：
- 超时次数
- JSON 解析失败次数
- 异常捕获次数

---

### Step 5: 对比旧版本逻辑

**目的**: 确认 v2.0 升级是否引入了新的过滤逻辑

**检查点**:
- [ ] v1.0 是否有质量分过滤
- [ ] v1.0 是否有去重逻辑
- [ ] 新旧 Prompt 对比
