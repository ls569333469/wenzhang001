## 一、优化目标

### 1.1 核心目标

| 目标 | 指标 | 当前状态 | 目标状态 |
|------|------|----------|----------|
| **安全性** | XSS 漏洞数 | 1 (高危) | 0 |
| **健壮性** | SSE 中断恢复 | 不支持 | 支持 |
| **可用性** | 核心功能完整率 | 70% | 100% |
| **可维护性** | 主页面代码行数 | 566 行 | <200 行 |

### 1.2 非目标 (本期不做)

- 暗色模式
- 移动端适配
- 历史记录功能
- i18n 国际化

    a.href = url
    a.download = `quantum_${Date.now()}.md`
    a.click()
}

### Phase 5: 代码结构重构 (P3) ⏱️ 4-5h

**目标**: 提升代码可维护性

#### 5.1 组件拆分

**原结构**:
```
page.tsx (566 行)
```

**新结构**:
```
app/
├── page.tsx                 # 主页面布局 (~100 行)
├── components/
│   ├── panels/
│   │   ├── InputPanel.tsx       # 左侧输入面板 (~150 行)
│   │   ├── StagePanel.tsx       # 中央内容面板 (~150 行)
│   │   └── IntelligencePanel.tsx # 右侧 Agent 面板 (~80 行)
│   └── ...
├── hooks/
│   └── useGeneration.ts     # SSE 生成逻辑 (~200 行)
└── contexts/
    └── GenerationContext.tsx # 状态管理 (~80 行)
```

#### 5.2 状态管理重构

**创建 Context**:
```tsx
// contexts/GenerationContext.tsx
interface GenerationState {
    stage: Stage
    input: string
    mode: string
    options: StrategyOption[]
    result: string
    agentSteps: AgentStep[]
    logs: Log[]
    loading: boolean
    error: string | null
}

type GenerationAction = 
    | { type: 'SET_INPUT'; payload: string }
    | { type: 'SET_STAGE'; payload: Stage }
    | { type: 'ADD_LOG'; payload: Log }
    | { type: 'UPDATE_AGENT'; payload: { id: string; update: Partial<AgentStep> } }
    | { type: 'SET_RESULT'; payload: string }
    | { type: 'RESET' }
```

**创建 Hook**:
```tsx
// hooks/useGeneration.ts
function useGeneration() {
    const { state, dispatch } = useContext(GenerationContext)
    const abortRef = useRef<AbortController | null>(null)
    
    const startAnalysis = async () => { /* ... */ }
    const startGeneration = async (option: StrategyOption) => { /* ... */ }
    const stopGeneration = () => { /* ... */ }
    
    return { state, startAnalysis, startGeneration, stopGeneration }
}
```
