## 📦 项目概述

### 1.1 目标定义

创建一个 **独立的命令行工具 (`cleaner_cli.py`)**，用于批量清洗、结构化、打标签，并将处理后的素材上传到 Lark Base。

该工具将实现 `数据清洗.md` 中定义的 **"壳肉分离 (Shell-Kernel Separation)"** 核心方法论。

### 1.2 核心决策 (v3.0 新增)

> **用户决策**: 采用 `数据清洗.md` 定义的新数据模型，替换旧的 Lark Schema。

## 🗂️ 新 Lark Schema (核心变更)

### 旧 Schema → 新 Schema 对照表

| 旧字段 | 新字段 | 值域变化 | 说明 |
|:-------|:-------|:---------|:-----|
| `内容` | `内容` (content) | 不变 | 去名化后的文本 |
| `作者` | `作者` (author) | 不变 | 原作者名 |
| `风格` | `风格` (style) | 不变 | mimeng/banfo/xinshixiang 等 |
| `类型` | `类型` (snippet_type) | **Hook/Body/CTA/Quote/Hard_Fact** | ⚠️ 值域变更 |
| `情绪` | `情绪` (emotional_valence) | **High Arousal/Positive/Negative/Neutral** | ⚠️ 值域变更 |
| - | 🆕 `逻辑公式` (logic_pattern) | "先抑后扬+制造焦虑" 等 | 新增字段 |
| - | 🆕 `质量分` (quality_score) | 1-5 整数 | 新增字段 |
| `状态` | `状态` (status) | 待处理/已同步 | 不变 |
