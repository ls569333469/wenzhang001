## 📋 问题摘要

在进行深度 DOM 测试时，Gemini 云端 `browser_subagent` 报错 `$HOME environment variable is not set`。
虽然云端环境无法修复，但已确认 **本地环境完全正常**，并通过本地 Python 脚本成功绕过云端限制。

---

## ✅ 核心解决方案 (给晚班同事的交接)

**不要依赖 `browser_subagent` (云端)**，直接使用 **本地 Python 脚本** 调用 `playwright`。

### 1. 验证脚本位置
`backend/scripts/verify_p10_local.py`

### 2. 运行方法
在终端中直接运行：
```powershell
python backend/scripts/verify_p10_local.py
```

### 3. 脚本关键点 (Why it works)
本地脚本运行在用户的机器上，具有完整的环境变量 (`$HOME`, `$USERPROFILE`)，因此可以正常启动浏览器。

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    # headless=True 保证在后台快速运行
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    page.goto("http://localhost:3000/studio")
    # ... 进行 DOM 检查 ...
```

## 🔍 错误详情 (历史记录)

### 错误信息
```
failed to create browser context: failed to install playwright: $HOME environment variable is not set
```

### 根因分析
- **云端**: Gemini `browser_subagent` 运行在受限容器中，缺少 `$HOME`。
- **本地**: 用户机器环境正常，已安装 Playwright。
