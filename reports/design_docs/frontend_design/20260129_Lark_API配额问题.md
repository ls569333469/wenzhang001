## 推荐方案：本地备份模式

### 实现思路

1. **导出 Lark 数据到本地 CSV/JSON**
   - 手动或脚本一次性导出
   - 存储到 `backend/data/style_library_offline.json`

2. **SyncService 增加离线模式**
   ```python
   class SyncService:
       def get_samples(self, style, ...):
           if self.lark_available:
               return self._fetch_from_lark(...)
           else:
               return self._load_from_local_cache(...)
   ```

3. **定期同步策略**
   - Lark 配额恢复时批量同步
   - 同步完成后更新本地缓存
