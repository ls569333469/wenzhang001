## 附录：计算公式

```
输入 Token = 5806 条 × 600 Token/条 × 2 次 = 6,967,200 Token ≈ 7M
输出 Token = 5806 条 × 50 Token/条 × 2 次 = 580,600 Token ≈ 0.58M

在线费用 = 7M × ¥2/M + 0.58M × ¥8/M = ¥14 + ¥4.6 = ¥18.6
批量费用 = 7M × ¥1/M + 0.58M × ¥4/M = ¥7 + ¥2.3 = ¥9.3

合并调用后 (1次/条):
在线费用 = ¥18.6 / 2 = ¥9.3
批量费用 = ¥9.3 / 2 = ¥4.65 ≈ ¥5.25
```
