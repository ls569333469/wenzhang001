## 🚀 今日进展

### 1. 问题诊断 ✅

**发现的根因：**
- LLM 直接复制 prompt 中的示例短语
- 典型固定短语：`"真相藏在这里"`、`"上车"`、`"泡沫还是起点"`
- 原 prompt 的爆款公式提供了可复制的模板

### 2. Strategist Prompt 重构 ✅

**文件：** `backend/data/prompts/strategist.jinja2`

**修改内容：**

| 修改项 | 说明 |
|--------|------|
| 添加详细中文注释 | 每个部分都有 `{# 中文解释 #}` 帮助新人理解 |
| 重写爆款公式 | 用抽象技巧描述替代可复制短语 |
| 添加三类禁止词体系 | 全面覆盖 AI 检测器关注的特征 |

### 3. 三类 AI 禁止词体系 ✅

```
第一类：Top 30 铁证 AI 味词汇 (检测器重点抓)
  - 深入探讨/深入剖析/深入研究/深入挖掘
  - 值得注意的是/值得一提的是/不容忽视的是
  - 至关重要/举足轻重/不可或缺/核心要素
  - 赋能/深度赋能/赋能千行百业
  - 范式/范式转变/范式变革
  ... 共30组

第二类：第二梯队高频词 (商业/科技/学术文浓度高)
  - 杠杆/驾驭/harness
  - 变革性/革命性/颠覆性/transformative
  - 尖端/前沿/cutting-edge
  - 协同/synergy/协同效应
  ... 共28组

第三类：句式结构特征 (比单个词更致命)
  - 段落开头禁止：首先、其次、再次、此外
  - 强行总结禁止：展望未来、让我们携手
  - 假真诚禁止：你并不孤单
  - 升华禁止：这不仅仅是……更是……
  ... 共10类
```
