# Gemini 浏览器子系统故障报告

> **报告日期**: 2026-01-28 16:35  
> **报告人**: AI Assistant (Gemini Code Assist)  
> **状态**: 🔴 未解决 (Gemini 内部问题)

---

## 📋 问题摘要

在进行深度 DOM 测试时，Gemini 内部的 `browser_subagent` 工具持续报错，无法打开任何网页。

---

## 🔍 错误详情

### 错误信息

```
failed to create browser context: failed to install playwright: $HOME environment variable is not set
```

### 尝试的操作

| 操作 | 结果 |
|------|------|
| 打开 `http://localhost:3000/studio` | ❌ 失败 |
| 打开 `http://127.0.0.1:3000/studio` | ❌ 失败 |
| 打开 `https://www.google.com` | ❌ 失败 |
| 列出浏览器页面 | 返回空列表 |

### 本地环境验证

```powershell
# 环境变量检查
echo $env:HOME          # C:\Users\ls569
echo $env:USERPROFILE   # C:\Users\ls569

# Playwright 版本
npx playwright --version  # Version 1.58.0

# 已安装的浏览器
ls $env:LOCALAPPDATA\ms-playwright
# chromium-1200, chromium-1208, ffmpeg-1011, winldd-1007
```

**结论**: 本地环境完全正常，问题出在 Gemini 云端。

---

## 🧩 技术分析

### browser_subagent 工作原理

```
┌─────────────────┐      ┌──────────────────────┐
│  用户本地机器    │      │   Gemini 云服务器      │
│                 │      │                      │
│  localhost:3000 │◄────►│  browser_subagent    │
│  (Next.js 应用) │      │  (Playwright 容器)   │
└─────────────────┘      └──────────────────────┘
                                   ▲
                                   │
                         ❌ $HOME 未设置
                            Playwright 安装失败
```

### 问题根因

1. `browser_subagent` 是 Gemini 云端的 Playwright 实例
2. 该容器的 `$HOME` 环境变量未正确配置
3. Playwright 需要 `$HOME` 来确定缓存和安装目录
4. 这是 **Google 基础设施配置问题**，非用户可控

---

## 🛠️ 临时解决方案

已采用的替代方案:

```powershell
# 使用 HTTP 请求抓取 HTML 进行 DOM 分析
Invoke-WebRequest -Uri "http://localhost:3000/studio" -OutFile "studio.html"
```

这种方法可以获取 **服务端渲染 (SSR)** 的 HTML，足以进行基础 DOM 结构分析。

---

## ⚠️ 局限性

使用 HTTP 抓取 **无法**:
- 捕获 JavaScript 动态渲染的内容
- 进行交互测试 (点击、输入)
- 截取屏幕截图
- 验证动画和过渡效果
