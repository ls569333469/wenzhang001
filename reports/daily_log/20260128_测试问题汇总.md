## 📝 详细分析

### 问题 1: 标题重复 ⚠️

**根因**: `backend/app/agents/strategist.py` 中 `temperature=0.2` 过低
**建议**: 提高至 `0.6` 并在 Prompt 中增加多样性指令

---

### 问题 2: 思维链信息不全 ⚠️

**根因**: 后端 `graph.py` 未构建 `thinking_steps` 数据
**建议**: 在 `node_strategist/writer/critic` 中构建步骤列表，通过 SSE 推送

---

### 问题 3: 字数限制 ✅ **已实现**

**DOM 发现**: `/studio` 页面包含完整的篇幅选择器 UI：

```html
<label>篇幅长度</label>
<button>短篇 (~500字)</button>   <!-- 默认未选中 -->
<button>中篇 (~1.5k字)</button>  <!-- 默认选中 -->
<button>长文 (~3k字)</button>
```

**结论**: 前端 UI 已完整实现，需验证后端是否正确接收和处理该参数。

---

### 问题 4: Per-Agent API 选择 ⚠️

**现状**: `/agents` 页面显示所有 Agent 共用同一模型 (从 `localStorage.qs_model` 读取)
**建议**: 可选增强，为每个 Agent 添加独立模型下拉选择器
