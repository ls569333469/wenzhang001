## 5. 发现的代码问题

### 🔴 高优先级 (P0/P1)

#### 5.1 最终结果无法正确显示 (P0)
- **文件**: `page.tsx` L300-340
- **问题**: SSE 中 `final_result` 事件处理逻辑错误
- **原因**: 前端使用 `data.type === 'final'`，后端发送 `final_result`

```javascript
// 前端代码 (page.tsx L319)
if (data.type === 'final') {
    setResult(data.content)  // 永远不会匹配
}

// 后端发送 (main.py L208)
{"type": "final_result", "payload": content}  // 使用 final_result
```

**修复方案**:
```javascript
if (data.type === 'final_result') {
    setResult(data.payload)
}
```

- **问题**: `references` 状态已定义但无对应 UI

### 10.3 SSE 连接健壮性

#### 当前实现分析

```tsx
// page.tsx:265-277 - handleGenerate
const response = await fetch(`${API_BASE_URL}/generate`, {
    method: 'POST',
    // ❌ 无 timeout
    // ❌ 无 AbortController
    // ❌ 无重连机制
})
```

#### 评估结论

| 检查项 | 状态 | 代码位置 | 风险等级 |
|--------|------|----------|----------|
| **停止生成按钮** | ❌ 不存在 | - | 🔴 **高** |
| AbortController | ❌ 未使用 | `page.tsx:265` | 🔴 **高** |
| Fetch 超时 | ❌ 未配置 | `page.tsx:265` | 🟡 中 |
| 断线重连 | ❌ 未实现 | - | 🟡 中 |
| Keep-Alive | ❌ 未配置 | - | 🟡 中 |

#### 问题影响

1. **无法中途停止**: 用户必须等待生成完成或刷新页面
2. **网络抖动丢失**: 长文章生成(3-5分钟)期间网络断开，进度全部丢失
3. **浏览器卡死风险**: SSE 流未正常关闭可能导致内存泄漏

#### 修复方案

```tsx
// 1. 添加 AbortController
const [abortController, setAbortController] = useState<AbortController | null>(null)

const handleGenerate = async () => {
    const controller = new AbortController()
    setAbortController(controller)
    
    // 5 分钟超时
    const timeoutId = setTimeout(() => controller.abort(), 5 * 60 * 1000)
    
    try {
        const response = await fetch(`${API_BASE_URL}/generate`, {
            signal: controller.signal,
            // ...
        })
        // ...
    } finally {
        clearTimeout(timeoutId)
        setAbortController(null)
    }
}

// 2. 停止按钮
const handleStop = () => {
    abortController?.abort()
    setLoading(false)
    setStage('selection')
}

// 3. UI
{loading && (
    <Button variant="destructive" onClick={handleStop}>
        <StopCircle className="w-4 h-4 mr-2" />
        停止生成
    </Button>
)}
```
