## 二、技术要点

1. **ChainCatcher 爬虫**: API (`/api/article/lists`) 返回 400, RSS 返回 404, 最终采用 **HTML scraping** (`/news` + `/article`), 有网站结构变更风险
2. **AI 分析**: 使用 `generate_text` (volcengine) 进行摘要/评分/实体抽取, 单条约 5-10 秒
3. **去重逻辑**: 基于 URL 去重, 写入前检查已有 URLs
4. **"去创作"流程**: 通过 zustand store 的 `materialPrefill` 字段实现跨组件通信
