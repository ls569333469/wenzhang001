## Part B2: 禁止虚构开头规则 (方案 A)

**问题**: AI 生成"凌晨三点，李哥盯着屏幕..."等虚构开头，显得很假。

**解决方案**: 在 `writer.jinja2` 中硬编码禁止规则：

```jinja2
{% if mode == "quick_take" %}
【快讯模式专属规则】
✓ 直接陈述事实，开门见山
✓ 用数据/引用开头
✗ 禁止虚构人物故事 ("凌晨三点，李哥...")
✗ 禁止编造场景 ("某个交易员...")
✗ 禁止过度情绪渲染
{% endif %}
```

**改动文件**: `backend/data/prompts/writer.jinja2`  
**改动行数**: +15 行
