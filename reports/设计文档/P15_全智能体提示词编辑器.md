### 5. 提示词组装逻辑

```typescript
// 文件: frontend/src/features/settings/constants/promptSchemas.ts (新建)

export const OUTPUT_FORMATS = {
  hot_take: `
## 📤 输出格式
\`\`\`json
{
  "candidates": [
    {"id": 1, "content": "锐评内容...", "word_count": 85}
  ]
}
\`\`\``,
  mid_take: `...`,
  deep_analysis: `...`
};

// 前端组装完整提示词
function assemblePrompt(section: PromptSection, mode: string): string {
  let prompt = `Current Time: ${new Date().toISOString()}\n\n`;
  
  prompt += section.role + '\n\n---\n\n';
  prompt += '## 🎯 任务\n' + section.task + '\n\n---\n\n';
  
  if (section.style?.trim()) {
    prompt += '## ✍️ 风格要求\n' + section.style + '\n\n---\n\n';
  }
  
  if (section.forbidden?.trim()) {
    prompt += '## ❌ 严禁\n' + section.forbidden + '\n\n---\n\n';
  }
  
  // 系统区块 (固定 - 自动注入 JSON Schema)
  prompt += '## 📥 素材\n{{ raw_input }}\n\n---\n\n';
  prompt += OUTPUT_FORMATS[mode] || '';  // 从常量自动注入
  
  return prompt;
}
```

## ⚠️ 注意事项

1. **空值处理**: 区块留空时不添加该区块到最终提示词
2. **默认值**: "加载默认模板"按钮从 `defaultPrompts.ts` 加载
3. **启用开关**: 需要有"使用自定义提示词"开关，关闭时使用后端模板
4. **预览功能**: 显示组装后的完整提示词 (只读)
5. **保存提示**: 保存成功后显示 toast 提示
