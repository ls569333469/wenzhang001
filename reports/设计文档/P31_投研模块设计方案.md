## 一、模块定位

投研模块是 Studio 的一个创作模式，用于自动生成每日投研快报。支持两种触发方式：
- **手动**：用户在 Studio 投研页面操作
- **自动**：定时任务调用 API

## 二、日报生成流程

```
POST /api/research/daily-report
  │
  ├─ 🔭 侦察官 ×1      搜索 leak.me → 发现 N 个项目
  │
  ├─ 🔬 策略官 ×N      并发 3 个，Surf API 深度分析每个项目
  │   └─ 每个项目保存完整报告到 reports/research/projects/
  │
  ├─ 📋 审核官 ×1      总结归纳 N 篇长报告 → 精简版
  │
  ├─ ✍️ 写手 ×1       组装日报
  │
  └─ ✨ 润色官 ×1      定稿 → reports/research/daily_research_YYYYMMDD.md
```

## 三、AI 模型搭配

全局 4 个 provider，Settings 每个智能体每个模式可自由切换。

| 智能体 | 投研默认 | 类型 | 全局可选 |
|--------|---------|------|---------|
| 🔭 侦察官 | Surf 1.5 | 搜索型 | 火山引擎 / Gemini / Grok / Surf |
| 🔬 策略官 | Surf 1.5 | 搜索型 | 火山引擎 / Gemini / Grok / Surf |
| 📋 审核官 | 豆包 | 生成型 | 火山引擎 / Gemini / Grok / Surf |
| ✍️ 写手 | DeepSeek V3.2 | 生成型 | 火山引擎 / Gemini / Grok / Surf |
| ✨ 润色官 | 豆包 | 生成型 | 火山引擎 / Gemini / Grok / Surf |

## 四、前端布局（Studio 投研模式）

```
左栏（不动）  |  DataPanel（投研面板）  |  主区域         |  右栏（不动）
通用导航      |  侦察官搜索按钮         |  输入框           |  思考过程
模式切换      |  项目搜索过滤           |  日报输出          |  每步进度
设置入口      |  项目卡片（可勾选）      |  素材中心同步提示   |  状态显示
             |  「生成日报」按钮        |                  |
```

**分工**：
- **Studio 投研页面** → 主操作：搜索、选项目、生成日报、查看输出
- **素材中心** → 存档：历史日报 + 单项目报告，可导出，可回调 Studio

**与素材中心打通**：
- 日报生成后自动同步到素材中心「投研报告」标签
- 素材中心可打开报告详情 → 一键跳回 Studio 投研页面

### 功能

| 功能 | 说明 |
|------|------|
| 日报列表 | 按日期倒序展示，显示项目数和摘要 |
| 单项目报告 | 展示 `projects/` 目录下的完整 Surf 报告 |
| 查看 | 展开报告内容，支持 Markdown 渲染 |
| 导出 | 支持 Markdown 和 PDF 两种格式 |
| 在 Studio 打开 | 跳转到 Studio 投研模式，预填项目信息 |
| 日期筛选 | 按日期范围过滤日报 |
| 搜索 | 按项目名称搜索历史报告 |

### 数据来源

读取 `reports/research/` 目录：
- `daily_research_*.md` → 日报列表
- `projects/*.md` → 单项目报告列表



```

      ├── Ethena_20260227.md         ← 策略官完整报告
```
