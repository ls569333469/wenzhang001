# P27 布局问题汇总

> **设备环境**: 32寸显示器 · 2560×1305 分辨率 · 全屏浏览器
> **日期**: 2026-02-20
> **当前状态**: 已完成 P0 清理 + P1 ConfigPanel/DataPanel 重构，布局参数仍需优化

---

## 一、问题全景

用户核心诉求是：**当前布局在 32寸 2560px 全屏下，要么太宽（内容撑满整个屏幕），要么太窄（约束过头留白过多），缺少一个"刚好"的平衡点。**

---

## 二、逐项问题清单

### 问题 1：左侧动态栏（ConfigPanel）不一致

**现象**:
- ConfigIsland 展开状态为 `356px`，收起为 `96px`
- 展开/收起时主内容区的 margin 跟随变化 (`lg:ml-[356px]` ↔ `lg:ml-[96px]`)
- 切换速度和动画虽已实现，但整体交互逻辑需要进一步打磨

**当前代码** (`StudioLayout.tsx:89`):
```tsx
hasLeftPanel && (configExpanded ? "lg:ml-[356px]" : "lg:ml-[96px]")
```

**用户感受**: 左栏和中心内容的比例关系不够"科学"，视觉上不够协调

---

### 问题 2：输入框太宽 / 太窄

**变迁历史**:
| 阶段 | 输入框宽度 | 问题 |
|------|-----------|------|
| P1 完成后 | `max-w-full` (撑满) | 在 2560px 下横跨整屏，太宽 |
| 第一次修复 | `max-w-[680px]` | 在 2560px 全屏下又显得太窄、太拥挤 |

**当前代码** (`HeroInput.tsx:117-118`):
```tsx
"w-full transition-all duration-500 mx-auto",
"max-w-[680px]"
```

**核心矛盾**: `680px` 在小窗口下正好，但在 32寸全屏（中心可用区域约 1920px）下显得远远不够——只占了中心区域的 35%

---

### 问题 3：内容区太宽 / 太窄

**变迁历史**:
| 阶段 | 内容区限制 | 问题 |
|------|-----------|------|
| P1 完成后 | 无 `max-width` | 内容撑满可用空间，2560px 下一行文字太长 |
| 第一次修复 | `max-w-3xl` (768px) / `max-w-5xl` (1024px) | 768px 在 1920px 可用区太小 |

**当前代码** (`StudioLayout.tsx:96-99`):
```tsx
"w-full mx-auto",
hasDataPanel ? "max-w-5xl" : "max-w-3xl"
```

**核心矛盾**: 
- 标准模式 `max-w-3xl = 768px` → 在 1920px 可用区中只占 40%，两侧各留 ~576px 空白
- DataPanel 模式 `max-w-5xl = 1024px` → 300px DataPanel + 700px 输入区，勉强可用但不够宽敞

---

### 问题 4：DataPanel 溢出视口

**已修复**:
DataPanel 已加入 `sticky top-24` + `max-h-[calc(100vh-120px)]` + 独立滚动，不再溢出视口。

**当前代码** (`DataPanel.tsx:37`):
```tsx
"w-[300px] shrink-0 sticky top-24 self-start max-h-[calc(100vh-120px)] overflow-y-auto rounded-xl border border-zinc-200 bg-white shadow-sm scrollbar-hide"
```

**残余问题**: `300px` 宽度是否足够展示数据内容，待用户确认

---

### 问题 5：Textarea 高度

**已修复**: 从 `80px` 降到 `56px`，但在全屏布局下是否合适取决于输入框整体宽度

**当前代码** (`HeroInput.tsx:135`):
```tsx
"w-full h-[56px] bg-transparent border-none outline-none ..."
```

---

### 问题 6：模式切换时布局跳变

**现象**:
- 标准模式（中篇、长篇等）→ 内容居中，无 DataPanel
- DataPanel 模式（吹捧、嘴撸、投研）→ 内容右移，左侧出现 DataPanel

**当前行为**: 切换时 `max-width` 从 `3xl` 跳到 `5xl`，加上 DataPanel 突然出现，视觉跳动明显

**理想状态**: 切换应该是平滑过渡，或者两种模式下内容区宽度保持一致

---

### 问题 7：Mockup 预览方案与真实效果差距大

**现象**: 之前提供的 Mockup 方案是在一个"窗口化"的小框里渲染的，在 32 寸屏幕上看到的实际效果和 Mockup 差距巨大

**根因**: Mockup 使用了固定像素的虚拟视窗（约 1200px 宽的小框），而真实环境是 2560px 全屏

**教训**: 后续设计预览必须在真实应用中实测，或使用 100vw/100vh 全屏 1:1 渲染

---

## 三、核心矛盾总结

```
32寸 2560px 全屏
├─ 左栏: ~356px (固定)
├─ 中心可用: ~1920px
│   ├─ 当前 max-w-3xl = 768px → 只用了 40%，空太多 ❌
│   ├─ 之前无限制 = 1920px → 全打满，太宽 ❌
│   └─ 需要找到: 40% < X < 100%
└─ 右栏: ~260px (固定)
```

**关键数字**:
- 可用中心区: `2560 - 356 - 260 = 1944px`（左栏展开时）
- 可用中心区: `2560 - 96 - 260 = 2204px`（左栏收起时）
- 最佳输入框行宽: `600-800px`（参考 Medium、Notion）
- 最佳 DataPanel 宽: `300-400px`
- 合理的内容区 max-width: **待用户决定**
