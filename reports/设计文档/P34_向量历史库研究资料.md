### 10 大AI 记忆层

**1. Mem0：AI 智能体的通用记忆层 - 48k stars**

到目前为止被采用最多的记忆系统。

当你调用 `add()` 时，Mem0 会进行两次 LLM 调用：一次从对话中提取事实，另一次与现有记忆进行比较并决定要添加、更新或删除什么。

事实存储在向量存储（默认是 Qdrant）中，并可通过 Neo4j 选择性地添加图层。没有模式（schema），没有结构验证，只有干净、快速的事实存储。

Mem0 做得最好的是降低了采用门槛：只需三行代码，你就能获得一个可用的记忆系统。已在 Netflix、Lemonade 和 Rocket Money 的生产环境中使用。

**2. Letta (MemGPT)：管理自身记忆的智能体**

与这里的其他系统不同，Letta 不会替智能体提取记忆：而是由智能体自己决定要记住什么。

它使用在提示词（prompt）中持久存在的、可编辑的“核心记忆块（core memory blocks）”，加上通过搜索检索的用于长期存储的归档记忆。

可以把它想象成给你的智能体一个它可以读写的笔记本。白盒且与模型无关。由最初发表 MemGPT 论文的加州大学伯克利分校研究人员构建。设置起来比较复杂，但赋予了智能体对自己上下文的真正自主权。

**3. Cognee：能够学习和自我改进的知识图谱**

从你的数据中构建知识图谱，然后不断对其进行优化。

其流水线运行方式为：分类 → 提取分块 → LLM 提取实体和关系 → 嵌入到向量存储 → 将边提交到图谱。

“memify（记忆化）”步骤是它的与众不同之处：它会修剪陈旧的节点，强化频繁的连接，并根据使用情况重新衡量边的权重。

每一条记忆都可以追溯到它的源文档。提供从基础 RAG 到思维链图遍历的 14 种检索模式。在 HotPotQA 基准测试中准确率最高。已在拜耳（Bayer）和 70 多家公司的生产环境中运行。

**4. memU：面向主动型智能体的文件系统式记忆**

像文件系统一样组织记忆：`preferences/communication_style.md`（偏好/沟通风格）、`relationships/contacts/`（关系/联系人）、`knowledge/learned_skills/`（知识/已学技能）、`context/pending_tasks/`（上下文/待办任务）。

专为全天候（24/7）、能预测你需求的智能体而设计。从浏览中学习主题偏好，跟踪作者的信誉，根据互动历史过滤噪音。

在 LoCoMo 基准测试的所有推理任务中平均准确率达到 92%。可以把它想象成给你的 AI 智能体一个它可以自己浏览和更新的结构化大脑。

**5. Graphiti：追踪事实随时间变化的时序知识图谱**

唯一一个认真对待时间的系统。Graphiti 使用双时态模式（bi-temporal schema）在每条边上存储时间戳和关系的演变。

当用户换工作、结婚或更新偏好时，Graphiti 不会覆盖，而是进行版本控制。你可以问“智能体上周二知道什么？”，并得到一个准确的答案。

结合了基于图的记忆和向量搜索，以处理复杂的企业场景。它是 Zep 的 SaaS 产品背后的开源引擎。

如果你想了解时序 AI 记忆中的难题，它有非常优秀的博客文章可供参考。

**6. MemOS：支持多模态的记忆操作系统**

将记忆视为操作系统。其核心概念是“记忆立方体（memory cubes）”，它们是可组合的单元，你可以按用户隔离、跨项目共享或动态组合。

在一个记忆系统中原生处理文本、图像、图表和工具执行追踪。具有毫秒级延迟的异步数据摄取。

具有学术背景，出自发表过最早的 Memory OS 论文的研究团队。对于需要在用户之间进行严格记忆隔离的平台来说，这是一个很好的架构。

**7. MemoryOS：为个性化智能体打造的 MCP 原生记忆**

被接收为 EMNLP 2025 的 Oral 论文，具有很高的学术信誉。

专为需要了解你是谁的个性化 AI 智能体而构建。随着时间的推移，从对话中提取性格特征、兴趣偏好和知识背景。

MCP 优先的架构意味着它可以直接插入 Claude、Cursor 和其他兼容 MCP 的工具中。支持 BGE-M3 和 Qwen3 嵌入。

体积虽小但专注于一个难题：让智能体感觉起来像是真正了解你。

**8. SimpleMem：极简记忆，零复杂性**

当你不需要知识图谱、时序推理或自我改进的流水线时，你只需要你的智能体在不同的会话之间记住事情。

SimpleMem 专注于做好一件事：在没有基础设施开销的情况下持久化上下文。

不需要启动向量数据库，不需要配置图引擎。只有可靠、快速、简单的记忆。AI 记忆领域的 SQLite。

令人惊讶地受欢迎，因为大多数智能体不需要企业级记忆，它们只需要不遗忘。

**9. LangMem：LangGraph 内部的长期记忆**

如果你已经在 LangChain/LangGraph 生态系统中构建智能体，LangMem 是你的原生选择。

使用命名空间和键将记忆作为 JSON 文档存储在结构化存储中。专注于工作记忆：将冗长的对话历史压缩成可操作的摘要。

虽然不如独立的记忆系统那么强大，但如果你是 LangGraph 团队，就可以实现零上下文切换。紧密的集成意味着你不需要管理任何其他依赖项。

**10. 作为 MCP 服务器的即插即用持久化记忆**

氛围派程序员（vibe coder）进入记忆系统的首选。

没有知识图谱，没有时序推理，没有复杂的流水线，只有一个即插即用的 MCP 服务器，为 Claude Code、Cursor 和 Windsurf 提供跨会话的持久记忆。

安装它，连接它，你的编程助手就不会每次在你关闭终端时都忘记你的项目上下文了。

它是这个列表中最小的系统，但它解决了当今任何使用 AI 编程工具进行构建的人最迫切的痛点。有时候，最好的工具就是那个最简单且能被实际使用的工具。

### 现在是最有趣的部分。

**实际上你可以将它们组合使用以达到最佳效果：**

**分层记忆：Mem0 + Graphiti**

使用 Mem0 作为快速记忆层，使用 Graphiti 进行长期的历史追踪。

*工作原理：*

Mem0 从对话中提取事实并存储起来以便快速检索。

重要的事实会被提升到 Graphiti 中，在那里它们会随着时间进行版本控制。

这为你提供了快速回忆 + 历史推理的能力。

**智能体自主性 + 结构化知识：Letta + Cognee**

将 Letta 与 Cognee 结合。

*工作原理：*

Letta 让智能体决定在其核心记忆中记住什么。

Cognee 从文档和数据源中构建知识图谱。

这为你提供了智能体自主性 + 深度知识推理的能力。

**个人助手技术栈：memU + MemoryOS**

将 memU 与 MemoryOS 结合。

*工作原理：*

memU 像结构化的大脑一样组织记忆：`preferences/`、`relationships/`、`tasks/`。

MemoryOS 提取个性和长期的行为特征。

它们共同产生了深度的个性化 + 结构化的上下文。

**轻量级开发技术栈：SimpleMem + MCP 记忆服务器**

将 SimpleMem 与 MCP 持久化记忆服务器配对。

*工作原理：*

SimpleMem 以极低的成本存储会话上下文。

MCP 服务器在 Cursor 或 Claude 等工具之间共享该记忆。

跨越终端会话、IDE 和智能体。

**平台级记忆：MemOS + Mem0**

将 MemOS 与 Mem0 结合。

*工作原理：*

MemOS 管理每个用户或项目的多租户记忆立方体。

Mem0 处理事实提取和更新。

你获得了企业级隔离 + 自动记忆提取的能力。

**简而言之（TL;DR）：最好的系统是混合系统**

大多数生产环境中的智能体最终都会有 3 个记忆层：

1. 快速事实记忆 → Mem0 / SimpleMem
2. 结构化推理 → Cognee / Graphiti
3. 个性化或智能体控制 → Letta / MemoryOS / memU

正确地堆叠它们，你将得到这样的智能体：

- 记住用户
- 基于知识进行推理
- 追踪事实的变化
- 在生产环境中保持快速。

收藏这篇文章，并尝试这些组合。你会对这些记忆系统带给你的好处感到惊讶的。

11. OpenClaw 原生文件驱动记忆系统极简透明、无黑盒、手工可控的记忆方式。所有记忆以纯 Markdown 文件形式存在磁盘，作为唯一真相源。模型不保留任何内存，只在每次会话读取文件内容。四层结构：

1. 短期：当前会话上下文，满了自动 compaction 压缩摘要写入 daily md。
2. 中期：memory/YYYY-MM-DD.md，存放当天日志、召回片段、总结、教训，启动加载最近 1–3 天。
3. 长期：MEMORY.md（核心规则、知识沉淀）、STYLE_GUIDE.md（风格圣经）、KNOWLEDGE_BASE.md 等，常驻注入主会话 prompt。
4. 检索加速：SQLite-vec + BM25 + MMR + 时间衰减，切块嵌入 md 文件，支持 memory_search 带条件召回。

使用核心指令：

“先 memory_search 情绪=激昂 逻辑=数据流+对比 quality>=7 n=8 → 严格遵守 MEMORY.md 和 STYLE_GUIDE.md → 开始任务”每周维护：

“回顾本周 daily md，提炼高频模式/教训/新规则，更新 MEMORY.md 和 STYLE_GUIDE.md”打开文本编辑器就能改它“记得什么”，改完立即生效。最纯粹的“文件即记忆”。
