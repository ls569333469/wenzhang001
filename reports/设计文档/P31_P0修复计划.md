# P31 P0 修复方案

## 目标

把投研报告从 Dashboard 迁到 Studio 投研模式中间画布，同时确保配图适合 X 分享。

---

## 改动 1：Studio 主区域展示日报

**现状**：Studio 投研模式主区域只有 HeroInput（输入框），生成日报后无输出。
**目标**：日报生成完成后，主区域切换为「配图预览 + 推文 + 完整报告」三段式。

### [MODIFY] Studio 投研模式主区域

- 当 `mode=project_research` 时，主区域根据状态切换：
  - **空状态**：显示引导文案「在左侧搜索项目，然后生成日报」
  - **生成中**：显示进度条（侦察官→策略官→审核官→写手→润色官）
  - **生成完成**：显示 `ResearchView`（配图 + 推文 + 报告）
- `ResearchPanel.tsx`（DataPanel）生成日报后，把结果写入全局 store
- 主区域组件读取 store，渲染 `ResearchView`

---

## 改动 2：配图生成（适配 X 分享）

**现状**：`daily_report_service.py` 没有配图生成。旧版 `card_*.html` 存在但排版乱。
**目标**：日报生成后自动产出 `card_*.html`，尺寸 1200×675（X 推荐 16:9），排版干净。

### [MODIFY] `daily_report_service.py` — 加入配图生成步骤

在写手之后、润色官之前，插入配图生成：

```
侦察官 → 策略官×N → 审核官 → 写手 → 📸 配图生成 → 润色官
```

配图 HTML 模板设计：

```
┌────────────────────────────── 1200 × 675 ──────────────────────────────┐
│  INSTITUTIONAL GRADE INTEL                                              │
│  WEB3 ALPHA DAILY                              2026.02.28               │
│                                                                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                              │
│  │ 项目1     │  │ 项目2     │  │ 项目3     │                              │
│  │ 赛道      │  │ 赛道      │  │ 赛道      │                              │
│  │ 一句话    │  │ 一句话    │  │ 一句话    │                              │
│  └──────────┘  └──────────┘  └──────────┘                              │
│                                                                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                              │
│  │ 项目4     │  │ 项目5     │  │ 项目6     │                              │
│  │ ...       │  │ ...       │  │ ...       │                              │
│  └──────────┘  └──────────┘  └──────────┘                              │
└─────────────────────────────────────────────────────────────────────────┘
```

- 暗色背景（#050505），白色/金色文字
- 每个项目卡片最多 3 行文字（名称 + 赛道 + 一句话定位）
- 最多 6 个项目（2 行 × 3 列），超出部分不显示
- 前端用 `html2canvas` 截图为 PNG（已有现成逻辑）

### [NEW] `services/card_generator.py`

纯 Python 生成 HTML 字符串，不依赖 AI：
- 输入：项目列表 + 日期
- 输出：`card_{date}.html` 文件
