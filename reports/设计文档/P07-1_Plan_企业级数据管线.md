## ⚠️ 8 大警告

### 类型 1: 批量推理坑 (运行失败)

| # | 问题 | 解决方案 |
|---|------|----------|
| 1 | **TOS IAM 权限** | 配置 `TOSReadOnlyAccess` + `TOSWriteAccess` |
| 2 | **JSONL 格式严苛** | `json.dumps()` + 回读校验，每行一个 JSON |
| 3 | **Batch Endpoint** | 确认是 Batch 端点非在线端点 |
| 4 | **24h 窗口** | 前端诚实显示 "1-24h"，提供邮件通知 |

### 类型 2: 数据质量杀手 (数据洗坏)

| # | 问题 | 解决方案 |
|---|------|----------|
| A | **模型选型** | 用满血版非蒸馏版 (R1 vs R1-Distill) |

| C | **上下文截断** | 超 30k tokens 需切分 |
| D | **温度参数** | `temperature = 0` 无幻觉 |

## 🔧 关键实现

### JSONL 格式强校验

```python
def generate_jsonl(files: list) -> str:
    lines = []
    for i, file in enumerate(files):
        request = {
            "custom_id": f"file_{i:05d}",
            "body": {
                "model": "deepseek-v3-2-251201",
                "messages": [{"role": "user", "content": file['content']}]
            }
        }
        # 强校验
        line = json.dumps(request, ensure_ascii=False)
        json.loads(line)  # 回读验证
        lines.append(line)
    return "\n".join(lines)
```
