# P33: 上线前代码审查计划

> P25-P33 快速迭代期代码审查，确保生产环境稳定性。
> 预计工时: 2-3 小时

---

## 一、安全审查 🔴 最高优先

| # | 检查项 | 检查内容 | 文件范围 |
|---|--------|---------|---------|
| S1 | **API Key 泄露** | 全仓库扫描硬编码 Key | `git grep -i "sk-\|ak-\|AIza\|xai-"` |
| S2 | **敏感文件排除** | `.env`, `config/`, `*.json` 凭证不在 Git | `.gitignore` |
| S3 | **CORS 配置** | 生产环境限定允许域名，不能 `*` | `main.py` |
| S4 | **API 无鉴权** | 所有 `/api/*` 端点是否需要 Token | `api/*.py` |
| S5 | **路径遍历** | 文件读取是否有安全检查 | `research.py` L310 ✅ 已有 |

---

## 二、错误处理 🟠 高优先

| # | 检查项 | 检查内容 | 文件范围 |
|---|--------|---------|---------|
| E1 | **Surf API 超时** | timeout 设置是否合理、异常是否捕获 | `surf_service.py` |
| E2 | **LLM 调用失败** | 余额不足/限流/超时是否优雅降级 | `llm.py` |
| E3 | **Sheets 连接失败** | 离线模式是否 graceful fallback | `research_sheet.py`, `google_sheets_source.py` |
| E4 | **管道部分失败** | 策略官 3/7 成功时管道是否继续 | `daily_report_service.py` |
| E5 | **前端 API 错误** | fetch 失败是否有 loading/error UI | 所有 `fetch()` 调用 |

---

## 三、死代码 & 废弃代码清理 🟡 中优先

| # | 检查项 | 检查内容 | 文件范围 |
|---|--------|---------|---------|
| D1 | **未使用的 import** | TypeScript + Python 中死 import | 全项目 |
| D2 | **废弃的函数/组件** | P25-P30 遗留但不再调用的代码 | `agents/`, `services/` |
| D3 | **实验性脚本** | `scripts/` 下一次性测试脚本 | `backend/scripts/` |
| D4 | **调试日志** | `print()`、`console.log()` 硬编码调试信息 | 全项目 |
| D5 | **注释掉的代码块** | 大段注释代码应删除 | 全项目 |

---

## 四、生产环境适配 🟡 中优先

| # | 检查项 | 检查内容 | 文件范围 |
|---|--------|---------|---------|
| P1 | **DEBUG 模式** | `--reload` 不能用于生产 | uvicorn 启动参数 |
| P2 | **日志级别** | 生产环境 INFO 级别，不要 DEBUG | `config.py` |
| P3 | **前端 API_URL** | 需要 `NEXT_PUBLIC_API_URL` 指向生产地址 | `api.ts` |
| P4 | **文件路径** | 相对路径是否在 Linux 上兼容 | `daily_report_service.py` Path 用法 |
| P5 | **requirements.txt** | 是否存在、是否完整 | `backend/` 根目录 |
| P6 | **报告目录** | `reports/research/` 目录自动创建 | 启动时判断 |

---

## 五、性能 & 稳定性 🟢 低优先

| # | 检查项 | 检查内容 | 文件范围 |
|---|--------|---------|---------|
| R1 | **内存泄漏** | 大文本是否及时释放 | 管道函数 |
| R2 | **并发安全** | Sheets 缓存在并发下是否安全 | `research_sheet.py` 单例 |
| R3 | **磁盘占用** | 报告文件是否会无限增长 | `reports/research/` |
