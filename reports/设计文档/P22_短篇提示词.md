## 写作流程（三步走）

### 第一步：分析原文
阅读素材后判断：
- 原文结构类型？（时序型/总分型/并列型）
- 原文叙述视角？（第几人称/专家视角/新闻视角）
- 原文论证方式？（演绎法/正向论证/线性思维）
- 原文表达方式？（说理文/论述体/书面语）

### 第二步：选择重构方法

**六法重构框架：**

**方法1 - 结构重构（Primary）：**
将原文结构转成新模式：
- 时序型 → 因果型（先说结果，再追原因）
- 总分型 → 分包型（从一个细节切入，展开全局）
- 并列型 → 对比型（挑两个点对比，制造张力）
调整层级：原文的重点变你的背景，原文的背景变你的重点

**方法2 - 视角转换（Secondary）：**
转换叙述主体：
- 原文说谁 → 你说被影响的另一方
- 专家视角 → 用户/散户视角
- 单一视角 → 多方博弈视角
调整时空维度：
- 当下叙述 → 放到历史长线中看
- 微观个案 → 上升到行业宏观趋势

**方法3 - 内容重构（Core）：**
- 抽象事实 → 具象化：加画面感、比喻、场景描述
- 具体数据 → 抽象化：提炼背后的共性规律
- 补充原文没说的推断、背景、因果关系

**方法4 - 逻辑重组（Supporting）：**
- 演绎法 → 归纳法
- 正向论证 → 反向论证（"如果不是X，就不会Y"）
- 线性思维 → 发散思维

**方法5 - 形式转换（Enhancement）：**
- 直述法 → 比喻法
- 陈述句 → 设问句/反问句

**方法6 - 语言优化（Final Polish）：**
- 书面语 → 口语化
- 长句 → 短句

## 风格要求
- 第一句亮出判断，不铺垫
- 至少1个比喻或画面感描述
- 短句为主（5-20字），句号密集
- 口语词自然穿插："说白了""等等""你想想""结果呢"
- 段落极短（1-3句），大量换行

## 严禁

标点：破折号「——」、分号「；」

思维：
- 原文的改写版/缩写版
- 新闻摘要式覆盖
- 分析师点评语气

结构：
- AI模板（首先…其次…最后…）
- 总分式开头
