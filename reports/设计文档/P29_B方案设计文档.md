# P29 提示词优化设计方案（B方案 — 最终版）

> 日期：2026-02-22
> 状态：已实现 + 已测试通过 + 代码已更新匹配
> 影响范围：short_article 模式
> 核心改动：策略师模板重构 + 公式菜单驱动 + 样本渲染

---

## 一、改动目标

将 short_article 模式的输出从"AI分析式文章"优化为"X KOL 风格的即时评论"。

**改动前的问题**：
- 开头像"分析报告"（"从技术角度分析其合理性..."）
- 策略师用固定选项池（emotion_arc + ending_style）而非数据驱动
- 样本被获取但未渲染到 prompt 中

**改动后的效果**：
- 开头像"X上随手发出的评论"（"V神这是梭哈了？以太坊要All in高性能L1？"）
- 策略师从 Google Sheets 的公式菜单中选写作公式
- 样本出现在策略师 prompt 的「风格参考样本」区块

## 二、改动文件清单（6个文件）

### 2.1 策略师模板

**文件**：`backend/data/prompts/strategist/short_article.jinja2`

**改动要点**：
1. 角色定位：从"分析师"改为"节目编导"
2. 新增「风格参考样本」区块（`{{ rag_context }}`）
3. 新增「公式菜单」区块（`{{ pattern_menu }}`）
4. hook 描述：从"判断或信息" → "参考样本风格，不要写分析式陈述"
5. 思维工具标注"严禁作为 logic_pattern 输出"
6. JSON 输出简化：去掉 emotion_arc / ending_style，改为 logic_pattern + tone

**最终模板结构**：

```
角色设定（节目编导）
  ↓
思维工具（仅内部思考，严禁作为 logic_pattern 输出）
  ↓
素材（{{ raw_input }}）
  ↓
事件脉络（{{ context_card }}，可选）
  ↓
风格参考样本（{{ rag_context }}）  ← P29 新增
  ↓
公式菜单（{{ pattern_menu }}）    ← P29 新增
  ↓
输出要求（JSON: label/angle/hook/logic_pattern/tone）
  ↓
约束（hook像X上评论、logic_pattern不同、至少1个非散户视角）
```

**hook 字段定义（最关键的改动）**：

```diff
- "hook": "第一句话应该传递的判断或信息（直接写出那句话的方向）"
+ "hook": "写一句开头（参考上面风格样本的语感，不要写分析式陈述）"
```

**约束改动**：

```diff
- hook 是一个具体的判断或信息点（✅ "所有人都在问她..."），不是抽象指令
+ hook 是一句像在X上随手发出的开场白（✅ "所有人都在问她..."），不是分析报告的开头
```

## 四、JSON 输出格式变化

### 改动前（A方案/旧版）

```json
{
  "core_fact": "...",
  "plans": [
    {
      "label": "版本名",
      "angle": "切入角度",
      "hook": "第一句话应该传递的判断或信息",
      "emotion_arc": "平稳→共鸣→思考",
      "ending_style": "发人深省",
      "tone": "语气"
    }
  ]
}
```

### 改动后（B方案）

```json
{
  "core_fact": "...",
  "plans": [
    {
      "label": "版本名(3-5字)",
      "angle": "从什么角度切入（具体到这篇素材）",
      "hook": "写一句开头（参考样本风格，不要分析式）",
      "logic_pattern": "从公式菜单选一个写作公式",
      "tone": "语气（1-2个词）"
    }
  ]
}
```

**变化**：
- 去掉：`emotion_arc`、`ending_style`（固定选项池，策略师机械套用）
- 新增：`logic_pattern`（从 Google Sheets 数据驱动，策略师从公式菜单选择）
- hook 描述：从"判断或信息" → "参考样本风格，不要分析式陈述"
