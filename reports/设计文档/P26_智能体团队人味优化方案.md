# P26：智能体团队优化方案（最终版）

> 创建：2026-02-17 20:25
> 基于：P25 的 30 篇实测 + 本次讨论全部结论

---

## 一、核心诊断

30 篇实测发现 7 个系统性问题（句式单一/情绪同质/结尾重复/比喻集中/散户视角过度/三版本趋同/过度确信），根因是**多个智能体的指令形成合谋——写手被强制全短句，critic 惩罚长句，禁用词清单散落三处且互相矛盾**。

## 二、设计原则

经过反复讨论确认的三条原则：

1. **能用代码做的事不交给 LLM**（禁用词扫描、字数检查、标点替换）
2. **prompt 做正面引导，不做负面清单**（给 LLM 创作空间，不用 100 行规则束缚它）
3. **最小改动原则**（润色只改命中词附近几个字，不整句重写）

## 三、禁用词架构重组

### 问题

禁用词散落三处，各自维护，互相矛盾：
- `forbidden_patterns.yaml`（170词）
- `P25_禁止列表清单.md`（设计文档）
- writer prompt 里硬编码（22词，其中"说白了"同时出现在正面示例和禁用清单）

### 方案（已完成 ✅）

**`forbidden_patterns.yaml` 为唯一数据源**，合并后 23 类 213 词，按优先级分层：

| 层级 | 类别 | 数量 | 处理方式 |
|---|---|---|---|
| 第一层 | 硬性屏蔽词 + 标点 | 7 | 代码直接拦截 |
| 第二层 | AI高频商业词 | 22 | 写手 prompt 保留8个最致命的，其余由润色官处理 |
| 第三层 | AI模板指纹词 | 5 | 润色官处理 |
| 第四层 | 废话文学（6子类） | 18 | 润色官处理 |
| 第五层 | 咨询报告结尾模板 | 7 | 润色官处理 |
| 第六~十四层 | 动词/形容词/名词/过渡句/翻译腔/互联网黑话/空洞形容词/陈旧比喻/八股文句式 | 154 | 润色官处理 |

## 四、四智能体改造方案

### 4.1 策略官（已实施 ✅）

**文件**：`strategist/short_article.jinja2`

- plans JSON 新增 `emotion_arc`（情感走向）和 `ending_style`（结尾方式，六选一）
- 约束：三版本 emotion_arc 必须不同，ending_style 必须不同
- 至少一个版本不以"散户"为假设读者

### 4.2 写手（需精简 🔧）

**文件**：`writer/short_article.jinja2`

当前状态：106行，禁用内容占33%（35行）。

**计划改动**：

| 操作 | 内容 |
|---|---|
| 删除 | 废话文学列表、AI伪口语、AI造词、模板指纹词、思维禁止、结构禁止（~25行） |
| 保留 | 标点禁止 + 8个最致命AI词 + 5个屏蔽词 + 事实禁止 |
| 修改 | 人味要求删除具体示例句子，只保留原则性指引 |

精简后 **~75行**，禁用内容从33%降至~10%，写作指引占主导。

### 4.3 评审官（需重构 🔧，暂保持 skip）

**文件**：`critic/short_article.jinja2`

旧版问题：115行，惩罚长句（和写手矛盾），给替代词（制造新模板），注入213词清单（稀释注意力），精确打分（LLM做不好）。

**新版设计**：

```
这篇短评能发吗？能发输出PASS，需要改输出REFINE并说哪里要改，
不能发输出REWRITE并说为什么。

策略官要求｜情感走向: {{ emotion_arc }}｜收尾: {{ ending_style }}
代码预检结果: {{ code_scan_results }}

待评文（{{ word_count }}字）：
{{ draft }}

输出JSON：
{"verdict": "PASS/REFINE/REWRITE", "reason": "一句话"}
```

核心思路：**让 LLM 做编辑的直觉判断，不做机械扫描。** 禁用词扫描、字数检查等机械工作全部由代码在调用 critic 之前完成，结果作为 `code_scan_results` 传入。

> critic 先重构好但保持 skip，等润色官验证通过后再开启测试。

### 4.4 润色官（需新建 🆕）

**文件**：
- `polisher/short_article.jinja2`（新建 prompt）
- `polisher/short_article.py`（新建代码）

**职责**：AI检测 + 最小改动修复 + 排版

**流程**：

```
写手初稿
  ↓
代码预扫 YAML 全量 213 词（用 get_all_forbidden_words()）
  ↓
无命中 → 只做标点后处理（——→，），原样返回，不调 LLM
  ↓
有命中 → 告诉 LLM 哪些句子命中了什么词 → LLM 最小改写
  ↓
改写后再扫一次（max_retry=1）→ 输出
```

**润色 prompt 核心规则**：
- 禁止整句重写
- 禁止改变原句的语气和结构
- 禁止添加原文没有的信息
- 没有命中禁用词的句子一个字都不动

**配置变更**：`mode_configs.py` 中 `skip_polisher: True` → `False`
