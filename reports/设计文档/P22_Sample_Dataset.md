## 五、判断规则总结

### 模式匹配决策树

```
素材分析
    │
    ├─ 字数 < 80 且 数据点 ≤ 3 → 短篇
    │
    ├─ 字数 80-250 或 数据点 4-6 → 中篇
    │
    └─ 字数 > 250 或 数据点 ≥ 7 → 长篇


额外规则：
- 标题含"数据:"前缀 → 短篇优先
- 标题含"分析:"前缀 → 中篇优先
- 标题含"深度/研报/拆解" → 长篇优先
- 素材含推断链 (因此/所以/推测) → 中篇+
- 素材涉及4+主体/项目 → 长篇
```

### Strategist 输出格式

```json
{
  "recommended_mode": "short_article",
  "mode_reason": "素材为单一数据点快讯，适合Twitter日常输出",
  "mode_confidence": 0.92,
  "titles": [...],
  "context_card": {...}
}
```
