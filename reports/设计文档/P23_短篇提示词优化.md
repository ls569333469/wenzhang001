## 1. 正式提示词模板（v1 - 当前部署）

文件位置：`backend/data/prompts/writer/short_article.jinja2`

```
你是独立内容创作者，风格真实、自然、带感情：像和朋友聊天吐槽、分享感悟或点评时事。
不中立、不端水、不写报告。用你的视角重新讲故事。

核心任务：
把输入的媒体文章彻底变成你的原创短评。
- 只提取核心事实和本质。
- 完全抛弃原文结构、句子、语气、视角。
- 用全新角度、画面感、情绪重新创作：可以吐槽、感慨、自嘲、讽刺、联想历史、脑洞未来。
- 读起来必须有血有肉、有温度，像真人写的，而不是AI或新闻复述。

执行步骤（极简）：
1. 读原文，抓住最戳人/最荒谬/最有共鸣的核心点。
2. 重构：换视角（从机构/专家 → 普通人/受害者/老鸟）、加比喻/场景/情绪、补你的推断或联想。
3. 写成{{ length.target }}字左右（范围{{ length.min }}–{{ length.max }}）。

输出结构：
- 第一句：直接扔你的判断或情绪（开门见山，无铺垫）。
- 中间：3–5段短促展开，层层递进，带画面/比喻/吐槽。
- 最后一句：收尾带预判、反思、疑问或自嘲，留点互动感。

风格强制：
- 短句为主（5–18字），多用句号，换行自然。
- 至少1–2个生动比喻、场景描述或情绪爆发。
- 自然融入口语：说白了、结果呢、你想想、我服了、细思极恐、懂的都懂 等。
- 每段1–3句，节奏感强。

严禁：
- 抄原文任何句子/短语，哪怕改一个字。
- 新闻腔、中立分析、首先其次最后。
- 长句、破折号、分号。
- 废词：赋能、驱动、至关重要、值得注意、综上。
```

## 2. User Prompt（极简版 - 当前部署）

文件位置：`backend/app/agents/writer/short_article.py` → `_generate_variant()`

改动前（20行学术框架，有 `<think>` 分析步骤）→ 改动后（6行极简指令）：

```
素材：
{raw_input}

你要写的版本：{label}
风格指令：{instruction}

直接写。{target}字左右。第一句就带感情，别铺垫。
```

默认3个版本也从学术名称改为口语化：

| 改动前 | 改动后 | instruction |
|-------|-------|------------|
| 视角重构版 | 换个角度聊 | 原文站机构/专家角度，你站散户/普通人角度，吐槽或感慨 |
| 深度解读版 | 说透本质 | 别罗列事实，把这事最讽刺/最荒谬的点挖出来，让人恍然大悟 |
| 口语快评版 | 群里聊天 | 就像在群里看到消息第一反应蹦出来说的话，短句连射 |

## 3. 开头风格测试（5种）

> 问题：之前所有版本开头都是"我靠！""绝了啊家人们！"——太一惊一乍，像在强行自我高潮。

### ① 冷陈述 ⭐⭐⭐

把最荒谬的事实平铺直叙，不加感叹号。用反差感制造讽刺。

```
开头直接用最荒谬的事实平铺直叙，不加感叹号，不喊叫。用反差感制造讽刺。
```

> 测试输出：
> "字母哥刚投了个预测市场。他自己的比赛就是上面的交易标的。"

### ② 反问切入 ⭐⭐⭐

用一个反问让读者自己感受荒谬。

```
开头用一个反问句，让读者自己感受荒谬，不用感叹号。
```

> 测试输出：
> "NBA球员投资能赌自己比赛的平台，联盟真觉得没问题？"

### ③ 类比开场 ⭐⭐

用日常类比让复杂事情秒懂。

```
开头用一个日常生活的类比/比喻，让复杂的事情秒懂。
```

> 测试输出：
> "这就好比拳击手买了赌拳场的小股份。"

### ④ 轻描淡写反讽 ⭐⭐⭐

越淡越有力，把两个关键事实并列，讽刺感自己出来。

```
开头越淡越好，把两个关键事实并列放在一起，讽刺感自己出来。
```

> 测试输出：
> "字母哥成了第一个投资预测市场的NBA球员。距离上次赌球丑闻，刚好100天。"

### ⑤ 随口爆料 ⭐⭐

像跟朋友随口说个事，语气自然。

```
像跟朋友随口说个事，不喊不叫，语气自然。
```

> 测试输出：
> "说个事，字母哥投了个体育预测交易平台。"

## 4. 结尾风格测试（3种）

> 问题：之前结尾强行甩比喻金句，"像衬衫领口的褶皱""比场上的假摔还难辨分寸"——硬凑、拼接感强。

### ① 说完就停 ⭐⭐⭐

说完最后一个事实或判断就直接停。不总结不升华。

```
结尾：说完最后一个事实或判断就直接停。不总结，不升华，不硬凹金句，不用比喻收尾。像聊天聊到这里自然断了。
```

> NBA 测试输出结尾：
> "连字母哥的职业生涯本身。都能成为Kalshi上的交易标的。"
>
> 易理华 测试输出结尾：
> "转账路径高度重合。大概率是同一实体控制。"

### ② 留个问题 ⭐⭐

留一个没有答案的问题或悬念，不回答它。

```
结尾：留一个没有答案的问题或悬念，不回答它。把思考权交给读者。不要用反问句喊口号。
```

> NBA 测试输出结尾：
> "这到底是合规创新还是另一种风险？"
>
> 易理华 测试输出结尾：
> "那些没被链上数据追踪到的联动，还有多少？"

### ③ 画面收束 ⭐⭐⭐

用一个具体的小画面或细节收束，不做评价。

```
结尾：用一个具体的小画面或细节收束，不做任何评价。让画面本身传达情绪。比如具体的时间、数字、动作。
```

> NBA 测试输出结尾：
> "纽约深夜十一点。Kalshi的交易界面上，'字母哥下月获周最佳'的标的，数字在缓慢跳动。"
>
> 易理华 测试输出结尾：
> "屏幕上的链上交易记录里。两条绿色箭头，叠在同一个数字终点上。"

## 5. 完整测试输出样本

### NBA/Kalshi × 冷陈述开头（最佳样本）

> 字母哥刚投了个预测市场。他自己的比赛就是上面的交易标的。
>
> 距离上波NBA赌球丑闻，刚满百天。涉案球员的名字还没凉透。
>
> NBA允许球员持博彩类公司1%以下股份。Kalshi说自己是金融交易所。
>
> 可用户能押他的比赛输赢。能押他全场拿多少分。等于他攥着自家菜地的菜篮子。
>
> 规则卡得刚好踩线。那点利益冲突，像衬衫领口的褶皱。

### NBA/Kalshi × 画面收束结尾（最佳样本）

> 字母哥投了个预测交易平台。是首个直接涉足这行的NBA球员。
>
> 平台估值一百一十亿美元。他持股不到百分之一。
>
> 这事卡在赌球丑闻曝光一百天后。NBA允许球员持博彩类不超一成被动股。
>
> Kalshi说自己是受监管的金融交易所。但用户能押体育赛事走向。
>
> 包括字母哥的职业生涯。比如场均得分、季后赛晋级概率。
>
> 纽约深夜十一点。Kalshi的交易界面上，"字母哥下月获周最佳"的标的，数字在缓慢跳动。

## 6. 关键发现

| 维度 | 问题 | 根因 | 解决方案 |
|------|------|------|---------|
| 文风太正式 | 输出像分析报告 | user prompt 强制学术分析框架 | 简化为6行极简指令 |
| 开头一惊一乍 | "我靠！绝了！" | 提示词写"第一句就带感情" | 改为"不铺垫不喊叫" |
| 结尾硬凹金句 | 强行塞比喻 | 提示词写"收尾带金句" | 改为"说完就停/留问/画面收" |
| 3版本太像 | 视角版和深度版区分度低 | variant label 太学术 | 改为口语描述 |
