### 2. Bug 修复：输出内容为空 (0 字)

**现象**：10 篇文章全部成功通过流水线，但输出内容均为 0 字。

**根因**：`call_generate()` 把 `plans[0]`（单个方案）传给 `selected_option`，但 `node_strategist` 需要看到 `"plans"` 键才能保留完整策略给写手。写手的 `_extract_plans_from_strategy()` 找不到 `plans` → ValueError → 空内容。

**修复**：
```python
# 修复前
selected_option = strategy_data["plans"][0]
# 修复后
selected_option = strategy_data  # 传完整策略数据
```

**验证**：修复后 4 篇文章确认有实际内容输出，禁用词检查通过。
