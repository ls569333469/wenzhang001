# 🔬 AgetherAI — 投研报告

> 生成时间: 20260317

**## 项目定位**

Agether（@agetherai）是一个为 AI Agents 提供信用（credit）的基础设施协议。核心功能是允许 AI Agents 在 Ethereum 和 Base 链上通过信用额度支付 x402 调用等费用，而无需直接使用私钥或手动管理资金。目前通过 npm i @agether/sdk 集成，支持 Morpho 借贷协议（更多借贷协议即将支持）。目标市场是构建自动化 AI Agents 的开发者，解决 AI Agents 在 Web3 环境中支付和信用访问的问题，强调“AI Agents need credit”。
