# 🔬 Moku — 投研报告

> 生成时间: 20260308

## 📊 项目定位
Moku 是一个以 Web3 游戏和 NFT 为中心的生态系统，专注于提供 NFT 铸币、游戏机制和社区连接工具。核心产品包括 Moki Genesis NFT 集合、Mokuverse 虚拟世界、Grand Arena 和 Moki Mayhem 等游戏模式、Discord 集成钱包 Moku Pouch，以及连接玩家与游戏公会和策略社区的工具。目标市场为 Web3 游戏玩家和 NFT 收藏者。

## 🏁 竞品对比
竞品 1：Pudgy Penguins，定位为 Web3 娱乐 IP 和 NFT 集合，结合 PENGU 代币和游戏（如 Pudgy World），差异在于 Moku 更专注 AI 幻想竞技和 Discord 集成钱包，而 Pudgy Penguins 强调 NFT 社区和商品化。  
竞品 2：Virtuals Protocol，定位为 AI 代理创建和代币化平台，使用 VIRTUAL 代币支持代理驱动服务，差异在于 Moku 侧重游戏机制和玩家连接，而 Virtuals Protocol 更注重 AI 代理的自主性和治理。  
竞品 3：BC.GAME，定位为加密赌场和投注平台，提供公平游戏和 BC 代币治理，差异在于 Moku 强调 NFT 和幻想竞技，而 BC.GAME 聚焦赌博和体育投注。
