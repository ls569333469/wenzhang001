# 🔬 Yellow — 投研报告

> 生成时间: 20260309

## 项目定位
Yellow 是一个 Layer-3 Web3 清算网络和 SDK，利用状态通道技术实现经纪商、交易所和应用之间的实时跨链交易和结算。其原生代币 YELLOW 用于费用、网络访问、质押和清算激励，同时提供 Yellow SDK 和 NeoDAX 经纪栈等工具。核心产品包括状态通道框架，支持非托管实时处理和开发者集成。目标市场为跨链桥接和开发者工具领域，针对经纪商、机构和私人交易者。

## 竞品对比
- Polygon (POL)：定位为 L2 缩放和 AggLayer 模块化框架，支持 EVM 兼容链和互操作性；差异：Yellow 专注 L3 状态通道清算网络，而 Polygon 更侧重通用缩放和 DA 层。
- Chainlink (LINK)：定位为跨链预言机网络，提供实时数据馈送和 API 连接；差异：Yellow 强调经纪商实时结算和 SDK 集成，而 Chainlink 专注于数据验证和外部输入。
- Polkadot (DOT)：定位为 L1 跨链和模块化框架，支持并行链互操作；差异：Yellow 作为 L3 网络针对清算激励和开发者工具，而 Polkadot 更注重基础层中继链和生态扩展。
