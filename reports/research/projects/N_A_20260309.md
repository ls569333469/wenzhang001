# 🔬 Utexo — 投研报告

> 生成时间: 20260309

## 项目定位
Utexo 是一个区块链基础设施公司，开发比特币网络上的原生稳定币结算解决方案，提供将 USDT 交易整合到比特币生态系统的技术框架。核心产品包括将比特币基础层、Lightning Network 和 RGB 协议整合到一个 API 中，实现少于 1 秒的交易最终性、固定费用模型、私密和安全的原子交易。目标市场为支付运营商、企业钱包、零售钱包、托管方、交易所和支付服务提供商（PSP）。
