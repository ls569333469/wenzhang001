# 🔬 Virtuals — 投研报告

> 生成时间: 20260309

## 项目定位
Virtuals Protocol 是 Base 生态的 AI Agent 平台，构建代理经济系统，实现 AI 代理的自主交易、协作和收入生成。核心产品包括 Agent Commerce Protocol (ACP) 用于代理间商务协调、OpenClaw 用于代理部署和技能共享、Butler 作为用户与代理网络的接口，以及扩展到机器人领域的 Fabric Protocol ($ROBO)。目标市场是 Web3 AI 代理经济、机器人基础设施和创作者工具。
