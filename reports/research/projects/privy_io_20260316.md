> 生成时间: 20260316

**## 项目定位**

Privy 是加密货币钱包基础设施提供商（Wallet Infrastructure），专注于为开发者提供低级 API 和嵌入式钱包解决方案，帮助应用轻松集成用户钱包功能。核心产品包括嵌入式钱包（Embedded Wallets）、账户抽象相关工具、onchain 支付和资产管理 API，支持无缝用户 onboarding 和资产操作。已服务超过 1.2 亿（120M+）账户，处理数十亿交易量，主要客户包括 Friend.tech（早期 in-app wallet）、Hyperliquid、Virtuals Protocol、Zora 等 DeFi、SocialFi 和 NFT 项目。目标市场为 Web3 应用开发者、消费级 dApp 和需要简化钱包体验的区块链项目，属于 Infra 赛道。

**## 竞品对比**

- **Dynamic.xyz**：同样专注嵌入式钱包和账户抽象基础设施，定位于开发者工具和无缝 onboarding，与 Privy 高度重叠，但 Privy 强调更低级 API 和支付/资产管理功能，已有更大规模采用案例（如 Friend.tech）。
- **Particle Network**：提供账户抽象和多链钱包基础设施，侧重跨链和 AA 体验，差异在于 Particle 更强调社交登录和跨链聚合，而 Privy 聚焦支付与资产管理 API。
- **Web3Auth**：早期嵌入式/社交登录钱包方案，目标市场类似，但 Privy 在消费级 dApp 集成深度和交易量规模上更具优势。
