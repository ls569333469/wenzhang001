# 短中长篇内容生成测试指南

> 测试话题: **现货黄金日内暴涨 100 美元，突破 5280 美元/盎司**  
> 测试日期: 2026-01-30

---

## 测试方法

### 方法 1: 前端 UI 测试 (推荐)

1. 打开浏览器访问: http://localhost:3000/studio
2. 在输入框中粘贴话题: `现货黄金日内暴涨 100 美元，突破 5280 美元/盎司`
3. 依次测试三种篇幅:
   - **短篇** (~500字): 选择「短篇」按钮
   - **中篇** (~1500字): 选择「中篇」按钮  
   - **长文** (~3000字): 选择「长文」按钮
4. 点击生成，观察结果

### 方法 2: API 直接测试

使用 curl 或 Postman 发送请求:

```bash
# 短篇测试
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "input": "现货黄金日内暴涨 100 美元，突破 5280 美元/盎司",
    "mode": "deep_analysis",
    "style": "banfo",
    "length": "short"
  }'

# 中篇测试
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "input": "现货黄金日内暴涨 100 美元，突破 5280 美元/盎司",
    "mode": "deep_analysis", 
    "style": "banfo",
    "length": "medium"
  }'

# 长篇测试
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "input": "现货黄金日内暴涨 100 美元，突破 5280 美元/盎司",
    "mode": "deep_analysis",
    "style": "banfo", 
    "length": "long"
  }'
```

---

## 验证标准

| 篇幅 | 预期字数 | 验证要点 |
|------|---------|---------|
| 短篇 | 300-700字 | 观点简洁、一个核心论点 |
| 中篇 | 1200-2000字 | 2-3个论点、有数据支撑 |
| 长文 | 2500-4000字 | 完整分析、多角度论证 |

---

## 已知问题

1. **生成时间较长**: 每篇内容需要 3-5 分钟（因为 writer-critic 多轮迭代）
2. **API 超时**: 长篇可能超过 3 分钟导致请求超时（需增加 timeout）
