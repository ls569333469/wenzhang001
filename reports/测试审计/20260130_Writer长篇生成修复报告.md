# Writer 长篇生成修复报告

**日期**: 2026-01-30 22:00  
**状态**: ✅ 已修复并验证通过

---

## 问题诊断

### 症状
- Writer 长篇（2000-4000字）生成返回 **0 字**
- 耗时 277-290 秒后超时失败

### 根本原因

| 问题 | 原值 | 影响 |
|------|:----:|------|
| **API 超时** | 90秒 | 长篇生成需要 2-4 分钟，90 秒不够 |
| **max_tokens** | 固定 4096 | 4000 字约需 8000-12000 tokens |

---

## 修复内容

### 1. llm.py - API 超时

```python
# 修复前
timeout_config = {"timeout": 90.0}

# 修复后
timeout_config = {"timeout": 300.0}  # 5分钟超时
```

### 2. writer.py - 动态 max_tokens

```python
# 新增代码
max_word_count = length_constraints.get("max", 1500)
calculated_max_tokens = min(max_word_count * 3, 16384)  # 动态计算

response_text = generate_text(
    ...,
    max_tokens=calculated_max_tokens  # 长篇使用 12000
)
```
