## 一、当前系统数据结构

### 1.1 样本字段格式 (Google Sheets → 代码映射)

根据 `google_sheets_source.py` 第 34-43 行：

| Google Sheets 列名 | 内部字段名 | 作用 |
|-------------------|-----------|------|
| `内容` | `content` | **必填** - 样本正文 |
| `博主` | `author` | 来源博主 |
| `风格标签` | `style` | **必填** - 匹配风格 (mimeng/banfo) |
| `片段类型` | `snippet_type` | 样本类型 (Hook/Body/Quote) |
| `情绪` | `emotional_valence` | 情绪标签 |
| `逻辑公式` | `logic_pattern` | **重要** - 写作技巧公式 |
| `质量评分` | `quality_score` | 1-5 评分 |
| `状态` | `status` | 待处理/已审核 |

### 1.2 现有样本示例 (style_library.json)

```json
{
    "author": "咪蒙",
    "content": "你凭什么穷得心安理得？",
    "style": "mimeng",
    "snippet_type": "Hook",
    "emotional_valence": "High Arousal",
    "quality_score": "5",
    "logic_pattern": "质问语气 + 批判"安于现状" + 制造羞愧感"
}
```

## 三、您需要提供的样本

### 3.1 样本格式模板

请按以下 CSV 格式提供样本，可直接导入 Google Sheets：

```csv
内容,博主,风格标签,片段类型,情绪,逻辑公式,质量评分,状态
"这里是样本正文，200-500字最佳",来源博主,tutorial,Hook,Neutral,"步骤拆解 + 预期收益 + 风险提示",4,待处理
```

### 3.2 推荐收集的样本来源

| 内容类型 | 推荐来源 | 样本数量建议 |
|----------|----------|:------------:|
| **教程体** (tutorial) | 律动BlockBeats、深潮TechFlow | 20+ 条 |
| **快讯体** (alpha) | 吴说区块链、金色财经 | 15+ 条 |
| **撸毛体** (degen) | 撸毛大师、空投猎人社区 | 15+ 条 |

### 3.3 各类型样本示例

#### 教程体 (tutorial)

```
第一步：打开 Blast 官网，连接你的钱包（推荐 MetaMask）
第二步：点击「获取邀请码」，输入邀请码后完成验证
第三步：存入 ETH，选择锁定期限（14天/90天/180天）
💡 预期收益：4% 原生收益 + 空投积分
⚠️ 风险提示：存入后锁定期内无法取出
```

**逻辑公式**: `步骤编号 + 具体操作 + 预期收益 + 风险提示`

#### 快讯体 (alpha)

```

链上追踪显示资金流向 Lido 质押。

**逻辑公式**: `紧急标记 + 事件描述 + 数据佐证 + 时效标记`

#### 撸毛体 (degen)

```
📌 任务清单：Eigenlayer S2 空投交互
☐ 1. 质押 0.1 ETH 到 Eigenlayer

## 四、技术实施路径

### 4.1 短期方案 (P0 - 1天)

**不需要新增风格**，只需扩充现有样本：

1. 收集 banfo 风格的**教程类样本** (半佛讲科普的形式)

1. 添加 `tutorial` 风格

   - 修改 `strategist.py` / `writer.py`
   - 上传样本到 Google Sheets

2. 添加 `alpha` 风格 (快讯体)

### 4.3 长期方案 (P2 - 1周)

建立**完整的内容矩阵**，覆盖图片中所有板块。
