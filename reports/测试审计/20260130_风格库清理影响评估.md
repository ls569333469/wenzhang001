## 三、修改方案

### 3.1 保留的风格

清理后仅保留 **2 个有数据的风格**：

```python
mode_descriptions = {
    "mimeng": "咪蒙体 - 制造焦虑、阶级冲突、情绪爆点",
    "banfo": "半佛仙人体 - 反常识观点、案例轰炸、硬核科普"
}
```

### 3.2 预设组合处理

| 原预设 | 引用的无效风格 | 建议操作 |
|--------|----------------|----------|
| `project_review` | 无 (仅 banfo + mimeng) | **保留** |
| `story` | xinshixiang + lianbushou | 删除或改为 mimeng+banfo |
| `nft_art` | shijuezhi + chengshian | 删除 |
| `investment` | lingongzi | 删除或改为 banfo only |
| `criticism` | fengqiongzi | 删除或改为 mimeng only |

### 3.3 Fallback 机制增强

在 `strategist.py` 中添加安全检查：

```python
VALID_STYLES = {"mimeng", "banfo"}

def get_style_description(style: str) -> str:
    if style not in VALID_STYLES:
        logger.warning(f"Unknown style '{style}', fallback to mimeng")
        style = "mimeng"
    return mode_descriptions.get(style, mode_descriptions["mimeng"])
```
