## 三、核心理念

**模板负责"创作风格"，配置负责"硬性约束"**

| 维度 | 策略师提示词 (LLM) | 统一配置上下文 (代码) |
|:---|:---|:---|
| 性质 | 创意决策 | 硬性规则 |
| 可变性 | 每次不同 | 固定不变 |
| 内容 | 标题、角度、结构 | 字数、语言、禁用词 |
| 执行 | LLM 可能忽略 | 代码强制执行 |

## 五、统一配置上下文实现 (待完成)

```python
def build_unified_context(state: AgentState) -> dict:
    """构建统一配置上下文 - 所有智能体共享"""
    mode = state["mode"]
    config = get_mode_config(mode)
    length = config.get("length") or {"min": 150, "max": 800, "target": 500}
    
    if state.get("custom_length") and state["custom_length"] > 0:
        length = {"min": 0, "max": state["custom_length"], "target": state["custom_length"]}
    
    return {
        "mode": mode,
        "constraints": {
            "language": "zh-CN",
            "length": length,
            "max_tokens_multiplier": 1.5,
            "forbidden_phrases": ["众所周知", "值得一提", "综上所述"],
        },
        "scoring": config.get("scoring"),
    }
```
