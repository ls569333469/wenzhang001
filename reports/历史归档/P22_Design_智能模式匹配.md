# P22 智能模式匹配 设计文档

## 一、核心目标

让 Strategist 分析素材后，**自动推荐创作模式（短/中/长篇）**，同时保留用户手动选择的能力。

---

## 二、现有流程 vs P22 新流程

### 现有流程 (P20 Context Card)

```
用户输入素材
      ↓
┌─────────────────────────────────────┐
│         Strategist 分析              │
│  ├─ 检索 RAG 知识                    │
│  ├─ 生成 Context Card               │
│  └─ 生成 3 个标题选项                │
└─────────────────────────────────────┘
      ↓
┌─────────────────────────────────────┐
│      前端显示策略卡片                 │
│                                     │
│  📋 Context Card                    │
│  ├─ headline: "..."                 │
│  ├─ timeline: "..."                 │
│  └─ forward_look: "..."             │
│                                     │
│  📝 标题选项                         │
│  ○ 标题1                            │
│  ○ 标题2                            │
│  ○ 标题3                            │
│                                     │
│  [开始创作]                          │
└─────────────────────────────────────┘
      ↓
      Writer (固定使用 mid_article)
```

---

### P22 新流程

```
用户输入素材
      ↓
┌─────────────────────────────────────┐
│         Strategist 分析              │
│  ├─ 检索 RAG 知识                    │
│  ├─ 生成 Context Card               │
│  ├─ 生成 3 个标题选项                │
│  └─ 【新增】评估推荐模式             │ ← P22 新增
└─────────────────────────────────────┘
      ↓
┌─────────────────────────────────────┐
│      前端显示策略卡片 (增强版)         │
│                                     │
│  📋 Context Card                    │
│  ├─ headline: "..."                 │
│  ├─ timeline: "..."                 │
│  └─ forward_look: "..."             │
│                                     │
│  📝 标题选项                         │
│  ○ 标题1                            │
│  ○ 标题2                            │
│  ○ 标题3                            │
│                                     │
│  🎯 【新增】推荐创作模式              │ ← P22 新增
│  ┌─────────────────────────────────┐│
│  │ 🔹 短篇 (100-280字) [推荐]      ││
│  │    "素材为单一数据点，适合Twitter"││
│  │ 🔸 中篇 (400-800字)             ││
│  │ 🔸 长篇 (900-1800字)            ││
│  └─────────────────────────────────┘│
│                                     │
│  [开始创作]                          │
└─────────────────────────────────────┘
      ↓
      Writer (根据选择的模式)
      ├─ short_article_writer (新增)
      ├─ mid_article_writer
      └─ long_article_writer
```

---

## 三、Strategist 输出格式变化

### 现有输出

```json
{
  "titles": [
    "标题1: ...",
    "标题2: ...",
    "标题3: ..."
  ],
  "context_card": {
    "headline": "核心事件",
    "timeline": "时间线",
    "forward_look": "前瞻信号"
  }
}
```

### P22 新增字段

```json
{
  "titles": [...],
  "context_card": {...},
  
  "recommended_mode": "short_article",
  "mode_reason": "素材为单一数据点快讯，适合Twitter日常输出",
  "mode_analysis": {
    "word_count": 26,
    "data_points": 2,
    "has_inference": false,
    "entity_count": 1
  }
}
```

## 五、流程位置总结

```
┌──────────────────────────────────────────────────────────────┐
│                      完整创作流程                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 0: 用户输入素材                                         │
│          ↓                                                   │
│  Step 1: Strategist 分析                                     │
│          ├─ RAG 检索                                         │
│          ├─ Context Card 生成 (P20)                          │
│          ├─ 标题生成                                          │
│          └─ ⭐ 模式推荐 (P22) ← 【在这里】                     │
│          ↓                                                   │
│  Step 2: 用户确认/选择                                        │
│          ├─ 选择标题                                          │
│          └─ ⭐ 确认/覆盖模式 (P22)                             │
│          ↓                                                   │
│  Step 3: Writer 创作                                         │
│          ├─ short_article_writer (P22 新增)                  │
│          ├─ mid_article_writer                               │
│          └─ long_article_writer                              │
│          ↓                                                   │
│  Step 4: Critic 评审                                         │
│          ↓                                                   │
│  Step 5: Polisher 润色                                       │
│          ↓                                                   │
│  Step 6: 输出最终文章                                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 六、模式配置

| 模式 | 字数范围 | max_tokens | 定位 |
|------|---------|------------|------|
| short_article (新增) | 100-280 | 800 | Twitter日常快评 |
| mid_article | 400-800 | 2000 | 深度Thread |
| long_article | 900-1800 | 4000 | 专题研究报告 |
