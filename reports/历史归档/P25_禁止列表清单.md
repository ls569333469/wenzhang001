## 二、废话文学

### 正确的废话（无信息量的万能句）
- 加密市场充满不确定性
- 区块链技术正在快速发展
- 在当前市场环境下

### 万能结尾
- 让我们拭目以待
- 后续值得关注
- 时间会给出答案
- 这会是XX的开端吗？

### 假装思考
- 这不禁让人思考
- 值得深思
- 引人深省

### 骑墙表态
- 机遇与挑战并存
- 有人看多有人看空
- 各有利弊

### 注水过渡
- 众所周知
- 说到这里不得不提
- 事实上
- 值得一提的是
- 综上所述

### 科普常识
- 所谓XX，就是...

## 六、事实禁止（反虚构）

| 禁止项 | 说明 |
|---|---|
| 虚构场景 | 编造素材中不存在的画面、对话、动作 |
| 编造数据 | 捏造数字、案例、项目、事件 |
| 编造引用 | 虚构社交媒体评论、群众反应 |
| 给人物加戏 | 编造心理活动、肢体动作、表情描写 |
| 编造时间地点 | 素材没提到的具体时间和地点 |

## 检索用法

测试时，对照以下步骤快速检查：

1. **Ctrl+F 搜屏蔽词**（第七类）→ 有就直接不合格
2. **扫标点**（第一类）→ 搜 `——` 和 `；`
3. **扫商业咨询腔**（第三类）→ 搜高频词表，3个以上就需要重写
4. **看结尾**（第二类万能结尾）→ 是否落入"拭目以待"类
5. **查虚构**（第六类）→ 每个事实点能否在素材中找到出处
6. **看结构**（第四类）→ 是否有三段并列/总分式/AI排列

### 快速评分标准

| 命中数 | 判定 |
|---|---|
| 0 | ✅ 合格 |
| 1-2 | ⚠️ 可修，润色阶段处理 |
| 3-5 | ❌ 需要重新生成 |
| 6+ | 🚨 提示词有问题，需要排查 |
