## 六、问题汇总与建议

| ID | 严重度 | 问题 | 建议 |
|----|--------|------|------|
| W-01 | 🟡 中 | Writer 字数严重超标 | 在 Writer prompt 中强化字数硬限制，或在 graph.py 中增加后置截断逻辑。... |
| C-01 | 🟡 中 | Critic PASS 率过低 (8%) | 同步调整 Critic 的字数判断阈值，或优先修复 Writer 字数控制。... |
| S-01 | 🟡 中 | 高频刻板句式：「就像」出现 29 次 | 在 Writer/Polisher prompt 中增加负面约束，明确禁止这些句式。... |
| A-01 | 🔴 高 | API 调用失败 1 篇 | 1) 增加请求间隔到 60s 以上；2) 考虑添加 API Key 轮换机制；3) 长期考虑迁移到更稳定的 API 提供... |
| H-01 | 🟢 低 | AI 高频词篇均 0.8 次 | 将高频词加入 forbidden_patterns.yaml，由 Polisher 自动替换。... |

### W-01: Writer 字数严重超标

**严重度**：🟡 中

short_article 模式目标字数 200 字，实际 Writer 平均产出 1016 字（约 5 倍），说明 Writer prompt 的字数约束没有生效。

**建议**：在 Writer prompt 中强化字数硬限制，或在 graph.py 中增加后置截断逻辑。

### C-01: Critic PASS 率过低 (8%)

**严重度**：🟡 中

25 篇测试中几乎全部为 REFINE，说明 Critic 字数约束与 Writer 产出严重不匹配。

**建议**：同步调整 Critic 的字数判断阈值，或优先修复 Writer 字数控制。

### S-01: 高频刻板句式：「就像」出现 29 次

**严重度**：🟡 中

前三高频：「就像」×29、「，而是」×23、「简直是」×7

**建议**：在 Writer/Polisher prompt 中增加负面约束，明确禁止这些句式。

### A-01: API 调用失败 1 篇

**严重度**：🔴 高

Google API Rate Limit 和 SSL 连接中断导致多篇素材生成失败，补跑后仍有个别版本缺失。

**建议**：1) 增加请求间隔到 60s 以上；2) 考虑添加 API Key 轮换机制；3) 长期考虑迁移到更稳定的 API 提供商。

### H-01: AI 高频词篇均 0.8 次

**严重度**：🟢 低

前三高频：「叙事」×7、「杠杆」×3、「落地」×2

**建议**：将高频词加入 forbidden_patterns.yaml，由 Polisher 自动替换。
