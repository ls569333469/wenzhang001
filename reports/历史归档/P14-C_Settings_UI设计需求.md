# P14-C: Settings UI 交互重构 - 弹窗式配置

## 🗣️ 用户需求
"智能体团队四个角色都在一个页面，点击策略师，就弹出来一个独立得页面，点击写手也弹出来一个独立的配置页面"

## 🎨 交互设计方案

### 主视图 (Main View)
- 保持整洁的 **2x2 网格** 布局。
- 每个卡片仅展示：角色图标、名称、当前状态（如"已配置/未配置"或简要信息）。
- **去除**卡片上的直接下拉选框，改为"点击配置"按钮或整个卡片可点击。
- 视觉上非常干净，像一个仪表盘。

### 详情弹窗 (Configuration Dialog)
点击任意卡片后，弹出居中的模态框 (Modal) 或侧边抽屉 (Sheet)。

#### 1. 通用角色弹窗 (策略师/评论家/润色师)
- 标题: 配置[角色名]模型
- 内容:
  - 角色职责描述
  - Provider 选择
  - Model 选择
  - 连通性测试 (可选)

#### 2. 写手角色弹窗 (Writer)
- 标题: 配置写手 (按模式)
- 内容:
  - **列表视图**展示 5 种模式
  - 每行独立配置 Provider/Model
  - 顶部显示全局推荐/批量操作 (可选)

### 优势
1. **极度整洁**: 主页面没有任何冗余控件。
2. **专注**: 配置时通过弹窗聚焦，不受其他元素干扰。
3. **扩展性**: 弹窗内空间充足，Writer 的 5 种模式可以舒展开展示，甚至可以加更多说明。

## � 技术实现

需要创建一个通用的 `Modal` 组件 (如果项目中没有)。

```tsx
<Dialog open={isOpen} onOpenChange={setIsOpen}>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>配置策略师</DialogTitle>
    </DialogHeader>
    {/* 配置表单 */}
  </DialogContent>
</Dialog>
```
