## 一、P31 目标与定位

P31 的核心目标是为 Quantum Studio 新增 **投研模式（project_research）**，实现每日自动化投研快报生成。

**产品定位**：
- 从 KOL Tracker（leak.me）自动发现热门 Web3/AI 项目
- 通过 Surf AI 进行深度投研分析
- 输出可直接发布到 X（Twitter）的投研快报 + 配图

**与现有系统的关系**：
- 作为 Studio 的第 8 种创作模式，复用现有 4 栏布局
- 独立 5 Agent Pipeline（不同于普通创作的 4 Agent）
- 松耦合打通，投研数据可供锐评/Kaito 模式选题

### v4 终稿架构

```
POST /api/research/daily-report
  │
  ├─ 🔭 侦察官 ×1      Surf 1.5 搜索 leak.me → 发现 N 个项目
  │
  ├─ 🔬 策略官 ×N      Surf 1.5 并发 3 个，深度分析每个项目
  │   └─ 每个项目保存完整报告到 reports/research/projects/
  │
  ├─ 📋 审核官 ×1      豆包，总结归纳 N 篇长报告 → 精简版
  │
  ├─ ✍️ 写手 ×1       DeepSeek V3.2，组装日报
  │
  └─ ✨ 润色官 ×1      豆包，定稿 → reports/research/daily_research_YYYYMMDD.md
```

### 关键架构决策

| 决策项 | 结论 | 理由 |
|--------|------|------|
| 每日项目数 | 5 个 | 平衡深度与广度 |
| 报告语言 | 中文 | 目标受众 |
| Layer 3 实现 | 本地 Python，0 API 调用 | 省 token + 可控清洗 |
| Layer 4 模型 | 换 AI（非 Surf），Gemini/豆包 | Surf 擅搜索不擅写作 |
| 中间存储 | JSON 文件解耦 | 采集和写作分离 |
| 触发方式 | Phase 1 手动，后续定时任务 | 渐进式上线 |
| Pipeline 耦合 | 松耦合打通 | 可供其他模式选题 |

## 四、关键经验沉淀

### Surf API Prompt 最佳实践

| 原则 | 说明 |
|------|------|
| **越简洁越好** | 一两句话自然语言 > 复杂 System Prompt |
| **不限输出格式** | 让 Surf 自由输出 Markdown 表格，后用 Python 解析 |
| **双源搜索** | 同时搜 leak.me 网站 + @leakmealpha 推文 |
| **明确上下文** | 告诉 Surf "leak.me 是 Crypto KOL Tracker" |
| **禁止"待验证"** | Prompt 中禁止输出来源标记和不确定标注 |

### 配图方案选型

| 方案 | 结果 | 原因 |
|------|------|------|
| HTML 手写 | ❌ | 太丑 |
| AI 生图 | ❌ | 中文渲染差 |
| PPT + COM | ❌ | 服务器不可用 |
| **HTML 模板 + Headless 截图** | **✅** | 可控、美观、自动化 |
