## 二、关键架构决策（v2 vs v1）

| 项目 | v1 (旧) | v2 (新) |
|------|---------|---------|
| Layer 顺序 | 选题→分类→分析→报告 | **选题→分析→分级清洗→报告** |
| Layer 3 | Surf API 调用 | **本地 Python，0 调用** |
| Layer 4 | Surf/Python 模板 | **换 AI（Gemini/豆包）润色写作** |
| 中间存储 | 无 | **JSON 文件，解耦采集和写作** |
| Pipeline 耦合 | 独立运行 | **松耦合打通**，可供 Kaito/锐评选题 |

### 新架构一览
```
Layer 1: 选题发现 [1次 Surf] → 项目列表
Layer 2: 深度分析 [5次 Surf] → 原始数据
Layer 3: 分级+清洗 [0次,本地] → 干净 JSON
Layer 4: 报告组装 [5次 Gemini] → Markdown + HTML
```
