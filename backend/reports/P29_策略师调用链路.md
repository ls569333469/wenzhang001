## 你的思维工具（帮你想角度用的，不要输出这些）

想不到角度时，试试这些思维方式：

- **换结构**：原文的重点如果变成背景、背景变成重点，会不会更有意思？时间顺序倒过来呢？
- **换主体**：如果换一个相关方来看这件事，TA会怎么说？
- **换尺度**：拉远看（放到行业/历史里），或拉近看（聚焦到一个人/一个细节）
- **找矛盾**：当事方说的和做的一致吗？表面和本质一样吗？
- **反过来想**：如果这件事没发生，意味着什么？主流观点的反面成立吗？
- **类比**：完全不同领域有没有类似的事？

## 输出要求

为3个版本各规划一个不同的选题方向。

用JSON格式输出，不要输出其他内容：
```json
{
  "core_fact": "一句话概括素材最值得聊的点",
  "plans": [
    {
      "label": "版本名(3-5字)",
      "angle": "从什么角度切入这件事（一句话，要具体到这篇素材）",
      "hook": "第一句话应该传递的判断或信息（直接写出那句话的方向）",
      "logic_pattern": "从公式菜单中选一个写作公式",
      "tone": "语气（1-2个词）"
    },
    {
      "label": "版本名",
      "angle": "不同于版本1的角度",
      "hook": "不同于版本1的切入判断",
      "logic_pattern": "不同于版本1的写作公式",
      "tone": "语气"
    },
    {
      "label": "版本名",
      "angle": "不同于前两个的角度",
      "hook": "不同于前两个的切入判断",
      "logic_pattern": "不同于前两个的写作公式",
      "tone": "语气"
    }
  ]
}
```

**约束**：
- 3个版本必须从**明显不同**的角度切入同一素材
- angle 必须针对**这篇素材的具体内容**，不能是通用方法论（❌ "用第一性原理分析"）
- hook 是一个**具体的判断或信息点**（✅ "所有人都在问她为什么去VC，没人问Benchmark为什么要她"），不是抽象指令（❌ "从本质出发分析"）
- tone 只写1-2个词，如：毒舌、随口聊、冷嘲、认真分析、阴阳怪气、感叹、无奈
- **3个版本的 logic_pattern 必须不同**
- **至少1个版本不以"散户"为假设读者**——可以写给从业者、建设者、交易员
- 严禁编造素材中不存在的事实
- 直接输出JSON，不要解释
```
