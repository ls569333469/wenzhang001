NFT 是一个新兴的小众加密领域，2020 年起愈发引人注目，越来越多的名人、高净值收藏家入场参与投资 NFT 产品，知名机构参与 NFT 项目的部署，NFT 快速发展得益于 DeFi 的火爆，并成为了继 DeFi 之后链圈寄予厚望的未来方向之一。

NFT 目前市值规模较小，但行业活跃度越来越高。落地应用场景主要是游戏道具，加密艺术品以及社交代币等领域。NFT 的唯一性和稀缺性使得它非常适合在区块链中标记资产的所有权，真正实现虚拟世界数字资产和现实资产的连接。

未来 NFT 的流动性会越来越高，更多的实物资产会上链，会更趋于金融化发展，但是也有生态环境不够完善和安全监管问题。我们认为 NFT 主要值得投资的赛道包括：优质公链、发行和流动平台以及代币本身。 

 

一、市场概况

 

在区块链领域，从可交换角度，代币可分为同质化和非同质化两种。同质化代币，即 FT（Fungible Token），以 ERC20 为基本标准，是互相可以替代、可接近无限拆分的 Token。

但同质化代币有局限性，现实生活中真正具有价值的事物往往是不可替代的，也无法进行无限拆分，具有唯一性的资产是无法用同质化代币进行锚定的。

非同质化代币 NFT（Non-Fungible Token），则是唯一的、不可拆分的 Token，如 token 化的游戏道具、门票、艺术品等。NFT 以 ERC721 为标准，之后又出现了 ERC1155 协议，即每个 ID 代表的不是单一资产，而是资产的类别，允许一次批量创建多个代币。

1.1 NFT 行业活跃度越来越高：从 2017 年加密猫开始，NFT 市场已经存在了三年多的时间，NFT 项目几乎全部活跃在以太坊以及 WAX 链上。

如下图可见，目前排名前十的 NFT 代币包括 Enjin，Flow，Decentraland，RedFOX Labs，Gala，SAND, Ultra，NFTX, WAX, Bondly，其中 Enjin 币 24 小时内交易额可达到一亿美元左右。

根据 DappRadar2020 年第三季度 NFT 行业报告，以太坊方面，与上季度相比，NFT 日活跃钱包数增长了 350%，NFT 交易量增长了 57%，CryptoPunks 日活跃钱包地址和交易量最多。WAX 区块链方面，与上季度相比，WAX 的 NFT 日活钱包数量增长 24375％，交易额增长 10086％。

另外，值得一提的是，Flow 是 2021 年专注于 NFT 加密游戏、加密艺术领域的又一公链，由 CryptoKitties 的开发团队 Dapper Labs 开发创建，和大多数 Layer2 扩容方案将区块链分片不同，Flow 在不降区块链分片的情况下实现扩容：节点不再参与整个交易的验证过程，节点之间存在分工。

仅仅参与收集、共识、执行、验证的其中一个环节，因此速度大幅提升，吞吐量提高。2021 年卡牌项目 NBA Top Shot 基于 Flow 开发，并且 2021 年二月 Flow 宣布将 NFT 交易平台 Opeansea 纳入生态系统。

1.2 总市值增长较快，但规模较小：截至 2021 年 2 月 25 日，NFT 市值达到 30 亿美元左右，其中 Enjin 币市值占 NFT 市场市值的 16.7%。历史成交总额达 32.3 亿美元，总共销售 531 万件 NFT 作品，平均成交单价 60 美金。

总交易额增长的基础是单个 NFT 资产的上涨，NFT 均价在 2021 年 2 月 22 号达到峰值 4334.21USD, 然而半年前这个数字约为 100USD, 上涨四十倍，2 月 21 日，NFT 资产的历史成交额也登上 2000 万美元的新峰值，约是半年前的 45 倍。

总交易额方面，2020 年总交易额是 2019 年的 1.8 倍，2020 年截止到 2021 年 2 月 25 日，总交易额达到 1.7 亿，2021 年前两个月的交易额是 2020 年全年的 2.7 倍。由这些数据可见，业界对 NFT 市场兴趣不断升温。目前 NFT 只占全部加密市场市值的 0.2%，市值规模很小， NFT 市场还处在在萌芽期，是一个小众领域。

1.3 知名机构参与部署，名人参与投资，热门项目表现优异：NFT 领域的一些项目比如 MEME、NBA Top Shot、Hashmask 等带来的经济效益大，表现优异，让众多参与者相信 NFT 会成为新的爆发板块。

此外，一些有影响力的名人也在参与 NFT，比如林肯公园乐队成员于 2021 年 2 月在 Zora 上发起音乐 NFT 拍卖。一些知名机构也相继入局，包括漫威、美国国家篮球协会（NBA）、Louis Vuitton 等奢侈品品牌所有者 LVMH 在内的知名机构也参与了 NFT 部署，机构的影响力将会有力的推动 NFT 进一步增长。

 

二、落地应用场景

 

2. 1 加密游戏 —— 最早的落地尝试，NFT 主要应用之一

我们认为 NFT 赋予了玩家真正的游戏资产所有权，使游戏玩家的资产交易去中介化，在多个游戏中无缝转移和使用。游戏数据在链上得以安全存储，同时游戏代码开源，玩家可以发挥创意创造游戏规则。未来加密游戏的去中心化程度会更彻底，也会有更多的专属游戏开发的优质公链。

2.1.1 发展历史

自 2013 起，陆续有些将比特币融入的在线游戏诞生，它是如今区块区块链游戏背后的灵感。2017 年年末，加密猫（CryptoKitties）横空出世，这普遍被认为是区块链游戏行业的开端，加密猫曾创造了单日 14000 + 日活跃地址记录（2017-12-09），一度造成以太坊交易堵塞。

截止到 4 月 30 日总交易额为 43067.04 ETH，约 2 亿人民币。2018 年 4 月上线的 Ether Go，第一款区块链放置类游戏，日活一度近 5000 用户，仅仅一天多就完成了 40000 余次交易。在此后的两年多时间里，区块链游戏数量实现了巨大增长，尤其是以 EOS、以太坊等平台为代表，涌出了一批现象级游戏，但都是维持了一时热度。

2.1.3 特色项目 ——NBA Top Shot

2.1.3.1 市场概况

2.1.3.1a 总交易额排名第一。NBA Top Shot 集卡游戏公测不到半年后在 2021 年迅速蹿红，按历史总成交额计算， NBA Top Shot 的成交额现已达到 2 亿美元以上，排名加密收藏品第一。

约是交易额排名第二的 CryptoPunks 的 3 倍，共有将近 170 万个参与收藏的钱包地址，约 9 万收藏者。其中平台上洛杉矶湖人队著名球星 LeBron James 经典扣篮镜头的数字收藏卡以 7.14 万美元价格售出，成为目前为止售价最高的卡片。

Source: Cryptoslam

2.1.3.1b 基于 Flow 区块链开发。 与大多数基于以太坊和 WAX 的 NFT 项目不同，NBA Top Shot 基于 Flow 区块链开发，Flow 是 CryptoKitties 的开发团队 Dapper Labs 开发的公链，采用了秘密知识专业证明（SPoCK） 的密码学技术，借助 Layer 2 实现去中心化的高性能。

Flow 通过 PoSy 一致性算法对开发者的代码升级保护，对开发者高度友好，安全性强，吞吐量高，更能针对区中心化游戏的需求，生态也在不断完善中，著名 NFT 交易所 Opensea 在 2021 年 2 月 24 日加入 Flow 生态。

2.1.3.2 传统球星卡历史

2.1.3.2a 发源于美国，主要以棒球卡为主。最早的棒球卡发行于 19 世纪 80 年代，也是棒球职业化出现的年代，一张卡片上印有一个球员照片，这种球星卡被称为 Trade Card。早期的球员卡主要作为买香烟的赠品，糖果和玩具制造商也进行效仿，逐渐成为了美国的一种收藏品。

Goodwin & Co., maker of Old Judge and Gypsy Queen 烟草制造商是第一家制造球星卡的公司，Topps 是第一家正式专门生产球员卡的公司，1951 年后的一段时间内一度垄断市场。反托拉斯法案推出后，Topps 仅保有 NBA 篮球巨星卡片发行权，美国球员卡市场从此进入战国时代。

2.1.3.2b 承载了文化价值。棒球和篮球等传统运动是美国文化的重要部分，球员卡有时会代表一个传奇的时代或一个伟大的球队，具有很高的收藏价值。除了棒球之外，NBA 所代表的篮球文化在世界范围内的影响力不言而喻，不乏詹姆斯、科比这样的超级体育巨星。

现在的球星卡不再只是卡片上印有一个或两个球员的照片，有更多新玩法出现，比如限量卡、新秀卡、球衣卡，球星亲笔签名卡等，这些卡片具有稀缺性，随着时间的推移收藏价值越来越高。

2.1.3.3 NFT 球星卡较传统球星卡优势

2.1.3.3a 表现形式更为丰富：除了传统球星卡上的球星图片和基本信息介绍的文字以外，NFT 球星卡还有短视频或者 GIF 动图的形式，记录 NBA 球星的「精彩时刻」，NFT 球星卡表现形式更多元，更具有吸引力、趣味性，投资和收藏价值更高。

2.1.3.3b 存储难度低：卡片随着时间流逝在保存过程中可能出现氧化、变色、破损等问题。球星亲笔签名卡的墨水也可能褪色。NFT 球星卡作为资产上链后，不存在会出现实体球星卡的存储或运输问题，NFT 资产可以储存在钱包中，储存成本几乎为零，这也让球星卡的收藏门槛下降，吸引更多玩家参与，另外链上资产更强的流通性赋予了 NFT 球星卡收藏更理想的投资属性。

2.1.3.3c 山寨卡风险降低：传统球星卡交易市场是不受监管的，官方发售卡片后，个人之间的二级市场交易很有可能出现出售山寨卡现象，玩家判断失误就可能会高价买入成本十分低廉的伪造品。借助智能合约，NFT 球星卡的出处以及每一个持有或转让它的地址都可以被追踪，每张卡牌都是独一无二的、不可复制的，信息也无法被篡改，出现假卡的几率很低。

2.1.4 加密游戏优势

加密游戏和传统游戏相比有以下优势：

2.1.4.1 玩家拥有游戏资产所有权：传统游戏中，游戏资产的所有权属于开发商，玩家仅拥有使用权，开发商可以随意的转让或更改用户的游戏资产，而在加密游戏中，通过智能合约，用户可以真正拥有游戏资产的所有权。

2.1.4.2 游戏数据得以永久安全存储：传统游戏中，游戏数据存在被黑客盗取的风险，而加密游戏基于区块链技术，黑客无法入侵和攻击分布式账本，因此游戏数据得以被永久保存，不得篡改。

2.1.4.3 游戏开源开发：传统游戏的代码是不开源的，即游戏厂商制定游戏规则，加密游戏与传统游戏单点信任不同，是点对点的生态系统，游戏的代码是开源的，透明的，开发者可以发挥创意自由创新，让游戏的可玩度更高，这也体现了 Web 3.0 的概念。

2.1.5 发展前景

2.1.5.1 中心化程度更彻底，去中心化社区治理（DAO）赋能 NFT 游戏：游戏生态中底层设施不完善，去中心化程度不彻底是 NFT 游戏的问题之一。即使玩家名义上拥有游戏资产的所有权，但 NFT 在前端上以什么样的形式呈现，是由游戏厂商的中心化服务器决定的。

而 DAO 是指通过一系列社区成员都认可，公开透明的规则，社区在无人治理的情况下都可以自主运行。NFT 游戏社区中任何的代币奖励、投票、交易都是得到整个社区认可的。数据公开透明，任何成员都可以查询且无法篡改，一旦部署后将不受创建者和外界力量的影响。DAO 将在 NFT 游戏中的「去中心化」抗争中发挥重要作用。

2.1.5.2 构建游戏专属的公链生态：目前 NFT 游戏大多都基于以太坊开发，但是以太坊有着低 TPS，高 Gas 费用等缺点，专属于 NFT 游戏开发的优质公链基础设施也是未来 NFT 游戏的发展方向之一。

由 Dapper Labs 开发的 Flow 是游戏专用领先的公链，它与 NBA 等组织的取得了独家合作权，NBA Top Shot 是在 Flow 上开发建立的。Flow 具有低成本、低延迟、高吞吐量且开发环境 以及用户体验友好的优点。

2.2 加密艺术 —— 与 NFT 最契合的应用

我们认为加密艺术作品市场可以带来传统系统无法达到的经济效益。通过智能合约，艺术品的历史交易信息包括发出者、展览记录、买卖记录完全是公开透明的，这就大大降低了艺术品的交易成本。

并且创作者在本质上也拥有了艺术品的所有权，艺术家也可以通过可证明的编程方式获得二次销售补偿。NFT 锚定的艺术品具有稀缺性、唯一性，正是这种稀缺性推动了人们对艺术品的需求。

2.2.1 传统数字艺术品交易弊端

除了艺术品本身具有上链条件外，传统艺术品交易的弊端也是推动加密艺术产生的重要原因。传统艺术品弊端有以下两点：

2.2.1.1 作品流动性差：在传统艺术品市场中，交易场所主要是画廊、拍卖行等，创意者经过中间商在画廊或者拍卖行中展出作品，买家付款后，便可以用 USB 拷贝艺术品。这种交易模式的弊端是显而易见的：作品曝光率低，受时间、地域、人群限制大，变现能力和普及度低，流动性差。

2.2.1.2 创作者无法拥有真正的版权：买家从创作者手中得到作品后，可以复制一份相同的作品继续放到二级市场上交易，艺术作品的稀缺性在不断的复制传播中降低，收藏品的价值下降。与初次销售收入相比较，二次销售转卖升值的经济效益是客观的。

这些年来，原创者们不断在争取二次销售的版税，即「追续权」，1920 年法国首先引入「追续权」概念，追续税率通常很低，在法国艺术家可以得到 转售价 3% 的分红，遵循欧盟 2001 年发出的《艺术作品作者追续权保护指令》的国家，艺术家在转售中可以获得 4% 的收益。

在美国，1976 年加州立法承认追续权，1991 年、2011 年国会关于追续权制度都曾向公众征求过意见，但都没有通过，2012 年，加州追续权法案被废止。除了立法不够完善之外，执法的难度也很大，往往需要法律层参与之后进来原创者才能收取二次销售的收益，法律成本较高。

2.2.3 NFT 为艺术领域赋能 —— 以 SupeRare 为例

SuperRare 是成立于 2017 年的主要加密艺术市场之一，该平台拥有画廊、拍卖行、博物馆、社交、商务等功能。目前该平台有超过 600 名创作者，作品一般以 ETH 标价出售，总交易额达到 2000 万左右，交易数量总共约 16000 件，目前最贵的作品单价达到 165ETH，约 85000 美元，该平台上出售作品的艺术家和作品都会被平台审核。

2.2.3.2 SuperRare 赋能艺术品交易

2.2.3.2a 艺术家初级销售收益增加：全世界的投资者可以通过平台欣赏艺术家的作品，作品曝光度较传统拍卖行高，并且在加密艺术市场点对点去中心化的生态系统中，艺术家不受拍卖行、经销商等中间人的高额佣金影响，初级销售 85% 收益归属于自己（平台收取 15% 佣金），艺术家初级销售收益增加。

2.2.3.2b 艺术家和二次销售权益绑定：以太坊智能合约中加入了二级市场销售特许权，Superare 交易市场中，艺术品在二级市场进行交易后，原创者可从中获得 10 % 的佣金，获得被转卖的被动收入。因为智能合约有对资产支配的权力，二次交易后会立即自动付款，不需要第三方法律人员来执行，艺术家真正拥有了二次销售的权益。

2.2.4 加密艺术优势

总体而言，加密艺术较传统艺术的优势可以概括为以下三点：

2.2.4.1 降低成本：加密艺术品相对于传统艺术品交易减少了高昂的运输成本，储存成本，维护成本，法律成本等。

2.2.4.2 增加曝光度和流动性：目前传统艺术品交易都时间、地域、受众限制很大，主要的艺术展只集中在纽约、柏林、巴黎、香港等大城市，受众人群也主要是社会富有阶层，但加密艺术通过区块链于智能合约成功连接了全球市场，整合了全球艺术品资源，汇集了全世界的艺术家、收藏家、投资者以及评论家，玩家选择可以投资 NFT 资产碎片，收藏门槛降低，可以在加密艺术综合交易平台随时浏览艺术品。

2.2.4.3 明确作品所有权：加密艺术的展览、流转信息全部会被记录在链上，便于审核、跟踪特定艺术品，出现仿造品、山寨品可能性大大降低。ERC721 协议明确了代币的出处，明确了作品所有权，二次销售的剩余价值归创造者所有。

2.2.5 加密艺术未来设想

关于加密艺术未来的发展趋势主要有四点：

2.2.5.1 与更多的元素结合或捆绑形成新的资产类别：比如金融，建筑等等，这些创新的捆绑组合将会释放加密艺术的更大潜力。

2.2.5.2 艺术品会和更多潮品或者玩具结合：潮玩市场现金流收入高于艺术品，而且个性化设计、潮流属性成为当今许多年轻人的消费逻辑，潮玩市场火爆规模将持续扩张。潮玩市场传统艺术界已经有这种趋势，比如艺术家村上隆的作品，他的绘画、雕塑作品有很强的玩具属性。

2.2.5.3 流动性增加：未来可能会出现更多的类似 Opensea 一样的综合性交易平台以及二手交易平台。其次，另一个流动性来源是 DeFi, 用户在 DeFi 协议中抵押优质 NFT 资产之后贷款去购买新的资产，NFT 的流动性就会增加。

另外，除了单版限量艺术品，也会有更多多版限量艺术品的交易流通。多版艺术品是艺术家根据自己的想法委托或自己制作的一系列相同的艺术作品，多版艺术品对于玩家而言收藏门槛更低，社交属性更强，流动性会增加，升值空间更高。

2.2.5.4 艺术品鉴真以及防伪技术升级：随着鉴真溯源芯片技术的升级，玩家遇到伪造品的可能性会降低。

2.3 社交代币 ——NFT 未来最有潜力的增量市场之一

我们认为社交代币集中体现了 Web3.0 点对点传输的内涵，有助于减少创意者对中心化平台的依赖，增加创意作品的流通性和变现能力，也可以真正实现创意者和权益绑定。相比实物资产上链，这类互联网社区中的原生资产的价值捕获将会更高。目前人们还只是触及了社交代币的浅层潜力，社交代币未来可能成为 NFT 最有潜力的增量市场之一。

2.3.1 社交代币分类

社交代币（social tokens）是一种由个人声誉、品牌或社区支持的代币，是 NFT 领域中一个较新的应用。社交代币是建立在社区价值会不断提高的前提之上的。社交代币大致分为两类：个人代币和社区代币。

2.3.1.1 个人代币：由个人创建，会随着个人价值的增长而升值，但捕获价值有限，受个人品牌影响大，创作者可以通过发币来管理自己创建的社区。

2.3.1.2 社区代币：通常用于进入有特定成员资格才可以进入的社区，比如必须拥有该社区创建者发行的代币，才可以进入特定的 telegram 讨论组，获得资讯或服务等等，同时这些社区也会通过发放代币鼓励人们对社区做出贡献，社区代币大多是去中心化自治组织（DAO）的治理代币，社区通常比个人成就更广，增长潜力更大。

2.3.2 社交代币价值   

2.3.2.1 增加创意作品变现能力。互联网为创意者们了提供分享作品的平台，但是创意者作品的商业化能力，作品共享、传播能力、增值都是空间都是有限的，即创意者的作品变现能力不足。

但 Web 3.0 的出现有望解决这一问题，创意者可以在社区内通过发放社交代币，让支持者共享所喜爱的作品，从而提高流动性，达到作品增值的目的，而且创意者可以根据社区内用户的活跃度以及贡献度划分层级并享受代币化权益。

2.3.2.2 创意者和权益绑定。创作者可以利用社交代币允许粉丝访问该创作者全社交平台的作品，粉丝可以不再去依赖平台支持创作者和喜爱的作品，这种方式通过代币化工具统一对创作者支持。创作者可享有作品增值空间的全部利润，实现创意者和权益的绑定，这也体现了 Web 3.0 的点对点生态系统的核心内涵 。

2.3.5 社交代币价值思考

2.3.5.1 相比实物资产上链，社交代币原生资产价值捕获更高。社交代币在粉丝经济持续发展的背景下是有实际价值支撑的，拿个人代币举例，发币者个人影响力越高，代币的价格就会越高，发行代币由发起人的个人品牌和声望背书。相比资产上链，这类互联网社区中的原生资产的价值将会更高，只是在 Web3.0 时代正式到来之前不够明显。

2.3.5.2 对识别人才及品牌的增值预测能力有要求。社交代币主要由个人声誉、品牌或社区支持，会随着个人或社区价值的增长而升值，对投资者识别人才的能力有要求。

三．展望与瓶颈

 

3.1 优质资产提升市场流动性。首先 NFT 领域预计会出现更多优质的综合性交易平台，为世界各地的玩家提供铸造或交易 NFT 的场所。另外 DeFi 可以为 NFT 提供流动性，优质的得到广泛认可的 NFT 资产可以在 DeFi 的协议里抵押借贷，用户抵押 NFT 之后再去购买新的资产，优质的 NFT 资产将提高市场流动性。

3.2 更多现实资产上链。NFT 的真正意义是为现实世界的物品提供一个上链渠道，充当物理世界和区块链世界的连接桥梁。除了现有的游戏道具、艺术收藏品等应用，未来有更多现实资产比如房地产、版权等都可以上链，以 NFT 形式存在。此外，NFT 也可以看成是现实兴趣爱好的一次上链过程，比如电影、音乐、戏剧、时尚等都可上链，玩法将更多元。

3.3 金融属性增加。商业票据例如债券、保单等在金融市场流通、交易的过程中需要承载着大量信息，具有唯一性，NFT 作为非同质化代币，可以对标不同实物，票据的信息可被追踪。NFT 可以为金融领域赋能，未来金融属性将会增加。

3.4 生态环境不够完善。相较于先前热门的 DeFi 生态，现阶段 NFT 的生态完善还不够完善，不同于 DeFi 领域各个赛道的相似的业务和投资逻辑，NFT 赛道分化明显，项目差异较大，而且只有少部分赛道发展较为成熟并具有投资价值，导致 NFT 的项目和赛道合力不足，影响力有限。

其次，NFT 中涉及的私钥、钱包、助记词等概念对玩家而言门槛较高，很多玩家因此望而却步。另外，NFT 市场由于是新兴小众领域，流动性较 DeFi 项目较差。

3.5 安全风险较高。首先全球在 NFT 领域政策的监管尚处在空白阶段，NFT 发展属于无监管的「野蛮生长」状态，根据 NFT 非同质化代币对标实物的特点，可能会出现不法分子利用 NFT 洗钱、交易违禁物品这类犯罪活动。此外，随着 NFT 资产价值不断增加，生态系统逐渐扩大，可能成为继 DeFi 之后黑客新的攻击目标，网络安全问题漏洞也是潜在风险。

 

四．投资与赛道评估

 

4.1. 有投资价值的赛道包括：优质公链、发行和流动平台、代币本身

4.1.1 优质公链

以太坊高 Gas 费，速度慢，网络拥堵的问题限制了很多应用的开发，用户体验较差，像 Flow 这类新型作为游戏专用区块链或者 Matic, xDai Chain 这类 L2 解决方案有支持游戏或流媒体行业的潜力。

投资 L1 或 L2 上支持 NFT 项目开发的有更高吞吐量的优质公链或扩容解决方案是一个有潜力的 NFT 投资方向。但与更为集中的代币本身投资相比，公链这类较为广泛的投资带来的收益可能较少。

4.1.2 发行和流动平台

NFT 是非同质化代币，具有唯一性，和同质化代币不同，其商品属性大于货币属性。既然 NFT 商品属性更大，商品的发行和流动平台就是主要投资方向之一，例如 Opeansea、Superare 这类交易平台。

Opensea 和 Superare 目前尚未发币，交易平台 Rariable 的平台治理代币 Rari 允许玩家买卖 NFT 商品，进行流动性挖矿，获得代币奖励，投资者可以布局这类代币。但是，过于小众的市值很小的交易平台不建议布局，第一深度不够，价格波动大，用户容易遭受短期损失，第二平台规范性没有保障。

4.1.3 代币本身

前文提到的艺术收藏品、游戏道具、社交代币、NFT 金融产品、平台治理代币都具有投资价值。收藏品和艺术品往往因为不同的原因或背景变得有价值，这些原因通常不可复制，具有稀缺性，投资者需运用自身艺术品知识储备评估其收藏价值，游戏道具也根据游戏本身的热度和趣味性价值不同。

鉴于 NFT 的稀缺性、唯一性，NFT 在金融领域的应用是未来发展的重要方向，其中保险、衍生品、指数是 NFT 在金融领域的投资主要投资机会。平台治理代币的价值取决于其治理的资产以及生态系统的质量，代表该平台上 NFT 价值的索引。随着「粉丝经济」、「所有权经济」的兴起，标的个人价值和社区价值的社交代币也是有潜力的代币投资方向之一。

4.2 NFT 作品本身、艺术家、交易平台质量、外部评价是评估 NFT 的重要指标

加密货币领域中投资 NFT 类似于传统投资机构的另类投资。与传统投资相比，另类投资流动性较差，信息有效性弱，可能赚取超额收益，同时也有助于减少投资组合中的整体投资组合波动性，增加投资多样性。与传统艺术品的估值方法类似，玩家对 NFT 的投资主要需要考虑以下四大要素：

4.2.1 NFT 作品本身： NFT 作品本身是评估 NFT 的最重要指标。收藏品、艺术品这类 NFT 产品的内在价值很难估计，对玩家的艺术鉴赏水平有一定要求，游戏道具保值或增值的前提是游戏本身一直保持对用户的吸引力，玩家可以根据个人的兴趣爱好、艺术情怀和鉴赏角度评估 NFT 作品的投资价值。

4.2.2 艺术家： 如果一个艺术家知名度高，买家就更倾向购买该作品，这类拥有高市场需求的艺术家才能以高价出售作品，相反，初出茅庐的艺术家的作品卖出高价的可能性很低。NFT 领域活跃艺术家包括：Matt Kane、Pak、Josie、Pascal Boyart、Hackatao、Coldie、Trevor Jones、JOY 等，玩家可以优先选择这些艺术家的作品。

4.2.3. 交易平台质量：拍卖行在传统艺术品市场中起到很大作用。 如果一位艺术家的作品被一个著名的拍卖行购买，那么该艺术家在艺术界地位某种程度上得到了认可，其作品价值也会进一步提高。

如今 NFT 交易平台越来越多，玩家需要对其质量进行评估，须挑选知名度高，有信誉保障的平台购买，以此保障 NFT 作品的质量。比如用户可以选择 SuperRare 这类艺术家及其作品经过严格审查的平台购买 NFT 资产。

4.2.4 外部评价：传统艺术品投资中，收藏家可以通过收集艺术家档案、展览新闻、拍卖结果这些外部评价资料来评估艺术品价值。NFT 领域中，用户可以同样参考新闻，市场交易数据（例如成交单价、成交额）或第三方审计报告对加密艺术品价值进行评估。

4.3 注重保护资产，安全收藏 NFT

4.3.1 用户最好选择硬件钱包储存 NFT：硬件钱包的私钥是单独储存在芯片中的，不容易被恶意攻击，是储存 NFT 资产的安全方式，不像软件钱包面临更多攻击载体。

4.3.2 用户需考虑平台处理元数据的方式的安全性：如果一个 NFT 项目将其元数据储存在第三方中心化服务器，若该项目最终破产或第三方服务器遭黑客攻击，用户将遭受损失。对于收藏者来说，NFT 项目的上链程度是很重要的，应选择上链程度高的、元数据存储在链上的 NFT 项目。对于这类项目，用户也可以在在太坊浏览器或其他查询工具中追溯信息源头，跟进 NFT 资产状态。
