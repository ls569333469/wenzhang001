原文编译：微信公众号：老雅痞 

 

日前，我们与育碧战略创新实验室副总裁 Nicolas Pouard 就育碧 Quartz 和 Digits NFT 的发布进行了交谈。

2021 年 12 月 7 日，育碧成为第一个公开进入 NFT 领域的大牌游戏开发商。作为 NFT 的育碧 Digits 和 Quartz 平台的推出并不顺利。玩家的反馈非常消极，甚至到了咄咄逼人的地步。游戏媒体的知名人士在分析时也是不温不火。无论如何，这都是游戏领域的里程碑时刻。

我能够理解为什么玩家会如此谨慎。但我个人并不认同这种愤怒。事实上，我对 Quartz 和 Digits 的推出感到兴奋，尽管打了个星号。

在游戏媒体领域工作了 20 多年，我最看重的是体验。我玩是为了好玩。我对投资或从游戏中赚钱不感兴趣。但在过去 4 年里，我也密切关注了区块链和 NFT 游戏，我可以看到该技术有潜力为玩家提供更大的自由。如果像 Ubisoft Quartz 和 Digits 这样的产品（你可以相信会有更多的产品出现）处理得当，玩家可以获得很多好处。

真正拥有的不仅仅是一款产品，还有我们通过游戏和社区创造的游戏生态系统，如果处理得当，承诺得到兑现，这是一个具有积极潜力的未来。

育碧会做得好吗? 或者 Quartz 和 Digits 会成为吞噬我们挚爱爱好的恶魔之子吗?

我把我的担忧告诉了育碧战略创新实验室副总裁 Nicolas Pouard，他是 Quartz 和 Digits 的负责人，我想看看他会如何回应自己的产品所引发的不满。在育碧区块链技术总监 Didier Genevois 的帮助下，他是这样说的。

 

对于育碧 Quartz 和 Digits 的发行，玩家的反馈普遍是负面的。关于主流 NFT 的成功前景，这些反馈告诉了你什么?

Nicolas Pouard：这是我们所期待的反应。我们知道这不是一个容易理解的概念。但 Quartz 只是迈向更大成就的第一步。这样我们的玩家就更容易理解了。这就是我们思考这个问题的方式，也是我们不断尝试的原因。我们将继续围绕这一倡议发布功能和服务。我们的信念是，谜题将被我们的玩家一点一点地揭示和理解。我们希望他们能更好地理解我们提供给他们的价值。

 

你在演讲中谈到了如何改善与玩家的关系。如果这是您在 Quartz 的目标，那么看到您收到的反馈肯定会很沮丧。

NP：我认为这是过程的一部分。这是我们习以为常的反应。我认为这很棒，因为它展示了玩家的沉浸感以及他们对自己的爱好和游戏的热情。看到这一点，我认为这在某种程度上是令人放心的。这表明我们的玩家喜欢我们的工作，也喜欢育碧提供优秀游戏的能力。所以这很好。

不过，显然我们还是有点沮丧。但我认为总的来说，它是好的，是我们能够真正理解的。我们坚信，我们 (对 Quartz 和 Digits) 所做的事情正朝着正确的方向发展。因此，我们将继续整合。显然，在我们前进的过程中，要听取我们的粉丝告诉我们什么，以及他们如何告诉我们，所以我们也可以调整我们正在做的事情和前进的方向。所以这是下一步行动。为了确保我们正在做的事情对玩家来说会更有意义。

 

好吧，让我们来谈谈它的意义。你认为游戏玩家忽略了 Digits 等 NFT 可以为他们提供的最大积极因素是什么?

NP：我认为玩家并不了解数字二级市场能给他们带来什么。就目前而言，由于 NFT 的现状和背景，玩家确实认为它首先是在破坏地球，其次只是一种投机工具。但我们 (育碧) 首先看到的是游戏的结局。最终游戏是让玩家在用完物品或玩完游戏后有机会转卖他们的物品。

所以，这真的是对他们来说很有益的。但他们现在还不明白。

同时，这也是游戏模式转变的一部分。从一个经济体系转移到另一个经济体系并不容易。有很多习惯你需要改变，很多根深蒂固的心态你需要改变。这需要时间。我们知道这一点。

你认为在不提及 NFT 或区块链的情况下推出 Quartz 会更好吗？如果您刚刚推出了一个新平台，它为游戏玩家提供了一些新的东西，而不向他们展示其潜在机制?

NP：实际上，我们在某种程度上做过尝试，这就是为什么我们把它们命名为 Digits。我们考虑过不谈论技术，但我们了解我们的玩家。他们会知道 Digits 是 NFT。所以，我们认为试图隐藏起来不是很明智。我们的原则是用 Quartz 打造一个安全的地方和环境。因此，我们需要对我们正在做的事情保持透明。

Didier Genevois: 如果我可以就这个问题发表一点意见的话。正如 Nicholas 所说，我们知道如果我们不提到技术，玩家就会注意到。当提到区块链时，玩家首先关心的是它对环境的影响以及它所消耗的能源。因此，对我们来说，关键是能够表明我们意识到了这种担忧，并且我们正在积极选择使用 Tezos。

这种 (沟通) 符合我们作为一个公司的职责。我们的研究在环境和相关问题上有很强的参与性。对于我们来说，我们能够先发制人地进行讨论，让玩家知道我们采取了正确的措施来保护环境。

 

恐怕不仅仅是环境的问题。我所读到的许多反馈都表明，玩家认为或担心 NFT 是新的微交易或新的战利品盒；Digits 将使育碧的游戏更加昂贵。他们是对的还是错的?

NP：好吧，首先玩家总是对的。因为他们是我们的玩家，我们爱他们。所以，他们总是对的。但你的观察是正确的。我想说的第一点是，Digits 是完全可选的。这是我们在游戏经济之外所创造的内容。所以，你可以使用 Quartz，也可以选择不使用它。这其实是个人选择的问题。

在任何时候，我们都不会强迫玩家使用 Quartz 和 Digits。我们只是告诉他们，有一个新的系统可以为他们提供比现有系统更高的价值。这是第一点。

然后是我们建立平台的方式，关于资格标准。我们把它做得有点让人难以进入。你必须购买游戏。你必须至少玩两个小时。所以，对于纯粹的投机者来说，去那里投资并使市场膨胀有点复杂。这也不是那么复杂，但有很多其他的选择可供投机者进入和搅乱。我们认为 Quartz 主要是为我们的玩家服务的，而我们的初步数据也证实了我们的预期。这就是我们在看数据时所看到的。

记住，这仍然是一个实验。我们将调整我们即将发行的版本的数量，以便不会有太多的通货膨胀。我们主要关注的是，确保即使在二级市

场上，游戏价格也不会太高，这样普通玩家也能玩到。

所以，澄清一下，在《幽灵行动:断点》发布的皮肤 NFT，是否也可以通过游戏经济购买--甚至在游戏中获得--然后只有通过 Quartz 获得或注册，才能成为独特的 NFT？

NP：不，所以这些皮肤是 Quartz 独有的。如果你不通过 Quartz，你就无法在游戏中获得它们。

 

与区块链相关的一个重要信念是去中心化。将权力从大公司手中转移到消费者手中。从外部来看，我立即质疑去中心化对育碧这样的公司的价值。去中心化对育碧有什么好处？

NP：所以这个问题实际上是关于玩家参与度以及如何与他们共享生态系统。当你只看育碧这家公司的估值时，我认为它超过了 30 亿美元。但是 (育碧产品的) 整个生态系统的价值超过 150 亿美元。因此，生态系统远不止一家公司那么简单。这个生态系统不仅由公司组成，还包括玩家以及玩家在这个生态系统中所扮演的各种角色。

因此，对于像育碧这样的中心化公司来说，去中心化的利益在于打开我们游戏的大门，并通过与玩家分享 (股份) 来使它们变得更大。在迄今为止每款游戏的基础上构建新的体验。这是一种观察游戏的新方法。

我不想细数，但在今天，拥有一个庞大生态系统可能比只拥有一款游戏更有趣。我很抱歉，因为我知道现在很难理解，因为这种想法还没有真正 (在游戏中) 存在。但我们看到，在为每个人创造价值方面，一个游戏的生态系统可以比今天的游戏大得多、多得多。

 

我从玩家那里读到的最愤世嫉俗的反馈指出，这一切都是育碧为了赚更多钱而采取的策略。但你认为这是为了创造更深入的玩家参与体验?

NP：是的。赚钱的游戏模式是让玩家通过增加整个生态系统的价值来赚钱。所以，这不仅仅是关于育碧。

 

考虑到育碧正试图引领这一新兴领域，当你看到《潜行者 2》团队所发生的事情时——他们宣布了 NFT 的整合，但在遭到强烈反对后又放弃了——你对此有何感想? 你的反应是什么?

NP：遗憾的是，仍然有一些基于误解的阻力。但我不确定我们是否能够将《潜行者 2》与 Quartz 的目标进行比较。我想说的是，这对于玩家来说是不同的用例。

 

我知道 Quartz 发布才几周时间，但到目前为止，你从 Digits 的发布中得到了哪些宝贵的经验?

DG：我们所了解到的是，我们为资格标准设置的障碍发挥了作用。在游戏前两周所订购的 2500 个代币中，绝大多数都是来自《幽灵行动:断点》的玩家。他们并不是在我们 12 月 7 日推出 Quartz 时开始玩的。他们在此之前已经玩了很长时间的游戏。很高兴看到这一点，因为对我们来说，这是最大的风险。市场会被投机者抢占先机。这绝对是我们不希望看到的。

NP：也许从技术角度来说，我们很高兴一切都如我们所愿。这并不容易，因为我们是在 Tezos 之上构建的，当你构建 NFT 时，这不是显而易见的选择。但我们想要致力于这种环保的选择。我们对此非常满意。此外，我认为从用户体验来看，使用 Quartz 平台很容易上手。

 

你们认为未来玩家会拥有自己的游戏吗? 这些游戏是 NFT？

NP：这是我们可以探索的部分用例，但不是今天的重点。

 

你认为未来大部分育碧游戏 (如果不是全部) 都将以某种方式与 Quartz 和 Digits 结合在一起吗?

NP：实际上，我们已经是一个非常分散的公司了。我们让每个项目的团队决定他们是否想拥有 Digits，或者使用 Quartz 平台本身。所以，这是开放的。

 

但显然，和汤姆·克兰西的比赛将是第一个接触点?

NP:：（笑) 有可能。

 

从游戏开始，在你关于 Quartz 和 Digits 的演讲中，您提到了未来可能收购去中心化自治组织 (DAO)。你那是什么意思？我听错了吗？

NP：(我指的是) 用户获取的未来。当你与像 Yield Guild Games 这样的 DAO 成员交谈时，他们确实将自己视为游戏中获取用户的新工具。因为如果你创造了优秀的游戏体验，那么这些公会便会出现在你的游戏中，并推动着你生态系统的发展，而最终的效果便是你需要融入整个经济和社区。所以，这不仅仅是你获取新玩家的营销费用，而是你如何以一种能够吸引公会的方式去构建游戏。

 

吸引公会非常具体地谈到了游戏的赚钱空间。这是你感兴趣的东西吗? 如果是的话，是通过一个新的 IP，还是你会考虑将 P2E 应用到现有的 IP?

NP：是的，我们对游戏收入感兴趣。对我们来说，这与我们今天所做的事情是一样的逻辑。所以，我们试图把育碧游戏看作是一个能为你的体验提供最大价值的地方。这意味着，在你玩游戏的过程中，有不同种类的价值。

当然也有乐趣。你从玩游戏中获得的乐趣。事实上，你可以学到东西。例如，在《刺客信条》中，玩家可以学习历史，而我们在旧游戏中进行实验，让玩家学习新的软技能。所以，游戏可以包含很多东西，可以为玩家带来很多东西。在游戏已经提供的所有价值之上添加现实价值奖励可能是下一个补充。

所以，Quartz 只是我们已经在做的事情的一个延续，但我想说的是，它必须得到很好的处理。这就是为什么使用现有的游戏与现有的经济，并试图将其转移到游戏经济中是没有意义的。它确实需要从零开始。因为这是对游戏经济和货币化的一种非常不同的思考方式。

 

你们是否已经在讨论将育碧的角色与其他 NFT 游戏交叉使用? 就像 Axie Infinity 里那个看起来像 Rabbid 的 axie 吗? 你们是否正在研究类似的事情，并试图在现有的 NFT 领域中推广育碧品牌?

DG：过去我们加入了 Cryptokitties 和 rabbid 做了一些实验。所以，像这样的跨品牌实验肯定是有途径的。就目前而言，没有任何东西将被输出。但是，是的，在内部，这在某些点上是有可能的，因为这就是技术最终提供出来的。
