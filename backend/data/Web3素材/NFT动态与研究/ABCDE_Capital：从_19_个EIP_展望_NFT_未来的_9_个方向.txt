标题: ABCDE Capital：从 19 个EIP 展望 NFT 未来的 9 个方向
链接: https://www.chaincatcher.com/article/2089676
发布时间: 2023-03-21

==================================================

来源：ABCDE Capital

编译：十文，Odaily星球日报

 

ERC-721 于 2018 年 1 月创建，当时链上已经出现了一些 NFT 实验。但没人能够预测到它将导致 NFT 生态的诞生并释放出 NFT 应用的潜力。PFP 和 GameFi NFT 在 2021 年和 2022 年一度成为 Web3 主舞台，我们也更为兴奋地期待 NFT 增长的下一个阶段。

越来越多的创新和标准化措施正进一步带动 NFT。在本文中，我们将分析最新的 EIPs（以太坊改进提案），并提炼出 NFT 的 9 个未来方向。

 

1. 权限启用的 NFT

此前我们一直遵循 NFT 的一个模型：每个 NFT 在元数据中都有一个所有者字段，代表它的一个所有者。然而，单一所有者的配置会导致在使用 NFT 时缺乏灵活性。如果所有者想要出租 NFT 的实用性怎么办？如果发行者想要限制总 NFT 的数量但仍然让其观众广泛访问其服务怎么办？这引导我们转向了权限启用的 NFTs。

通过启用权限，我们指的是在 NFT 上通用化权限的方法。一个 NFT 可以有一个所有者，但也可以有专门针对潜在权利持有者、忠诚度赠予者等的字段。我们可以将 NFT 的实用性分解成特定的部分，让不同的玩家从中获得最大的好处。

EIP-4400 引入了 NFT 的消费者角色，通过为非所有者创建权限，使他们能够享受给定 NFT 实例的好处。主要用例来自元宇宙：土地所有者可以授权消费者使用他们的土地。它暗示了利用附加角色的潜力，以启用基于 NFT 租赁市场和 NFT 收益农场中的受益者用户关系。

EIP-4907 提出了可租赁的 NFT 的概念。它在 ERC-721 合约中包括用户字段和有效期字段，以便在一个 NFT 内实现精细的所有者-受益人关系。通过这个改进，一个人可以很容易地出租一个 NFT 或授权他人使用 IP。在这个 EIP 之前，NFT 持有者必须转让 NFT 以启用租赁，并仔细计算所需的担保以保护他或她的最终所有权。这种模型并不是最安全的，会导致 NFT 租赁市场表现得像期权市场：如果 NFT 的价值急剧上升，出借人可以选择放弃担保并获得 NFT 上涨的好处。

EIP-5023 创建了一个接口，用于创建被多个所有者共享的 NFT，称为可共享 NFT。当前的参考实现会发出一个共享事件，以便基于给定的令牌 ID 以铸造新令牌，并转移给接收者。虽然实现并不完美，但它指向了一个未来：NFT 的所有权可以细化到每个特定的功能或功能模块。所有者可以共享 NFT 授予的相同或不同部分的权利。此外，它可以应对当前的供需矛盾：NFT 需要稀缺性和有限的供应来稳定市场价格，然而，NFT 应该被共享，因此对所有人都应该是可访问的。通过可共享 NFT，例如音乐 NFT 的应用程序可能会实现既保留价格增值，同时通过共享功能向所有粉丝提供访问权限的目标。

简而言之，我们期待权限启用的 NFT 在租赁市场上的应用，期待 NFTFi 的变种，以及通过 NFT 分发粉丝的产品。

 

2. 关系启用的 NFT

除了在 NFT 的多个所有者和用户方面进行创新之外，我们还迫切需要实现多个 NFT 捆绑在一起属于同一所有者的功能。在游戏中，一组资产的价值或产出可能远高于单个物品。在元宇宙中，人们可能希望在多元宇宙之间进行传送，并仍然能够以兼容的格式访问其资产。如果 NFT 可以在 ERC-721 合约、应用程序和链之间进行组合，那么将会有一个巨大的市场通过 NFTFi 释放价值平衡。

EIP-5606  提出了多元宇宙 NFT 的概念，以在不同平台上实现多个相关 NFT 的通用表示形式。作为单个资产，它使用户能够捆绑和解绑任何 NFT 以支持收藏需求和实用性。它可以定义资产之间的关系和它们的关联性质，以实现更好的跨链和跨元宇宙互操作性。

EIP-6059 将捆绑的 NFT 进一步扩展为受父级控制的可嵌套 NFT，这在捆绑的 NFT 中添加了关系层。它通过指定控制父 NFT 的 EOA 和所有子 NFT 的树状结构，为捆绑提供更好的清晰度。它可以支持捆绑、标准化收藏、链上成员关系和委托，以增强 NFT 收藏体验和 NFT 实用潜力。

EIP-6150  提出了分层 NFT 的概念，类似于操作系统中的文件系统。它可以更准确地将 NFT 层次结构分层和分级。此外，它还提议标准化为每个层次结构的每个分层设置权限，以实现更好的 NFT 权限操作。

EIP-6220  创建了具有固定和可定制插槽的可组合 NFT，可以使 NFT 直接组合成一个实用或交易的资产。它可以支持游戏应用程序具备标准化的方式来装备角色，或任何 DApps 使用组合的 NFT 来创建新的用户体验或资产。

 

3. NFT 作为分期归属工具

代币一直是投资者和早期支持者获得项目股份和回报的媒介。然而，出现了更多的短期炒作行为，而非支持生态系统的健康增长。对于项目来说，使用加密本地方式来制定公平的股份分配方式很困难，或者一般人很难在 ERC-721 中轻松创建逐步所有权声明。归属 NFT 可以成为解决方案，它有巨大的潜力扩展到各种应用程序，将传统融资转移到区块链上。

EIP-5725  创建了可转让的解锁 NFT 接口，可以按照一定时间释放底层代币。这意味着 NFT 是解锁代币的载体，或者可以按照预定曲线进行解锁，以达到其最终使用价值。

EIP-5753  提出了一种可锁定的 NFT 扩展，以在锁定期间禁用代币转移。这可以在 Defi 借贷或收益农场中实现更安全的 NFT 抵押。持有人可以选择将 NFT 锁定在自己的账户下，而不是将其存入外部合约，以达到相同的结果，但协议风险更小，不易丢失 NFT。

我们期待着更多的金融结构能够被 NFT 所包容并丰富整个区块链市场。

 

4. NFT 作为实用工具

除了作为可行的授予工具之外，NFT 还被用作支持游戏应用和俱乐部会员资格的实用工具。NFT 实用价值的潜力是什么？我们期待无限量的实用价值，从 Web2 中继承用户的行为和特征。新的 EIP 被提出来支持 NFT 的实用价值。

EIP-5050  建议 NFT 应该通过行动消息和发现协议去定义相互交互的方式。这可以使创建者不断与持有者交互，或使游戏连接到其 NFT 角色。此外，它预示着 NFT 可能成为用户相互交互并将 NFT 用作电话或社交媒体的连接节点。代币合同将可被应用程序发现和使用，以便游戏和其他应用程序可以有一个与 NFT 互动的层。

EIP-5643  提出订阅 NFT，以嵌入到有效订阅的到期和重复支付计划。它将为 NFT 发行者提供稳定的收入流，而不是完全依赖于交易中波动的忠诚度费用。这意味着 NFT 创建者可以专注于开发可持续的商业模式，而不是专注于推动 NFT 并引发 FOMO 以赚取收入。此外，它还将帮助用户轻松管理他们的订阅，并能够通过早期支持有前途的项目而在 NFT 中获得资本收益。

 

5. NFT 作为身份 token

灵魂绑定代币和命名服务一直是链上身份表示的流行方式。它们都依赖于 NFT 来承载身份，并代表身份的独特特征和财产。EIP 一直在增加对 SBT 及其生态系统的支持，同时我们期望 zkID 技术堆栈，即链上隐私保护身份的技术堆栈，将很快准备就绪，并在 EIP 标准化管道中。

SBT 最初在 EIP-4671  中提出，旨在创建非交易型代币作为持有和成就的证明。它被开发为由一个机构发放的证书，不能被撤销或转让。然而，EIP-4671 未能成为以太坊的标准，被搁置了。它并没有消弭 SBT 的热情，反而在 SBT 领域启动了更直接的开发和 EIP。

EIP-5192 提出了灵魂绑定 NFT 的最小接口，以实现 SBT 在钱包实现和转移功能方面的标准化。它提出了通向 SBT 规范界面的最简单路径。这是目前 ERC 上 SBT 的现行标准。通过标准化，我们将看到更多开发者使用 SBT，以及更多 SBT 导向的应用程序和实用工具的创建。

 

6. NFT 用于更丰富的内容

目前，NFT 需要依赖外部存储来保存 PFP 或其他媒体，这导致在各种元宇宙和市场中展示和使用 NFT 时可能会出现互操作性问题，因为链接的文件可能会以不同的格式存在或不可用。我们认为，未来 NFT 本身将能够容纳更丰富的内容，以便在任何中介平台和多元宇宙中使用。

EIP-4955  是采用更丰富的内容来改进 NFT 的第一步：供应商元数据扩展。它简单地为 NFT 元数据添加了一个新字段，以便供应商可以自由存储应用特定的 JSON 数据，以及 NFT 市场和元宇宙可以通过呈现自定义元数据来利用 NFT。例如，元数据可以包括 NFT 的自定义 3D 表示或其他属性。

EIP-5489  提出了超链接扩展，为所有 NFT 添加了可点击功能，以将用户引导到指定的网页。如果 NFT 成为 Web3 世界中的主要媒体和信息载体，NFT 需要一种替代方式来附加比链上更多的内容。超链接标准是实现任何类型信息传播的重要一步。

EIP-5773  规定了一种多资产令牌的接口，具有上下文相关的资产类型。每个 NFT 可以根据访问模式以相应格式进行显示，例如将 PDF 文件显示为电子阅读器格式，将 3D 模型资产显示为游戏格式等。将不同上下文中的各种资产直接嵌入到 NFT 中，可以创造出更流畅、更充实的用户体验。

更丰富的内容可以完全提升 NFT 的体验。它为 NFT 的用户体验创造了更大的表面积，并且可以带来更多的创新和用例。

 

7. 实物资产的 NFT

实现区块链广泛应用的重要一步是连接现实世界和区块链世界。数字-物理（digi-physical）是一个常用术语，用于描述数字和物理体验与资产的组合。NFT 是数字-物理产品和服务关系的一个有前途的载体。

EIP-4519  提出了通过 NFTs 表示实物资产的接口，并具有生成或恢复账户的能力。它将 NFTs 与独特的物理资产联系起来，以实现与物理传感器和资产相关的应用程序。该规范是实现将实物资产完全集成到区块链加密方案中的强有力迹象，尽管还需要更多工作才能实现完全的物理层与区块链的融合。

EIP-5700  可以通过令牌绑定和跟踪到唯一资产，这可以创建有用的 NFT 捆绑的实物资产。例如，可以是植入微芯片的服装或数字注册的房地产资产。该标准还支持 NFT 的可组合性，通过赋予 ERC-721 和 ERC-1155 合约绑定的能力，从而支持唯一或非唯一的物理资产。

 

8. 具有高级度量标准的 NFTFi

随着 NFT 中权限、关系、锁定期、实用价值等方面的不断增加，NFT 的估值和交易需要更加精细的机制来体现市场对 NFT 各部分价值的不同评估。EIP 的不断推进和丰富显示了 NFTFi 的演进之路，未来将出现更多层次的细节和更精细的用户体验，同时也面临更艰巨的任务来确保平稳流畅的用户体验。

我们看到，未来的 NFT 需要和促进更好的市场、交易选项和收益农场算法的出现。

 

9. NFT 作为 EOA（Externally Owned Account）

最后，NFT 可以成为自己的实体。它可以作为持有人的钱包、身份或者通常的 EOA。这可以限制一个人在链上的追踪，建立 NFT 的历史和声誉，并使更多的 NFT 所有权结构成为可能。

EIP-6066  规范了 NFT 的签名验证方法，以便轻松验证 ERC-721 和 ERC-1155 合约的签名。它从本质上扩展了 NFT 的实用性，从一个要拥有的资产，变成了一个具有交互、支付和批准交易能力的 EOA。NFT 可以成为 Web3 世界中的管理者或角色，丰富当前的所有权体验。

我们可以想象，随着 NFT 成为一个主权链上实体，任何人都可以自由地建立 NFT 的知识产权。此外，使用关系或权限启用的 EIP 方案，用户可以创建层级签名或以全新的方式与 NFT 捆绑包交互。
