数字资产的独特性使得它们可以用来证明数字物品的所有权和稀缺性，从而为数字艺术家和创作者提供了新的收入来源。

Blur 在利用空投激励、挂单激励、自建交易市场与聚合器等多种手段的结合，超越了 Opensea。虽然 Opensea 在这之前是流动性最好的 NFT 市场，但 Blur 的综合策略使其在市场上获得了越来越多的关注。当前 Blur 的流动性解决方案是最好的，其市场和聚合器的结合为用户提供了更广泛的选择。这一点是非常重要的，因为在 NFT 市场中，流动性往往是关键所在，而 Blur 的流动性解决方案已经被证明是非常可靠的。

为了迎接冲击，Opensea 将手续费降至 0%，表明了其对竞争对手的重视。然而，这种策略可能会对 Opensea 的可持续性产生负面影响。可选版税是另一个战略板块。这使得 Blur 能够在市场上提供更多的选择，从而吸引更多的用户。细分的 Marketplace 难再有机会。

虽然在 NFT 市场上还有很多机会，但是像 X2Y2、LooksRare 以及 Uni V3（Genie）这样的细分市场已经难以再有机会了。这是因为这些市场已经被大公司和实力雄厚的竞争对手所占据，新进入的公司将面临巨大的挑战。

Blur 在 NFT 市场上的综合策略已经被证明是非常成功的。虽然市场竞争激烈，但 Blur 在市场上的表现越来越好，这表明了其策略的可行性和实用性。

我们将结合 NFT Marketplace 过去的发展轨迹，探索未来可能的范式。

 

Crypto Kitties Market 是最原始的 NFT 交易平台

 

Crypto Kitties Market 是最早的 NFT 交易平台，最初是作为 Crypto Kitties 游戏的一个扩展而建立的。Crypto Kitties（最早的 NFT）是一个基于以太坊的游戏，玩家可以购买、繁殖、出售数字猫。每只数字猫都是独一无二的，使用了 NFT 来确保其独特性和流通性。

它的生态系统由平台、用户、数字猫咪、交易市场组成。平台提供数字猫咪的创建、购买、繁殖和出售服务，同时还提供数字猫咪的展示、社交互动和交易市场。用户购买、繁殖和出售数字猫咪，并参与社交互动和活动推广。数字猫咪的品种、繁殖季节和竞赛活动也为平台增加了不少乐趣和互动性。交易市场为用户提供了数字猫咪的购买和出售服务，并提供了交易历史记录和价格走势分析。所以，Crypto Kitties Market 的设立初衷是为了完善数字猫的货币属性和资产属性。

Crypto Kitties Market 的发展非常迅速，也吸引了越来越多的用户和收藏家加入其中，带动了 NFT 交易市场的发展。除了 Crypto Kitties 之外，该平台还开始支持其他类型的数字资产，如数字艺术品、游戏道具等。

尽管 Crypto Kitties Market 的交易速度非常慢，这主要是因为它是基于以太坊构建的，而以太坊的交易速度和处理能力有限，提供的交易品种也有限。但是，Crypto Kitties Market 对 NFT 市场的发展和推广做出了重要贡献。它的出现为 NFT 交易市场的发展开辟了先河，也为其他更先进、更方便的 NFT 交易平台提供了启示。

NFT Summer 标志着 NFT 市场的爆发式增长和普及

 

2021 年的夏季，NFT 市场经历了一个快速的增长和普及期。在这个时间段内，NFT 交易量和 NFT 价格都创下了历史新高。Opensea 在 NFT Summer 期间迅速发展，并成为最大的 NFT 交易平台之一。在这个时间段内，OpenSea 的交易量和用户数都大幅增加，平台上的 NFT 价格也达到了历史新高。

2021 年的 NFT 交易总额达到了约 200 亿美元，创下历史新高。这个数字比 2020 年增长了约 10 倍。NFT 市场的主要平台包括 OpenSea、Nifty Gateway、Super Rare、Foundation 等。在 NFT Summer 期间，一些项目尤为受欢迎，如 CryptoPunks、Bored Ape Yacht Club、Art Blocks 等。

在 NFT Summer 期间，各种 PFP（Profile Picture）项目迅速崛起，吸引了大量的用户和投资者。PFP 是指以数字形式呈现的头像图片，可以用于社交媒体、游戏或其他在线场景。但是，这些 PFP 项目并不仅仅是简单的头像，而是一种身份认同和社群建设的象征，类似于在现实生活中穿戴的时尚单品。

于是，一场疯狂的抢购战就在 NFT 市场上展开。投资者和收藏者纷纷加入，以数百万美元的价格购买各种 PFP 作品，以显示自己的身份和社会地位。即使有些作品的设计看起来甚至有些奇怪，但在 NFT 市场上却能够获得高价。有些人甚至为了买到心仪的 PFP，不惜花费上千美元的手续费。

然而，NFT Summer 并不是一个平静的夏季。随着投机情绪的升温，一些 PFP 项目的价格开始出现暴跌，投资者和藏家纷纷抛售手中的作品，市场情绪开始出现动荡。一些 PFP 项目因为缺乏足够的社群支持而无法生存下去，它们就像在海洋中的小船一样，最终被大浪淹没。在 NFT Summer 之后，人们开始反思这场疯狂的数字艺术狂潮，一些人认为这只是一种短暂的投机行为，而另一些人则认为这标志着数字艺术市场的新篇章的开启。

不管怎样，NFT Summer 是一个充满了机遇和风险的时期，它展现了 NFT 市场的潜力和魅力。

PFP 引爆 NFT 交易

 

NFT 资产累计交易额约为 400 亿美元，其中 PFP 交易金额超过 250 亿美元，占比超过 62.5%。这个数据表明，PFP 在 NFT 市场中的交易量和交易金额占据了非常大的比例，也反映出人们对于个人身份和数字形象的重视和需求。同时，这也意味着在 NFT 市场中，PFP 是最受欢迎和活跃的资产之一，成为了市场的主要推动力之一。

从经济学角度来看，PFP 的火爆主要与供需因素有关。首先，由于 NFT 市场的快速崛起，越来越多的人开始注意到 NFT 的投资价值，并愿意为其支付高昂的价格。其次，PFP 市场的供给相对较少，因为 PFP 是由个人或团队进行设计和发行，其数量通常受到限制。因此，PFP 的供给相对较少，但需求却很高，导致价格不断攀升。然而，随着 PFP 市场的扩大，越来越多的设计师和团队正在涌现，为市场带来更多选择和竞争，进一步推动了市场发展。

从社会学角度来看，PFP 的火爆也与社交因素有关。PFP 不仅可以显示个人风格和身份认同，还可以作为社交资本的一种形式。许多人在购买 PFP 时，会选择那些与自己身份认同或兴趣爱好相关的设计，以便在社交圈中获得更多的关注和认可。此外，由于 PFP 的供给量有限，一些设计受到的欢迎程度往往较高，因此拥有这些受欢迎的 PFP 也可以成为社交资本的一种形式。随着 PFP 市场的发展，人们对 PFP 作为社交资本的认识也在不断提高，这进一步推动了市场的火爆。

这对于 NFT 的发展和未来有一些启示。首先，随着数字化程度的不断提高，人们对于数字身份和数字资产的需求将越来越大，因此数字艺术品和数字收藏品等 NFT 资产的市场潜力将不断释放。其次，随着技术的不断进步和普及，更多的人能够参与到 NFT 市场中来，从而进一步推动市场的发展。最后，PFP 作为 NFT 市场中的主要资产之一，也表明了市场的一些偏好和趋势，这为 NFT 市场的投资和经营提供了一些参考和指导。

OpenSea 成为 NFT Summer 的龙头 MarketPlace

 

先发优势。Opensea 是较早建立的 NFT Marketplace，于 2017 年成立，并且得到了一些著名资本的支持，并在 2022 年初获得 130 亿美金的高估值。这使得 Opensea 在 NFT 热潮开始前就已经建立了一个较大的用户群体和收藏者受众，这使得该平台能够迅速地吸引更多的卖家和买家。Opensea 提供了种类最广泛的 NFT，包括收藏品、PFP、虚拟地产、游戏物品、音乐、电影和其他收藏品。这使得平台能够吸引有多元需求的用户，并让他们在同一个平台上进行交易。

Web2 和 Web3 的桥梁。Opensea 的用户界面非常简单易用，这使得不熟悉区块链技术的人也可以轻松进行交易，在一定程度上降低了 NFT 市场甚至是 Crypto 的准入门槛，为 Crypto 行业带来了一定的增量资金。同时，Opensea 也提供了一些交易工具和资源，帮助用户更好地利用 NFT。

布局多链。虽然以太坊 NFTs 是最大 NFT 生态，但 Opensea 在多个公链上的提前布局建立自身更强的护城河。Opensea 支持多种区块链，包括 Polygon、Arbitrum、Fantom 等。这使得用户可以选择最适合自己的区块链进行交易，并可以享受更低的交易费用。

Opensea 提供了 NFT Marketplace 的最早解决方案，但受限于传统的运营模式。Opensea 从建立之初就明确表示不会发币，因为其采用的是传统的股权融资方式，股东的退出方式也将是传统形式，而非代币形式，所以其资本运作属于传统金融范畴。此外，其收入主要来自于交易手续费，虽然在 Blur 出现之前一直保持 2.5% 的较高的交易手续费，但为了应对 Blur 对市场的冲击将其降至 0%。综合来说，Opensea 更像一个在 Web3 世界套用 Web2 运营模式的布道者，但目前看来，Opensea 的发展状态确实有点「水土不服」。

LooksRare、X2Y2 利用吸血鬼攻击抢占市场份额

 

LooksRare 和 X2Y2 相继上线，采取了通过向 Opensea 用户空投代币的方式，以获取初步流量积累的策略。之后，它们推出了各自的挖矿奖励，试图占据市场份额。但由于奖励机制不断减少，最终导致真实交易量持续下跌。

尽管如此，LooksRare 和 X2Y2 仍然是与 Opensea 竞争的有力对手，因为它们通过优于 Opensea 的用户体验来实现这一目标。除了基础 NFT 买卖交易外，它们还推出了批量上架、批量购买等附加功能，并集成了其他交易工具，方便用户对 NFT 的稀有度进行查询。与 Opensea 相比，这两个平台的交易手续费较低，这对于那些真实交易和转账的用户来说，更加友好。不过，这也可能导致平台存在一定程度的刷量交易。

总的来说，LooksRare 和 X2Y2 的设计理念是将 Marketplace 设计为「淘宝商城」的模式，即提供更便利和完善服务，收取更低的手续费。

当涉及到低价 NFT 交易时，批量交易是一种更为适合的交易方式。这是因为批量交易可以减少单个 NFT 交易所需的时间和劳动力成本，从而降低交易的成本和费用。另外，批量交易还可以增加交易的效率和速度，使交易更为迅速和高效。

然而，在进行批量交易时，需要注意征收适当的手续费以维护平台的正常运营和发展。手续费的收取应该在合理的范围内，既要能够维护平台的运营，也要能够让交易者承受得起。在批量交易的过程中，刷单现象也是需要引起重视的问题。刷单现象的出现会导致真实交易量持续下降，从而影响整个交易市场的正常运转。因此，需要采取措施来防止和打击刷单行为，维护交易市场的健康和稳定发展。

整体来说，LooksRare、X2Y2 不是从功能性的差异化入手，而是从代币经济的角度切入，抓住 Opensea 没有平台代币这一明显短板，实施了更具有 Crypto Native 的策略，但随着边际奖励的减少，业务变得不可持续。这也给 Blur 的成功埋下了伏笔。

聚合器的故事

 

Gem 是⼀个 NFT 聚合器项⽬，是在 Blur 上线之前最⼤的聚合器。 它提供了⼀个平台，让⽤⼾可以轻松发现和购买不同 NFT 市场和平台上的 NFT。类似于 Blur，Gem 聚合了多个主流 NFT 市场的流量，并以较 低的成本实现批量购买 NFT。这可以帮助⽤⼾在不同的 Marketplace 上获得最好的交易，同时也为 Gem 本⾝带来更多的流量和收益。Gem 具有导流作⽤，可以将⽤⼾从不同的 NFT 市场和平台引导到⾃⼰的 平台上，这可能会形成⼀定的流量劫持效应，使 Gem 成为⼀个聚合⼤量 NFT 流量的中⼼。在 2022 年 4 ⽉，Gem 被 Opensea 收购，但保持独⽴运营。这意味着 Gem 将成为 Opensea 的⼀部分，并受到 Opensea 的⽀持和资源，但仍将继续提供其独特的功能和服务，以满⾜不同⽤⼾的需求。作为 Opensea 的⼀部分，Gem 可以更好地服务于 Opensea 的⽤⼾，并扩⼤其影响⼒和市场份额。

Genie 是最早的 NFT 聚合器项⽬，与 Gem 具有相似的功能和定位。 与 Gem 相⽐，Genie 聚合的 NFT 市场和平台数量较少，但仍然能够为⽤⼾提供⼀个⽅便的平台，让他们可以轻松发现和购买不同 NFT 市场 和平台上的 NFT。在 2022 年 6 ⽉，Genie 被 Uniswap 收购，成为 Uniswap 的⼀部分。Uniswap 是⼀个基 于以太坊区块链的去中⼼化交易所，通过智能合约实现资产交换和流动性提供。收购 Genie 可以帮助 Uniswap 扩展其服务范围，并为⽤⼾提供更多 NFT 相关的⼯具和服务。这意味着 Uniswap 可以利⽤其 在去中⼼化交易领域的领先地位，吸引更多⽤⼾并为其提供更多 NFT 服务。同时，使⽤ Genie 作为⼯ 具，Uniswap 可以提供更好的 NFT 浏览和购买体验。此外，与新兴的 NFT 市场合作可以帮助 Uniswap 扩 ⼤其⽤⼾基础并增加收⼊来源。

整体来说，Gem 的 Genie 的功能较为单⼀，可替代性强。此外，两个平台都未发⾏代币，从⽽⽆法利 ⽤代币驱动业务的持续发展。然⽽，在收购后，Gem 和 Genie 都可以借助其⺟公司的⽀持和资源来扩展 其服务范围，并为⽤⼾提供更多的功能和服务。这将有助于它们在竞争激烈的 NFT 聚合器市场中保持竞 争⼒并实现⻓期发展。

Blur 的横空出世

 

Blur 的目标人群是 NFT 专业交易员、鲸鱼玩家，以及普通用户（虽然普通用户人数较少），这种目标群体的定位从一开始就跟市场其他平台迥异。该平台的模式是 Marketplace+Aggregator，旨在将多个市场和平台聚合在一起，为用户提供更加便利的体验，所以在这种模式下，NFT 做市商和 LP 提供者会在一定程度上获益。

除此之外，其经济模型也值得一提，其中包括空投激励、版税费用激励和挂单激励。这些措施的目的是减小挂单缺口，为 NFT 订单提供稳定的流动性。但笔者认为 Blur 做的最好的策略是对预期的管理。比如平台第一季空投的目标是激励智能挂单，第二季空投的目标是激励 Bid pool，第三季是激励做市。而这一系列操作的核心点是，规则模糊，预期永远。

此外，Blur 的费率为 0，同时 Gas fee 也非常实惠。用户可以轻松扫货，同时交易工具齐全（包括数据分析面板）。此外，相较于其他聚合器，Blur 的交易速度更快，为用户带来更快捷的交易体验。功能上的差异化为 Blur 区分了使用人群，更专业的交易深度图表、监控流动性和地板价的工具更适合专业的交易员。

通过独特的产品定位、产品设计和空投发放方式，Blur 初步创造了一种与 Opensea 不同的定位，解决了差异化不足的问题，在众多 NFT 交易市场中脱颖而出，然而 Blur 真正解决的问题是流动性不足的问题。

整体来说，Blur 既做到了差异化的功能性改进，也做到了代币的预期激励，在一定程度上也改善了 NFT 流动性不足的缺陷。

最近 3 个月 NFT MarketPlace 的日均交易量和市场份额

 

当我们在 Web 2.0 的背景下想到亚马逊时，脑海中浮现的是琳琅满目的商品、高效快捷的物流以及人性化的售后服务。NFT 本质上是一种消费品 / 商品，为 NFT 提供买卖平台的场所的特征与电商平台相似。因此，我们认为，NFT 市场可以看作是 Web3 的亚马逊。

首先，电子商务有几个关键的商业特征，使企业能够在线销售他们的产品。其中包括在线品类和产品信息、购物车和结帐系统、安全支付处理、订单管理和履行、客户关系管理、分析和报告以及个性化和定制选项。通过利用这些功能，企业可以创建强大的在线商场、高效地销售产品或服务、管理订单和库存、建立客户关系以及优化营销和销售策略。

此外，NFT 可以被认为是一种商品。商品被定义为可以买卖的原材料或初级农产品，例如黄金、石油或小麦。另一方面，NFT 是独特的数字资产，代表特定数字项目（例如艺术品、音乐甚至推文）的所有权或真实性证明。它们可以像其他商品一样买卖，其价值由市场供求决定。

与传统商品类似，NFT 的价值会因各种因素而波动，例如基础数字资产的受欢迎程度、艺术家或创作者的声誉，或者 NFT 本身的稀有度。此外，NFT 可以作为分散投资组合的一种手段，或作为潜在经济收益的投机资产。

总的来说，虽然 NFT 是一种独特的数字资产类型，但从它们在市场上买卖的意义上来说，它们可以被视为一种商品，并且它们的价值由市场力量决定。所以，可以认为 NFT 首先是一种商品，其次才是具有投资属性的资产。

有两个关键因素有助于 NFT Marketplace 的成功：流动性和用户粘性。在流动性方面，一个市场需要有足够数量的买卖双方来保证交易的深度从而保证交易的顺利进行。至于用户粘性，这在很大程度上是由代币经济模型驱动的，从这个角度出发的策略的最终结果不一定能转化为用户之间深厚的「忠诚度」。但是，一旦平台的流动性有所改善，再加上代币经济模型的催化作用，平台的流动性将持续形成正反馈循环，直至边际套利机会消失。

因此，我们认为 Blur 是一个现象级的项目。随着该领域的发展，我们可以期待看到具有更好性能、更快订单交易和更低总体成本的 Marketplace。

 

OpenSea 输给市场

 

更新迭代的速度跟不上市场需求变化的速度。这意味着 Opensea 在更新其平台和功能以满足市场不断变化的需求方面进展缓慢。Opensea 在早期凭借着较好的流动性深度以及能够提供品类更齐全的 NFT 资产领先着市场。但 NFT 市场非常不稳定，并且容易受到需求突然变化的影响，无法跟上这些变化的平台可能会失去客户给竞争对手。本质上，Opensea 无法在交易性能上做出超越其他项目的东西，因为市场总会出现 Fork 的产品。

没有代币经济。代币经济是指使用代币作为交换和激励手段的系统。Opensea 目前没有代币经济，这可能会限制其吸引和留住有兴趣在平台上赚取或使用代币的用户的能力。LooksRare、X2Y2 对其进行的吸血鬼攻击并且吸引了一批用户过去就是直接的例证。

脆弱的用户粘性。用户粘性是指用户对特定平台或品牌的忠诚度。Opensea 的用户粘性很脆弱，这意味着用户不一定忠于平台，并且可能对投机性投资（即购买 NFT，希望以后出售以获利）比对平台本身更感兴趣，换句话说，使用 Opensea 的大多数用户对于能够通过不同平台进行套利的需求大于对平台本身性能的追求。Blur 正是瞄准这一部分用户的需求，进行了具有强预期管理的代币空投计划。

总体而言，这些因素表明 Opensea 可能难以在快速发展的市场中竞争，并且给予后发项目以启示。为了保持竞争力，Opensea 可能需要专注于改善其平台功能和用户体验，创建代币经济以激励用户参与（Opensea 发币可能性不大，但很大可能通过旗下的 Gem 发币），并建立更牢固的客户关系以提高用户粘性。

最近 2 年 NFT MarketPlace 的市场份额

 

Blur 能走多远

 

NFT 市场面临的最大挑战之一是确定 NFT 的价值。与传统资产不同，NFT 是独一无二的，没有其他内在价值的支撑。因此，确定 NFT 的底价或公允价值可能很困难。这种缺乏透明度使得很难进行额外的衍生品交易或二级市场交易，因为买卖双方可能无法就资产的价值达成一致。Opensea 和 Blur 等试图通过为 NFT 交易提供透明且值得信赖的市场来解决这个问题。

Opensea 是最早的 NFT 市场之一。该平台通过允许用户构建不同的 NFT 并培养社区文化。这种方法成功地建立了忠实的用户群，Opensea 的成功为 LooksRare 和 X2Y2 等其他市场提供了范式，它们采用了类似的模式，但增加了代币经济来推广自己的产品。

Blur 是另一个 NFT 市场，它更侧重于投机而非收藏。这些用户的底层目的是来 Blur 赚钱，他们不关心持有的 NFT 类型，只要它有底价即可。Blur 被视为投机者的平台，投机者对价值发现和进行有利可图的交易比对建立收藏更感兴趣。

因此，我们认为 NFT Marketplace 的护城河不深。

 

下一个现象级项目在哪里

 

当下，我们可以将有做市商、LP 和交易员参与的平台看作是专业化的 NFT Marketplace，代表项目为 Blur；而那些仅提供最基础的 Mint、Collect、Buy 和 Sell 的平台看作散户化的 NFT Marketplace，代表项目 Opensea。事实上，NFT Marketplace 的竞争也是集中在两者。对于专业化的 Marketplace 而言，能否给交易者更稳定的交易深度以及更专业的交易工具是其需要注重关注的要点。而对于散户化的 Marketplace 需要思考如何为平台赋能，给平台带来持续的流量输入。因为初期的流量导入是 NFT Marketplace 能否起步的关键因素。

综上，我们做出以下结论性的预测：

NFT 市场未来发展的一个趋势是垂直细分平台的出现。这些平台将专注于特定类型的资产或市场，例如游戏 NFT、体育 NFT 或音乐 NFT。通过专注于特定市场，这些平台可以提供更多量身定制的服务并吸引相对应的用户群。

另一个趋势是新交易资产的出现。不仅仅是 PFP（个人资料图片 NFT），随着 NFT 市场的不断发展和演变，新型资产将会出现并成为投机的对象。

在技术发展方面，需要更高效、功能更健全的 NFT Marketplace。目前，大多数 NFT 市场使用相同的 AMM/ 债券曲线协议，这些协议可能会受到操纵和效率低下。可能会出现新的协议，提供更透明和高效的交易机制。

最后，由于以太坊区块链的网络效应和已建立的用户群，多链 NFT 和 L2 NFT 在与 ETH NFT 的竞争中可能面临挑战。然而，随着其他区块链继续发展并获得牵引力，可能会有跨链交易和互操作性的机会。
