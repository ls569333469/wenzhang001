作者： Simon de la Rouviere

编译： Kxp，律动 BlockBeats

 

NFT 创意宇宙正处于疯狂实验阶段：强调自由 IP、新型经济与重新组合。随着这些宇宙的发展，想要取得成功主要依赖于以下三个要素：

 

1、宽松式许可，主要为知识共享零版权（CC0）的形式。这种模式将鼓励创造性进行重新组合，对原创者和模仿者都有好处。

2、关注能够激发想象的低保真度及元数据，而较低的保真度保证了重新组合能有更具像化的诠释。

3、通过将元数据分类到链上包中，项目可以经捆绑后指导扩展。

 

这让我感到非常兴奋，因为如果把这三个要素结合在一起，就能形成令人难以忽视的全新媒体特许经营权。它将打造自由、丰富的 IP，并为所有合作者创造财富。接下来，让我们深入了解一下这三个要素：

 
一、正统性与 CC0 NFT 飞轮

 

一个 NFT 参考了一个典型解释：例如，定期发布的文件链接或链上图像。NFT 的所有权与被引用图像的版权是分开的，在许多情况下，无论 NFT 经历了什么变动，版权都由原创作者保留。这样一来，NFT 持有者就只能享有被引用图像的所有权，而不能以任何其他方式使用该图像，尤其是商业性使用。

NFT 价值来源于它所表示的内容，区块链上不可更改的时间戳引擎可以正统化特定的参考物。人们把各类「信号」进行了编码，这让人们虽然知道参考物没有代币价值，也想去拥有它。

虽然图像本身通常是不可改变的编码，并增加了很大一部分的可取性，但 NFT 由谁「签署」也是非常重要的事情。NFT 大部分的价值是通过特定个体的时间戳加密签名的合法性而产生的，而这也印证了「签名」的重要性。它是一个焦点引擎，可以随着时间将社会关系嵌入到文化对象上。

这个建立在签名文化对象所有权上的合法性引擎也赋予了衍生作品以权力。

以前，衍生作品的创作者往往需要满足以下条件：

1）不能将衍生 IP 商业化；

2）不能拥有他们向上游输送的任何收益（衍生作品向上游输送关注度，并成为原创作者的潜在收入来源）。

对原创作者来说，默许衍生作品就意味着他们可以接受失去对潜在收入及自身创意的控制，但劣质的衍生作品也会给他们带来负面影响。

对于使用传统版权的 NFT 的衍生作品，这些激励因素仍然存在，但是，如果原创作者允许知识产权的自由商业化，这种激励效果就会变得更强。有了 NFT 以后，正向激励的价值激励效果还会变得更强，这是因为：衍生作品创作者不仅可以从他们的衍生作品中获得收益，还可以从他们向原作上游输送的关注度中赚取回报。

如果衍生品创作者拥有原始作品的 NFT，他们可以赚取两倍的收入。这就像你成功创作了一个衍生的哈利波特故事续集，就能从哈利波特魔杖的销售额中获得收益。在某些情况下，这是有可能发生的事情（例如，如果你拥有迪斯尼的股票并创作了一部优秀的《星球大战》衍生作品）。当然，这只有在你能创作衍生作品的情况下才是可行的；也就是说，随着更多的人加入，CC0 模式将更具前景。

原创者也希望如此，因为这样一来他们不仅可以在二次销售中赚取版税，从上游的价值增长中获利；还可以得到更多的关注，为未来作品的销售（原创或衍生品）做好铺垫。

飞轮（flywheel）的具体过程如下：

- A 创作 CC0 内容 

- A 将 CC0 内容的 NFT#1 出售给 B 

- B 决定创作 CC0 的衍生内容 

- B 将 CC0 的衍生内容 NFT#2 出售给 C 

- C 非常喜欢这个衍生作品，决定购买原版 NFT#1 

- 因此：A 从销售中获得版权费，B 从销售衍生作品+销售原始 NFT 中获得收入，C 则收藏了两个版本的 NFT 

- C 决定创作 NFT#2 或 NFT#1 的衍生作品并进入下一轮的循环

这种模式在各类 NFT 项目中都得到了实践。虽然它还处于早期阶段，但许多项目已经采纳了这一模式：顺应趋势开始重新组合自由 IP。

二、借助保真度与元数据进行扩展

 

当你还是个孩子的时候，一根树枝在你眼里都有无限可能：可以是一把剑、一把枪，或者一根魔杖。然而，一把塑料玩具剑就不可能成为一把真正的枪。有时候，物体越抽象，它能被重新组合或解释的可能性就越大。所以说，更高的保真度并不总能成就更好的图像。

2022 年 4K 高清版本

90 年代的 CRT 电视版本

为了扩展与传播，典范参照物的可解释性越强，传播起来就越容易。这就像是树枝可供发挥想象的空间比高保真度的玩具要广阔得多。

以 Chain runners 为例，他们自己的一个扩展包正在增加其典型参照物的保真度。

我们可以注意到的是，HyperLoot 的概念艺术衍生作品为 Nouns、CrypToadz 和 Blitnauts 提高了分辨率。

许多 NFT 游戏正在往这个方向发展。

游戏行业内一些批评者认为，你不能通过游戏重新使用 NFT，因为这不是游戏该有的运行方式。虽然这是真的，但却并不重要，因为有了 CC0 以及基础层面的低保真度之后，在游戏中使用 NFT 只是为了重新解释经典的图像/文件。有些项目仅仅是让你访问可以在游戏中使用的额外文件，但即使如此，也没有必要。Chainrunners XR、Meebits和Forgotten Runes都为你提供了相应文件，但如果是 CC0 的话，一个重新组合而成的作品不需要依赖经典的文件/图片。

价值来自于重新阐释，而如果典型参照物保真度越低，重新解读就会越容易。在未来，NFT 项目在发布经典版本时只会披露一些特征，而其首个衍生作品只是一些概念性的图像展示。于是，之前只有一个系列的收藏，现在变成了两个。

唯一的问题在于，我们可能会失去对创意的控制。因此，这个飞轮并不适用于所有的创意作品。有些项目愿意将创意的控制权转手他人，但有些则不愿意。你仍然可以在一些宽松式许可项目中看到这种对立关系，比如 Fluf World（不属于 CC0）。

AngelBaby 是 Fluf World 的一个衍生角色，这些 NFT 在音乐项目中的应用发生了很大变化：可用于创建虚拟乐队/艺术家。

 

这是来自 Fluf World 的知识产权协议：

只要您掌握相关 NFT 的所有权与控制权，就能拥有对 FLUF 和该特定角色底层艺术作品的非独家商业权，正如我们的许可协议中所规定的那样。未经 NF Labs 团队明确的书面许可，您将不能拥有使用 FLUF World 品牌或其任何注册商标的任何权利，包括 FLUF 的 logo。NFT 的所有权将完全由我们的智能合约来调控。在任何情况下，我们都不能扣押、冻结或以其他方式修改任何 NFT 的所有权。

您可以将一部分权利转让给其他商业项目，但您 NFT 的传送将受制于您已经转让的那些权利。您可以将您的 FLUF World 角色印到服装或商品上、将其放入视频游戏和视频项目中，或者拿它做任何事情。您不能在任何商业产品上使用「FLUF」这个名字，除非直接连接到您的 FLUF 的名称或号码，表明您拥有该 NFT。您不得在任何涉及仇恨言论、种族主义、色情或任何非法内容的项目或衍生作品中使用您的 FLUF。

这些规定相当合理，因为任何一个充斥着仇恨言论的衍生作品都会影响整个项目以及所有后续的衍生作品。我们无法真正规避这类风险，但我们可以不断强化项目的风格特性，这样衍生作品也会跟着变得积极阳光，有了进一步扩展的可能。

目前为止，我所描述的大多数项目主要是头像或身份项目。就其性质而言，它不一定会大范围传播。兼备 CC0 和低保真度肯定会更有助于扩展传播，但保持原样也完全可以了。比如说，Chain Runner 就不会强制你去为其宣传。目前，这些项目中有许多是社交俱乐部，并希望扩展到元宇宙当中（如 Yuga Labs 的 Otherside）。因此，它们会邀请你使用它们的 NFT，并把它设置为你在 Twitter 和 Discord 上的个人照片。

不过，头像项目只是其中一种项目类别，我们还有很多类别尚未探索。在我看来，我们必须先有头像，但在有了头像以后，就可以开始探索其他项目了。要想让元数据至上的方法充分发挥作用，我们必须将元数据层置于链上。目前，对于许多项目来说，元数据都是是独立存在的。这是一个用于扩展的 API，但只不过是以 web2.0 的方式进行，而且它并不存在于相同的模块化框架中。如果 NFT 世界的元数据存在于同一模块化框架中的话，相互组合在特定方向上进行扩展将会变得更加容易。

除了头像之外，战利品组合也是新的发展趋势。让我们来看看 Loot 和 Dopewars 是如何利用这些组件，通过 CC0、低保真度以及向特定领域扩展来建立广阔的 NFT 宇宙的。

即使在 NFT 空间中，元宇宙也不只有一个典型代表了，几乎所有的 NFT 都与他们的经典解释进行了结合。例如，下图展示的是 Cryptovoxels 的区域地图：

但是，它并没有向你展示其中的内容，而且，它与链外元数据相链接，所以你不能在链上使用这些信息。在我看来，未来 NFT 宇宙的发展将主要依靠可消耗的链上战利品组合。而且，比起 Cryptovoxels，它可能更像是 Loot Realms。经验的解释将依赖于特定的 UI（或「观看器」），元数据将成为主流，之后才是解释。目前来看，所谓的元宇宙就是一个由元数据组成的多元世界。

我相信不久便会有标准出现，之后我们便可以利用这一标准对物品如何放入包中，以及相互之间如何拼合做出自定义的规定。

战利品组合只是借助分类进行扩展的其中一个例子，我们还有很多其他类别没有进行探索。真正的元数据地图将能够在一块土地上完成添加/建造/扩展等操作。未来，我们还会发现更多重新组合特定种类的 NFT 的方法。「记录册」将帮助我们捆绑元数据。随着时间的推移，会有更多的元数据被置于链上，我们可以跟踪并捆绑事件到特定的「记录册」当中，同时「记录册」的种类也会增加：利用链上事件讲述故事。

它将我们被标记上时间戳的共享、公共框架进行了可视化处理。而且，它就像一个巨大的故事宇宙，依据历史记录将我们的头像链接到了一起。

 

问题与结论

 

我的评估可能不那么准确。低保真度真的重要吗？著名的 NFT 收藏（如 BAYC）就没有低保真度的图片，也没有用包收集链上元数据，但这也没对它产生多大影响。因此在我看来，虽然这三个要素有一定作用，但更重要的是它所带来的更多可能性。Loot 就是是最典型的例子，但我不认为它会是最后一个。至于 CC0，它在长期来看可行吗，还是这个飞轮并不像我们预期的那样强大？链上元数据和捆绑能在多大程度上实现扩展？

这些问题将在时间中得到检验，而且最起码它为新兴文化提供了肥沃的土壤。在未来，有了时间戳引擎、开放的 API 以及自由文化，它们还会创造出多少可能？至少，在我们离开后的很长一段时间里，我们会把我们在这一路上结交的朋友嵌入其中。
