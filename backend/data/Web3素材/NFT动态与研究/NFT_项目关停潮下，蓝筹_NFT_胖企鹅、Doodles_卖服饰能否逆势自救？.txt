标题: NFT 项目关停潮下，蓝筹 NFT 胖企鹅、Doodles 卖服饰能否逆势自救？
链接: https://www.chaincatcher.com/article/2100472
发布时间: 2023-08-30

==================================================

撰文：Mia，flowie，Chaincatcher

 

超级IP 《精灵宝可梦》2022 年通过 IP 衍生品零售创造了超百亿美元的巨额收入。而在Web3领域，曾面临濒死危机的两大蓝筹 NFT，也不约而同地通过尝试 IP 衍生品零售，试图走向“从虚向实”的自救之路。

周一，胖企鹅 Pudgy Penguins 宣布已其服装品牌 Igloo 首发系列上线。这是继 Pudgy Toys 玩具品牌推出大获成功后，Pudgy Penguins 的又一次实体品牌尝试。

而近日，Doodles 也宣布与全球创新休闲鞋品牌 Crocs 达成合作，将陆续推出鞋子、可穿戴设备等。其中 Crocs 联名推出的限量款"洞洞鞋"将于本周发布，售价为 120 美元。

在NFT惨淡的当下，胖企鹅 Pudgy Penguins、Doodles 能通过卖玩具、卖服饰等IP变现能否实现逆势自救？

从虚向实，两大蓝筹 NFT 的自救之路

2021 年的 NFT Summer 中，胖企鹅 Pudgy Penguins 如日中天，曾一度每周交易量超过了 Punks 和 BAYC。但好景不长，2021年底开始，Pudgy Penguins 社区和创始团队矛盾重重，随着 Pudgy Penguins 持仓大户发出质疑创始人卷钱跑路的檄文后，愤怒之下的社区将 Pudgy Penguins 创始人 @ColeThereum 罢免，Pudgy Penguins 地板价跌至0.5ETH左右。

但摇摇欲坠的 Pudgy Penguin 随着易主而得以有新的一线生机。2022 年 4 月，Luca Netz 出价 750 ETH 购入了 Pudgy Penguins，并开启了一系列挽救 Pudgy Penguin 的动作。
除了在品牌曝光、社区增长中大展拳脚外，更值得一提的，Pudgy Penguin 在思考如何摆脱旁氏，打造出真正的消费品。

而深熊之下，Pudgy Penguin 没有局限在流动性枯竭的 Web3，而是看向了 Web2 IP 衍生品销售的变现玩法。要知道，漫威、宝可梦等 Web2 IP 巨头的收入来源主要来源是衍生品销售、游戏、 影视票房三大类，其中衍生品与游戏可以说是 IP 变现的两大引擎，相对于需要投入大量资金研发的游戏板块而言，衍生品的开发则显得物美价廉。《精灵宝可梦》2022 年通过 IP 衍生品零售创造了超百亿美元的巨额收入。

Pudgy Penguins 在 IP 衍生品销售上也取得不菲的成绩。今年 5 月，Pudgy Penguins 在社交媒体宣布，正式上线发布首个将 NFT 和区块链技术与实体玩具相结合的社区许可大众市场产品 Pudgy Toys、以及 NFT 数字平台 Pudgy Worlds，据悉，Pudgy Toys 是其第一个由社区支持的市场产品，每个玩具都可在其网站上进行数字体验。

据官方介绍，Pudgy Toys 售价从 8.99 美元到 24.99 美元不等，买家将获得一份“出生证明（birth certificate）”来解锁 Pudgy World 第一季上的特征盒（trait box），并获得灵魂绑定代币和NFT，据悉所有铸造过程将在Polygon区块链上进行，用户只需要一个邮箱，便可以注册区块链钱包，用户可以在网站上装扮自己喜欢的企鹅。

将“实物”与虚拟加密技术的绑定融合，使得 Pudgy Toys 一经推出就引发了不小的反响。据亚马逊网站数据显示，Pudgy Toys 在亚马逊推出之后两天内就售出超过两万个，销售额超过 50 万美元，一起本就略显可爱的企鹅形象一举在新品销量榜中战胜了芭比娃娃、乐高和宝可梦来到榜首。

目前，据亚马逊官网显示，Pudgy Toys 好评如潮，5 星评价占到了 9 成以上，算是初次尝试的成功，为 IP 的由虚向实迈出了第一步。获得初次成功后，Pudgy Penguins 近日又开始尝试推出自己的服装品牌 Igloo，据官网显示，产品涵盖了T恤、连帽衫、运动裤与配件等，从 Igloo 官网上看，首发系列服饰价格范围为 45 美元-120 美元，目前具体销售数据暂未公布，官方也并未披露更多细节，单从服装上来看这次仅为IP的授权联动，不会与链上进行联动。

无独有偶，另一个经历大幅下跌的蓝筹 NFT Doodles也在探索IP开发和实体商品零售，尝试在流动性枯竭中自救。而今年 Doodles 联创 Poopie 在社区中表示：“正在努力从一家新创公司发展成为一家领先的媒体品牌公司。我们不再是一个“NFT项目”。

今年 6 月，NFT 项目 Doodles 在社交媒体宣布与 CAMP 达成合作将在今夏推出交互式零售体验，旨在进一步连接 Doodles 社区的数字和实体领域。相关服务将首先覆盖纽约、洛杉矶和达拉斯等主要城市的 CAMP 实体店，Doodles NFT 持有者将有机会获得特殊访问权和福利，包括免费入场、商品积分、礼宾服务和定制创作的机会等。

与 CAMP 的联动标志着 Doodles 进军主流IP界的尝试，而Doodles 在实体领域的业务扩展早已布局已久。早在今年一月， Doodles 就宣布收购《瑞克与莫蒂》制作动画工作室 Golden Wolf，将探索动画之外的领域，例如体验设计、时尚和音乐等，进而推动打造下一波Doodles品牌。

而近日，Doodles 再次与休闲鞋国际 IP Crocs 合作，将于 8 月 29 日发售联名款限量版洞洞鞋推出，售价为 120 美元，购买者有权获得一件独特的 Crocs Box 数字藏品，将其销毁即可解锁两件 Crocs 可穿戴设备和一张 Stoodio Beta Pass 以便在 Doodles 2 中使用。此次实物产品发售是采用与 Pudgy Toys 一样的虚实相融的模式，为实物发售赋能链上相关权利，在用户享受实物体验的同时也享受到相应地数字体验与链上赋能。

NFT 项目关停潮下，拓展 Web2 IP 变现模式是正解吗？

NFT 的惨淡其实已不用过多赘述。Nansen NFT-500 指数今年迄今已下跌 40%，而Blue Chip 10 指数则下跌 33%。中尾部的 Recur、Cardinal、Rentable 和 Tessera 等项目也没能挺过深熊，选择关停。

而胖企鹅 Pudgy Penguins 实现了逆势增长。根据 coingecko 的数据，过去一年相BAYC、MAYC、Moonbirds 等头部蓝筹NFT地板价的集体大幅下跌 20%-90%，Pudgy Penguins 的地板价上涨了 35%。

Doodles 以为 IP 衍生品刚刚推出，目前还并未有足够的数据反应这一举措带来的效果。但在 NFT 深熊、关停潮下，也有不少 NFT 项目开始将中心转向 Web2 商业模式。比如国产NFT 项目小幽灵 Weirdo Ghost Gang 在《NFT 首次漫长深熊，项目接连死亡，路在何方？》的采访中提到，在熊市大环境下他们进一步调小了在 Web3 领域的发展比重，其将重心放在 Web2 商业模式，包括 IP 和潮牌行业。比如近期，小幽灵 Weirdo Ghost Gang 官宣与 DQ 联名推出限定冰淇淋与形象店专属优惠，与法国公寓酒店品牌 Citadines 达成合作，为活动参与者提供独家客房预订优惠福利。

通过漫威、宝可梦等 Web2 超级 IP 的实践下，扎实的品牌中的确无限的变现机会，可以衍生游戏、服装、甚至食品品牌等等，几乎一切皆可 IP 衍生。但NFT 拓展Web2 IP 的变现是正解吗？

一方面不少加密社区用户认为，在技术上这些蓝筹 NFT 都在专注 Web2 业务中也在远离Web3 的创新探索。NFT研究员@huntersolaire 断言，大多数尝试这种做法的 NFT 项目从一开始就注定会失败，而胖企鹅、Doodles 拥有有数千名名持有者的社区基础，则处境相对较好。“而2024 年或 2025 年最大的 NFT 将是那些弄清楚如何扩大其品牌规模，然后将部分价值分配给持有者的项目。”

但对于当下面临归零危机的 NFT 项目而言，在 Web3 环境还未回暖下，活着或许更重要。
