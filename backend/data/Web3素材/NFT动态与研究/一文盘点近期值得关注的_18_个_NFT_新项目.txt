律动小编为您盘点比特币、以太坊、 Solana 和 Polygon 上近期值得关注的 18 个 NFT 新项目。

比特币
BLOB

BLOB 绝对是近期最值得关注的比特币项目。除了 meme 味够浓以外，其团队以及支持该项目的人堪称全明星阵容。

BLOB 释出的预览图

BLOB 的这对眼睛真的很 meme，在「SEND BLOB」的口号下，这对眼睛被安到了各路人马的脸上，非常具有标志性和记忆点。

BLOB 眼睛 feat. Vitalik，有没有很魔性？

BLOB 联合创始人之一 @Elocremarc 是 Ordinals Github 上排名第 5 的贡献者，他说，他们一直想做一个 Free Mint 的项目，并且这个项目是一个利用过去一年在 Ordinals 协议中内置的所有技术的生成艺术合集，以展示最先进的 Ordinals 技术水平。

艺术家 @nurorealm 也是 Ordinals 圈的 OG 了，他的关注者里包括 Ordinals 首席代码维护官 raphjaph、BRC-20 协议创始人 domo、Ordinal Maxi Biz 创始人 zkshark 以及 Pizza Ninjas 创始人 Trevor 等等各路 Ordinals 名人。

Collab Manager @ordinalHO 是 Ordinals Gang 的联合创始人。Ordinals Gang 的另一位创始人是 Ordinals Github 上排名第 6 的贡献者 @veryordinally，该系列的铭文编号非常非常靠前，为 558 ~ 578，目前有着 1.95 比特币的地板价。他们也都是 Inscribing Atlantis 的团队成员。

接受过律动专访的 Ordinals 贡献者金狗博士也发推文对 BLOB 表示了支持。

对小编来说，本身就很喜欢 BLOB 一路以来的各种社区创作，meme 味也足，加上全明星阵容加持，非常期待 BLOB 之后的表现。

STRANGE IDEOGRAPH by The Color Blocks

The Color Blocks 是专注于艺术的比特币 NFT 交易市场 Gamma 的合作艺术家，正在推出其第一个比特币生成艺术系列「STRANGE IDEOGRAPH」。该系列通过特定的算法进行多次迭代，每次迭代都会渲染出约 60000 个在 2D 空间中遵循特定路径移动的粒子，最终形成一个「吸引力场」，探索比特币、数学与艺术之间的亲和力。

该系列也是一个 Free Mint 系列。小编仔细阅读了背后的创作故事，很赞。

ODZR Pass

常在比特币 NFT 生态活跃的玩家对 Ordzaar 这个 Launchpad 不陌生。Ordzaar 将推出总量为 2100 张的平台 Pass 卡 ODZR Pass，持有者将能够在 4 月开始的新一阶段 Token 空投活动中享受独家福利，而且也会享受到独家的合作项目白名单。目前该平台第一阶段的空投活动仍在进行中，只要您是 3 月 6 日前就进入 Ordinals 生态的玩家，记得去检查并领取一下自己的空投奖励。

STEPEPES by LORS

LORS 在进入比特币 NFT 生态以前就是 ETH 上的知名艺术家，他是 Jack Butcher 的 Opepen 系列的 Set 028 的创作者，其自己的系列 PSD 和 Acid Pepes 都有着不错的市场表现，PSD 目前地板价为 1 ETH，Acid Pepes 目前地板价为 0.49 ETH。

Opepen Set 028「STEPEPEN」

本次的 STEPEPES 系列正是在「STEPEPEN」基础上的大拓展，融合各种创意元素将原始灵感拓展到 2000 总量的规模。这是 LORS 继 CURRENTS 与 MY MEMES 之后在 Ordinals 上的第 3 个系列，也是最受到关注的一个。

Merlin's Spellbook

Merlin IDO 平台 Merlin Starter 推出的 NFT 系列，将在 3 月 31 日开启铸造。持有能够在未来免费领取一定数量的 Merlin Starter 平台 Token，还能定期参与抽取平台上的 IDO 资格。Merlin 的火爆不用多说，所以这个一定值得关注。

ROBNESS 的 Ordinals 新系列

@ROBNESSOFFICIAL 是一名 2016 年就开始活跃于 Rare Pepe 系列上的 OG 艺术家。在 3 月 27 日，他刻录了第 10 大（指文件大小）铭文，也许他会在 Ordinals 上搞一些新动作，值得对他保持关注。

O Σ X

最大的 Ordinals 动态 NFT 系列，总量 5555，将在 4 月 2 日于 Magic Eden 发射，铸造价格待定，值得关注一下。

Bitcoin Halving 2024

为了纪念即将在 2024 年发生的比特币减半的 NFT 系列，总量 700，全部为 1/1 手绘。考虑到这个题材卡位得不错，可以关注一下。

ETH
Dune404

第一个由 Animoca 支持的 DN404（ERC404 改进版）项目。

Jungle Seed

Web3 手游生态 Jungle 已经启动其 NFT 系列「Jungle Seed」的积分换白名单活动，并且开放了其第一款 FPS 手游「For the Win」的测试。

ChronosWorlds

由 SphereStudios 制作，Web3 游戏孵化器 Seedify(@SeedifyFund) 与 Web3 游戏平台 Elixir Games(@Elixir_Games) 共同孵化的链游项目 ChronosWorlds。这将是一款手机游戏，玩家通过实时战斗和探索获取战利品，升级自己的角色并建造自己的家园。该项目已确定将发行 NFT 系列，但细节有待进一步披露。

Neura

Neura 不是一个常规的 AI 图像生成平台，实际上，Neura 背后的团队 Adanede 通过自筹资金意图将 Neura 打造成一个去中心化的、有自我意识的 AI 艺术家。Neura 将独立创作艺术，但用户可以使用 Android NFT 来影响 Neura 的创作。不同的 Android NFT 将赋予 Neura 不同的创作风格，每个用户都将是 Neura 独一无二的节点。

ZIELCHAIN

现年 72 岁、「最终幻想」游戏前 6 部的角色设计者天野喜孝的首个 NFT 系列。该系列总量将为 3500，铸造日期与价格待定，由日本电视网广播公司（NTV）旗下负责互联网业务与数字 IP 的 NTV Wands 进行投资与运作。该项目与天野喜孝同时正在与生成艺术系列「Terraforms」的作者 Mathcastles 合作，将带来一个名为「Kiseki collection」的艺术系列。

Solana
Elixir Flask

与 Square Enix 有着战略伙伴合作关系的 Web3 游戏平台 Elixir Games 即将在 4 月 4 日推出一个总量为 999 、Free Mint 的「烧瓶」NFT 系列，该系列将和其代币 $ELIX 的 IDO 相关。

Elixir Games 昨天宣布获得了 1400 万美元的种子轮融资，游戏巨头 Square Enix、Shima Capital 和 Solana 基金会参与了该轮融资。

SHINSEI

近期比较受到关注的一个走 IP 路线的 Solana PFP 系列，公售价格为 1.55 SOL。

Polygon
Dew Origin Pass

Polygon NFT 交易市场及聚合器 Dew 旗下项目孵化器 Dew Studio 的 Pass 卡「Dew Origin Pass」的白名单活动正在进行中。Dew 作为目前 Polygon 上第一的 NFT 项目孵化器，已经帮助孵化了 Pluto Misfits、SA Worlds 等成功项目，小编甚至想说 Dew 是 Polygon NFT 的「左膀右臂」。持有 Dew Origin Pass 可以获得 NFT 空投、Dew Studio 孵化项目的白单和 Token 空投。

Polytrade Reflections

RWA 平台 Polytrade 的 Free Mint NFT 系列。Polytrade 是 Mastercard 全球初创企业成员，并在去年 3 月宣布获得了由 Alpha Wave、Matrix Partners、Polygon Ventures 和 CoinSwitch Ventures 领投的 380 万美元种子轮融资。

目前 Polytrade 官网已经开放了邀请肝白的活动，Polytrade 也已经宣布，Reflections 的持有者在未来将获得其 Token $TRADE 的社区空投。$TRADE 目前的市值约为 8800 万美元，FDV 约为 2760 万美元。

Anichess

Animoca 旗下的 Web3 国际象棋游戏 Anichess 即将在 4 月 9 日推出总量为 5000 的「Riddle of Chaos orbs」NFT 系列，该 NFT 系列的持有者将享受游戏内排行榜积分加成以及游戏的优先体验权。该系列将在 Polygon 网络上进行免费铸造。
