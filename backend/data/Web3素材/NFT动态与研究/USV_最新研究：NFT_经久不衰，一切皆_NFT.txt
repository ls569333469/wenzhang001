USV 于 2017 年开始尝试 NFT，最初帮助 Rare Pepes 在小众市场获得一些流行，然后 Cryptokitties 横空出世。在那次探索之后不久，我们投资了 Cryptokitties 背后的团队并写道：

我们认为，数字收藏品是区块链带来的众多令人惊奇的事情之一，而在这项技术出现之前，这些事情实际上是不可能实现的。

自互联网诞生以来，数字商品就是丰富充沛的代名词。所有权的概念只存在于具有独裁者的封闭系统的范围内。公共区块链的出现释放了拥有独特且完全由个人拥有的数字物品的能力——这个概念跟六年前一样强大。数字环境中的所有权和可验证来源具有变革性，而我们只是触及了这些想法的表面。

泡沫

NFT 于 2017 年爆发，正如你们许多人可能已经观察到的那样，在接下来的几年里发生了很多事情。以下是所有公链 NFT 每周二次销售量的视图：

所有链的每月二级交易量在 2022 年 1 月达到约 60 亿美元峰值，在 2023 年 10 月触底于约 3 亿美元，并于上个月反弹至约 17 亿美元 - 比特币和 Solana 生态系统的显着增长。

NFT，特别是作为收藏品的 NFT，经历了以资产泡沫为标志的大规模炒作周期。泡沫破灭，资产价格和二级市场交易量急剧下降，分别下降了 85% 和 95% 以上。2021 年市场处于极度风险、零利率的环境中，我们面临着特别剧烈的上涨和下跌。

如果这个故事听起来很熟悉，那是因为它几乎涉及所有新兴的创新技术。NFT 是加密生态系统的缩影，两者最近都经历了非理性繁荣时期。在卡洛塔·佩雷斯（Carlota Perez）（我们经常依赖他的开创性想法）的框架中，我们似乎正在经历这些技术的初始安装阶段，其中核心基础设施将继续铺设。

尽管经历了这段“疯狂”时期和资产价值崩溃，NFT 的核心理念仍然没有改变。它们是一种创新的基质，一种代表我们数字生活中不可替代的工具——门票、会员资格、收藏品、收据、艺术、媒体、点赞行为。

在我们看来，我们在加密货币中看到的各种泡沫，包括 NFT 狂热，是重大技术变革如何显现且不可避免的一部分。它们还提供了一个直接的好处：投机市场泡沫在一定程度上提供了建设下一阶段基础设施所需的资本。

创新

加密货币的大幅震荡有助于显现出该领域的问题，例如交易成本过高和普通消费者的可用性差，而剧烈的价格波动也有助于为这些问题的解决方案提供资金，并推动了我们继续建设和创新。

在过去 24 个月和经过多年的发展后，市场上出现大量的 Layer2 区块链，这是更便宜的区块空间和更快的最终确定性解决方案，同时仍然保留了以太坊强大的安全保证。Solana 推出了 NFT压缩方案，允许开发者和用户以约 1/100 美分的成本创建 NFT。嵌入式钱包（Embedded wallets）现在提供了一种在保持无需信任的情况下构建低摩擦加密应用程序的方法。ERC-6551等新标准允许 NFT 本身充当账户/钱包，为 NFT 开辟了设计空间。像 Arweave 这样的网络已经成熟，并在很大程度上解决了在链上存储任意内容（而不仅仅是元数据）的问题。

这些改进的最终结果是，NFT 领域正在迅速开放，与 NFT 的交互变得越来越便宜和容易。在许多情况下，我们现在拥有工具来完全抽象技术，并让用户参与由 NFT 底层支持的数字体验。艺术品和收藏品只是拼图中的一小部分，我们生活中的任何数字文物都适用，而且可能最终会被 NFT 替代。

艺术品和收藏品

数字收藏品（包括艺术品）是 NFT 最初在区块链上的采用方式。它们仍然是 NFT 的一部分，迄今为止几乎占据了 NFT 绝大部分的销量和市值。尽管存在资产泡沫，但它们并没有消失。

NFT 为数字艺术家和创作者带来了巨大的机遇，他们现在可以将自己的作品货币化，并满足对数字创作不断增长的需求。收藏家、投机者和赞助人最终可以拥有并无需许可地转让独特且稀缺的数字物品，这反过来又为许多此类资产创造了充满活力的市场。区块链提供的互联网原生金融轨道也使创作者更容易向全球受众出售作品。区块链还催生了新的艺术形式，并在与创造性工作（例如随机性）互动的同时催生新的元素。

此外，我们生活在一个数字世界，由于加密货币的影响，互联网原生资本池稳步增长，在人工智能的助力下，数字创作日益无处不在。这些趋势是帮助更多的人在数字对象中存储更多的价值。

行为转变

尽管交易活动和市值严重下降，但加密货币的创造步伐仍然强劲。每个月都有成千上万的创作者仍在创作数字艺术、生成艺术或人工智能艺术。每个月，加密货币用户都会从这些收藏中铸造作品。

我们还看到新的 NFT 行为出现。开放版风格的铸造活动通常是零成本，在 2023 年变得越来越受欢迎。例如，项目将在推出产品时在固定时间窗口内发布开放版系列。消费者选择铸造 NFT 并不是一种投机行为，而是一种表达支持的方式——消费者可能从中受益。在某些情况下，低成本/无成本铸造正逐渐成为一种新的社会原语，类似于“点赞”或“转发”。

这些新行为助力低成本铸造活动的持续增长。我们可以看到，尽管 2023 年二级交易量枯竭，但仍有更多用户铸造比以往更多的 NFT。这些趋势的一些代表性观点：

一切皆NFT

这篇文章的大部分内容都集中在 NFT 的特定部分及其复兴和演变上，但实际上，NFT 是一个可以代表几乎任何事物的底层支持。

以太坊名称系统使用 NFT 来表示身份。Uniswap 使用 NFT 来表示提供给资金池的流动性。Blackbird 将用户与餐厅的每一种关系表示为 NFT。Paragraph 将读者订阅表示为 NFT。Helium 代表了作为 NFT 获得网络奖励（即热点运营商）的资格。而这样的例子不胜枚举。

我们也很高兴看到更多以 NFT 为代表的行为和工件。从音乐会、电影到航空公司的门票，一切都应该是 NFT。任何可以从真正的所有权和开放、永久系统的复合价值中受益的东西。

值得一提的是，NFT 并不总是可转让的——例如，许多可重复使用的 KYC 提供商会发行Soulbound 代币。此外，NFT 并不总是必须代表数字对象 - 由于不可替代的现实世界资产寻求利用区块链，NFT 通常可以充当数字孪生，代表从交易卡到豪华手袋的所有事物。

NFT 与其他区块链标准一样，受益于区块链的开放性和标准的一致性。它们是便携式的，可以随用户移动到任何应用程序——而该应用程序又保证能够理解 NFT 是什么，对其采取行动，从而进一步扩展其效用。这也意味着，对于任何发行的 NFT，它都可以立即访问为此标准构建的所有现有工具。一般来说，这意味着创建的任何 NFT 都可以立即在交易所进行交换、借用或捐赠。

区块链数据的可组合性和开放性，以及扩展的 NFT，拥有巨大的潜力，但也并非没有问题。它们可以提供新颖的体验，并使应用程序能够更丰富地了解用户，但我们仍处于以保护隐私的方式构建这些系统的早期阶段。它们可以允许透明和程序化的价值转移，例如铸币费或版税，但它们也可以允许应用程序绕过这些规则（版税对创作者来说是一个福音，较新的生态系统选择在 NFT 标准级别强制征收版税）。

最后的思考

与之前的许多其他技术一样，我们正在见证加密货币（特别是 NFT）的持续发展和改进。我们相信，NFT 是一种极其简单但又极其强大的加密原语，是区块链独有的功能，我们对即将出现的实验和新体验深感兴奋。
