标题: Youtube 加入社交媒体巨头的「NFT」战事
链接: https://www.chaincatcher.com/article/2069418
发布时间: 2022-01-26

==================================================

作者：白泽研究院

 

在过去的一年里，NFT 的受欢迎程度飙升，几乎引起了所有行业的个人、企业和组织的关注。NFT 正迅速成为主流公众想要参与其中的一种现象。

Youtube 向 NFT 迈进

昨日，在线视频服务公司 Youtube 的首席执行官 Susan Wojcicki 发布创作者年度信，分享了该公司将创作者经济列为 2022 年的优先事项，以及致力于扩展“YouTube 生态系统”，帮助创作者利用新兴技术，包括 NFT 等技术。

在信中，Wojcicki 将 Web3 称为 YouTube 创新的“灵感来源”，她写道：“我们还展望未来，并一直关注 Web3 中发生的一切，以此作为继续在 YouTube 上创新的灵感来源。过去一年，在加密货币、NFT 甚至去中心化自治组织（DAO）的世界中，都突显了一个以前难以想象的机会来加强创作者与其粉丝之间的联系。我们一直专注于扩展 YouTube 生态系统，以帮助创作者利用新兴技术，包括 NFT 等技术，同时继续加强和提升创作者和粉丝在 YouTube 上的体验。 ”

Wojcicki 表示，NFT 可能是创作者的另一种收入形式。然而，她没有提供更多细节或时间。 

专注于虚拟音乐会的初创公司 Animal Concerts 的首席执行官 Colin Fitzpatrick 将 Youtube 可能的 NFT 整合描述为“创作者无需依赖广告收入即可通过其频道获利的好方法”。Fitzpatrick 认为：“如果 YouTube 打算在他们的平台上促进 NFT，那么他们的广告合作伙伴可能会强迫内容创作者货币化。引入 NFT 可能是他们规避企业利益并为用户提供替代方法来创收的一种方式。”

社交媒体巨头集体拥抱 NFT

NFT 领域的竞争正在升温，社交媒体巨头站在最前沿。

TikTok

作为全球最流行的短视频应用之一，TikTok 早在去年 10 月就推出了首个由创作者主导的 NFT 系列—

TikTok Top Moments。该系列聚焦于在娱乐、文化和社区中具有影响力的创作者及其热门视频，将他们的精彩时刻制作为 NFT 并发行，收益将主要直接捐给相关的创作者和 NFT 艺术家，旨在为粉丝和 NFT 爱好者提供一种向他们喜爱的创作者表示支持的方式。该系列 NFT 在以太坊上发布，由第 2 层扩展解决方案（Layer2） Immutable X 提供支持。

TikTok 全球营销主管 Nick Tran 表示：“在 TikTok 上发生的创作有助于推动文化并引发平台之外的趋势。随着创作者经济的持续增长，我们不断寻找新的和差异化的方式来支持我们的创作者。现在，粉丝可以在 TikTok 上拥有一个既帮助塑造互联网，同时也支持了他们最喜欢的一些创作者的时刻。我们很高兴看到我们的社区和 NFT 社区如何参与互联网上一些最受欢迎的文化里程碑。”

为此，TikTok 在《纽约时报》上刊登了整版广告，以促进其热度。广告的最后一句话似乎也揭示了该公司奖励短视频创作的下一步：“我们希望成为一个不断寻找创新方式来表彰和奖励我们的创作者的平台。”

Twitter

时间追溯到去年 9 月，社交媒体巨头 Twitter 首次公布了其 NFT 计划。当时，Twitter 表示身份验证可以让创作者在 Twitter 上更好地展示他们的作品，并表示正在探索。

上周， Twitter 正式推出了这项新功能，允许用户展示他们的 NFT。iOS 设备上的 Twitter Blue 订阅者可以将基于以太坊的加密钱包连接到他们的账户，并将他们的 NFT 设置为个人资料展示图片。该功能将很快推广到 Android 用户。然而，虽然目前只有 iOS 用户能够将他们的 NFT 设置为他们的个人资料图片，但 Twitter 上的每个人都能看到。

Twitter 使用第三方 API 从 OpenSea 市场获取用户的 NFT 数据作为验证。如果 OpenSea 对用户的 NFT 存在任何问题，那么 Twitter 将无法验证用户 NFT 的真实性。

 
Twitter Blue 订阅服务尚未在全球范围内提供，这将限制 NFT 个人资料图片的采用，仅限于该产品现已上线的市场——美国、加拿大、澳大利亚和新西兰。

该公司早些时候曾暗示其计划更全面地采用 NFT，因为这已成为该平台上的一个重要话题。可以预见的是，Twitter 正在“将自己定位为围绕 NFT、区块链和加密技术进行发现、对话和教育的社交网络”。

此次推出是在 Twitter 表达对“把去中心化技术融入平台”的兴趣之后，其中包括支持比特币作为打赏的小费。该公司去年还尝试铸造自己的 NFT，并免费发放给用户。

Twitter 的发言人在接受采访时表示：“Twitter 是人们谈论他们关心的事情的地方，通常是人们第一次接触加密货币和 NFT 的地方。我们现在看到人们将 NFT 用作身份的一种形式，并作为加入蓬勃发展的加密社区的一种方式。”

Meta

早在去年 8 月，Facebook 金融部门的负责人 David Marcus 就表示，该公司“肯定在考虑”这件事，因此 Facebook 首次就涉足 NFT 市场做出了重大暗示。

“当您设计需要面向未来的产品时，将元宇宙视为一个完全数字化的环境实际上非常有用。当我看到元宇宙需要什么时，它确实是价值的无缝流动，为此，我们需要一个新的基础设施，互操作性，因为你需要多个钱包能够参与一个元宇宙。而且我认为在区块链之上拥有可编程货币和智能合约将对元宇宙产生变革。因为如果您是创建者，如果您正在创建 NFT，您可能想租用您的 NFT 或出售您的 NFT，你可以想到各种新的商业模式，这些模式在当前的支付基础设施和智能合约的情况下是不可能的。”

在 Twitter 开始允许其 iOS 用户在他们的个人资料照片中显示 NFT 之后不久，Meta 也开始拥抱该行业。

据英国《金融时报》报道，Meta 公司（前身为 Facebook）正在讨论建立 NFT 市场的可能性，并研究允许用户铸造和销售 NFT，此外，Meta 计划允许用户在 Facebook 和 Instagram 平台上展示 NFT。

不过，相比于前面几位先行者而言，Meta 并不顺利，此举并未获得 NFT 领域艺术家的认可。

Serwah Attafuah 是一位专注于创作非洲未来主义抽象 NFT 的澳大利亚艺术家，曾在 Meta 子公司 Instagram 平台上拥有 20,000 名粉丝。随着 Instagram 上诈骗、数据隐私问题和侵犯艺术作品的版权问题成为常事，她最近在 Instagram 上的互动少了很多。 

世界上最畅销的女性 NFT 艺术家 Itzel Yard 表示，Instagram 上到处都是模仿者：“有人搜刮了我的 Instagram，他们从里面拿走了所有作品，把它发布到 OpenSea 上，然后他们开始试图出售它。”

一些 NFT 专家和艺术家表示，出于多种原因，他们对 Meta 的策略持谨慎态度。

罗格斯商学院的区块链专家和金融科技教授梅拉夫·奥扎尔认为，去中心化的艺术品销售“与 Facebook 这样的公司没有很好的共鸣”。

追踪 NFT 交易的平台 Nonfungible 的联合创始人兼总裁 Dan Kelly 表示，他对 Meta 进入 NFT 领域持“谨慎的怀疑态度”，但任何事情都有双面性，他认为 Meta 涉足 NFT 可能会进一步使 Web3 社区主流化，增强更广泛公众的接受度。 

NFT 浪潮延续

尽管自今年年初以来加密市场已经下跌了超过 5000 亿美元，但 NFT 市场似乎并未受到影响。

1 月 17 日，最大的 NFT 市场 OpenSea 报告了以太坊 35 亿美元的月交易量再创新高。

除了社交媒体巨头以外，例如 Tom Brady、Paris Hilton、Jimmy Fallon、Post Malone 等名人也加入了 NFT 浪潮之中，有些人推出了自己的 NFT 平台，有些则购买了<无聊猿>、<加密朋克>等顶级加密艺术品。此外，全球拍卖行、金融机构也在纷纷涌入。

现在，随着 YouTube 加入 TikTok、Twitter、Instagram 和 Facebook 的「NFT」战事，数字收藏品的未来值得期待，未来的发展空间可能会远超我们的想象。
