==================================================

主持人：angelilu，Foresight News 研究员

嘉宾：Blur 创始人 Pacman、Joy Rich 社区红神、LD Capital VP Vicky

 
圆桌提问

 

嘉宾自我介绍 + 参与 Blur 的经历分享

相比于 NFT 交易平台龙头 Opensea，Blur 有哪些优势？

angelilu：大家好，欢迎大家来到 OKX 中文联合 Foresight News 举办的 Twitter Space，我是今天活动的主持人 Foresight News 的研究员，今天活动的主题是「Blur 发币在即，NFTFi 哪些板块值得关注？」，有请三位嘉宾介绍下自己，并且可以简单说下使用 Blur 的经历？

 

Pacman（Skyler 译）：Packman 是 Blur 的 Founder，8 年前在硅谷做软件工程师，然后 2016 年开始第一次创业，并且参加了 Y Combinator 孵化器的一个项目，之后申请了麻省理工 MIT 并且遇到了合作伙伴，两个人在创业理念上志同道合，开始了很多创业的项目。2018 创立了第一个合作的创业项目，然后在 2021 年年底成功的被收购了，之后便开始了 Blur 的创业之旅。

红神：大家好，我是 Joy Rich 的社区负责人，我说一下我个人参与 NFT 的经历，我是去年参与的，我个人主要是关注就是二级市场，本身也非常喜欢 NFT，去年 Blur 有一个发盲盒的方式吸引大家，我从那之后开始使用 Blur 了。

Vicky：我是 Vicky，目前在 LD Capital，我是在 2022 年 12 月底在好朋友的推荐下使用 Blur listing 了现在头像的这个 Ape。我以及身边的所有的 NFT 资深玩家使用 Blur 后的感受是这个东西有一些非常新的功能，包括 Gas、产品流畅度、交易的实时交易速度，还有聚合的流动性等方面。

 

angelilu：近期 NFT 市场回暖，哪类项目会成为新一代的 NFT 蓝筹？

 

Pacman（Skyler 译）：先说类别，因为现在理论上来说我们还是处于熊市，所以说一些全新的 NFT 项目可能风险还是比较大的，Pacman 比较倾向的还是 NFT 蓝筹这个板块，这方面会关注的比较多。

红神：我主要从事二级市场交易，买 NFT 首先是因为我喜欢它的画风，第二主要是它的社区还有它的文化，例如现在的一些蓝筹 NFT。然后我认为游戏赛道叙事比较长的话，NFT 的发展也会越来越好。

 

angelilu：近两年 NFT 崛起，生态越发健全，NFTFi 会成为下一轮牛市主力军吗，目前有哪些板块？

 

Vicky：对于 NFTFi 能不能成为下一轮的主力军的问题，我认为是有的，但是需要时间。最早玩 NFTFi 的人和玩 DeFi 的人，其实是两个不同圈子的人，到 NFTFi 的群里可以看到大家都是新面孔，但是 DeFi 的群里可以看到很多熟人的面孔，需要时间让玩 DeFi 的人到 NFTFi 去。另外，最早的玩 IP 的那帮人，其实最早是不知道什么是 NFTFi 的，以及为什么要「Fi」这个东西，大家都说不清楚的，所以 NFTFi 要成为下一轮牛市主力军，前提是要把用户培养起来，让 NFT 早期用户体会到「Fi」的魔力，也把玩 DeFi 的人吸引到 NFTFi 中。

红神：我个人对 NFTFi 发展特别看好，因为它特别容易出圈并且存在很多机会，NFT 本身最大的缺点就是对于散户来说流动性比较好的蓝筹 NFT 的入场门槛太高了，NFTFi 有可能会解决这个问题。现在是 NFTFi 发展的初期阶段，相信在不久的将来，随着 NFT 市场的繁荣，NFTFi 一定会成为一个特别重要的板块，包括下轮牛市。NFTFi 的重要板块包括 NFT 的抵押借贷、NFT 租赁，还有 NFT 碎片化等。

Pacman（Skyler 译）： NFT 的增长其实就类似于代币市场的增长，但比代币市场晚了几年，DeFi 的出现是因为代币交易量的增多且金融化，NFT 其实也遵循同样的趋势，所以我们现阶段主要是专注于不断增强 NFT 交易的专业化，当 NFT 交易变得更专业且数量更多的话，NFTFi 才会发展成一个重要的板块。NFTFi 在目前来说是有市场的，但是可能我们现在没有看到一些非常让人激动的项目出现，所以对这方面持观望态度，作为一个给专业交易员提供的 NFT 交易平台，Blur 未来还是会在交易方面优化和完善。

 

angelilu：相比于 NFT 交易平台龙头 Opensea，Blur 有哪些优势？

 

Pacman（Skyler 译）：我们开始创立 Blur 的原因是因为，在 2021 年，我个人接触了 NFT 交易领域，但我对当时的基础设施感到非常沮丧，因为 OpenSea 和其他所有 NFT 市场都非常注重零售用户，它们与 Coinbase 非常相似，为新用户进行了优化。但我希望有更专业的 NFT 交易平台，一个真正专注于实时交易，快速高效的 NFT 市场。我们的目标用户是专业交易者，就像在代币交易中，Coinbase 在零售中非常占优势，但 OKX 等其他交易所可以为更多的专业交易用户服务，Blur 就是为专业的 NFT 交易去做的一个平台，优势就是为专业 NFT 交易用户提供服务。

红神：Blur 本身就是一个 NFT 交易聚合器，个人作为一个用户的观点来讲，他给我最大感觉就是速度快比较快，更容易抢到地板价的 NFT。另外就是界面，Blur 的界面并不像是传统 OpenSea 那样会在首页上推荐一下画风比较好看或者新的项目，它更像是一个交易所。

Vicky：第一从散户的角度来讲，购买 NFT 的成本可能包括 NFT 本身的价格，然后矿工 Gas 费、平台手续费和版税等多个结构，如果你购买一个 NFT，本身 NFT 需要涨 8~10% 左右你才可以回本。Blur 其实是从根本上在让成本更加可控，其实对用户来讲是更加友好的。第二个方面就是说因为 Blur 的系统把你自己的以太坊提前就 Staking 进去了，你的钱就在那个板块，所以它的购买的速度可能就是优于其他的平台。第三是在产品方面的，目前为止 Blur 使用 Seaport 的协议实现双系统，它有效的绕开了 OpenSea 针对市场上强制版税的限制，也就是说你 0 版税的项目和强制版税的项目都可以在 Blur 的平台上来交易，很大的程度上巩固了 Blur 的 trading volume 数据的上涨。除了在速度和抢地板的方面的优势，还有它多平台聚合的流动性，在批量挂单买卖方面的功能对想要专业交易 NFT 的一些 Trader 更友好。我看到 Blur 的版面上有价格、索引和 listing 这些细节，这个东西其实是很有效的，让我们不再需要在钱包里再去 check 我有哪些 NFT 以及哪些是在 listing 的，以及要再跳转到其他第三方市场去看，目前我持有的这些 NFT 的地板价大概是一个什么样子，它在很大程度上有效地提供了我们管理自己的 NFT Portfolio 的这样的一个功能。

 

angelilu：随着大盘的复苏，NFT 行情也出现回暖，最后请各位嘉宾分享一个近期关注的 NFT 项目？

 

红神：我分享的是在超级碗上花费 650 万美元购买广告的 NFT 项目 DigiDaigaku，我去年就关注了这个项目而且自己也投资了，这个项目本身就是一个大型游戏的叙事，项目方通过发行游戏中的角色武器开展故事线，我觉得这个项目很有可能发展为蓝筹。

Pacman（Skyler 译）：这算是一个比较敏感的问题，因为它涉及到投资相关的问题，通常我不说某一个特定的 NFT 项目，但是可以讲一下评判一个 NFT 项目到底优不优质或者未来有没有潜力的方法。首先就是看这个项目的团队，也就是它 Founder，有没有对这个项目投入百分百的用心程度，以足以产生 Alpha。目前的情况下可以很明显的看出，NFT 在西方整个市场的火热程度要高于亚洲，但亚洲市场也处于稳步上升阶段，例如 Azuki。

 

听众提问

 

ZW：第一个问题是关于产品层面的问题，和其他的聚合器相比 Blur 为什么能做到刷新速度这么快？因为它在合约层面做的一些优化，还是说它是通过前后端的接口调用和刷新比较频繁？

Pacman（Skyler 译）：能做到这么快是因为 Blur 有着世界顶级的开发团队，10 个人的团队里面有 7 个是软件工程师，并且这些软件工程师都是来自于其他的一些全球头部的优质项目以及在 MIT，优秀的软件团队来提供技术上的支持。

 

ZW：第二个问题是关于项目收入来源，目前不盈利就意味着还没有正式的收入来源，后期除了马上要发币以外，还考虑其他盈利模式吗？

Pacman（Skyler 译）：作为一个 NFT 交易平台，Blur 从长期来看收入来源最终还是依靠用户交易时收取的交易费，至于前期不收取交易费是因为 Blur 目前处于一个向专业 NFT Trader 推广的阶段，需要有一些优势抢占市场，让专业的 NFT Trader 知道 Blur 有快速、实时交易这些好处。目前做这个决定是为了 Blur 长远的积极的发展。

 

Fiona：Blur 在空投激励结束以后还怎么保证平台的交易量像现在一样高？

Pacman（Skyler 译）：我们始终坚持如果使用激励机制的话那我们只激励流动性，而不激励交易量，这类似于 DeFi 里 Curve 的激励方式，如果激励交易量的话，只会让人们认为是刷量不是真正的用户。我们已经有信心，不需要奖励也能保持交易量，因为我们已经关闭了一半的奖励，但是交易量仍然在增长，大约在 2 个月前，12 月 6 日的时候我们就停止了对 NFT 上架的激励。激励对于从头构建的网络来说或许非常有用，但我们认为维持交易量不需要激励。hildobby 在 Dune 对 Blur 的交易量做了很多数据分析，发现绝大多数是自由的交易量。总的来说，空投并不是决定 Blur 交易量的决定性或唯一指标。

 

story： DID 赛道中为什么像 ENS 这样的头部项目没有上线 Blur？Blur 上线 NFT 项目的标准是什么？后续有没有计划上线 ENS 这样的项目？

Pacman（Skyler 译）： Blur 上线的项目标准就是整个社群成员的 request，没有上线 Blur 的项目可能是社群成员目前没有让它上线的需求，但如果听众朋友想让 Blur 上线某个项目，可以去 Discord 里面提出上线需求。

 

story： Blur 目前仅支持 Web 端的使用，未来有计划支持移动端吗？

Pacman（Skyler 译）：就像这位用户说的一样，目前 Blur 仅支持 Web 端不支持移动端，但从交易数据上看，Blur 已经超过了很多 NFT 交易平台，如果增加了移动端的话，对于平台扩大以及用户增长肯定是有正面的影响，所以未来是有计划增加移动端的 APP，但是目前的话还没有一个明确的时间，之后大家可以在社群中关注。

 

bin：Blur 未来有开放 Open API 的计划吗？开发者如何来聚合 Blur 以及开发一些衍生的工具？

Pacman（Skyler 译）：我们正在开发 API 并且之后将发布它，这样任何人都可以直接访问它，而不需要通过申请程序或类似的东西，目前瓶颈在于工程师团队上，因为现在还是属于项目发展的阶段，所以说团队里的 7 个软件工程师都都只专注于启动，等到项目成熟以后，会在未来开放 Open API，让更多的开发者去使用，或者是基于 Blur 去构建其他工具和生态内的一些项目。
