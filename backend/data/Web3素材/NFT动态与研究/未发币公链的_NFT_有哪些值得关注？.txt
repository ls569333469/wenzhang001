标题: 未发币公链的 NFT 有哪些值得关注？
链接: https://www.chaincatcher.com/article/2158984
发布时间: 2024-12-24

==================================================

作者：Cookie，BlockBeats

 

上一期的 NFT 项目盘点（相关阅读：近期值得关注的 8 个 NFT 新项目）中，我们主要为大家盘点了 Abstract 链上的一些新机会。大家可能会感觉 Abstract 链上的新项目现在都比较卷，更有很多 NFT 内容创作者在 Twitter 上发盘点试图在白名单战争中拔得头筹，难度越来越大了。

当白单获取难度不是单个项目变大而是生态整体都变大时，赔率空间自然而然也就被压缩了。这篇文章，我们把目光放到 Abstract 之外，以声势正在变大的 Monad NFT 为主，辅以 Story Protocol，有哪些东西是值得我们动起来的？

Monad NFT

首先先去做一下 @monadverse 的白单任务，虽然完成任务只有 100 个白单，但是如果连门都不出，馅饼砸头上的机会都不会有。

除了要回答一个最喜欢的 Monad NFT 项目以外，都是关注、转发、评论 Twitter 的任务，5 分钟不用就能搞定。（传送门）

接下来的项目，NFT 老玩家们应该都很熟悉拿白需要干（肝）些啥了，Twitter 疯狂互动 Discord 疯狂刷存在感，这些我不赘述，直接给大家筛哪些值得去肝。理由也没有什么长篇大论，就是高热度 + 物料展现出的质量过关。

Woolly Eggs(@WoollyEggs) - 抽象鸡蛋，总量 5000。

lil chogstar(@chogstarrr) - 以 Monad 生态重要吉祥物之一「Chog」为灵感的 PFP 系列，热度已经起飞。这里也一定要参加一下他们在 Premint 弄的 100 个白单抽奖（传送门）

Spiky Nads(@spikynads) - 像素画风的 Monad NFT 不多，这个还不错。

Motatoes(@Motatoes_) - 也是像素画风，有点 Cryptodickbutt + 土豆的感觉，但是总量似乎只会有 504 个。

B00(@theBooDAO) - 幽灵形象比较出挑，需要保持观察，等待更多信息。

Story Protocol

Story Protocol 的融资背景非常强，有 $PENGU、$VANA 这些 NFT 能够带来丰厚代币空投的案例在前，Story Protocol - Onchain Chronicles 这个 NFT 系列被视为了潜在获取 Story Protocol 代币空投的凭证，过去半个月已经上涨了 5 倍，目前的地板价大约为 0.05 ETH。

除了这个系列之外，因为这就是一个 IP 链，IP NFT 自然也值得关注。目前需要关注的是 Globkins(@globkins)。这个 NFT 系列已经售罄了，但是还没有 NFT 交易市场可以进行二级交易。

Berachain

熊链的 NFT 项目已经不少了，很多都是先发在了 Arbitrum 上。新项目中热度最高的毫无疑问是 steady teddys(@steadyteddys)，场外白差不多要 1500U 一个，现在的白单已经很难搞了。

Eclipse

这个链一句话总结就是「以太坊上的 Solana」，官方 NFT 系列叫 ASC(@asclubnft)，现在已经涨到约 0.6 ETH 的地板了。
