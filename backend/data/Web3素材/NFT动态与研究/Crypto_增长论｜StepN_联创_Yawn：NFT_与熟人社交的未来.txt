当前 NFT 市场正处于一个风口浪尖、面对众多挑战的时期，但 NFT 仍是传统互联网用户迈向 Web3 世界的重要桥梁。

NFT 为什么辉煌不再？

NFT 大体可分为两类：生产型 NFT （包括 GameFi ）和集体型 NFT （比如 PFP ）。

生产型 NFT 是在经历真正意义上的「要么增长，要么消亡」的困境。由于增长的需求，导致无节制的发行，造成市场通货膨胀，价值摇摆不定最终陷入死亡螺旋。这类生产型 NFT 的生态过于碎片化，各项目彼此割裂，互不相通，让用户摸不到头绪，也难以深度参与。

集体性 NFT 因稀缺性塑造出封闭的小圈子文化，圈内人难以形成价值外扩，导致了一个社区充其量只有三五千人假狂欢的局面。而圈外人的自发性运动，如制作文化衫这种将「猴子印在 20 块钱的短袖上」的事件又从另一个维度降低了品牌调性。品牌基于调性而生，而调性代表着社区的态度。疯狂复制的背后体现的是防范机制和良性土壤的缺失。同时，靠故事性营销撑起来的热度，又少了实际应用场景的支撑，即如何将「 Situational Storytelling 」转变成「 Sustainable Narrative 」。最终也只能是昙花一现，徒留用户体验的空虚感。

为什么我们需要 Make NFT Great Again ?

本质上来看，相比于加密货币， NFT 的非金融特性可以实打实地降低用户的心理门槛，被人诟病的低流动性反而让用户从心理上将这种资产归类为更安全的类别，从而更易于接受。

同时  NFT 能够让 Web3 资产在 Token 与 NFT 之间转换从而提升资产流动性，还能让项目方围绕 NFT 设计一系列活动来提高社区的的参与感和归属感，形成不同玩法在平面上的叠加。这种用户体验从一定程度上解开了 Web3 在 Web2 面前的一些自卑情结。

最重要的是， NFT 还具有独特的社交和情感价值，更能在社交网络中代表个人身份和兴趣爱好从而展现个人特色。这是数字化生活方式的极大一部分。

过去 3 年， StepN 积累了哪些经验？

1. Move - To - Earn 模式的验证

经过三年的运营， Move - To - Earn 模式已被市场验证。年化收益、价格与本地社区的稳定性（如越南、日本每月 3 场的线下活动）、社区的非金融化证明了这一商业模式的可行性。 Builder 们应关注这一模式的潜力，尤其是在健康和健身领域的应用。

2. 防作弊系统与激活码的重要性

为了确保用户增长的可持续性，建立有效的作弊防范系统和激活码机制至关重要。在防作弊方面，鉴别女巫攻击，鉴别 bot 的攻击尤其重要。缺乏有效的防作弊系统，用户增长可能会受到严重影响，导致项目的信誉和发展受损。在激活码方面，我们要理解共识的增长需要时间， Builder 应掌握增长的节奏感，我们每天放出 1.5% 的激活码，让真正需要的、想要的、会珍惜我们产品使用权的用户参与才是重要的，并非都是以「高举高打」的模式，可持续增长在 Web3 更加弥足珍贵。

3. Web2 用户引导的挑战

目前，也许是 Web3 史上最难做用户增长的时期。与 Web2 相比， Web3 用户的引导更加复杂。用户对新技术的接受度和理解能力参差不齐，开发团队需要投入更多精力进行教育和引导，以提高用户的参与度和留存率。如何当 Web2 用户能无感地顺滑进行 Web3 领域显得尤其重要。把 Web3 中反人性的设定打造成用户无感的体验，才可能让 Web2 的用户考虑进来（都不一定会进来），在这里我们必须有心态的调整。

4. Web3 社交的真实需求

Web3 社交是一种刚需。 Web3 用户自发地做了许多 Web3 社交的组局。 Web3 社交平台的兴起反映了用户对真实社交互动的需求。这一趋势表明，项目应注重构建真实、可信的社交环境，以增强用户的黏性和参与感。如何让 Web3 与 Web2 的用户通过社交做一个非金融化的配对是当务之急。

StepN Go 如何实现可持续增长？
如何获取用户的注意力？

注意力的稀缺性：用户的注意力才是当代最值钱的东西。在信息泛滥的时代，用户的注意力变得愈加珍贵。项目需要设计吸引用户的内容，以提高参与度。

信息传达的时效性：越早传递关键信息，成功的概率越高。项目方应迅速响应市场变化，及时向用户传达重要信息。

零投资的激励机制：允许用户在无需前期投资的情况下获得收益，有助于保持用户的积极性，吸引更多潜在用户参与。

简化机制以增强理解：复杂的机制可能导致用户困惑，简化用户体验能够有效提升用户的理解和参与度。

StepN Go 租赁系统：熟人社交的未来

The HAUS System 与 FSL ID 是 StepN 的新机制。 The HAUS system 是 StepN Go 推出的跑鞋租赁系统， Web3 用户可通过收入共享计划将跑鞋租借给 Web2 用户。 FSL ID 则能让 Web2 用户通过 Email 与 FSL ID 完全无感的进来。

1. 熟人社交的优势

熟人社交的最大优势在于其深度和信任度。与陌生人交往时，往往需要经历多重筛选和验证，而熟人之间的互动则建立在已有的信任基础之上。这种信任使得信息传播更为高效，用户更容易接受来自朋友的推荐和意见。

2. 六度理论与影响力

根据六度理论，一个人只需通过最多六次转介绍，就能认识到任何人。这意味着，一个人的社交网络能够迅速扩展，只要他能够影响身边的五个亲朋好友。每个好友中，至少有一个人对某个领域或活动特别感兴趣，这就为熟人社交平台的有效性提供了基础。

3. 租赁系统的潜力

在熟人社交的框架下，租赁系统的引入将为用户提供更多的机会。用户可以通过租赁服务来获取资源或体验。这种模式不仅能够满足用户的需求，还能促进他们之间的互动和合作。通过熟人推荐，用户更愿意尝试这些服务，因为他们信任推荐者。

4. 真实用户体验的重要性

要想推动熟人社交的成功，必须从用户的真实体验出发。传统的社交平台往往注重用户数量和活跃度，但熟人社交需要关注的是用户之间的真实互动和体验。平台应注重提供有价值的内容和活动，而不是单纯依赖测试币或虚拟奖励。通过创造真实的社交场景，用户将更容易参与其中，并建立深厚的社交联系。

未来的社交网络将不再是冷冰冰的陌生人连接，而是温暖的熟人互动。通过充分利用熟人社交的优势，我们可以实现更高效的社交方式，建立更深层次的信任关系。随着用户体验的不断优化和租赁系统的有效运用，熟人社交将成为未来社交的主流。

可持续增长

共识需要时间，比特币的共识也有十多年的，我们要让增长再慢一些。除了 Onboarding 更多 Web2 用户遏制通胀，还可以延长产品的生命周期，重塑经济模型的设计，去掉 Web2 思维；同时，激活码起到了入口设置的作品，确保缓慢而持续的增长。另外，机制的改进消除了最大的通货膨胀——可再生资源。

有了可持续增长，人们就会安心，从而促进社区发展、达成共识并推动消费。这会推动对 StepN Go 原生 Collective NFT 的需求，将其作为社会地位的象征，进一步抑制了通货膨胀，因为 Collective NFT 不会产生代币。

面对 End - game ：增长停止后的应对策略
1、理解 End - game 的本质

现在流行的 Telegram 小游戏生命周期都非常短，「 End - game 」并不意味着项目的终结，而是一个转折点。在这一阶段，项目需要重新审视自身的市场定位、用户需求以及竞争策略。了解用户在这一阶段的消费心理和行为是关键， Web3 项目应聚焦于如何提升用户的消费体验和满意度。

2、促进用户消费的策略

为了激励用户继续消费，可以采取以下几种策略：

内部共识的建立：首先，项目需要在社区内部建立共识，明确目标和方向。通过团队的共同努力，形成一致的营销策略和用户体验。内部的团结将直接影响到外部的用户感受。
与大品牌合作：与知名品牌的合作不仅可以提升企业的品牌形象，还能吸引更多的用户关注。通过联合营销活动，企业可以借助大品牌的影响力，扩大自身的市场份额。例如，推出联名产品（阿迪达斯）或共同举办活动，吸引用户的参与。
IP 合作：购买或合作知名 IP 是一种有效的策略。这种跨界合作不仅能提升品牌的知名度，还能为用户提供独特的消费体验。
3、社交分享的力量

在 End - game 阶段，社交分享成为促进用户消费的重要手段。用户愿意分享他们的消费体验，尤其是当他们认为某个产品或服务具有独特性或价值时。项目可以通过以下方式促进社交分享：

Show off 机制：鼓励用户在社交媒体上展示他们的消费成果。例如，推出用户分享活动，用户可以晒出他们的购买体验，参与抽奖或获得优惠。这种「炫耀」行为不仅能提升用户的参与感，还能吸引更多潜在用户的关注。
社交媒体营销：利用社交媒体平台进行精准营销，发布用户生成内容（ UGC ），增强品牌的可信度和亲和力。通过与用户的互动，项目可以更好地理解用户需求，并及时调整营销策略。
