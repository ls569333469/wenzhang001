标题: 盘点近期三起 NFT 市场并购案：Uniswap、Opensea 和 eBay 竞相圈地
链接: https://www.chaincatcher.com/article/2075808
发布时间: 2022-06-24

==================================================

作者：念青，链捕手


加密货币市场持续走熊，投融资市场也趋于平静与放缓，但NFT赛道近期接连发生多起并购案件，尽管性质各自不同，但仍然传递出不同寻常的信号。

前两天，Uniswap Labs 宣布收购NFT聚合市场Genie，正式进军NFT赛道。Uniswap Labs表示，Uniswap会很快将在其应用程序上推出NFT平台，据说也将会集成开发人员 API 和小部件。

早在2019年，Uniswap就曾推出过一款名为 Unisocks的NFT产品，这款由实物支撑的NFT仅发行了500枚，一度炒到近十万美元的价格。Uniswap曾提到，NFT是通往Web3的重要门户，而不是“与ERC20 分开的生态系统”。

关于此次收购，Uniswap 创始人 Hayden Adams在Bankless的博客中提到：Web3最终会实现不同形式的价值交换，Uniswap希望成为一个更广泛的资产交易平台，NFT只是代表了不同所有权的资产。Uniswap将把在构建 DeFi 产品方面的经验应用到NFT上，来满足自身用户对更多类型资产的交易需求。

在过去很长时间，Uniswap 作为加密交易协议只支持同质化的ERC20代币交易，ERC721代币的交易则由Opensea等交易平台提供，目前仍然没有同时支持ERC20与ERC721交易的去中心化交易平台。

而作为DEX龙头，Uniswap收购Genie可谓基于ERC721的NFT市场和ERC20代币市场之间进行垂直整合的第一个案例，在一定程度上将改变整个NFT市场的格局。从Uniswap方面的表态来看，这次收购将打破NFT和ERC20同质化代币之间的交易界限，譬如像Opensea等交易市场一般都是用ETH购买，而未来在Uniswap上，用户可用任何ERC20代币购买NFT，可以大幅提升了用户交易的便利程度。

此外，Genie并不是单纯的NFT交易市场，更是一个NFT市场聚合器，也就是说，Uniswap集成Genie之后，无需在NFT流动性方面下更多功夫，可以将更多精力用于双方产品的打磨。

目前，Genie已经聚合了OpenSea、NFTX、NFT20、LooksRare、 Rarible、X2Y2、Coinbase NFT等交易平台，支持ERC-721、ERC-1155协议。Genie最大的亮点就是，允许用户在一次交易中批量购买所有主要市场的 NFT，并节省高达 40% 的gas费。

就像Web2中的很多比价平台一样，NFT聚合器方便用户找到最便宜的NFT，并且联合小平台形成正向循环。也因此Genie等聚合器的诞生，也给X2Y2、LooksRare等小平台带来了更多流动性和对抗Opensea的机会。

说到这里，就不得不提到两个月前，Opensea对另一NFT聚合平台GEM的并购。

4月25日，OpenSea宣布收购NFT市场聚合器Gem，表示此举是“投资专业社区的未来”，改善用户体验。收购完成后，Gem将作为独立的产品和品牌继续独立于OpenSea运营。

但很明显，这是一次来自垄断方的“防御性”并购。

Gem在去年12月28日上线Beta版，虽然比Genie出现更晚，但Gem因其顺畅的使用体验、紧密的社区关系占据了更大的市场份额。无论是交易量、项目数量还是用户数量，Gem都远超Genie。

Gem当前聚合了 NFTX、NFT20、Rarbible、OpenSea、Larva Labs 、LooksRare等市场，此外，还能帮助用户路由Uniswap V2和V3、SushiSwap以及通过0x的任何流动性，也因此支持用户在交易NFT时使用持有的多种ERC-20代币进行支付，也可以组合不同代币支付（如果不是Opensea收购在先，Uniswap大概更想收购Gem）。

此外，OpenSea之所以强调，收购Gem是为了“投资专业社区的未来”，还源于Gem在技术开发和功能迭代中会更倾向于采纳社区的意见，例如购物车、稀有度、flashbot、whales 购买通报等Gem特有的功能也是社区一直希望 OpenSea 添加的。

但因为Gem不收取平台费用，缺少良好的盈利模式，社区猜测，这也是Gem接受收购的原因之一。

除了以上两个圈内的并购事件，还有一个跨界的并购事件值得注意。

以前，我们总把OpenSea比作“NFT界的eBay”，现在 eBay亲自下场来做NFT市场了。6月22日，电子商务巨头 eBay宣布收购了一家总部位于英国的 NFT 市场，表示将进一步推动其在数字收藏领域的业务。

eBay此前也在NFT领域试过水。今年5月，eBay通过NFT 平台 OneOf 推出“创世纪”（Genesis）NFT系列，以3D和动画方式诠释多年来《体育画报》（Sports Illustrated）封面上的标志性运动员。或许，此次试水让eBay发现了NFT市场大有可为。

此次被收购的KnownOrigin于2018年在英国曼彻斯特成立，是一个由建立在以太坊生态上的NFT市场，允许艺术家和收藏家创建、购买和销售NFT。

但和Opensea等和Web3文化紧密相连的NFT市场不同，KnownOrigin更靠近传统市场。这是一个以艺术家为中心的NFT交易平台，NFT作品更像是数字艺术，而不是主流NFT市场中的头像类合集。

KnownOrigin初心是帮助数字创作者将艺术货币化。KnownOrigin 还与 Adobe、Adidas 和 Netflix等品牌合作开发了一个版税系统，允许艺术家通过二次销售赚钱。曾于今年3月完成由GBV和Sanctor Capital领投的350万英镑的融资。目前销售额超过3000万美元，已与5000 多名内容创作者合作。相比之下，OpenSea累计销售额超过300亿美元。

但eBay 作为全球最受欢迎的交易平台之一，将成为多数人进入NFT甚至是Web3的第一站。而eBay即将推出的NFT市场也将更加面向传统市场。就像此前联合《体育画报》联合推出的NFT系列一样，随着NFT在时尚、体育等领域的渗透，日后KnownOrigin也将通过和更多品牌联合、跨界，吸引更多来自传统市场的全球用户。

总结而言，Opensea防御性地收购了潜在的“屠龙者”Gem聚合器，尽早将NFT聚合器助力LooksRare等小平台抢占市场份额的威胁扼杀在了摇篮里，另一方面，Opensea也将吸取Gem的优势，优化用户体验，加强为社区的服务能力，从而巩固垄断地位。

作为DEX龙头，Uniswap收购NFT聚合器Genie将打破ERC20代币和NFT资产之间的界限，为交易NFT大大减少了摩擦，这也是Uniswap试图挑战Opensea所具有的天然优势，同时也为自身的发展前景带来更多的想象力。

而eBay作为全球主流的商品交易平台之一，这次收购有利于提升自己在NFT赛道的布局，将自己在传统市场中的流量优势与被收购平台的专业能力相结合，为未来在加密赛道的更多探索奠定基础。

可以预见，随着市场的持续低迷，加密行业一二级市场的项目估值都会较此前大幅缩水，这对于资金充沛的巨头将是进行并购整合的有利时机，未来或许将看到越来越多类似的行动。
