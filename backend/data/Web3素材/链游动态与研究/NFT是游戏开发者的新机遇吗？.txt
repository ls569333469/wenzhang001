标题: NFT是游戏开发者的新机遇吗？

发布时间: 2021-07-28

本文作者为钱奕

一. 什么是NFT：

NFT英文全称为Non-Fungible Token，翻译成中文就是：非同质化代币，具有不可分割、不可替代、独一无二等特点。

NFT不是虚拟货币，后者可以细分为小单位。虚拟货币的每个单位彼此等效（类似于每个面额相同的硬币一样），这就是同质化、可替代性。“不可替代”资产是一种不可分割的资产，比如：一幅画、一栋房子、一辆车、甚至数字收藏品。

NFT 的创新在于其提供了一种标记原生数字资产所有权（即存在于数字世界，或发源于数字世界的资产）的方法，且该所有权可以存在于中心化服务之外。

NFT为数字艺术家提供了一种全新的收入模式——让他们从数字作品的转售中获利，并从数字艺术中赚钱。

几千年来，人类不得不依靠真品证书、专家和信任来验证书画等艺术收藏品的有效性和唯一性。现在有了 NFT 和区块链的公共账本，伪造和偷盗是几乎不可能发生的。一切都是可验证，而且是公开的。收藏并交易这个传统的商业模式终于为数字艺术品敞开了大门。

Cryptopunks是由24x24、8bit样式的不规则像素组成的艺术图像集合，属于2017年NFT热潮中的产物，由Larva Labs团队推出，数量约10,000个，每个图像都有自己随机生成的独特外观和特征。

自NFT上线以来，围绕 NFT 产生的大部分热度都来自数字艺术世界。很多创作者将NFT视为一种直接与收藏家建立沟通的方式，而不是占据其潜在收入的 80-90% 的传统画廊的市场生态系统。而收藏家将NFT视为一种收集已证明稀缺的作品（类似于限量版印刷品），同时更直接地支持他们最喜欢的艺术家的方式。

有些开发者已经注意到，NFT在音乐和时尚领域的新机会——以及域名或房地产等其他资产领域的机会。自然，也有开发者在想：NFT 能否应用于多年来一直在没有区块链的情况下生产虚拟道具商品的游戏？

对于游戏产品的开发者和游戏玩家来说，过去在游戏体验过程中，产生的游戏道具、装备、皮肤等虚拟数字商品，过去很难通过公开市场确定产权和价格并且交易。游戏账号一旦被盗，其账号的拥有者往往会带来难以估算的巨大损失。而有了NFT的出现，和一切问题变得迎刃而解。

5月下旬至今，虽然受加密货币市场下行影响，NFT项目热度、销售量与钱包活跃度有所下降，但与2020年整体水平相比，NFT市场已经实现一大跨步。这说明在本轮热潮中，整个市场已经开始重新评估NFT价值，以及用户参与度在不断加深。

二. 对于具备完整经济体系的游戏产品而言，NFT一些最重要的功能包括：

1.真正的所有权。NFT 是玩家钱包中拥有的实际资产。即使游戏平台方突然回滚游戏，也不会从玩家手中拿走在游戏内已经获得的数字资产。

2.永久性。一旦 NFT 被铸造，它可能永远存在于区块链上。

3.可证明的稀缺性。由于所有记录都可以公开访问，因此软件可以检查区块链并确认可以存在多少。例如，如果某个虚拟道具是游戏内一类道具的其中一个（在 NFT 空间中通常称为“1 中的 1”），玩家可以立即确认这一点。如果它是 1,000 的限量版，玩家也可以立即确认这一点。

4.可证明的出处。项目所有权的历史记录在区块链中。有些物品可能仅仅因为过去持有它的人而增值。使用 NFT，玩家将确切知道谁持有过某个游戏物品（一直追溯到创建者）。

5.可编程性。使用“智能合约”技术，NFT 可以实现玩家之间的互联网交易——甚至是其他游戏

6.权力下放。没有中心化的平台方来控制经济和执行智能合约。游戏的经济系统以完全去信任的方式保持其完整性，这样能为游戏的社区生态系统增加巨大的经济价值。

三. NFT对游戏开发者的机会：

NFT对于游戏开发者来说，有非常明显的优点，但也有一些缺点，如游戏开发者一旦发现新上线的游戏版本有巨大bug，很难通过回滚的方式快速修复版本迭代产生的问题。去中心化的方式，也导致虚拟数字道具商品的数据交换和同步效率没有中心化的方式高效。

因此，不是所有的游戏都适合采用NFT，比较适合NFT的游戏场景方向可能有：

1.保留玩家的体验。适用于现有游戏和新游戏的一个机会是NFT记录玩家的记录的方式和过去不同。想象一下，玩家在游戏内探索一个有趣的地方，赢得了一场比赛，达到了一定的水平，获得了游戏内的奖励，并通过NFT的方式保存了记录。

这样，在玩家放下那个游戏很久之后，那个记忆可能会被刻在一个虚拟的人造物品中，成为你永久收藏的一部分。在以故事驱动的游戏中，这类记忆比以往任何其他都重要。

2.增加价值认知。现在，全球的游戏玩家购买、打造在游戏中的各类游戏装备、道具、皮肤，推动了 $100B+ 的游戏交易行业——即使这些虚拟商品只在某个游戏内存在。

但如果玩家通过NFT真正拥有这些虚拟商品的产权，他们会更加重视这些物品。想象一下，这种全新的主人翁意识会在多大程度上改变玩家投入到游戏世界的方式。

3.新的资助形式。目前游戏的开发资金主要来自股权投资者、发行商融资或众筹（预售）等方式。

但未来，销售NFT限量版虚拟商品可能是一种比众筹更早地为游戏开发者提供资金的新方式。与众筹不同的是，限量版虚拟商品也提供了交易和流动性的优势。拥有资产的玩家可能会更加“投资”于游戏的成功，他们可能会成为游戏产品的重要推动者。

事实上，目前游戏开发者的最大运营成本之一就是用户拉新成本。但现在开发者可以通过向用户空投NFT数字收藏品，将拉新成本从运营费用转移到（轻微）稀释游戏开发者的资产，可能最终用户拉新的性价比更高。

4.电子竞技和主播的新机遇。由于 NFT 可以证明出处，因此物品产生价值的方式之一不仅包括物品是什么，还包括谁持有它。

过去，表现出色的电子竞技明星代言在比赛胜利期间所穿的服装品牌，可以成为电子竞技团队的广告收入。

现在，演示游戏、报道活动或帮助发布的主播可以通过先获得NFT限量版虚拟商品，然后再转授给粉丝作为销售收入来源。

5.专为交易而构建的游戏。NFT可以为收藏品增加可观的价值。专注于资产的价值创造而不是销售游戏软件，可以让游戏公司自由地构建玩家感受的全新体验。与

现实世界中的交易卡不同，玩家可以利用 NFT 上的智能合约在每次转售交易时获得交易份额。

6.专为社区打造的游戏。作为玩家拥有世界的资产，允许玩家添加软件作为去中心化生态系统的一部分意味着什么？去中心化可以从根本上打开游戏世界的新体验。

7.边玩边赚。NFT游戏可能会为玩家创造新的赚钱方式，玩家可以在游戏通过发现、打造稀缺的虚拟道具和物品，并通过交易市场，将虚拟商品出售给其他玩家。并且，这种交易是去中心化的，根据玩家供需和市场变化来定价。

四. 现在的一些NFT游戏：

1.Axie Infinity：Axie Infinity 是一款收集、饲养各式各样小怪物的游戏。除了普通的收集属性，Axie 还增加了独有的战斗属性，成为了最早能战斗的 NFT 宠物之一。

Axie 团队在 2 月份还为游戏推出了定制化以太坊侧链 Ronin，通过 POA 共识来提高验证速度以缓解以太坊网络拥挤和玩家 gas fee 的压力。目前 Axie 已然成为了NFT链游的代表，6 月份销售额突破 1.21 亿美元，环比增长 351%。

2.Gods Unchained：基于以太坊的链上首个电竞类卡牌游戏，类似《炉石传说》，用户能够自由地交易和出售他们的卡片，并且拥有卡牌的所有权。

3.Zed：基于以太坊 Layer2 的区块链上首个 AR 赛马类游戏，形成了养马、赛马、观看比赛等各类玩法充值的一站式 NFT 赛马体验。

而其背后推手 Atari 已经向 Zed Run 授权《Asteroids》、《Centipede》、《Missile Command》、《Pong》等多个游戏 IP 内容。未来，随着更多赛马游戏人士的不断加入，玩法和内容边界也将随之不断拓展。

4.Skyweaver：类似 Gods Unchained，是一款具有实际交易功能的数字交易卡游戏。玩家根据他们在不同游戏模式中锻造的卡牌数量、商店上对某些卡牌的需求以及在商店上提供卡牌销售的玩家数量来控制经济和 NFT 卡牌的价值。

5.Alien Worlds：基于 WAX 公链的 DeFi 类游戏，玩家可以通过挖矿赚取 Trilium （TLM），每次挖矿时还有一定的几率挖到 NFT。

Trilium 可以用来质押到游戏内的六个星球中的一个或多个上面，在报名成为星球理事候选人后，玩家将有可能统治该星球。NFT 游戏卡会随着时间的推移推出创新玩法，包括通过「闪耀」来升级卡牌以及在格斗游戏中作战。

6.Sorare：基于以太坊、由初创公司 Sorare 开发的梦幻足球游戏。玩家可以购买和交易经过俱乐部或联盟认证的 NFT 球员卡来组建自己的球队，且都有其稀缺性和唯一性等级，每张球员卡的评分都是根据他们现实比赛中的表现评定的。玩家搭配完整阵容后可以参加平台上的梦幻足球比赛并获得卡牌和代币奖励。

7.Mega Crypto Polis: 基于以太坊和 TRON 的城市经营管理游戏，玩家可以开始在分散式的城市地图上获得一块土地，建造一系列的建筑类型。每一块土地连同在建造的建筑物都是以 NFT 存在的，可以在市场被转让或交易。

游戏中的每一个动作都需要为地区和联邦预算征收一些税收，然后根据他们在游戏周期内 (24 小时）产生的总影响力点中所占的份额，将其分配给所有玩家。

8.Somnium Space：是一个开放的、社交的、由区块链提供动力的虚拟现实世界，用户可以在其中购买土地、建造或进口物体，并轻松地将其体验货币化。Somnium Space 支持复杂的游戏经济，包括虚拟化身、NFT 收藏品等。

9.Marble.Cards：是一款创新的纸牌游戏，玩家可将任何网页雕刻进一张由 NFT 表示的可收集卡牌中，每张卡牌独一无二且可以公开拍卖，URL 只能被雕刻一次并由一个人拥有。
