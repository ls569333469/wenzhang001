标题: 从 Pirate Nation 独立行情，看当前链游项目投资思路
链接: https://www.chaincatcher.com/article/2134246
发布时间: 2024-07-18

==================================================

作者：Cookie，BlockBeats

 

链游是个很独特的赛道。时间来到今年，也就是 2024 年，如果您和小编我一样是一个轻链游玩家（即不把主要精力放在关注链游赛道，并且每天投入大量时间在实际游玩链游上），您对链游的印象可能就只是现如今的链游做得越来越精良，可玩性越来越好了。

过去我们熟悉的链游打金模式大概都是：

有入场成本。比如 Wolf Game 和 StepN，越早进入意味着入场成本越低，越晚进入越高。
Token 的价值高度依赖其消耗情况。或者至少可以说，玩家们很关心这一点。

基于以上两点，就有了引起大家无数次讨论的「死亡螺旋」问题。

但实际上，今年赚钱的链游项目，许多都不再如同以往的模式。

从 Pirate Nation 看链游资产投资思路

最典型的例子之一是 Pirate Nation，这个游戏哪怕是在发 Token 前 1 个多月进去玩，单号都能获得几百 U 的收益。在最近，Pirate Nation 也因为其 NFT 系列以及 Token $PIRATE 走出了独立行情而受到了更多的关注。

TGE 的抛压过后，过去 1 个月 $PIRATE 稳步上涨

NFT 系列的地板价也是屡创新高

为什么 Pirate Nation 能够获得成功？主要有这三方面原因：

团队背景雄厚，有大额融资支撑。其背后的游戏工作室 Proof of Play 于去年 9 月份宣布完成了由 Greenoaks Capital、a16z Crypto 领投的 3300 万美元融资。CEO Amitt Mahajan 曾经是 Epic Games 的开发工程师，Zynga 的开发总监而且还是 Zynga 王牌游戏之一 FarmVille（「QQ 农场」原型）的联合创始人。
游戏的更新迭代速度快。
对 Token 获取的调控做得很好。

那么话说回来，回到本文的主题，对于轻链游玩家，参与的机会在哪里？从上面的 NFT 系列地板价走势我们可以看到，Pirate Nation 在今年 6 月份才 TGE，其 NFT 系列即使在宣布获得大额融资后也在 0.15 ETH 左右横了足足一个多月，在那个时候买入拿到现在，抛开获得的 $PIRATE 份额，都有接近 10x 的收益。

这是当前不少 NFT 玩家投资链游类 NFT 资产的思路——寻找有大额融资、可靠背景团队的链游项目，博一手未来的 Token 预期。只要团队更新频繁不躺平，等到 Token 预期被官宣明确后，很多不关注项目本身只关注市场消息的其它投资者就会进来「抬轿子」。

现在的「Play 2 Earn」，更像「Play 2 Airdrop」

为什么在 TGE 后 Pirate Nation 的 NFT 还能涨？这里又是现在链游和过去不同的一个地方。以前的链游通常是一个双 Token 模型，一个无供应量上限的游戏内 Token，一个治理 Token，项目方随着玩家数量的暴涨要一直进行调控，最后就是控不住。但像 Pirate Nation 的 $PIRATE 就是有供应量上限的游戏内 Token，TGE 的时候统一发给玩家一部分作为奖励，想要更多？那请接着玩游戏。

而且，Pirate Nation 还会做一系列游戏基建，现在质押 $PIRATE 还可以拿 Proof of Play 积分，如果以后的基建再发一个 Token 呢？那估值肯定高于单纯的链游项目本身。所以从这个层面上来思考，我们很容易会想到 Blur 和 Blast，尽管 Blur 不是链游，但也是相同的模式——先有一个成熟的产品（NFT 市场），在市场上交易来获取 Token，最后再发一个链（Blast），让用户不断留在生态内。

玩游戏，但 Token 奖励不立刻结算，而是留到某个时间节点统一发，这个套路现在几乎成了潮流，所以投资策略上也发生了很大的改变。比起 Axie 那种和工作室去卷，埋伏链游赛道的 NFT 资产，然后佛系但是认真地把游戏当作游戏本身而不是打金工具去体验，是轻链游玩家在该赛道可以获取收益的新路径。

在去年，Parallel 的 PFP 系列只需要使用各个种族获取总共 25 场对局胜利就可以免费拿到，后来地板价格涨破 1 ETH。在今年，The Beacon 的第一次 Token 奖励活动是通过玩游戏和参与社交任务来获得，TGE 还要等大半年，而且他们还把 Token 的份额拿出来以 NFT 的形式销售，后续要拿到这部分认购的 Token 份额还是得去打游戏。尽管如此，凭借大概 2000 多万的 Token FDV，10000 个后续能获取 Token 的 NFT 还是以 0.115 ETH 的价格售罄，而且其宠物 NFT 的价格也被玩家们拉涨。

轻链游玩家的思路：观察角度从「游戏」回归 Crypto 项目

所以评判链游项目能不能赚钱的标准也发生了一定变化：

可玩性当然是重要的，但是游戏质量本身并不是决定能否赚钱的因素，游戏质量所引起的话题度才是关键。
项目方本身不可以滥发 NFT 资产稀释 Token 价值，项目方对 NFT 系列的定位和维护该系列赋能（Token 份额）的动作越明确干脆越好。
最好能够比较清楚地算出 FDV，大家都会自行去对比，只要和「PPT 项目」一对比显得很有性价比，就不会缺人来搏一搏。

最没有性价比的操作是当一个链游火到我们在任何社交媒体上都能看到一堆人在讨论然后才去打金，这个时候对轻链游玩家来说已经很难有可观的收益了。我们可以不玩链游，但是要把观察链游项目的思路从「游戏」的定位里解放出来，用 Crypto 项目的角度去观察——这个项目的融资和团队情况是否可以引起关注？这个项目呈现出来的内容（游戏性）是否可以引起关注？如果这个项目有 Token，当前的估值在我们看来是否有足够好的赔率？

甚至现在还有不少链游项目的 Token 活动是完成社交媒体任务就可以参与的，这种项目小编在之前的文章（相关阅读：盘点值得随手低强度撸一撸的 4 个项目、盘点值得随手低强度撸一撸的 6 个项目 | E02）中都有提及，其中提到过的 Super Champs 的 NFT 系列就已经涨了约 50%。（不构成任何投资建议，小编在之后也会尽力为大家发掘更多类似的链游项目）

总的来说，目前在链游项目上的收益是用时间换取空间。链游这个赛道和 Solana meme Token 或者比特币生态基建来比，它在关注度层面和这些顶流市场焦点不是一个层级，但大家都爱 Token，所以在和 Token 相关的链游资产上就会有信息差。当它们不被市场关注时，寻找可能性大的且相对便宜的标的进行埋伏，在市场反应过来以后出货或者是继续拿着参与到游戏中都是可以的，进可攻、退可守。究其根本，链游项目也是 Crypto 项目，所以我们并不需要真的花特别多的精力去打游戏，打游戏本身更像是对链游项目的投研，能够辅助我们对团队是否可靠、未来是否能够获得足够的市场话题度进行判断。
