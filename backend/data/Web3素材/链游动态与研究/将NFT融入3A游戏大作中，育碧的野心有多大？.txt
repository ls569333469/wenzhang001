标题: 将NFT融入3A游戏大作中，育碧的野心有多大？
链接: https://www.chaincatcher.com/article/2067454
发布时间: 2021-12-08

==================================================

作者：白泽研究院

 

育碧（Ubisoft）是一家总部设于法国的电子游戏开发商，于 1986 年成立。育碧在全世界拥有 23 间游戏开发工作室和 28 家分公司，是 2008 年欧洲第三大独立游戏开发商、北美第四大独立游戏出版商。旗下知名的视频游戏 IP 包括：《刺客信条》、《彩虹六号》、《孤岛惊魂》等，其中《刺客信条》系列游戏的销量在截止 2014 年时就已达到 7300 万份。

昨日，育碧通过新闻稿宣布将在 Tezos 区块链上推出 Quartz 数字平台，这是一个可供玩家获取 NFT 资产的平台。而第一个 NFT 也将在明日的《幽灵行动：断点》测试版中发布，在游戏中达到 5 级、游戏时长 100 小时以上和 600 小时以上这三个要求的玩家可以分别获得枪、头盔和战术裤的 NFT，由此来看，育碧是第一个正式将 NFT 融入 3A 游戏中的公司。

（注：3A游戏是指那些开发成本高、周期长、质量高的游戏）

 

既可交易,也满足低能耗

 

根据新闻稿，育碧公司的 NFT 名为“Digits”（数码资产），最初的 NFT 将以游戏内物品（装饰品、武器、装备）的形式出现，也代表了游戏世界的收藏品，它们不会影响游戏玩法，也不会影响游戏玩家体验的失衡。

这些 NFT 的特征如下：

独特性：每个 NFT 都是独一无二的收藏品，具有自己的序列号，可供其他玩家在游戏中查看。 

可玩性：NFT 是具有实用价值的高品质游戏中的收藏品。作为可玩的装饰品，NFT 使玩家能够个性化的体验游戏，并以时尚的方式完成他们的任务。

控制：每个 NFT 都带有存储在区块链上的所有权证书，这是一种独立于育碧的去中心化、社区驱动的技术，赋予玩家比以往更多的控制权。有了这项技术，游戏物品不再绑定到玩家的游戏库存，因为它们可以出售给其他玩家，以便在游戏生态系统之外的第三方平台上交易。

与传统的游戏皮肤或装备不同，每个育碧的 NFT 都会为玩家提供一个唯一的序列号，因此使它们“不可替代”。此外，甚至不玩游戏的用户也可以会在 Tezos 上买卖它们。

育碧的战略创新实验室副总裁尼古拉斯·普阿尔（Nicolas Pouard）表示：

“我们的长期努力使我们了解区块链的去中心化方法如何真正让玩家成为我们游戏的利益相关者，以一种对我们行业来说也是可持续的方式，将他们通过花费的时间产生的价值交回他们手中，他们购买的物品或他们在线创建的内容，育碧 Quartz 是我们开发真正的元世界的雄心勃勃的愿景的第一个组成部分。”

“如果不克服区块链对游戏的早期限制，包括可扩展性和能源消耗，它就无法实现。Tezos，这是一种运行在权益证明机制上的区块链，与比特币或以太坊等工作量证明区块链相比，运行所需的能源要少得多。”

 

从链游到元宇宙

 

育碧的迈步并不止于 NFT，育碧的区块链技术总监迪埃·日内瓦（Didier Genevois）在接受采访时表示：“Quartz 平台只是第一步，我们想看看玩家们将如何与 NFT 进行互动。”

在今年第二季度公司财报会议上，首席财务官弗雷德里克·杜盖 (Frédérick Duguet) 谈到了其对区块链游戏的野心，他更是建议，可以在育碧自己的游戏中使用“Play-to-Earn”（玩-赚），让玩家在享受游戏的同时也可以赚取加密资产，育碧“希望成为链游的主要参与者之一”。

今年 10 月，育碧投资了链游开发工作室 Animoca Brands，旗下产品包括 Revv Racing、Revv Motorsport 和赛车游戏。这些游戏均是基于加密资产，允许玩家收集 NFT。除此以外，育碧在官网的“支持游戏初创公司”页面列出了它之前支持的其他公司，包括链游公司 Horizon Blockchain Games。

在主流游戏玩家圈子中，当国内玩家还在讨论“什么时候才能有一款国产 3A 游戏”出现的时候，育碧却在电话会议上表示，将逐步从专注于 3A 游戏转向免费游戏。

其实“3A游戏”是一个被游戏厂商创造出的概念，是过去欧美厂商在面对创新能力和内容生产能力更胜一筹的日系厂商时，拿出的一个武器。其本质就是“大力出奇迹”，凭借高昂的研发成本带来的视觉冲击来吸引玩家。但这样所产生的结果是，3A 游戏的制作成本不断水涨船高，而欧美大厂在高成本的压迫下，则开始进入借助经典 IP 这根“救命稻草”，就像好莱坞式旧瓶装新酒的老路。

然而，目前的免费游戏虽然会定期为玩家提供新的内容，同时为开发商增加所需的收入。但是不可否认的是，玩家在共同创造游戏体验方面也一直发挥着积极作用，而开发商并未奖励内容创作者和社区在游戏体验环节所产生的价值。

所以，在育碧本月初发布的《对区块链的愿景》报告中，它将区块链技术视为一种“使游戏回归社区”手段，来让玩家花费的时间、购买的物品=他们的贡献中创造价值。

“我们的立场是，采取明智的方法将区块链集成到游戏中，才能实现一条更公平、更以玩家为中心的道路。不可忽视的是，对这项技术的信任受到了严重阻碍。在首次亮相时，出现了依赖这种技术的环境不可持续形式、营销噱头、骗局和其他投机机制的项目。”

然而，转向去中心化意味着育碧将赋予玩家更多的控制权。通过在游戏中引入所有权，使玩家能够更多地控制自己在游戏中的身份，无论是角色还是建造的房子。从本质上讲，玩家在游戏中的每一个元素都将变成属于他们自己的元素。玩家应该能够像对待任何现实生活中的物品一样对待它们，包括出售它们并获得从建造它们或获得它们所需的时间和技能中产生的收益和价值。

当然，只有游戏开发者将玩家置于中心时，区块链才会真正改变游戏。之后，玩家可以对游戏世界产生无穷无尽的可能性，例如游戏物品将不再绑定到单个游戏世界中，从技术层面上可以做到实现游戏世界之间的真正互联，而这也将为真正的“元宇宙”打开了大门，这才是育碧的最终目的。

“元宇宙”这个概念远远超出了单个公司的战略，如果没有数字经济、去中心化和社区驱动，那么“元宇宙”就不可能存在。

 

还有哪些游戏大厂涉足 NFT？

 

除了育碧以外，总部位于美国的视频游戏大厂艺电 (EA) 也在最近几个月表达了对区块链游戏的兴趣。EA 旗下拥有的游戏 IP 包括《战地》、《FIFA》、《极品飞车》等。在本月 EA 公司的财报会议上，首席执行官安德鲁·威尔逊 (Andrew Wilson)表示，NFT 和“P2E”是游戏行业的未来。“我认为，可收藏的 NFT 将在我们的未来发挥重要作用，尽管现在下结论还为时过早，但我认为我们处于非常有利的位置，我们应该期待我们在前进的基础上对此进行更具创新性和创造性的思考。”

最近 EA 的职位招聘中添加了包括“NFT”和“区块链”，这表明该公司至少意识到区块链游戏受欢迎程度激增。“我们为 EA 在游戏订阅、我们的 PC 店面和平台、竞技游戏（包括 FIFA、Apex Legends 和 Madden NFL）以及新的商业机会，包括梦幻体育、区块链和 NFT 等等。”

旗下拥有《合金装备》、《寂静岭》、《实况足球》的日本著名游戏大厂科乐美（KONAMI）也在上个月表达了对 NFT 的兴趣：“随着我们迈向未来，随着移动设备和家用游戏机等电子产品的进步，以及利用云技术的新分销平台的出现，我们的业务领域将继续扩大。此外，随着人工智能、5G 和 NFT 等技术的发展，以及电子竞技作为一项体育赛事的日益认可，我们预计市场将通过创造性的新方式来享受游戏。”

另一家日本视频游戏巨头世嘉（Sega）也正在入局 NFT，旗下拥有《刺猬索尼克》、《三国志》等游戏 IP。世嘉在今年上半年投资了知名的区块链游戏公司 Double Jump.tokyo 后，正在与该公司合作，将可以活用世嘉旗下众多的优秀 IP ，使其创造更多价值。在推出例如游戏插画、背景音乐等 NFT 内容之后，官方还将提供更多服务，让这些 NFT 所有者能够更加有效地利用和享受 NFT 内容。

10月，全球最大的视频游戏商店 Steam 禁止了“Play-to-Earn”游戏，确切的说是所有基于区块链技术或可以交换 NFT 和加密货币的游戏，这一禁止也被写入了 Steam 商城内的规则中。不过，作为 Steam 竞争对手的 Epic 游戏商店对所有被 Steam 抛弃的区块链游戏表示欢迎，但前提是他们必须完全遵守金融法规，有明确的区块链使用政策。

在这样的前提下，Epic 允许区块链游戏使用自己的支付系统。尽管 Epic 的首席执行官蒂姆·斯威尼 (Tim Sweeney) 表示，该公司曾经对 NFT 不感兴趣，但是现在欢迎“技术和金融领域的创新”，并暗示区块链本质上没有好坏之分。

 

小思考

 

NFT 的创造是“偶然”；

NFT 衍生区块链游戏是“奋然”；

传统游戏大厂布局 NFT 和链游领域是“自然”；

NFT 和链游走向更大的舞台是“必然”。
