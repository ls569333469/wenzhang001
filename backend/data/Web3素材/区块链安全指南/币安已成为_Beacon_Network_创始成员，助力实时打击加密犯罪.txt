标题: 币安已成为 Beacon Network 创始成员，助力实时打击加密犯罪
链接: https://www.chaincatcher.com/article/2199094
发布时间: 2025-08-21

==================================================

ChainCatcher 消息，币安宣布成为 Beacon Network 的创始成员，加入全球首个实时加密犯罪应对网络。该网络由 TRM Labs 开发，并与加密行业领军企业和执法机构合作，旨在通过实时情报共享与协作，防止非法资金离开区块链。作为全球最大加密货币交易所，币安的参与将强化加密生态的安全性，并推动加密资产的长期增长与普及。

币安全球首席合规官 Noah Perlman 表示：“事实证明，区块链是打击金融犯罪最有力的工具之一。Beacon Network 进一步促进了公私部门的合作，确保我们持续降低区块链上的犯罪率。”
