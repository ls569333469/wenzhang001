标题: a16z合伙人Chris Dixon：区块链是新时代的应用商店
链接: https://www.chaincatcher.com/article/2064217
发布时间: 2021-08-17

==================================================

来源：Chris Dixon推特

编译：链捕手

 

如果你在 2009-12 年左右的移动黄金时代是一位雄心勃勃、喜欢冒险的创始人，那么你开发了一款新的移动应用。那是 Uber、WhatsApp、Instagram、Venmo、Snapchat 和许多其他顶级应用程序诞生的时候。
 
自那以后，移动技术的采用率呈现了 S 型曲线。仍然会构建出色的移动应用程序，但已经摘下了唾手可得的果实。这十年的计算前沿是在以太坊等可编程区块链上构建应用程序。
 
区块链是运行在物理计算机网络之上的虚拟计算机。它们具有以前类型的计算机所没有的新属性和新功能。
 
当区块链具有高度表达性、接近图灵完备的编程语言时，我们说区块链是可编程的。最受欢迎的可编程区块链是以太坊。
 
我们在去年的“DeFi 夏季”期间看到了这种情况，因为第一波加密/区块链杀手级应用程序爆发：Uniswap、Aave、Compound、Maker 等。
 
DeFi 表明建立包容、公平、透明和可组合的金融服务是可能的。在华尔街，价值流向处于中心的机构。在 DeFi 中，价值向外流向边缘的人。
 
今年 NFT 和游戏是下一波爆发的区块链应用程序：NBA Top Shot、CryptoPunks、Axie Infinity 等。你可以看到这反映在最大的 NFT 市场 OpenSea 的销售总额的快速增长中：
 
 
对某些人来说，NFT 看起来很轻浮，就像玩具一样。但 NFT 很重要，因为与现有的 Web 2 平台相比，它们为创作者和开发者提供了更好的经济效益。
 
下一波区块链杀手级应用会是什么？计算机浪潮很难预测，但有一些有趣的新兴类别。
 
DAO（去中心化自治组织）是互联网原生的全球集体，它们共享资源、构建产品并为实现共同目标而共同努力。
 
社交代币是创作者在线赚钱的新方式。他们消除了寻租中介，并促进了与粉丝群一起成长的微型经济体的发展。
 
基于区块链的社交网络对用户和开发人员做出了强有力的承诺，因此他们可以在坚实的基础上进行建设，而无需担心 API 和经济性的变化。
 
支持加密的 3D 世界和元宇宙体验让人们可以社交、赚钱和构建迷你世界，同时保证互操作性和真正的所有权。
 
这些是一些想法，但企业家更擅长创造未来，而不是像我这样的人预测它。很可能最好的想法要么尚未构思出来，要么对我们今天来说似乎很陌生。
 
如果你在加密领域工作，你会习惯于外人看着你很有趣，或者认为你在做什么是愚蠢的或骗局。对于人们正在从事的工作，我们通常没有名字。太新了。
 
这就是在 S 曲线开始时工作的感觉。可编程区块链是计算前沿，就像 80 年代的个人电脑、90 年代的互联网和过去十年的移动设备一样。
 
我们今天回顾计算领域的经典时刻，想知道在那里是什么感觉。
 
 
但你在那里！2021 年的 Homebrew Computer Club （注：上世纪70年底的知名黑客组织）是 DAO 或 Discord 服务器，但模式是相同的。爱好者互相分享想法。修补匠在晚上和周末进行黑客攻击。这些都是过去的美好时光——边缘生活。
