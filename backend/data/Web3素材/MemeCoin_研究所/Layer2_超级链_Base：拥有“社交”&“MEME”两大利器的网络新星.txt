TLDR:

Base 链，含着金钥匙出生的明星 layer2，获得了美国顶级交易所 Coinbase 的扶持，凭着为主 Farcaster 的 SocialFi 和繁荣的 MEME 文化，在一众 Layer2 中脱颖而出，在加密市场中占据一席之位。

在坎昆升级和 ETH ETF 通过的双频共振叙事下，Layer2、LSD 和 Restaking 赛道也获得了空前关注。其中，尤其是 Layer2 板块中的 Base 链，凭借着基于 OP Stack 模块打造的低成本、开源特性和美国顶级交易所 Coinbase 的加持，仅在 10 个月的时间里，其 TVL 已经达到了 77 亿美元。最新的数据显示 5 月份 Base 网络链上利润达到 698 万美元，成为利润最高的二层网络，同时超过了 Blast 和 Optimism 等网络，该生态受到了众多加密爱好者和大型机构的普遍看涨预期，其实力不容小觑。

下面 LBank 将就根据 Base 的发展历程、生态解读，以及重点赛道解读等，梳理盘点 Base 生态进展，让更多用户能够深刻了解 Base 链在 MEME、SocialFi 领域的闪光点。

 

Base 简介

Base 是 Coinbase 研发的一款 Layer2 扩容方案，由 Optimism 的 OP Stack 提供技术支持，致力于打造一个更开放、更多用户使用、更安全、更低网络费用的交易环境，以实现对以太坊网络的扩容目标。

Base 基于 Optimism 的 OP Stack 技术堆栈开发，创建的是一个采用 Optimism Rollup 扩容方案的以太坊 Layer2 网络，完全兼容以太坊虚拟机（EVM）。它为应用提供了与 Coinbase 的无缝融合、方便的法币入口，以及进入 Coinbase 生态中的数百万认证用户的通道。

 

Base 发展历程

2023 年 2 月 23 日，Coinbase 宣布推出基于 OP Stack 的以太坊 Layer 2 网络 Base，并成立 Base 生态系统基金。

2023 年 2 月 Coinbase 宣布 Base 测试网上线；

2023 年 8 月 9 日，Coinbase 正式推出 Base Network 主网；

2023 年 8 月，Base 链上 MEME 币 BALD，涨幅超数万倍，2 天时间市值破亿，但在第二日撤回大量流动性，导致剧烈下跌，毫无疑问这场 MEME 狂欢为 Base 链带来了超前曝光；

2023 年 8 月 10 日，friend.tech 在 base 链上正式上線，邀请码刷屏社交网络；

2023 年 8 月，Base 与 Optimism 共同推出了治理与收益分享框架，开创 Layer2 经济同盟先河；

2023 年 8 月 31 日，DEX 协议 Velodrome 在 Base 链上推出了 Aerodrome 的分叉 DEX 项目；

2023 年 9 月 2 日，Aerodrome 的 TVL 一度达到了 2 亿美元，占据了 Base 总 TVL 的 50%；

2023 年 10 月，friend.tech 的 TVL 突破 5000 万美元，协议总收入达 14000 ETH；

2024 年 2 月 23 日，社交平台 Farcaster Frames 开始在 Base 链使用，Base 官方为 Based Frames 进行多轮 Grants；

2024 年 5 月，Farcaster 完成 1.5 亿美元融资，协议收入 154 万美元，总用户数突破 45 万。

 
Base 技术特征

 

Base 链作为 OP Stack 采用的重要一环，在技术上具有超强的优势。首先，Base 充分利用以太坊的安全性、稳定性和可扩展性，并融入 Coinbase 的最佳实践，以确保开发者从 Coinbase、以太坊 Layer 1 以及其他可互操作的区块链顺利地加入 Base 链。

Base 秉承去中心化和开放原则，欢迎所有具有远见卓识的创作者。它构建在 Optimism 的开源 OP Stack 之上，确保了一个无需许可、包容创新的环境。Base 以极低的成本提供 EVM 兼容的服务，使用简单的 API 即可为去中心化应用程序设置费用交易以进行帐户抽象，使用易于使用的桥接器安全地构建多链应用程序。

 

不仅如此，Base 与 Optimism 共同推出了治理与收益分享框架：

Base 定序器总收入的 2.5% Base 链上定序器净收入（L2 交易收入减去 L1 数据提交成本）的 15% 中的数额较大者将归 Collective 所有。

Optimism 基金会还为 Base 提供了在未来六年内赚取最多约 1.18 亿枚 OP 代币的机会。

其次，背靠 Coinbace 的强大支持，基于 AA 钱包利用账户抽象，预计该钱包将提高新采用者对链上交易的可访问性，为更多用户提供便利的链上交易方式。Base 与 Coinbase 的产品、用户和工具完美融合，使开发者能够访问超过 1.1 亿经过验证的用户和 800 亿美元资产的 Coinbase 生态系统。这种融合不仅增强了用户体验，还加速了区块链的广泛采用。

 

疯狂吸纳资金，链上数据持续增长

 

在没有发币预期的情况下，Base 链依旧成为 Layer2 领域具有超强竞争力的网络。L2BEAT 数据显示，Base 链市场占比已经达到了 16.08%（数据截止到 6 月 5 日），与 OP Mainnet 的 16.50% 仅有 0.42% 的微小差距。此外，衡量一条链价值的一个重要指标是锁定总价值（TVL），目前 Base TVL 已达到 76 亿美元，在 Layer2 中排名第三，同比增长 6.56%。

 

根据 DefiLama 的数据，最显著的增长发生在 3 月中旬到 4 月之间，当时 TVL 从 6.95 亿美元增长至至 16.6 亿美元，增幅达到了 138.85%，目前 TVL 维持在 17 亿美元左右。

数据显示，Base 的每日交易量为 3.13 亿美元，虽然不到 Arbitrum 的 4.31 亿美元和 Solana 的 10.26 亿美元的，但对于上线时间不足一年的新链来说，颇有些黑马之势。

 

此外，用户数量指标最能衡量一个网络受欢迎和采用程度的指标之一。从用户规模来看，Base 网络依托 Coinbase 1.1 亿的庞大用户基础，在上主网之后就逐步积累了大量的活跃用户。

 

根据 BaseScan 数据，Base 链上的钱包地址总数达到了 1039 万（时间截止至 2024/06/04），24 小时活跃钱包地址数达到了 27 万。

 

其中特别值得一提的是，Base 链在 3 月中下旬新用户数、活跃用户数和交易笔数均创下新高，其很大原因与当时的风靡 MEME 热潮，Base 集成 EIP-4844（3 月 14 日）后手续费大幅下降以及在 3 月 30 日 NFT 项目 Mfers 的创始人 Sartoshi，在 X 上宣布将在 Base 链上发行自己的 meme 代币 mfercoin，造成 6 小时 100 倍的神盘奇迹。

 

Base 生态财富效应显著

 

据不完全统计，Base 生态项目数量已超过 300 个，规模相对完善，囊括了跨链桥、钱包、预言机、节点提供商等基础设置，和 DEX、借贷、聚合器、衍生品等金融产品，以及独具特色的 MEME、Social 原生叙事，孕育着独具特色的 Base 生态。

在 Total Value Locked 追踪上，不难发现 Base 链上出现了两次明显的增长异动，首次上涨是 2023 年 9 月份 Friend.tech 爆发驱动的社交增长和以 Aerodrome 为主的 DEX 的吸引力，第二次上涨是发生在 2024 年 3 月中下旬，Farcaster 持续增长和坎昆升级后 gas 费降低、MEME 盛行，链上流动性获得了巨大的爆发，进一步推动了 TVL 的增长。

其中在两大社交协议 Frend.tech 和 Farcaster 的社交裂变和市场传播下，其机构 Paradigm 的布局也是关键因素。作为加密圈的顶级机构，Paradigm 擅长各种金融机制的设计和市场情绪炒作，NFT 交易市场新秀 Blur、比特币质押协议 Babylon 的都有其参与的身影。

社交协议王国

 

如果说 2023 年 Friend.tech 的爆火只是让 Base 链崭露头角，那么在 2024 年超级社交巨头 Farcaster 的断层式社交数据，1.5 亿融资和 VC 争相押注，并获得 Vitalik 力推，其爆火也让 Base 链在 SocialFi 这个赛道，一骑绝尘。

根据 Base 网站，其中社交占的比例和吸引力与其他公链相比，占据更多市场份额，其背后一方面是注意力经济的金融化，另一方面是得天独厚的社交环境扶持，正如所说的那样“你的网络就是你的净资产”，Base 链上的社交实现 mass adoption。

接下来，LBank 研究院将详细盘点热门的 Base 链上的热门社交，仅作为参考，不作为投资建议。

 
社交新秀、VC 扎堆的 Farcaster

 

Farcaster 当下加密市场社交产品的“龙头”，估值达 10 亿美元，累计融资达到了 1.8 亿美元，获得了 V 神的夸赞，并获得顶级 VC a16z、Paradigm 的大力扶持，正如 Variant 所言：Farcaster 社区就像我（Jesse）十年前加入的早期加密社区的缩影：乐观、有技术性、雄心勃勃、协作性强且总是在线。

巨额融资、空投预期等诸多因素都促使 Farcaster 在上线初期就获得了大量的市场注意力，后伴随着 Frames 的功能推广和 meme 热潮，Farcaster 的总用户量达到了 46 万，协议总收入达到了 165 万美元。

对于普通用户而言，Farcaster 是一个新兴但快速增长的协议，旨在构建“充分去中心化的社交网络”。与传统社交媒体相比，它的一个显著特点是高质量和低噪音的社区氛围。作为 Base 生态的重要组成部分，Farcaster 开放的协议之上衍生出了诸多产品，比如创作者平台 Paragraph，内容金融化客户端 Jam，社区任务平台 Bountycaster，开发者工具 Neynar 等，这很大程度上都归功于 Frames 功能的实现。

 

没落贵族 Friend.tech

 

Friend.tech 是一款基于 Base 链的去中心化的社交应用，将粉丝经济和链上博弈进行了结合，类似 web3 知识星球，将资产发行、社交影响力相挂钩，用户通过购买 token「KEY」进入特定房间浏览内容，随时购买数量的增多，Key 的价值将被推高。

在上线后的半年内，凭着着小众、邀请码饥饿营销等方式火出圈，但因其高手续费磨损，投机过重，加载耗时过久、卡顿、数据更新不及时等产品体验问题，以及高抽水和 Bot 严重损伤了用户，其 TVL 以及从高点 5000 万美元降到了 1000 万美元附近。

 

MEME 新宠乐园

作为 2024 年度最富有争议与热度的热门板块，MEME 无疑延续了市场热度，其中 MEME 的爆发也是为 Solana、Base 链迅速于一众网络中脱颖而出的幕后推手。BASE，作为一款背靠 COINBASE 的新兴网络，通过无缝对接以太坊庞大的基础设施和用户群，为 MEME 爱好者提供了一个极为理想的炒作环境。这一特性使得 BASE 迅速成为 MEME 爱好者的新宠。

接下来，LBank 研究院将详细盘点热门的 Base 链上的 MEME，仅作为参考，不作为投资建议。

 

TYBG

TYBG 被称之为 Base 链的 MEME 中心，是 The Based Institute 发行的 MEME 币，这是 Jesse Pollak 以个人身份资助和领导的一个研究机构，旨在通过研究，支持 Base 生态经济中乐观、丰富和 Based 专有文化的发展。

目前 TYBG 价格为 0.0002448 USDT，市值为 3018 万美元，市值排名#928，最高涨幅为 10767.8%。

 

BRETT

BRETT 灵感来自《男孩俱乐部》漫画中的角色布雷特，也是加密货币世界最重要的文化偶像之一 PEPE 的密友。布雷特的角色以其悠闲的态度和对电子游戏的热爱而闻名，引起了全世界粉丝的共鸣。BRETT 放弃合约且缺乏铸币功能，实现代币完全由社区驱动，创建者无法创建更多代币或操纵代币合约。

目前 BRETT 价格为 0.1394 USDT，市值为 13.63 亿美元，市值排名#81，最高涨幅为 16207.8%。

 

DEGEN

最初被空投到 Farcaster 的 Degen 社区当中，未来会继续空投给 Base 以及 Farcaster 生态系统当中的其他参与者。目前主要用于 Base 链的社交支付。

目前 DEGEN 价格为 0.02444USDT，市值为 3.04 亿美元，市值排名#243，最高涨幅为 109003.7%。

 

Toshi

TOSHI 是一款以「猫」作为动物的 Meme 币，取名源自于 Coinbase 创办人 Brian Armstrong 的猫，旨在 Base 链打造最大的猫咪社群。

目前 Toshi 价格为 0.0004311USDT，市值为 1.83 亿美元，市值排名#330，最高涨幅为 2308626.5%。

 

总结

 

从美国合规交易所，到加密生态破局者，Base 链打开了交易平台盈利的又一新的尝试。在第一季度的财报中，表现极其亮眼，净收入实现 16 亿美元，同比增长 116%，远超华尔街预期，其中 Base 链在 2024 年第一季度中 TVL 增长率达到了 165.14%。

在不断发展的加密货币环境中，Base 成为了希望的灯塔。它与 Coinbase 推出的 AA 钱包 的无缝集成以及在 memecoin 爆炸式增长的推动下的显着增长指标，预示着 Base 在加密领域进入了新的关注时代。

正如 Jesse Pollak 所言“stay Based, stay onchain”，借助超级链 OP Stack 的高性能、低 gas 等优势，Base 链逐步搭建起了具有 Coinbase 特色的以社交和 MEME 为主的叙事文化生态。在这片土壤上，背靠 Coinbase 上亿用户，监管合规上的优势，Base 链仍旧处于早期阶段。相信，随着 ETHETF 的到来和 Layer2 链上活跃指标的增长，Base 有望继 Arbitrum、Optimism 和 Solana 后的生态体系，最终实现 Mass adoption 的目标。
