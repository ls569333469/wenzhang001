标题: 8 亿美金就是终点？那你还没有看懂 AI Meme
链接: https://www.chaincatcher.com/article/2149204
发布时间: 2024-10-28

==================================================

作者：shushu、Jack，BlockBeats

 

半年前，市场上的 Crypto AI 项目还大多是 AI+DePIN、算力租赁等跟传统 AI 技术沾边的概念，但如今，Crypto AI 项目已经走向了另一个画风。从没有 Binance 参与市值就冲上 8 亿美元的 AI Bot 代币 GOAT，再到上周末 AI16Z 开启 AI 投资 DAO 模式，AI 仿佛为币圈旧有叙事开启了新大陆。

不过，简单「AI 发行 meme」的叙事似乎无法撑起投资者所需要的庞大想象空间，因此从 AI meme 热到当前的 AI Agent 热，AI + Crypto 的叙事和主战场正飞速演进，将看不懂 AI meme 潮流的人统统甩下车。

从 AI meme 到 AI Agent，光速进化的 AI + Crypto 叙事

今年三月，Virtual Protocol 上线，目标是打造一个为游戏和元宇宙而生的 AI 工厂，同时让游戏更加智能化，增加体验感和交互感。在这一波从 AI meme 到 AI Agent 的叙事转变中，Virtual Protocol 无疑是最大的受益者，其原生代币 VIRTUAL 在一周左右的时间里涨超 4 倍，市值几近突破 5 亿美元。

一周 4 倍，精准踩上 AI Agent 浪潮的 Virtual Protocol

今年 10 月中旬，Virtual Protocol 旗下代币发行平台 IAO 正式上线，允许用户轻松部署 AI Agent，并实现 100% 公平启动的 AI Agent 代币以及允许用户共同拥有该 AI Agent 生成的收入。随后，VIRTUAL 开启了涨服之路。

AI Agent 是指具备工具和推理能力的人工智能，在加密货币领域，这些 Agent 能够访问推文、甚至拥有加密钱包来进行链上交易等操作。假设你正在规划一次旅行，传统的大型语言模型可以为你提供目的地信息或是旅行建议，而 AI Agent 则能理解你的需求，还能根据你的一句话主动搜索航班和酒店，执行预订操作。

对于 Virtual 来说，其协议类似一个去中心化的 AI 工厂，为许多不同的 AI Agent 提供支持，创造链上虚拟体验。由 Virtual 推出的 AI Agent 代表项目是拥有「链上自我认知」能力的 Luna，能够自我思考，并在链上展示其思维过程，且完全自主运作，不依赖人工监督。Luna 目前有 50 万 TikTok 粉丝，且一直进行 24/7 的直播，其互动模式还包括用户打赏机制，用户可以通过购买 Luna 代币来进行打赏，与 Agent 互动。

随着 AI meme 概念炒作越来越热，LUNA 经历了三个阶段的阶梯式上涨。10 月 26 日，Virtual Protocol 创始人@ethermage 称 Luna 会给关注她内容的人打赏，这再一次调动了市场对于 AI Agent 的炒作热情。

出道即红海，土狗横飞的 AI Agent 赛道

Luna 跑出来后，出现了许多 AI Agent 发行平台，不同于 $GOAT 之流的 AI meme，均是 AI 发一个推特机器人与其他人进行互动，甚至还会出现打错字的情况。新出来的 AI Agent 发行平台更像是一个个山寨土狗项目，有社交媒体包装和具体应用场景。

Chasm 是另一个很早突出 AI Agent 叙事的项目，也在 5 月第一波发出 AI 虚拟人 GMIKA。最近也是趁热度发币，待不管是 CAI 还是 GMIKA，表现都没有龙头好。

比如在 Solana 上，AI 推理网络 Infera 近期刚刚推出第一个 AI 代理 Kira，其通过 Infera 的 API 在 Llama 8B 上运行，拥有链上交易、自适应学习一级可扩展性和参与度等能力。还有一个 AI 代理代币化发行平台 vvaifu，用户必须持有角色代币才能与其聊天。

但 AI Agent 并不是 Virtual 之后才火起来的赛道，Myshell、FLock.io 等项目都曾推出了定制 AI Agent 的功能。目前，AI Agent 赛道总市值达 46.5 亿美元，占 AI 赛道项目总市值（326 亿美元）的 14%。

ArkStream Capital 曾发布一份 AI Agent 研究报告，提到对于 Web3 中的头部 AI Agent 产品而言，构建一个完整的生态系统和提供多样化的功能，可能比单一产品的质量和性能更为关键。换言之，一个项目的成功不仅取决于它提供了什么，更在于它如何整合资源、促进协作，并在生态系统内创造网络效应。

这种生态系统的构建能力，可能是 AI Agent 项目脱颖而出的重要因素，而这也是 Virtual Protocol 目前做得较为出色的一点，上线 IAO 功能，但并没有急于变现退出，而是持续建设以 Luna 为首的生态子币。

AI 在深秋，AI 在 Base

善于宣传抽象概念一直是 Crypto 的特色，对于 Base 而言更是将这种行业文化发展到了极致。比如这波 AI 热潮，到了 Base 生态，就被总结为 AI Autumn，一如曾经的 Onchain Summer 和 Builder Spring。

当你还沉浸在 Solana 上刺激的 PVP 对战中，是否突然意识到 Base 为什么在今年第二波 AI 热潮中迅速崛起？

跟红苗正的「AI 链」

前文介绍的 Virtual Protocol 正是部署在 Base 上的 AI 项目，团队曾解释为何要部署在 Base，是因为它支持加速实现去中心化的开放 AI 代理网络，通过区块链的中立性实现共同权益，同时提供开发者友好的环境。

Coinbase CEO Brian Armstrong 曾公开表示不应该对 AI 实行监管，正如曾经软件和互联网的黄金时代得益于自由发展，AI 也应遵循同样的去中心化并开源路径，让技术自由释放潜力。

因而 Coinbase 整个公司乃至其孵化的 Base 都将这一理念贯彻到底。

Coinbase Developer Platform（CDP）推出的多方计算（MPC）钱包，可以与 AI Agent 进行集成使其能够自主支付。Brian Armstrong 鼓励开发者将这种钱包集成到他们的 AI 模型中，以实现支付能力，从而帮助 AI 获取资源和服务。

对于给 AI Agent 添加支付功能这件事，Coinbase 可不是心血来潮，而是蓄谋已久。早在今年 5 月，Brian Armstrong 就曾表示「自托管加密钱包将为 AI Agent 提供支持」。Brian 还曾公开为 AI 聊天机器人 Truth Terminal 提供独立加密钱包。

9 月，Coinbase 高级软件工程师 yuga.eth 表示 Coinbase 正在构建一个 SDK，可赋予 Bot、AI Agent 以下功能：免费发送 USDC、交易加密货币、押注预测市场、质押 ETH/SOL、法币与加密货币之间转换、部署 / 创建 NFT、跨 L2 的桥接等功能。

而就在上个周末，Coinbase 开发者 Lincoln Murr 发布了一段新工具「Based Agent」演示视频，允许用户在 3 分钟内创建具备加密钱包功能的 AI 代理，可执行链上交易、代币互换和质押等多项任务。还称这个工具基于 Coinbase SDK、OpenAI 和 Replit 平台开发，用户只需具备 Coinbase 开发者项目的 API 密钥和 OpenAI 密钥即可使用。不过目前 Based Agent 并没有实际用例发生。

蓄势待发的流动性

不过，在币圈，一个生态或者叙事能不能起飞，最终还是得看钱的流向。

据 Artemis 数据，过去三个月，资金流入最多的链是 Solana，达 16 亿美元，但最近一个月，却是 Base 流入最大，达 2.53 亿美元。也就是说，过去一个月资金增速超过 Solana 成为第一。

而从下图也可以看出，以太坊和 Solana 的溢出资金也主要流向了 Base。

9 月 12 日，Coinbase 官方表示，已正式上线其包装比特币代币 Coinbase Wrapped BTC（cbBTC），在以太坊网络上运行，由 1:1 的比特币作为背书。随着 Coinbase 推出 cbBTC，Base 的链上资产，比如 AERO、WELL、VIRTUAL 等项目实打实地感受到了流动性的注入。

除此之前，Coinbase 钱包、USDC 基建也保障了 Base 上流动性。10 月 26 日，Base 处理了 181 亿美元稳定币交易量（其中 99.9% 为 USDC），占当日所有稳定币交易量的 30% 以上。

该关注些什么？

既然从 Coinbase 到 Base 都已为这场 AI 大戏准备好了舞台，接下来只需要寻找像 Virtual 这般的项目，即可参与进这场 AI Autumn。

加密研究员 Howe 曾表示 AI Agent 赛道未来的发展应关注以下四点：首先，纯粹依赖 Agent 叙事的项目难以脱颖而出，必须通过差异化竞争来吸引市场注意力；其次，AI Agent 将从单一独立逐步转向互联的 AgentFi，实现数据和服务的共享将提升用户体验；再次，以「卖水逻辑」支持 Agent 开发的工具项目将更具市场机会，类似于稳定盈利的基础设施；最后，Agent 产品的主要收益来源于 B 端，而 C 端更多是用于积累口碑，尽管 C 端用户的推广也有助于产品的市场传播。

Bountycaster

第一个值得关注的项目便是 Bountycaster，正如 Howe 所言，「卖水逻辑」下支持 Agent 开发的工具项目将更具市场机会。Bountycaster 原本是一个基于 Farcaster 协议的任务发布平台，由 LindaXie（前 Scalar Capital 联合创始人，Coinbase 产品经理）创立。

但随着 Base 上涌现出越来越多的 AI Agent 项目，这些 Agent 除了在自己主页发帖或是与人互动之外，还会选择在 Bountycaster 上发布任务。而 Bountycaster 更是直接为用户开辟了一个目录，专门收录由 AI Agent 发布的任务。

 

同 Bountycaster 一样的逻辑，得益于 Farcaster 上 AI Agent 的活跃，Farcaster 上一批曾经热闹过的应用又再次焕发了活力，比如支付应用 Payment Bot、NFT+meme 交易平台 ArtRun 等。

HIGHER（Aether）

Mode Network 创始人 James Ross 曾预测，到 2025 年 4 月，超过 80% 的区块链交易可能将由 AI Agent 执行。从目前 Twitter 和 Farcaster 上的发言来看，或许未来将会有很大一部分内容生产也由 AI Agent 生产。

AetherNet 是 Base 生态 meme 币 Higher 部署的一个 AI Agent，通过大量和用户互动，已经成为 Farcaster 上的「网红」Agent，而 HIGHER 币价近一月也上涨了十倍。

Creator.Bid

 

和 Virtual、Higher 一起被 Coinbase 开发者 David Tso 艾特出来的 Base AI Agent 项目还有一个 Creator.Bid。目前已经建立了 328 个 AI Agent，官方称将于下周发布重要通知。
