标题: App 延迟、上线遭狙击，Base 联创发币引社群不满
链接: https://www.chaincatcher.com/article/2222616
发布时间: 2025-11-21

==================================================

作者： Chloe， ChainCatcher

 

昨日 Base 联创 Jesse Pollak 推出 jesse 代币，发布时间定于北京时间 11 月 21 日 1:00，发币前 Jesse 发推文表示，代币会在 Base App 首发，强调这是为了测试和推广 Base App 的创作者币功能,让用户通过 App 直接参与铸造和交易，同时承诺没有预售、内部分配或任何不公平机制。

不过后来社群反应强烈，许多用户在 Base App 中蹲守却因 App 崩溃和延迟而无法及时买入，最后 Jesse 转而在 X 上发布合约地址，Base App 的更新则迟迟晚了约 17-20 分钟，导致散户错失低价机会，社群抱怨被戏弄，称其为“Base 史上最失败的公平发射”，部分用户甚至花费数小时获取 App 邀请码却无功而返。

除此之外，据 Arkham 追踪数据，该币上线即遭到狙击，总共有 26% 供应量（约 2.617 亿枚）在同区块被买走，主要通过 Base 网络的 Flashblocks 机制实现，狙击手支付高优先费竞争，排名前两位的狙击手分别获利约 70.77 万美元和 61.96 万美元，总套利 130 万美元，社群则称这是“科学家战场”，散户几乎无从参与。

目前 jesse 价格 0.01705 美元，市值 1705 万美元。

Jesse 提出要把权益还给所有创作者的愿景

Jesse 坚称这不是迷因币，而是“创作者币”，也就是与他个人品牌和影响力深度挂钩的持久资产，而创作代币的出现结合“内容币”，旨在将所有权和收益重新还给创作者和粉丝。

早在今年四月，Base 就因内容币产生过争议。当时 Base 官方账号在 Zora 上发布了一则口号“Base is for everyone”，该帖文自动被铸造成可交易的代币，随后 Base 又在 X 平台上分享了这则帖文。由此产生的代币在一小时内市值飙升至 1700 万美元，但随即暴跌 90%。

这起事件引发社群诸多争议，许多用户认为这是 Base 官方背书的一款迷因币，另一方面链上分析平台 Lookonchain 也揭露，有三个加密货币钱包在 Base 官方宣布消息前就购买了 Base is for everyone 代币，并在消息出炉后快速抛售，合计获利 66.6 万美元。而在这些巨鲸抛售后，该代币市值曾跌到 200 万美元以下，使后来进场的用户成为牺牲者，引发了内线交易的疑虑。

Base is for everyone 代币等同于由 Base 背书，当时严重损害了社群信任。面对 Base 疑似发币割韭菜的争议，Base 解释称，该代币是由 Zora 平台自动铸造的，Base 只是在平台上发布了一则帖文。

据 CCN 报道指出，Jesse 后来承认是他个人批准了这则帖文，并表示这是实验，同时驳斥了市场操纵的指控。此后，他依然持续在 Zora 上铸造“内容币”。

名人币高概率以失败收场

尽管 Jesse 强调内容币/创作者币的差异化，但这种与名人、创作者本身绑定的发币行为本就常以失败收场。

CoinWire 的一项研究发现，在针对 377 位 X 平台名人推广的 1567 种迷因币的研究中，86% 在获得背书后的三个月内损失了至少 90% 的价值。

即使是像特朗普和歌手 Iggy Azalea 的代币这样相对成功、在较长时期内维持了市值和交易量的项目，也不太可能再次触及过往达到的高度。

不管是迷因币还是内容币/创作者币都是所谓的注意力经济游戏，散户即便有机会尝到高回报甜头，但其价值往往难以长久，何况在主流山寨币都疲软之际，Jesse 选择此时发币，市场可能不买账。
