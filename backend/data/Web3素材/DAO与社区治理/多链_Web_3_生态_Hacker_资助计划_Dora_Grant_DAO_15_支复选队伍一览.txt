标题: 多链 Web 3 生态 Hacker 资助计划 Dora Grant DAO 15 支复选队伍一览
链接: https://www.chaincatcher.com/article/2082131
发布时间: 2022-11-05

==================================================

作者:Dora Grant DAO

 

Dora Grant DAO 是一个由社区驱动的项开源极客资助计划，旨在资助开发者和极客运动——资助那些有创新和想法的开发者和极客，并最终帮助他们为多链 Web3 生态系统的未来打造重要产品和工具。

11月5日，Dora Grant DAO 正式进入零知识投票环节。经过预先设置的初筛环节，共 15 个项目从 111 个报名团队中脱颖而出，成功进入首轮投票环节，vcDORA 社区将对这 15 个项目进行投票。现在，就让我们一看看这 15 只队伍都是做什么的。(排名不分先后）

 

1、Faro

 

一个为基于 zk-rollup 设计的 L2 的流动性质押协议。团队正在建立一个流动的质押协议，目标是人和人，包括那些不符合 ETH2.0 最低质押要求的用户，提供质押服务。Faro 的服务将专注于部署在基于 ZK-rollup 的以太坊 L2 上，包括 zkSync, Starkware,  Scroll, Polygon zkEVM 等。  [BUIDL；提案]

 

2、CEDE Labs

 

目前，还没有任何工具可以像以非托管的方式同时聚合 CeFi 和 DeFi 资产。CEDE 希望可以帮助用户可以在同一个界面中以非托管的方式可视化和管理他们的所有加密资产，无论是在中心化还是去中心化的世界里。目前 CEDE 正在研发两个产品：CEDE.link，一个网页版投资管理工具，以及 CEDE.store，一个非托管的浏览器拓展应用，帮助用户管理中心化交易所资产。[BUIDL; 提案]

 

3、Faceless

 

一个跨平台人工识（HRI）读隐私合规支付解决方案。现有的 HRI 解决方案，如 ENS ，通常专注于一个特定的区块链，并且未能纳入许多现有的被人们广泛使用的 HRI ，比如邮箱，手机号，社交媒体账号，但是这些HRI往往隐私性又做的不够好。Faceless 使用的 HRI 是合规支付的基础，并且结合 IBE (identity-based encryption) 和零知识证明技术保障了用户的隐私，最终可以帮助大量用户以合规的方式在 Web3 的世界进行安全保密的自由交易。团队将会提供开源库来证明设计的可行性。[BUIDL; 提案]

 

4、Prestare.Finance

 

一个借贷协议，可以为用户提供较低的抵押率，甚至可以在不调用链下信息的情况下，支持几乎任何资产的低抵押贷款。特色是：

低抵押借贷
含信誉分的SBT
无许可的资产listing
协议可以提供内部清算。

[BUIDL; 提案]

 

5、Klezma
 

就像初创公司一样，只有 5% 的独立艺术家和音乐人可以获得成功。Klezma 想要改善这一问题，帮助独立音乐家们能够更轻松的获得曝光和资金支持。Klezma 是一个一站式的音乐家 Launchpad ，允许任何人都可以投资艺术家，并通过在 Tiktok 、Youtube、Instagram 等视频中使用他们的音乐获得奖励。[BUIDL; 提案]

 

6、Metopia
 

一个 web3 工具层基础设施，创建了一个用户信誉系统，并且根据该用户信誉系统提供了一系列有效的用例。

声誉系统：一个用户档案，自动聚合来自数据协议（RSS3、Ceramic、Moralis、The Graph等）的 Web 3 数据。
治理：一个治理平台，允许基于用户贡献和证书的定制 DAO 治理策略。
SBT 系统：一个凭证平台，社区可以通过 POAP、SBT 等奖励成员的贡献。
激励：Metopia 的不可转让的 SoulBound 协议帮助项目创建更好的激励系统。

[BUIDL; 提案]

 

7、KlayOracle
 

一个开源的预言机架构，将链下数据与 Klaytn 网络的智能合约安全地整合起来。通过 KlayOracle，智能合约开发者可以访问可靠和透明的数据，如价格数据、体育数据、天气数据、随机数字或其他外部 API ，并轻松地将它们整合到他们的 Klaytn dapps 中。[BUIDL; 提案]

 

8、SpaceDAO
 

SpaceDAO 政委为太空公司开发 DAO 工具，这些工具将解决太空主题公司所面临的关键问题，比如如获得资本和保留人才。此外，与旧的组织相比，这些新类型的组织提供了更加灵活、迭代和创新的机会。

目前 SpaceDAO 已经在怀俄明州注册了新的企业名称，the DAO LLC，并用这个称号设立了一个银行账户。同时还在怀俄明大学校园内的 WTBC 大楼有一个办公场所，并且已经开始与实习生接触。[BUIDL; 提案]

 

9、Pin Save
 

一个中心化的图像共享和内容聚合平台，旨在成为去中心化版 Pinterest 。现在单一的在线应用程序和平台保持着对用户的控制，阻碍了去中心化技术的采用。Pin Save 将去中心化存储、智能合约和创作者对知识产权的所有权相结合，在内容创作者之间创造了新的动力，以此形成了新的更有意义的社区。[BUIDL; 提案]

 

10、Feed.xyz
 

未来公共知识的元空间，旨在建立从 Web 2.0 进入 Web 3.0 的门户站，将所需内容有效地传递给受众群体。围绕日常用户对 Web3.0 内容互通的需求，团队将深度整合Mirror和其他内容创作平台，并在实践中创造一个有效的 Writer to Earn 、Share to Earn 的经济模式，一次让内容产出和创作者可以最大程度地发挥自己的影响力，而内容消费者则可以通过传播好的思想和内容做出贡献而获得回报。目前在 Feed.xyz ，内容可以无缝同步到 Mirror ，为创作者提供更友好的创作环境。[BUIDL; 提案]

 

11、WEB3CLOUD
 

WEB3CLOUD 是一个集成了存储、计算和网络核心能力的 Web 3.0 云计算平台。它旨在帮助用户实现从 Web 2.0到  Web 3.0 的迁徙，并成为数百万 Web 3.0 开发者和应用的基础设施。团队将自己定义为 web3 经济的 "AWS"，是去中心化云计算的一站式技术服务提供者。 [BUIDL; 提案]

 

12、Sisyphus Protocol
 

由于现在人们在生活中可以选择做的事情太多，我们往往没有一个长期的兴趣，很难坚持做一件事情。而过多的案头工作也导致了亚健康问题，如何帮助人们坚持锻炼也是一个急需解决的问题。Sisyphus 就是一个帮助人们自我完善和鼓励创作者经济的去中心化社会协议。协议采用组队+质押+记录+奖励的模式来约束和激励用户坚持完成目标。用户需要在协议内质押稳定币来参与任务。如果不能完成任务，就会造成经济损失。同时，创作者们可以在协议内发布课程和推出自己的代币，来帮助人们更好的完成目标。[BUIDL; 提案]

 

13、Cruzo
 

一个多链 Web3 营销平台和第一个集合了数字加密加密礼物，聚会用品，礼物贺卡的 NFT 市场。创作者、用户、收藏家和品牌可以在平台上使用作为 NFT 发布的数字内容进行会面和互动：问候语、明信片、故事、邀请函、礼物、Metaverse 的聚会用品以及其他数字资产。

通过在区块链技术的帮助下提供实用性和所有权，Cruzo 将在品牌互动、增加忠诚度和数字化方面为用户和客户开启全新的 Web3 体验。最终，Cruzo 希望将情感和快乐的时刻赋予每个人，并通过革命性的贺卡和礼品市场推进 NFT 的大众化。[BUIDL; 提案]

 

14、CashmereFi

 

一个基于 LayerZero 构建的全链，可互操作的，抗 MEV 的 DEX 聚合器和稳定币交换协议。允许用户在任何链之间交换任何资产，而提供最低的滑点和交易费用。[BUIDL; 提案]

 
15、LewK

 

团队想要构建一个去中心化的由用户拥有的招聘市场。[BUIDL; 提案]

 

11 月 5 日—11 月 13 日，vcDORA 社区可以通过 DoraHacks 平台为支持的项目进行投票以及后期的治理，首期 20 万美金 Grant 奖金的分配顺序由零知识投票结果决定。

Dora Grant DAO 计划旨在持续支持在以下三个领域的多链 Web3 开源极客团队: 多链 Web3 核心基础设施和工具, 加密原生应用, 加密-前沿科技交叉领域。
