标题: 余弦评论 Crypto AI Agent 现状：行业关注点仍停留在 Token 价 格，缺乏真正创新
链接: https://www.chaincatcher.com/article/2166824
发布时间: 2025-02-11

==================================================

ChainCatcher 消息，慢雾创始人 Cos(余弦) 在 X 平台发文指出，过去两个月，非加密领域的 AI Agent 发展迅猛，竞争激烈，尤其是 DeepSeek 和 Mistral AI 的推出，推动了大量基于 LLM API + Web2 OAuth + 云服务 的 AI Agent 创新应用。

相比之下，Crypto 行业的 AI Agent 仍然主要关注 Token 价格，而非真正的技术突破和应用落地。他质疑行业能否实现破圈创新，并直言炒币赚钱并不丢人，但自我催眠才是真正的问题。
