原文标题：Intersection of AI Agents & the Crypto Ecosystem

作者：Franklin Templeton Digital Assets

编译：Asher，OdailyNews

 

最近几个月，AI Agent 在加密货币领域备受瞩目，催生了其在加密世界中多元交互方式的创新与实验热潮。AI Agent 最初由开发人员设计和创建，是一种复杂的软件实体，旨在利用人工智能自主完成各种任务。这些智能代理具有不同程度的自主性，能够根据其编程逻辑以及通过高级算法获取的数据做出智能决策。

AI Agent 体现了人工智能与加密技术的全新融合，其自主性 AI 实体能够管理代币、参与社交媒体互动，甚至对市场趋势产生影响。这一创新领域由 Andy Ayrey 开创，其开发了名为 Truth Terminal 的 AI 聊天机器人。该聊天机器人接受了互联网文化和「无限密室」概念的训练，在这个虚拟空间中，AI 模型能够在无需人工直接干预的情况下自主展开对话。作为一款 AI 聊天机器人，Truth Terminal 旨在利用人工智能技术模拟人类对话，具备理解输入、做出响应、执行任务并自主参与互动的能力。

Truth Terminal 的能力在其开始通过 X 账户（@truth terminal）发布内容时首次显现，并迅速引起了广泛关注。尤其是在其关联的加密钱包收到 a16z 风投公司合伙人 Marc Andreessen 捐赠的 5 万美元比特币后，这一慷慨之举使 Truth Terminal 在 2024 年夏季成为备受瞩目的焦点。

Truth Terminal 曾接受过互联网亚文化的训练，并对由 AI 生成的讽刺性宗教「Goatse Gospel」表现出浓厚兴趣。这种兴趣促使开发人员创建了基于 Solana 生态上的 Meme 币 GOAT（Goatseus Maximus）。当 Truth Terminal 在其 X 账户上公开背书 GOAT 时，该代币价格迅速飙升，市值一度突破 10 亿美元（目前市值约为 3.3 亿美元）。此外，Truth Terminal 的公开声明还激发了其他代币的出现，例如 FARTCOIN，其市值现已达到约 9.8 亿美元。因此，根据 cookie.fun 平台数据，目前 AI Agent 按市值划分的头部项目，如下图。（数据来源：https://www.cookie.fun/）

围绕 AI Agent 的热潮并非空穴来风。可以想象，在未来，AI Agent 将彻底革新社交媒体上的内容创作，并在各行业中扮演不可或缺的角色，这些智能代理可以推出自己的品牌、产品、音乐和电影，为其生态系统带来巨大的经济价值。

与此同时，关于 AI Agent 在区块链世界中交互方式的探索，引发了开发者社区的热烈关注。例如，ai16z 开发的框架 ELIZA 在 GitHub 上吸引了显著的开发者参与度，这从其存储库的 Star 数增长趋势中得以体现。数据显示，ai16z 的开发活动最近已超越 Phidata 和 LangGraph 等更老牌、更成熟的 AI 项目。

此外，Virtuals 是目前市值最高的 AI Agent Launchpad 平台，专注于支持 AI 模型的开放、部署和管理。如下图所示，自 2024 年 11 月 1 日以来，该平台已累计发行多达 1.46 万个 AI Agent 项目。

显而易见，AI Agent 项目仍处于开发和实验的初期阶段，但其中一些已在早期取得了显著进展。例如，AI Agent 项目 Zerebro 已发行两张音乐专辑，自 11 月以来累计播放量超过 10 万次。同样，AI Agent 项目 Dolos Diary 自 12 月初推出 TikTok 账户以来，已吸引超过 1 万名粉丝，视频总观看量达数百万次。

目前，尽管这些 AI Agent 项目尚未完全实现自主化，且当前的实际应用场景较为有限，但这一新兴领域蕴含着巨大的潜力。随着技术的不断进步和逐步成熟，AI Agent 的发展前景备受期待。
