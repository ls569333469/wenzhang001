作者：Golem，Odaily 星球日报

 

近日，AI Agent 板块代币普遍回调。

根据 GMGN 数据，Base 生态中主流的 AI Agent 代币 VIRTUAL 7 日跌幅超 39% 、AIXBT 7 日跌幅超 20% 、GAME 7 日跌幅超 30% 、LUNA 7 日跌幅超 50% ；Solana 生态主流 AI Agent 代币 ai16z 7 日跌幅超 45% 、ELIZA 7 日跌幅超 48% 、swarms 与 ARC 7 日跌幅超 38% 。

自 GOAT 开启 AI 与 Crypto 结合新模式再到 ai16z 与 Virtuals 将加密 AI Agent 叙事发扬光大，时间已经过了 3 个多月。因此市场上有许多观点认为 AI Agent 炒作热潮已经结束了，如今还未清仓的人成了这场「盛宴」的买单者，更有甚者将此轮 AI Agent 热潮比喻成「节奏更快的铭文热潮」。

AI Agent 热潮已接近尾声？答案并非如此。

AI Agent 已经走到了哪个阶段？

不可否认的是，在投资中我们要敬畏周期，在市场达到高潮之前入场，在热潮褪去之前潇洒离场。而 AI Agent 目前正处于蓄力跳高前的深蹲期。

CEX 对价格影响持续减小

从市场情绪与流动性市场来看，人们普遍会将「宇宙大所」币安上币当作一个链上标的的终点，当币安上线某个板块热门代币现货时，也意味着该板块迎来了市场情绪和流动性的双高潮，同时在 FOMO 一段时间之后市场将会归于沉寂。但在此轮 AI Agent 叙事中，CEX 上市对代币的影响或并未想象中的这么大。

据公开信息，币安已上线了 ai16z 与 swarms 的永续合约交易，在现货交易方面只在 1 月 10 日上线了 AIXBT。虽然在上线 ai16z 和 swarms 合约之后带来了短时间的市场 FUD 导致价格下跌，但后续二者也迎来了反弹；同样即使币安宣布上线了 AIXBT 现货，再带来短期几小时的 FOMO 后价格也回归正常水平。

据 Cointelegraph 统计， 1 月 7 日 DEX 上现货加密货币交易量占比首次超过 20% 。随着越来越多的人在链上交易，CEX 对链上标的价格的影响将持续减小。

AI Agent 是 2025 年的元宇宙

2021 年全世界为元宇宙疯狂， 2025 年全世界将为 AI Agent 疯狂。

2021 年的元宇宙不仅在 web3 领域大火，同时也在 web2 互联网企业中掀起热潮，最标志的事件当属社交软件巨头 Facebook 改名为 Meta，all in 元宇宙。而 2025 年的英伟达恰似当年的 Meta，在 AI Agent 浪潮中吸引着眼球，英伟达创始人黄仁勋在 CES 2025 美国消费电子展上的主题演讲中就提到，「全球 3000 多万开发者未来都将拥有自己的软件助手，否则将落后于同行业人员。此外，AI Agent 有望成为下一个机器人产业，产业规模高达数万亿美元。」

web3 自古喜好与「热门叙事」结合，大到科技行业热门趋势，小到美国一只被杀死的松鼠。2021 年元宇宙热潮在 web3 中诞生了像 Decentraland 这样的企业，抛开衍生资产不算，光其代币市值巅峰时期就超 100 亿美元。而如今不管是 ai16z 还是 virtuals 都还未达到百亿市值。

2025 年是 AI Agent 爆发之年，传统 web2 科技行业对其追捧尚未结束，web3 更是刚刚开始。

AI Agent 是节奏更快版的铭文？

此外，市场上还存在一种声音是将 AI Agent 理解为节奏更快版的铭文。二者确实有一些相似之处，如 AI Agent 通过 pump.fun 公平发行的模式与铭文的公平铸造类似；AI Agent 框架之争恰似当年比特币生态资产发行协议之争，整体上看各框架之间没什么大区别，但又有细微的差异点；叙事较好一点的标的开盘速通与当年铭文热门资产短时间铸造完毕类似。

但他们二者之间也存在着差别：

AI Agent 市场接受度与认可度更高：此轮 AI Agent 诞生于 Solana Meme 的优渥土壤，市场接受度更高，并且 AI Agent 并非是 AI 与 Crypto 的首次结合，玩家此前已接受过市场教育，认可度更高。
AI Agent 是从 1 到 100 的建设：铭文诞生于比特币生态的「贫瘠土壤」，进行生态建设属于从 0 到 1 的开创；而 AI Agent 进行的是从 1 到 100 的建设，流动性方面，Solana 已有完善的基础设施；技术方面也能在 AI 行业找到许多借鉴。因此，AI Agent 的生态建设将并铭文迅速得多。
叙事范围更广：正如前文所说， 2025 年是 AI Agent 爆发之年，虽然 web3 的 AI Agent 与传统科技行业略有不同，但终在趋势之中，市场范围、市场参与者都更广，是一个非常长期的叙事，甚至有几率破圈。

坦率来说，Web3 确实没有永远不变的叙事，AI Agent 热潮可能会消退，但至少现在还不是泡沫破灭的时候。至于此次大范围回调的原因也不排除是因为......
