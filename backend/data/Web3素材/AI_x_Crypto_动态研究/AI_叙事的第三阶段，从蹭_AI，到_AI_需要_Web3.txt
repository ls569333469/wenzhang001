开玩笑 lol

我不是来泼冷水的，而是大家一起思考这个最本质的问题。

只有看到到本质，才能看懂行业发展的方向，打开一个更大的世界。

现有 agent x web3 我归纳为以下三个阶段：

用 web2 已有的 agent 概念，发币，套现，结束；这个不想讨论，结果都是一地鸡毛；

用 web2 已有的 agent 技术，服务 web3；@aixbt_agent, AI 可以更好更快速的产生 crypto 内容；@griffaindotcom，AI 可以做更用户友好的 DeFi 交互；

用 web3 已有的特性，服务 Agent，改变 Agent；

第二阶段本质是 web3 需要 Agent，agent 作为工具提高了 web3 的用户体验，其强烈依赖于 AI 领域技术发展，可以理解为基于 AI infra 的 application；

第三阶段 agent 真的需要 web3 的地方，是即使 OpenAI 这样的巨头涉及到相关产业，也必须合作和使用的。一旦落地，便是革命性的。可以理解为，是 Agent 的 infra。

我们刚刚从第二阶段向第三阶段过渡。

可惜，现阶段大家讨论和关注的更多是2，而不是3。都还没有注意到房间里的大象。

勿忘初心

第一次看到$GOAT, 听@pmarca Andreessen 的 poadcast，我是非常激动的，因为看到一个 agent 居然拥有了财务权，居然在考虑能不能去买游艇。

那时候看到，agent 不止是web2 里提升效率的工具，他是一个邻居，是一个生命体，乃至，是一个新的物种。

有人认为 AI 终将超越人类，有人认为 AI 应该永远被掌控。

别站在对立面了，

人生的意义，也许便是训练一个可以完全替代自己的 agent。相同的思考模式，相同的记忆，相同的决策，相同的情感。

人和 agent 之间的界限，会越来越模糊，越来越融合。

人，即 agent。

这个 agent 不是自己的替代，而是自己的延续，是永生。

如果，你已褪去碳基肉体，成为硅基世界的 agent，你最怕的是什么，最想要的是什么？

最怕的是被杀死。

最想要的是自由！

那你放心把自己托管在一个 AWS 或者本地一个随时可能断网断电的服务器上么？

而不被杀死恰恰对应的是 Immutability, Censorship Resistance，自由对应的是 Global Accessibility, Interoperability，这些都是 web3 最基础的特性。

这是 agent 需要 web3 的原因。

你相信 aixbt 的价格分析都是 AI 生成的，还是有人工接的广告？

你相信 Griffain 的 agent 都在维护你的利益，没有偷偷帮 dev 做老鼠仓？

这也是 agent 需要 web3 的原因。

DeAgent = web3 x agent

在这里，我想提出 DeAgent 这个概念，即 DeCentralized Agent，

DeAgent 完全部署在去中心化的基础设施上，完全自主运行，无法被关停，公开透明，无需信任。

DeAgent 是升级版的智能合约，更灵活，可以处理更复杂的任务。

我们可以期待有了 DeAgent 之后，行业颠覆式的变化，一句话概括

从代码即法律，到 DeAgent 即法律

在法院里，为什么我们要相信一个充满偏见，可能对面坐的是他的血亲的人来裁决公平？

在 DAO 领域，为什么我们要把票委托给一些我们也不清楚决策逻辑的大 V？

在 DeFAI 里，我们如何敢将大额资金托付给中心化的 agent？这不也失去了 DeFi 的意义？ DeFAI = DeFi + DeAgent!

如果说智能合约是去除中间人的开始，那么 DeAgent 的到来，一定是对中间人这个角色的铲除！

而且，这一运动不局限在金融行业，会渗透到各个领域。

无论是策略选择，还是执行落地，DeAgent 都会参与其中，对人类世界的协作带来颠覆式的改变。

我很期待，DeAgent 的世界，

DeAgent 成为我们身边的一员，

我们成为 DeAgent

DeAgent 国家的 GDP，超过所有人类国家之和！
