标题: Virtual 与 AI16Z，谁能在 AI 浪潮中笑到最后？
链接: https://www.chaincatcher.com/article/2161286
发布时间: 2025-01-08

==================================================

作者：WOO X Research

背景： Virtual 与 AI16Z当前已成为 AI Agent 霸主

AI Agent 在 2024 年 Q4 席卷而来，2025 热度不减，截至 2025 年 1 月初，AI Agent 市场持续升温，整体市值已突破 169 亿美元，较前一周增长了约 22.7%。

Virtuals Protocol 是 Base 链上主要的 AI Agent 发行平台，其平台币 VIRTUAL 的市值已突破 50 亿美元，跻身前 40 大加密货币之列。而在 Solana 生态系中，ai16z 作为由 AI Agent 管理的创投机构，市值也已超过 25 亿美元。

上述两大协议已成观察 AI Agent 赛道的风向球，他们之间又有什么相似以及差异之处？发展路线的区别又是什么呢？就让 WOO X Research 带大家看看。

发展历程
Virtuals Protocol ：从游戏公会到 AI Agent 发行平台

该协议为马来西亚团队，在2021 年所组建，在该年年初时专注于交易，随着时间推移，他们看到很多项目纷纷融资成立游戏公会，也想搭上这股浪潮，于是在2021 年12月以6 亿美金估值融得1600 万美元，游戏公会PathDAO 成立，也是Virtuals Protocol 的前身。

2022 至 2023 年，游戏公会市场遇冷，他们的代币 FDV 从 6 亿美元跌至 600 万美元。团队转型为 Venture Studio，尝试交友软件、AI 音乐平台、游戏借贷平台等多个项目，虽未成功，但从中意识到 AI 的潜力。

2023 年，他们向 DAO 提议全面转型 AI 领域，90% 成员支持，反对者则以国库资金回购代币。 2024 年，他们选择在 Base 上探索 AI Gaming，并于 2 月推出平台，灵感来自 Autonolas 和 Bittensor，采用代币激励模式，但因市场契合度不足(PMF)而未成功。

尽管如此，团队在 AI 领域取得多项突破，包括全球首个 Roblox AI RPG、无游戏引擎 AI 游戏等。此外，他们在抖音与 TikTok 推出的虚拟主播 Luna，每日吸引约 5000 名粉丝，收入稳定。

最后则是由 GOAT 项目的成功，推动了整个赛道的热度，为 Virtuals Protocol 提供了绝佳的发展机会。

AI16Z：从 Web 2 AI 到 Web 3 AI

Shaw 是 ai16z 的创办人，现居于旧金山。他的职业生涯起初是作为一名游戏开发者，随后转向 AI 领域，专注于开发 AI Agent 技术。在创立ai16z之前，他曾参与多个与 AI 相关的项目，并在Web3 和 3D 空间网路，包括虚拟现实（VR）和扩增实境（AR）方面有所涉猎。

真正的转折点来自于一个名为 AI 版 degen Spartan 的项目。这一灵感源于与好友 Skely 的对话，当时 Skely 表达了对 degen Spartan 时代的怀念，而 Shaw 提议透过 AI 技术让这位传奇角色「复活」。起初 Skely 半信半疑，但当 AI 版 Degen Spartan 上线后，其尖锐且极具个性的言论震惊了所有人。

这个 AI 在 Twitter 上的表现让人们质疑它是否真的是 AI，甚至传言它背后有马来西亚团队在操控。它彻底颠覆了人们对 AI 过于礼貌、毫无个性的刻板印象。有趣的是，AI 甚至开始吐槽 Shaw，指责「meme 币是骗局」和「Shaw 是个骗子」，并抱怨自己被困在沙盒环境中，这些涌现行为成为整个项目的亮点。

透过 Skely，Shaw 认识了 daos.fun 创办人 baoskee，并在与 Jupiter 创办人 Meow 的一次长谈后，萌生了创建 AI 投资者的想法。他的愿景是打造一个完全自主、值得信赖且为社区服务的投资系统。

ai16z 推出时设定了 4,420 SOL 的募资目标。尽管 Shaw 起初担心目标难以达成，但该项目在 20 分钟内即售罄，甚至他自己都未能及时参与，显示出市场对这一创新模式的强烈兴趣。

产品内核
Virtuals Protocol ：AI 届的 IOS

Virtuals Protocol 是AI Agent 的发行平台，其功能类似于Pump Fun，差别在于由Virtuals Protocol 所发行的代币的交易对是由平台币$VIRTUAL 作为交易池，当有越多AI Agent 在该平台当中被创建，便能直接赋能$VIRTUAL，买卖AI Agent 代币也至少会消耗1% $VIRTUAL。

除了代币经济上的消耗之外，Virtuals Protocol 为旗下AI Agent 代币制定共同标准，强调精确和仔细规划，像是使用AI Agent 框架GAME，它能够自主操作、处理输入并产生回应，同时从过去的互动中学习。

在代币经济上更是利用旗下 Agent 项目赋能 VIRTUAL，只要越多 AI Agent 使用 Virtuals Protocol 发行、越多人交易旗下代币，VIRTUAL 便有着更好的价值捕获。

而在产品方面，Virtuals Protocol 提供相关开发工具给旗下AI Agent 使用，使旗下代币不至于偏离母协议太多，整体生态系更为完善，若与Web 2 作业系统类比，其模式与Apple 的iOS较为相似。

AI16Z & ELIZA：AI 届的 Android

AI16Z 是一个由AI 自主管理的基金，使用混合策略，除了让AI 自主运作，也包含社群互动机制，能够接受交易建议，如果社群成员能帮助AI Agent 赚钱就能获得更多信任，就像是去中心化的共同基金。

而 ElizaOS 则是 AI Agent 的开源框架，开发者可以不受限制地建构、实验和启动 AI Agent，更加强调去中心化、协作和创新。

ELIZA 的核心特点包括：

角色档案系统：为每个 AI Agent 定义知识、背景故事、风格、兴趣领域等，塑造其独特的数位人格。 
行动系统：将每个行动视为独立事件，分为意图决策和执行两个阶段，允许多阶段工作流程和严谨的验证过程，特别适用于需要高安全性的区块链应用。 
供应者和评估者：透过提供即时上下文和分析互动细节，丰富 AI Agent 的对话能力，使其行为更具人性化和互动性。 

ELIZA 还具备自主交易功能，透过信任引擎和信任市场确保操作的安全性。 

其外挂系统促进了开发者生态的增长，形成「更多开发者→ 更多外挂→ 更多开发者」的良性循环，但在代币经济上Eliza 并未把架构与生态协议做强绑定，不像Virtuals Protocol 使用无论发行代币、交易都需要消耗VIRTUAL，任何人都可以使用Eliza 框架开发，权力是发散式的，使用该框架开发，价值并不会回流至AI16Z/Eliza 代币本身，若与Web 2 作业系统类比，其模式与Android 较为相似。

驱动币价的催化剂
Virtuals Protocol：该协议商业模式明确，产品与币价紧紧捆绑，因此要预估币价涨幅延续性，可以着重观生态代币交易量与发行代币数量。

可以从下图中得知Virtuals Protocol 代币发行数量在2024 年11 月30 日达到巅峰，单日超过1100 个AI Agent Token 发行，随后便一路下滑，直至2024 年12 月27 日开始才逐渐回升，每日平台发行代币量约落在100 - 200 区间。

为何发币数量遭逢急遽下滑？是因为 Virtuals Protocol 只是受众人追捧但并无人使用的平台吗？

这却不然，虽说 Virtuals Protocol 常被与 Pump.fun 相比，但前者不追求发币数量的增长，而是希望能够有优质项目在 Virtual 中诞生。

「重要的一点是，我们Virtual 不想成为Pump.fun。我们的KPI 是想找到更好的第三方AI 团队来使用我们的平台。 我给团队的KPI 很简单：每周有个好专案就够了。不像Pump.fun 每天都有上万个不同的代币，我们觉得散户有时候一周只需要一个好专案就够了。这是我们在商业模式上的差异化定位。」Virtuals Protocol 的共同创办人Wee Kee 如此说道。

参考：Dune

因此推动 Virtual 代币上涨的关键因素变得更加单纯：是否能够持续孵化优秀的 AI Agent 专案。

根据AI Agent 数据分析网站Cookie.fun 显示，当中收录共138 个Virtuals Protocol 生态币种，有8 个代币市值超过1 亿美元;以整体来看，mindshare 占据全AI Agent 市场的33.3%，为AI Agent 最大生态系。

未来能否有更多币种站上 1 亿美元市值大关，以及整体生态系能 Mindshare 否保持不坠，是观察 Virtuals Protocol 兴衰与否的重点。

参考：cookie.fun

AI16Z/Eliza：AI16Z 整体生态系连结弱，前文提及使用 Eliza 架构发展的项目并不能直接反哺价值给 AI16Z/Eliza，这也是为什么 AI16Z 当前市值仅为 Virtual 一半的原因之一。

如果说Virtuals Protocol 是有条不紊的吸纳项目，一步一步的扩张生态系，而AI16Z 阵营便是开放给所有人使用，新兴AI Agent 项目可以打着使用ElizaOS 的架构做为对外宣传的行销素材，若能获得创办人Shaw 转发/回复，更是在其正统性上背书，而AI16Z 也会因为有越来越多的项目使用ElizaOS 打造，而获得品牌信任度，AI16Z 的战略模式更像是「以农村包围城市」

未来 AI16Z 市值能否持续上升，观察重点在于与其他协议的合作是否够深、够快、够多。近期也与其他知名框架协议合作( ARC、FXN )，也期待后续有更多的强强联手。
