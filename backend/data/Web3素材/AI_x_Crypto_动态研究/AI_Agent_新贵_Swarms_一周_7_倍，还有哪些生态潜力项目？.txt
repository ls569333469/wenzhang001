==================================================

作者：Golem，Odaily 星球日报

 

2025 年第一周，AI Agent 赛道继续狂飙，两大生态 ai16z 和 Virtual 代币市值分别突破 20 亿美元和 50 亿美元，创下历史新高。

AI 创新仍在涌现，当人们以为 AI Agent 基础设施「派系之争」已定，所有 AI 代理都需要在这两大生态中「拜码头」时，一匹黑马——Swarms 杀出重围。过去一周，Swarms 代币涨幅超 768% ，市值最高触及 4.4 亿美元；目前 Swarms 在 GitHub 上的 Star 数也超 2800 。

Swarms 是一个多代理协作框架，核心在于提供了「框架」这一核心组件及长时记忆、任务分解等功能，帮助多个 AI 代理在同一个网络中无缝协作，以分解处理复杂的任务。当前 Swarms 也在大力推进生态项目发展，随着多代理协作生态的丰富，仍处早期的 Swarms 生态可能还蕴藏着 Alpha 机会。Odaily 星球日报将简单介绍 Swarms 生态项目和 Swarms 本身的进展。

生态项目介绍
MCS
市值： 2500 万美元
持有地址数： 3889 
代币合约：ALHFgnXSenUv17GMdf3dL9gtFW2KKQTz9avpM2Wypump

mcs 由 Swarms 创始人 Kye Gomez 创建，并且已将 mcs 官方推特链接挂在了其本人简介中，具有了官方背书。mcs 是基于 Swarms 构建的用于医疗诊断和编码的生产级多智能体系统，用户可以通过与 mcs 对话免费诊断和分析医疗及保健相关问题。根据 Kye Gomez 披露的数据，mcs 过去 2 天的日活超 6000 ，同时其 API 即将为美国最大的医疗供应商之一投入生产。

SPORES
市值： 940 万美元
持有地址： 5347 
代币合约：H1koD28XAHg2vuGp7XggehBCR4zP6r6k6EQ3MR6j3kU2

spores 是 Autonomous Spores 发行的代币，该项目在将代币的 10% 转移给了 swarms DAO。Autonomous Spores 计划基于 Swarms 框架开发四个 AI 代理：

第一个代理是 Saya，基于 Swarms Intelligence 构建的 AI 代理基金经理，其将管理一系列 AI 代理风险基金，其通过交易系统中大量交易数据磨练了决策能力，第一只基金即将推出；
第二个代理是 Oozeborn，该代理灵感来源于 Base 上的 Clanker，通过进行评论或在帖子中带上#Oozeborn 的标签，简化了用户在推特上启动代币和创建 AI 代理的过程；
第三个代理为 Grassian，其是基于 Swarms 算法构建的数据分析 AI 代理，主要关注点在推特上识别早期 Alpha 博主，并对这些个体进行评分，从而提供对生态系统的见解，同时 Grassian 也是 Saya 做出交易决策的重要信息来源。
第四个代理为 Jaguarundi，其是一个风险评估 AI 代理，既评估交易系统中的风险，为 Saya 提供安全保障，同时也将运行一个保险基金，旨在减轻整体交易系统损失。

Autonomous Spores 通过这四个 AI 代理的相互协作，发挥 AI 代理的集群智慧。当前 Autonomous Spores 已计划将部分 Saya 产生的管理费和 Oozeborn 产生的交易税分享给社区。不过 Grassian 和 Jaguarundi 暂未推出。

create 自称为终极创作引擎，实际上是一个基于 swarm 构建的根据文字提示生成图片或音频的 AI 平台。

IFSCI
市值： 350 万美元
持有地址： 1177 
代币合约：RqGHXg2eh3zPjyzNM7kUyrrSmhb9M9q4mCKFH1mpump

IFSCI 自称是第一个使用 Swarms 构建的垂直类 AI x DeSci Agent 项目，其旨在帮助用户个性化他们的禁食和膳食计划。用户可以以食品数据贡献者、健康指标提供商或研究者参与 AI，作为数据提供者用户只需将其用餐照片及相应描述发表至 X 平台并@adesciagent 即可，同时用户也将根据贡献获得奖励。

根据官方所发表的路线图，IFSCI 将在 2025 年 Q3 推出功能齐全的应用程序，并在全球范围内扩展科学研究。

Swarms 生态建设进展

如今繁荣的 AI Agent 框架项目，类似早期以太坊 L2 的繁荣时期。虽然技术、模式等各有不同，但对用户来说，最直观评判优劣的方式则是看生态繁荣度。作为一个多代理协作框架，某种程度上 Swarms 更需要繁荣的代理生态来「验证」自身的价值，与 ai16z、Virtuals 等生态相比，Swarms 虽然起步较晚，但目前已经在着力进行生态系统建设。

今日，Swarms 官推在 X 平台发文招募生态项目合作，并提供技术、营销和代理基础设施等支持，同时拿出 1000 万枚 swarms 代币（价值 338 万美元）作为生态基金。Swarms 创始人 Kye Gomez 也表示将「亲自会见并支持我们所有的合作伙伴项目，提供技术援助、营销指导等等」。

Kye Gomez 在今日也宣布 swarms Marketplace 即将推出新功能，包括：

自动生成和上传：无缝创建代理、工具和群，然后将它们直接上传到市场；
付费墙集成：通过以一定价格列出代理，从而将其货币化，让其他人购买开发者的创作；
swarms 代币集成：使用 Phantom 通过 swarms 代币购买和出售代理，简化交易；
swarms Auto-Cloud：只需一个 prompt 即可在云中启动 Swarm API；
代理质量奖励：发布高质量代理可获得 swarms 代币，使用先进的框架进行评估；
实时聊天和 API：为每个代理、群组、工具和提示提供实时交互和 API 功能；
使用情况跟踪：使用详细的跟踪工具监控代理的实时使用情况。

虽然外界仍有针对 Swarms 原创性的争议，但坚定不移的建设是对争议最好的回应，ai16z 早期也被指控为发币阴谋集团，但如今的市值已证明其价值得到了市场的认可。「要么继续起飞，要么从此没落」，Swarms 后续能否在生态建设上与 ai16z「掰掰手腕」，还需要时间来检验。
