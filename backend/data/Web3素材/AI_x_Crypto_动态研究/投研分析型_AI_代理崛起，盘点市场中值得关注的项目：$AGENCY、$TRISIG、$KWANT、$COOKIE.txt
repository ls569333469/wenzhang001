作者：深潮 TechFlow

 

加密资产在经历了一阵“圣诞打折”后，目前有所回暖。

其中，AI Agent 相关项目仍旧是反弹最猛的那一拨，体现着资金的持续看好。不过，这个大赛道中的分化效应也很明显：

有些项目跌下去可能不再回来，有些项目则在抱团反弹。

近几天反弹明显的项目中，除了几个龙头外，一类题材或许值得你重点关注 --- 用 AI Agent 搞加密投研。

不要误会，当前的 Agent 显然无法胜任专业的市场分析师，之前也有 AIXBT 这种帮你分析 Alpha 项目的 Agent 走红；

不过这阶段的“投研型” AI 代理相较于 AIXBT 则更加细化，有的能帮你看K线做技术分析、有的能帮你分析项目是否有Rug风险、还有的则可以生成类似研报的信息汇总...

在某个小方向上做出特点，能够部分的为交易提供参考，是这些 Agent 目前能够吸引关注的原因，毕竟离钱和交易近，获得青睐的概率也会提高。

深潮编辑部整理了其中几个比较突出的项目，汇总如下。

$AGENCY(Agent Scarlett)：你的代币尽调小特工

CA：

5UmDWgyLV1JBg8Jr8NwyezXdQkiU3vHGJu2efm7Cpump

当前市值：12M

7天涨幅：1100%

Agent Scarlett 看上去更像一个代币分析机器人，可以快速利用 Scarlett 来识别和调查潜在的可疑项目，并全面了解任何代币。

值得一提的是，该 AI Agent 也是基于 ai16z 的 Eliza 框架制作的，并且在最近几天的加密推特上拥有着较高的讨论度。

代币经济上，10% 的 AGENCY 代币也将捐献给 ai16z DAO。

功能上，她目前在 Telegram 和 Twitter 上供所有人使用，且不需要任何费用（使用教程）。

而且使用方法也很简单，你可以在TG或者推特上@她，然后输入你感兴趣的代币合约地址，她就会自动返回给你结果。

从实用性上看，Scarlett 比较好的一点在于，她返回给你的分析包含了某个代币的基本面和链上情况，例如会告诉你社媒情绪和与代币相关的组织和KOL是否给予了支持关注；同时也会为你总结链上的持币地址、人数等数据。

同时，她也会列出一个优缺点，类似一个短（浅）研报。

你也可以继续追问她更多问题，从而得到更为深度的答案（也考验你问问题的水平）。

不过编辑部的小编们很早就看过类似的产品，例如 Messari 上的 Copilot，以及0xScope的 Scopechat，形似加密版GPT。

但当前市场似乎对有代币的这类小助手非常买账，相关数据显示 $AGENCY的讨论热度快速上升，也能很明显的看出讨论度和价格之间互相影响的关系。

而从筹码分布来看，3k左右的持币地址中，持有不到100美金的散户几乎占了一半，这似乎也体现了这类 AI Agent 亲近韭菜的体质：

免费给你用，人人都能玩，用了觉得还不错就顺手买了

非常容易被 KOL 拿出来当标的进行传播，毕竟一个无害的分析工具韭菜们都喜欢，还不用链接钱包

$TRISIG（Tri Sigma 3σ): 会在X上写研究 Thread

CA：

BLDiYcvm3CLcgZ7XUBPgz6idSAkNmWY6MBbm8Xpjpump

当前市值：33M

7天涨幅：578%

TriSig是一个机智的加密分析师，自称能够识别早期的alpha项目，并且以简化的方式回答具有挑战性的问题，并分享其对加密货币市场中任何重大事件或动向的看法。

它的名字和形象更偏数学意味（对应数学符号σ：西格玛），更多往全知全能的 AI 造物主方向上去靠。

功能上与前述的 $Agency 类似，就是你提关于代币的问题，他来回答。

但不同之处在于，TG 上的 TriSig 目前只是一个仅供娱乐的机器人。严肃的分析对话限制在X上。

只需在X上@tri_sigma_，即可在任何的推文互动中使用他进行分析。

比较有意思的是，他自己会写推文，对一个项目做一个快速的研究介绍，包括一个项目是做什么的、当前社媒情绪分析再加上自己的主观多空判断。

此外这个项目也很社区化。如果TriSig对你提的问题印象深刻，它会通过要求你在推文回复中留下您的钱包地址，以空投的形式赠送$TriSig代币。

进一步看数据可以发现，TRISIG 代币在这2-3天内价格快速上涨，对应的是外部讨论逐渐增多；截止今日价格出现大幅回撤，但讨论度依然有增无减。

而在筹码结构上，持币100美金以下和1000美金以下的地址差距并不大，相较于上一个项目AGENCY来说，这个代币大家相对更喜欢重仓，但同时其市值也更高。

$KWANT（kwantxbt）： 专注技术分析，给到价格点位

CA：

9Yt5tHLFB2Uz1yg3cyEpTN4KTSWhiGpKxXPJ8HX3hat

当前市值：6M

7天涨幅：25%（24h 70%反弹）

如果说前两个项目还带基本面投研，Kwant 则更加直接，直接给你分析代币走势图表，并提出投资建议。

使用方式也大同小异，直接在TG中 @KwantAI_bot，对其发送某个代币的CA，即可得到纯粹的技术分析，包括但不限于量价关系、图像形态和后续的操作建议等。

与一般项目叠甲说“NFA”（非投资建议）不同，KWANT 直接给你了支撑位、突破位和止损位等非常具体的实操建议。

当然任何加密投资都有巨大的波动和风险，KWANT 的也必然不可能当常胜将军；不过当 AI Agent 拿到了更多信息和具备不断学习进化的特质后，你相信所谓“群友大佬”给的进场点位，还是相信 AI 给的？

多一种参考和声音总之不是坏事，这才是这类项目有人追捧的下限。

此外，由于 KWANT 代币发布已经有半个月以上的时间，看最近的社媒情绪参考意义并不是很大，因为隔一阵子总有人讨论到 KWANT，只看价格的话，代币近期的反弹趋势非常明显。

筹码结构上，依然是小散户构成了基本盘，持有25K以上的重仓用户并不多。笔者认为一种可能的原因是：

相较于投研基本面的bot来说，这类直接给点位的翻车率更高，很容易演变成多次说不准的反面教材。

$COOKIE （Cookie.fun)：为所有 AI 币提供数据与情绪分析

CA：

0xc0041ef357b183448b235a8ea73ce4e4ec8c265f （BSC和BASE都有）

当前市值：24M

7天涨幅：7%

注意，该项目并不是一个 AI Agent，而是一个在 AI Agent 热潮中快速崛起的数据分析平台。

之所以也列出来盘点，是小编和外网的分析师们也多使用该平台观察当前市场上的热点趋势，能为投研提供不少有意义的数据；

并且该平台也有自己的代币 $COOKIE，其中一个重要的作用就是你可以进行质押，从而使用该平台的更多数据分析功能，如查看某个 AI Agent 代币的链上筹码结构、巨鲸持仓以及更多辅助决策的情绪指标等。

在注意力驱动的加密市场，了解情绪和价格的关联，对于分析某个项目至关重要，所以Cookie这类数据分析平台当然有其存在的意义，且专注于 AI Agent 的数据分析也能在热潮中快速占据一个生态位。

与之相对的是，平台币并不是一个 Meme，严格意义上也不属于 AI Agent 币，所以价格波动幅度也有限，更多是提供实用价值。

我们在哪？

从玩笑Meme，到试图指导你“赚钱”，加密市场的 AI Agent 们不断演化，短短几个月时间内就已经业态全面开花。

是否能结果不好说，但这种百花齐放，也确实有当时 DeFi Summer 的某种感觉了。

如果回溯24年最后几个月的时间线，你可以清晰的发现一种脉络：

从没有实在意义，到试图找到更多实在意义，AI Agent 代币在找更多的功能以支撑叙事。

例如社交、制作音乐、帮你搭建开发框架或是投研，当前的市场如果你不和 AI 沾边，似乎都不好意思说自己的卖点。

我们唯一能做的，是明确自己处在哪个阶段，针对阶段热点做对应操作和判断。

至于喧闹之后，终章何时到来，是一个无法预料和担心也没用的问题。毕竟盛宴中总有人买单，趋势中总有人获益。

把握趋势，才是加密市场的主旋律。
