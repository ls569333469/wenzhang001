作者：深潮 TechFlow

 

每当你觉得市场沉闷时，就总会有新的金狗让人眼前一亮。

今天上午9点，一个名为 $AGIXT 的新 AI Agent 代币出现，在不到短短2小时的时间里市值迅速来到8000万美金；而更夸张的是，这期间代币的交易量达到了9600万，展现出久违的市场活跃度。

而在大家后知后觉时，与之形成对比的是在该代币发射的半小时分钟内，链上数据显示大量的聪明钱快速购入 AGIXT，并且不乏单笔交易超过 50 SOL 以上的鲸鱼。

这个 AGIXT 究竟是个啥，与其他 AI Agent 代币相比有何不同？小编们看了看它的 Github 和更多介绍，带你快速了解 AGIXT。

2700个点赞，一个 AI 自动化框架

有时候，一个 AI Agent 代币的技术细节其实大家并不关心，大家关心的其实是到底有没有一些线索使得这个项目“看起来很好”。

这个思路下，Github 的点赞数逐渐变成了 AI Agent 代币一个可以被拿来营销的点 --- 点赞数越多，代表着更多的开发者认可，也更能凸显这个项目在技术上的影响力和实力。

逛了逛 AGIXT 的代码仓库可以发现，该项目的点赞数（Star）已经超过了2700个，和纯靠空气吹故事并胡乱新建一个github的项目比确实更胜一筹。

更重要的是，这个点赞不是最近刷上去的。

从下图 Star History 可以看出，该项目早在去年初就启动了，自 2023 年7月以来，GitHub 星标数呈现稳健上升趋势。

如果是要做个样子，那布局也未免太久了，甚至早于整个 AI Agent 叙事开启的时间。因此这更像一个一直在做的圈外项目，在这波热潮中尝试代币化然后被价值发现。

不过，这个 AGIXT 究竟是干啥的？

从代码仓库的官方说明来看，AGIXT 本质上是一个 AI 自动化平台，简单来说就是让 AI 能够自动完成更多复杂任务的工具。它最大的特点是可以同时调用多个 AI 模型（比如 OpenAI、Claude 等）来协同工作，就像给你配备了一支 AI 助手团队。

这更像是对开发者说的，但你能用这个平台干点啥？

对最终用户来说，你可以向用这个平台的API构建出的工具发出自然语言请求，并获得可以操作的结果。说人话就是用正常语言和AI进行对话，在不同的任务场景里获得答案。

这听起来和现在流行的框架们做的事差不多，不过这个项目有几个吸引人的亮点：

多任务处理能力：它不仅能处理简单对话，还能自动规划任务步骤、上网搜索信息、执行命令，甚至能通过语音交互 —— 可以理解为是个超级加强版的 ChatGPT。

记忆力还不错：平台内置了智能记忆系统，让 AI 能够像人类一样保持长期对话的上下文，不会出现"健忘"的情况。

高度可扩展：通过插件系统，开发者可以轻松给 AGIXT 添加新功能。

全面的兼容性：支持目前主流的 AI 模型，包括 OpenAI、Hugging Face 等，用户可以根据需求自由切换不同的 AI 服务。

从技术角度来看，AGIXT 的设计相当完整，不仅提供了 Docker 快速部署方案，还配备了 API 接口，方便其他应用调用。这意味着它不仅能独立运行，还能轻松集成到其他系统中。

此外，项目的更新频率也很在线， 过去一年来逐月都在更新，并不像一个只有空壳子的代币。

从叙事视角来看，这更像一个框架或平台型的项目，它自己并不是一个单独应用，其他项目可以利用它的能力去做更多的 AI Agent。

不过用 AGIXT 做出的 Agent 效果到底如何，还需要更多的用例来检验；只能说项目 Github 所呈现出来的已有信息还不错。

并非加密圈的开发者，但专注于 AGI 开源贡献

关联信息显示，AGIXT 项目的开发者为 @Josh_XT ，是一个热衷于在 AI 开源领域持续贡献的人，去年一年在github上提交了8000次代码贡献。

有部分网友表示（消息待证实），该 dev 的贡献量能排在 Github 所有开发者中的前2%。

3个小时前，josh 在推文中表示，自己“还没有真正涉足加密货币领域”，但认为加密确实为开源社区提供了许多良好的支持。

同时，josh 也开始尝试对 AGIXT 代币进行锁仓。

公开数据显示，他正在使用 Streamflow Finance锁仓，将总量 450M 的 AGIXT 代币中的 5%（约 22.5M 个代币）进行为期两年的线性释放，从 2025 年 1 月 16 日开始，每两周自动解锁一次，直至 2027 年 1 月 28 日结束。

更多值得注意的数据

看起来不错的技术加上过硬的开发者，在一众玩票项目里 AGIXT 显得有点"扎实"。

但这是否构成了一定要 FOMO 的理由？以下是小编整理的各种信息，不妨先看看更多数据在做决定。

早期进场的KOL们在dump

当 AGIXT 市值快速上涨至50M以上时，可以发现社媒上越来越多的讨论；但与此同时也有眼尖的网友通过数据监测网站发现，部分早期进场的 KOL 们在逐步卖出，以锁定利润。

锁仓存疑

也有推友指出，虽然开发者在进行代币锁仓，但由于 cliff 设置为 0，这意味着开发者可以从第一天就开始获取解锁的代币，没有强制的初始锁定期来保护投资者。

这是一个风险信号，担心开发者可能会利用这种设置进行不当操作，并警告可能会出现价格暴跌的情况

前排持仓过于集中

投过 GMGN 自带的“筹码分析”功能可以看到，地址 HNFC...Sf4G 持有 42.83% 的代币。

按照图中显示的总价值 $2.2M 来算，这个地址持有约 71.65M 个代币，可以看出代币分布非常集中，最大持仓者占据了接近一半的代币总量，而前几位持仓地址合计控制了超过 50% 的代币。

不过筹码集中并不一定意味着砸盘，只是可能意味着前排的价格影响力会增强，后续也需要看前排是否进行了锁仓或进行了分仓等操作。

总体来看，AGIXT 是个代码过硬开发者水平在线的 AI 框架，但代币开盘到现在的3个小时内，能看到的公开信息也仅限于此。

究竟是一日金狗还是后起之秀，在激烈的PVP博弈和更多信息放出后，或许才能看到答案。
