作者：西柚，ChainCatcher

编辑：念青，ChainCatcher

 

2024年，“Crypto+AI"（加密AI）领域实现了前所未有的突破性增长。年初时，该领域还仅由寥寥可数的几个项目构成，如今却已成为加密市场中不容忽视的独立赛道。

根据ChainCatcher最新梳理数据显示，12月7日加密AI板块的资产总市值已突破700亿美元大关，在整个加密市场中最高占比已达到了2%，年增长率更是达到了400%。

与此同时，加密AI项目的数量也呈现出爆炸式增长，目前已超过600个，涵盖了去中心化AI基础设施、AI Dapp等多个类别产品。

回顾2024年，加密AI的叙事经历了多次重大变化。年初，OpenAI推出的Sora项目点燃了加密AI基础设施的炒作热潮。随后，英伟达AI年度大会的召开更是将去中心化GPU推向了市场关注的焦点，投资者们开始追捧AI去中心化基础设施。年中，加密AI赛道迎来投资热潮，加密VC机构纷纷宣布躬身布局，众多加密项目获得资金支持，加速了技术的研发和应用进程。而到了年末，AI Agent Meme的爆发更是将加密AI的叙事推向了新的高潮。

加密AI资产总市值年内突破700亿美元，相关项目数量超600个

根据CoinMarketCap的最新数据显示，加密人工智能（Crypto*AI）板块收录的Token数量已达到355个，其资产总市值在12月7日已突破700亿美元大关，峰值最高触及704.2亿美元。目前，受当前整体加密市场大盘回调趋势行情的影响，截至12月23日，加密AI板块的总市值回落至470亿美元，24小时交易量依然高达50亿美元。

回顾年初，加密AI板块的资产总市值仅为170亿美元。在短短不到一年内，该板块的资产总市值实现了逾400%的增幅，再次展现了加密AI领域的蓬勃发展和巨大潜力。

Syncracy Capital的联合创始人Daniel Cheung在12月12日发表观点指出，尽管当前加密AI板块仅占加密市场总市值约1%，但随着市场周期的不断演进，AI基础设施及AI Agent的强劲势头，他预测，该板块的市值有望实现10倍的增长。

值得一提的是，尽管当前加密行情整体回落，但12月23日整个加密市场的总市值达到了3.4万亿美元，而加密AI资产的市值在整个市场中此时占比仍有近1.4%（市值高峰期占比超2%），进一步证明了其未来的市场增长潜力。

2024年可谓是加密AI领域从崭露头角迈向全面爆发的关键转折之年。年初之际，加密AI赛道还处于萌芽阶段，项目数量屈指可数，主要以去中心化GPU项目Render(RNDR)、AI基础设施Fetch.ai(FET)和WorldCoin等为代表。然而，仅过去不到一年，加密AI领域已可划分多个细分赛道，涵盖去中心化GPU、AI数据平台、AI基础设施以及AI Agent等多个分支赛道，项目多达数百个。

根据加密数据平台Rootdata显示，目前收录的含有AI词条的加密项目已超过600个，且这一数字还在持续增加。

2024加密AI 催化剂：OpenAI叙事等外力，VC大力布局，AI Agent Meme爆发

从加密AI资产总市值的数据走势来看，2024年的增长呈现出两个显著的波峰：第一个波峰出现在2月至3月期间，而第二个则发生在10月之后，迎来了更为强劲的增长浪潮。

在2月至3月期间，加密AI领域的增长主要得益于AI领域的两大标志性事件所带来的强烈刺激。

2月，OpenAI震撼发布了“文生视频”大模型Sora，这一突破性成果在AI领域掀起了一场颠覆性的变革。同时，该事件也极大地推动了由OpenAI创始人Sam Altman主导的虹膜认证加密项目Worldcoin的代币WLD价格飙升，进而带动了整个加密AI资产板块的强劲增长。在此期间，诸如AI模型激励平台Bittensor（TAO）、AI数据平台Arkham的ARKM等优质项目开始受到市场的广泛关注，这些项目的崛起进一步点燃了加密AI市场的投资热情，吸引了大量投资者涌入这一充满潜力的新兴领域。

紧接着，3月英伟达年度AI大会GTC的盛大召开再次吸引了全球范围内的广泛关注，并推动其市值直线飙升，引发了GPU芯片炒作热潮。会上，Near联合创始人Illia Polosukhin、分布式GPU渲染网络Render Network创始人Jules Urbach等加密行业领军人物的亮相，再次为加密AI领域再次注入了新活力。这一系列事件使得去中心化GPU等概念项目如雨后春笋般涌现，其中，曾风靡一时的去中心化io.net便是在此时创立的。

自此，加密AI正式发展成为了一个独立的赛道，AI基础设施、去中心化GPU、去中心化AI数据等项目如雨后春笋般层出不穷，为市场带来了更多的选择与机遇。

而在10月份，加密AI领域的增长则主要归因于AI Agent Meme的大爆发。AI Agent项目Truth Terminal代币GOAT的横空出世，引发了AI Agent Meme项目发币炒作热潮，推动了近百个AI Agent Meme币的批量发行。这一趋势使得AI Agent迅速崛起，成长为加密AI领域内一个独立的细分赛道，其产品涵盖AI Agent Meme币、AI Agent发行平台（IAO）及AI Agent底层基础设施等，具体项目可查看ChainCatcher在11月发布的《系统梳理 AI Agent 赛道：AI Meme、发行平台和基础设施》。据Coingecko数据显示，截至12月23日AI Agent赛道代币的总市值已高达98亿美元，约占整个加密AI赛道项目总市值（470亿美元）的20%，且炒作热度还在持续。

如果说OpenAI推出的文生视频工具Sora、英伟达市值的攀升及其举办的AI峰会等构成了推动加密AI领域发展的外部强劲动力，那么AI Agent Meme的爆发式增长则无疑是加密市场内部点燃的一把火，加速了这一领域的崛起。在内外双重催化效应的共同作用下，加密AI赛道已经迅速成为加密世界中一个无法忽视的关键领域，其重要性日益显著。

另外，2024年，加密AI市场迎来了前所未有的投资热潮，各大投资机构竞相涌入，投资金额急剧攀升。在这一领域，灰度、Delphi Venture、Coinbase Ventures、Binance Labs 及 a16z 等加密行业内的顶级风险投资机构，都已积极布局“Crypto+AI”项目。

其中，Delphi Ventures年初即表示高度看好Crypto与AI的结合，并投资了多个相关项目，如io.net、OG Labs和Mythos Ventures等。a16z则募集了一只60亿美元的新基金，重点投资AI领域，并在其秋季加密创业加速器中入选了5个加密AI项目。进入下半年，Pantera Capital、灰度、Binance Labs和Coinbase Ventures等机构也相继宣布进军加密AI领域，设立专门基金或加大投资力度。根据Messari发布的报告，2024年第三季度加密风险投资机构向AI项目注入了超过2.13亿美元的资金，环比增长250%，同比增幅高达340%。

各加密机构在加密AI领域的具体布局动作及细节，可以查看ChainCatcher已发布的《2024 年加密风投 AI 布局全解析：a16z、币安、Coinbase 等头部 VC 都投了哪些项目？｜年度盘点》

“Crypto for AI”市场前景大于“AI for Crypto”

目前，市场上的加密AI产品主要可以划分为“AI for Crypto”和“Crypto for AI”两大形式。

前者“AI for Crypto”即用AI赋能Crypto，主要侧重于将AI技术应用于加密产品，通过融入AI元素来提升用户体验或强化产品的各项性能。如使用AI代码优化与安全审计：AI技术可以自动检测和分析Web3项目的代码，发现潜在的安全漏洞和错误，提高项目的安全性和稳定性；参与链上收益策略：利用AI算法分析市场趋势和用户行为，制定更高效的链上收益策略，帮助加密用户获得更高的回报；集成AI聊天机器人，解答用户疑问，提升用户体验；借助AI Agent消除链上用户体验中的障碍，如自动交易、资产管理等，使用户能够更便捷地参与加密市场。

“Crypto for AI”则侧重于利用加密技术为AI产业赋能，借助区块链技术的独特优势来解决或改进AI产业的某些环节。例如，区块链技术的隐私性和透明性可以解决AI模型在数据收集、处理和存储过程中的隐私和安全问题；通过使用经模型资产化允许社区通过去中心化的方式拥有或使用AI模型；通过区块链的Token技术聚合闲散的算力资源，形成算力市场，降低AI模型训练的成本，并提高算力资源的利用效率。

总结来看，Web3技术的精髓在于其去中心化的区块链基础架构，它依托Token经济体系的运作、智能合约的自主执行以及分布式技术的强大效能，不仅确保了数据所有权的精确界定，还借助Token的激励模式，极大地提升了商业模式的透明度与效率。这一特性恰如一剂良药，针对AI行业中普遍存在的数据不透明、商业模式模糊等顽疾，提供了有效的解决路径。这恰好契合了“AI旨在提升生产效率，而Web3则着重于优化生产关系”的宏观理念。

因此，行业人士普遍达成共识：“Crypto for AI”相较于“AI for Crypto”，在市场应用层面展现出了更为广阔的前景与潜力。这一趋势也自促使越来越多的AI行业内部人士开始积极寻求借助加密技术来攻克AI行业面临的种种挑战与难题。

围绕“数据、算力与算法”AI三要素打造加密AI生态系统

基于驱动AI大模型发展的核心三要素“数据、算力和算法”，我们可以进一步细分为涵盖基础设施及应用的数据、算力与算法模型产品。其中，数据是训练和优化AI模型的基础；算法是指驱动AI系统的数学模型和程序逻辑；算力是指执行这些算法所需要的计算资源，且这三要素也是模型持续更新、迭代的必要条件。

加密AI产品生态系统内的具体产品形态包含以下方面：

在数据层面，加密AI数据项目涵盖了数据的收集、存储及加工处理。首先在数据获取方面，为了保障数据的丰富性和多样性，部分加密AI项目借助Token经济机制，激励用户分享其私人或专有数据，如Grass项目通过奖励机制鼓励数据提供者，Sahara AI将AI数据资产化，并推出了专门的数据市场，Vana通过数据池的形式，为AI应用提供专门或定制化数据集等等；在数据处理方面，去中心化的数据标注平台为开发者贡献了高质量的训练数据集，从而改善AI模型的强化学习和微调机制，如Fraction AI（12月18日完成600万美元融资）、Alaya AI及Public AI等，为开发者提供了高质量的训练数据集，从而优化了AI模型的强化学习与微调过程。至于数据存储，Filecoin和Arweave等解决方案则确保了数据的安全性与持久性。

在算力层面，AI模型的训练和推理执行不开强大的GPU计算资源支持。随着AI模型复杂性的日益增加，对GPU计算资源的需求也在不断攀升。面对市场上高质量GPU资源供不应求、成本上升及等待时间延长等挑战，去中心化GPU计算网络应运而生。这些网络通过创建开放的市场与GPU聚合平台，允许任何人（如比特币矿工）贡献其闲置的GPU计算能力来执行AI任务，并通过Token获得奖励，代表性项目包括Akash、Render、Gensyn、io.net及Hyperbolic等。此外，Exabits和GAIB等项目更是将物理GPU代币化，将其转化为链上的金融数字资产，进一步推动了算力的去中心化与流动性。

在算法模型层面，目前市面上的去中心化AI算法网络本质上是一个去中心化的AI算法服务市场，它连接了众多具有不同专长和知识的AI模型。当用户提出问题时，该市场能够智能地挑选出最适合的AI模型来提供答案。代表性产品如Bittensor，它通过子网的形式汇聚了各种AI模型，为用户输出高质量的内容；而Pond则通过竞赛积分的形式评选出最优秀的去中心化模型，并通过将AI模型代币化来激励每一位模型贡献者，从而促进了AI算法的创新与优化。

由此来看，当前，加密市场已围绕“数据、算力与算法”AI三大支柱，已构建了一个蓬勃发展的加密AI生态系统。

2025年加密AI赛道有哪些利好？

然而，自10月份AI Agent Meme市场走红以来，AI Agent相关的产品成为加密AI市场的新宠，如11月宣布以1.5亿美元完成600万美元融资的Talus Network等项目，正式专门为AI Agent打造的构建框架与基础设施。

另外，AI Agent Meme的这股热潮，不仅点燃了加密AI赛道的新炒作热点，还促使市场关注点从原有的去中心化数据、GPU等加密AI赛道的基础设施领域，逐渐转向了对AI Agent应用的热烈追捧，如ai16z市值已突破10亿美元，且这一热潮仍在持续升温。

在近期多家机构发布的2025年加密行业趋势展望中，a16z、VanEck、Bitwise、Hashed、Blockworks、Messari、Framework等机构纷纷表示看好加密与AI市场的发展，并特别指出AI Agent相关产品将在2025年迎来爆发式增长。

与此同时，外部AI领域的热度也在持续攀升。12月23日埃隆·马斯克的AI公司xAI宣布再次完成60亿美元新融资，估值直接暴涨至400亿美元，进一步推动了AI市场的繁荣。

在叙事层面，OpenAI正经历从GPT到通用人工智能体AI Agent的转变。据悉，OpenAI计划在2025年1月推出全新的AI Agent产品“Operator”，该产品能够自动执行编写代码、旅行预订、电商购物等复杂操作，预计其将如同2024年初的Sora一样，再次引爆AI市场。此外，英伟达一年一度的AI峰会同样在2025年3月举行，同样是加密与AI行业关注的焦点。

每次英伟达、OpenAI等AI领域Web2公司的大模型升级，都会点燃AI赛道的热点，吸引新的资金涌入，进一步引爆加密AI赛道。

在政策层面，美国当选总统特朗普已宣布任命贝宝（PayPal）前高管戴维·萨克斯（DavidO.Sacks）为白宫人工智能和加密货币事务负责人，负责引导政府制定人工智能和加密货币领域的政策。而此人具有加密和AI行业的双重投资经验，曾参与投资过如Multicoin等多家加密公司及AI公司，自然也被认为其制定的政策会对加密与AI融合的领域起推动作用。
