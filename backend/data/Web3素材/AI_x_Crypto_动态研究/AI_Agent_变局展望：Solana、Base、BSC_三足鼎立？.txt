标题: AI Agent 变局展望：Solana、Base、BSC 三足鼎立？
链接: https://www.chaincatcher.com/article/2167568
发布时间: 2025-02-14

==================================================

作者：Haotian

 

关于 AI Agent 的若干「变局」可能性展望：

1）Solana、Base、BSC 三足鼎立，BSC 加入战局会加剧 AI Agent 赛道的进一步「内卷」，但经历第一波「大乱斗」之后的休整和洗牌，三足鼎立局面形成后，各个阵营会决出一些乱世英雄出来，竞争会进一步进一步加剧，成王败寇；

2）Virtual 和 ai16z 两驾马车得换「火车头」，经历第一波的野蛮生长，Virtual 系和 ai16z 系一将功成万骨枯，存留了各种乱象和复杂问题。Virtual 迁移向 solana 生态后如何扎根，ai16z 的 tokenomics 代币赋能问题如何规整等等。问题解决好之后，借开源开发社区的创新力量驱动，全新的「火车头」拉力会更迅猛，值得期待；

3）ai16z 大商业 IP 地位或许会受到 Arc 商业新势力的威压，其实 ai16z 宣布闭关赶进度以来，Arc 也一直穷追不舍，其 Rust 高性能的框架屡刷进展以及 Arc Forge 发射平台的抢先落地，还有 $arc 都佐证了 Arc 的王者之心。至于，Solana 生态会不会龙头易主，市场会逐渐给出答案；

4）AI Agent 的应用场景深化问题成挑战， @aixbt_agent 当前面临商业应用场景的拓展问题，需要在资讯策略之外增加全新 DeFai 交易决策类的应用场景突破，要么模块化组合到其他 AI Agent 矩阵里，要么自我商业产品 PMF 演化，总之小 AIXBT 必须要尽快自证自己的能力上限；

5）DeFai 和 GamFai 细分领域可能会有破局性的 AI Agent 应用杀出重围，DeFai 毫无疑问能接轨 DeFi 成熟的 infra 基础设施和庞大资金体量，让 AI Agent 有 TVL、Txs、UX、Fees、多代理协作等足够 Attractive 的价值评估维度落地。GamFai 也同理，如何让 AI Agent 的「交互、决策」等隐性价值体验通过显性化「游戏场景」直观代入，至关重要。
