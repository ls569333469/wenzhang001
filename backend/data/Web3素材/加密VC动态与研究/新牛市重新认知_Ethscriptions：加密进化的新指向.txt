==================================================

作者：探索猫

前言：

1、 Ethscriptions 价值体系和以太坊智能合约资产体系虽然不同，但 Ethscriptions 也同样可以构成价值。 Calldata 数据标准化，和哈希绑定有时间戳，以太坊 0 转账的同时也广播到区块链，存储在以太坊上，这些构成了信息类价值。 Ethscriptions 也是 L1 资产。

2、加密进化的逻辑，或许是 L1 的进化，而并不是 L1 L2 L3 这样的方向。今年牛市 Solana 生态大爆发正在逐渐印证这个观点。或许 Ethscriptions / Facet 反而比 L2 更有优势。因为 Ethscriptions / Facet （ Facet 计算平台可发行的代币其实也是 Ethscriptions 代币）本身就是 L1 资产。 Ethscriptions 资产形成的全新生态，也是 L1 生态的一部分。

3、区块链 L1 的进化，一方面指的是新进化出来的被大规模采用的 L1 ，就像今年牛市火爆的 Solana 作为 L1 成为比特币以太坊之后的第三极；另一方面指已经被大规模采用的 L1 本身的进化，这是 L1 的进化，而不是 L1 L2 L3 这样的方向。 Ethscriptions 是以太坊 L1 资产，其出现和进化本身也是 L1 的进化，这是符合加密进化逻辑的， Ethscriptions 是以太坊区块链 L1 的未来。 Ethscriptions 非智能合约生态的形成和发展也将是 L1 的进化。

 

以太坊铭文 Ethscriptions 在这个月 18 号将满一年。今年是新一轮大牛市，如何在本轮牛市大趋势的背景下，重新认知 Ethscriptions ？

1、首先，我们要弄清到底 Ethscriptions 是不是价值？

记得去年有一篇文章，说的是以太坊铭文 ETHS 本质是金融炒作而非产品革新，不知道这位作者看到了今年竟然是纯社区驱动的 meme 币变成了这一轮牛市的主导力量时会如何作想？

这篇文章中，作者给出了一个自认为简单的标准鉴别 L1 资产和 L2 资产的方法：它的状态能否在以太坊的“世界状态”上还原出来， L1 的 EVM 能否引用、调用、查询、修改该资产的状态，如果不能，那它就不是 L1 的资产。

根据此描述，就知道原作者把 L1 资产限定在了智能合约类资产。的确，以太坊最引以为荣的发明就是智能合约 EVM ，但 Ethscriptions 的横空出世，实际上已经突破了以太坊原本的界限，通过对 Calldata 数据进行标准化，重新定义以太坊上的价值，因为这些标准化数据都是存储在以太坊区块链上，不可篡改，有时间戳，当然可以作为价值。

什么是价值？我认为，价值是熵减所需的能量和信息。驱使工作，需要能量和信息，这两个就是价值的基础。比如面包、空气、水，都是能形成价值的要素，这些要素如果驱使生物体熵减，才能叫做价值，即对个体的人或者群体的人产生“需求”的就是价值。驱使熵减的能量和信息，这里面驱使熵减的信息，也是价值，这里面有一个很关键的东西，就是时间。与时间无关的信息，都不会形成价值。数据广播到区块链上，有时间戳，就可以形成价值的基础要素。

Calldata 数据标准化，和哈希绑定有时间戳，存储在以太坊区块链上，这些构成了信息价值的基础。 Ethscriptions 价值体系和以太坊智能合约资产虽然不同，但 Ethscriptions 也同样可以构成价值。这里面，数据形成价值的关键，就是数据有时间戳，以太坊 0 转账的同时也广播到区块链上。很多人诋毁铭文不是价值，是因为他们没有真正认知什么是价值。

也可以说， Ethscriptions 也是 L1 资产，是真正以太坊原生的数字资产类型，而通过伞型协议的不断升级发展，成为了以太坊另类扩容方案，甚至笔者认为将来还可以理解为以太坊扩展方案，而不是以太坊 L2 。

为什么说是扩展方案呢？因为或许未来还可以将 Facet 链下计算平台再次扩展，从以太坊区块链链下计算平台，扩展到比特币链下计算平台，扩展到更多主流区块链的链下计算平台，变成了一个连接各种区块链的链下计算中枢。价值在不同区块链间自由流通，是未来趋势，也是未来必然。

在加密领域，无论做的事情，将来能否持久存在并发展，只要是第一个做的，就会自然的得到关注，运气好的话，会变成“龙一”，会有更多项目方模仿、引用。加密领域里，注意力经济发挥到了极致。

2、新一轮大牛市到底是什么牛？新一轮的牛市发动机是什么？

最近，出现了几个与以太坊有关的事情。

一个是以太坊创始人 Vitalik 频繁在推特上表达“有争议的观点”。一方面，前段时间， Vitalik 转发很久以前一条 Ansem 的推文，另外一方面， Vitalik 是对名人发 meme 币发表意见。这些都暗含了 Vitalik 对以太坊目前发展状态的某种不安。在过去一个月中，以太坊的市值增长了 22% ，达到 4540 亿美元，而以太坊的费用收入却下降了 33% ，仅为 1.28 亿美元，因为热门交易已转移到了 Solana 上。

当时我认为，接下来会冒出来很多以太坊名人要发表对以太坊“出格”的言论了，要么是以太坊极大主义者言论，要么是对 Vitalik 和以太坊基金会表达不满的言论。这将是以太坊体系走下神坛的开始。

很快的，就看到了 Synthetix 创始人 kain 嘲笑 Vitalik 对 meme 币的评论，又看到 Wintermute CEO Evgeny Gaevoy 发表意见。 Gaevoy 说 Vitalik 和 Hayden （ uniswap 创始人） 和更多的以太坊社区都试图通过证明“最终结果是值得的（医疗保健、开源软件、艺术等）”才是值得尊重的。我想换句话说，就是市场是随机的，不是某些超级意志决定的，只有市场本身决定加密进化的方向，只有市场才能决定市场，没有任何个人或者团体可以去定义什么是对的，什么是错的。

嘲笑市场本身，就非常可笑。

区块链是庶民的金钱游戏，无数人通过纯利益驱动形成的宏观效应，纯市场化法则决定短期的起伏走向和长期的进化方向。

从加密生态进化的意义上说，这实际上意味着以太坊将变成下一个“比特币”，都会成为加密史上的过去式。以太坊也会出现很多“以太坊极大主义者”。加密的进化是随机性的，纯粹市场法则的，并不是指定的必然的，这真的非常有趣。

还有一个稍早一点的事情，在最新的 Gitcoin Grants 20 中 Facet 项目作为 web3 基础设施项目捐款金额和捐款地址数均是第一名，但最终排在第七位。网友们都在表达愤怒，但没有办法。只有让自然法则教训既得利益者们了，来自市场本身教训最自然最真实。 Gitcoin 违背了公平公开公正的原则，并且连像其他项目方那样申诉的机会都没有。加密领域是纯粹遵循市场法则的，这样下去，从今年牛市开始发展到后续，恐怕以太坊和 L2 都不会真正崛起，不遵循市场法则，反而会摧毁以太坊原本建立起来的优势。

现在 solana 正在崛起，变成比特币、以太坊以外的第三极。 Solana 本身作为 L1 或许是新一轮牛市的发动机。

有人会说，一个 L1 能成为牛市发动机？ 

什么是牛市发动机? 就是开启那一轮牛市的某种事物，通常是比特币减半前后突然爆发出来的，比如以前的 ICO 融资，上一轮 2020 年 5 月突然爆发的 uniswap ，本轮3月突然爆发出来的 Solana meme 。这种事物可以是某一个项目，也可以是某一个模式，或者某一种方法，某一类技术。

Solana 能认为是本轮牛市的发动机，这个原理和历史上每一轮牛市发动机原理是一样的，即新的需求和能产生暴涨的新机制。

Uniswap 的 AMM 机制是上一轮暴涨机制，这个机制激活了上一轮的各种 DeFi 项目的大爆发。 SHIB 则是社区驱动和 AMM 机制的集大成者。可以说，上一轮牛市起始于 2020 年5月突然爆发出来的 uniswap 土狗集群，又集大成于 uniswap 中生长壮大的 SHIB 。

SOL 代币从几十亿到接近千亿市值这个过程，是过去一年多历史形成的，这个过程造就了一个超级巨大的盈利资本池，它将是本轮牛市发动机的基础，会在币圈以外的资本（如 ETF ）流入刺激下产生巨大的超级杠杆效应，这个效应的结果就是将诞生本轮牛市的超大市值 meme 币。

每一轮牛市的发动机，都是市场自然形成的，这里面没有什么超级意志预先设计好指定哪一个模式、哪一个平台必然会成为牛市发动机。而任何一种能在后来牛市爆发的类别，都其实在之前牛市中已经早就出现过萌芽过，经历了从默默无闻到被鄙视为非主流异类，再到真正成为新牛市的主导范式。上一轮的 DeFi 如此，本轮的的 meme 币也是如此。或许 meme 币才是打开加密货币大规模采用的钥匙。

每一轮牛市发动机，都并不会是上一轮牛市的延续，这是历史告诉我们的经验。这就是加密领域最迷人的地方。加密领域令人着迷的地方，就是这种出乎意料性，如同微观量子具有的特性那样。这里没有哪一个超级意志事先安排好设计好，完全市场法则自然进化自然形成。只有市场本身才是永远正确的，没有谁能决定整个进化的方向一定必然是按照他设计好的方向发展。

Solana 能成为今年牛市发动机，完全都是随机形成的，没有谁故意设计出来的。故意设计出来的，是以太坊 L2 。这并非是市场自然规律驱动的演进方向。

现在回到前面提到的那篇文章作者认为的“以太坊铭文 ETHS 是金融炒作而非产品革新”，实际上金融炒作本身也是加密进化的最重要的属性。社区驱动代币，开始之前不需要融资，也不需要 KOL 来开启传播，就像上一轮的 SHIB ，实际上开始传播都是各个社区里进行的，而且实际上开始还会有很多 KOL 看到后不以为然，认为只是一个山寨币种而已，而 SHIB 突然市值暴涨之后，才出现各种 KOL 讨论传播，这个过程与 VC 币完全不同。

今年牛市的主要外部动力，是美股散户。注意这里的外部动力，更主要是起激活原有币圈的作用。和上一轮 DEFI 大资本挖矿，完全不是一股力量了。 ICO 是虹吸传统融资模式， DeFi 是吸引大资本零成本赚钱模式，今年的 meme 是因为美股散户主导现在比特币 ETF ，很多人以为 ETF 的购买主导是机构，其实有统计的，大比例还是美股散户，这是币圈老人认知误区。牛市与资本供给和需求有关，不同阶段新技术激活了不同类别的资本需求，加上外部环境充裕。 ICO 是虹吸传统股权融资的全新替代模式， DeFi 是吸引大资本零成本质押赚币范式革命，今年的 meme 则是因为加密货币 IPO 带来的美股散户大规模涌入。

比特币的意义是开创了加密货币这个全新世界。但全新世界是要进化的，不会只有一个加密货币存在，即使出现第二个比特币，也不会只有第一个和第二个存在。比特币极大主义者和以太坊极大主义者都是一样的，只是说辞变幻了花样。世界是向前的，到了今年牛市，出现了第三个最有影响力的， solana 是第三极。

关于如何理解 meme 币，我认为可能根本的原因在于加密进化的逻辑，以前大多数人认知有误。加密进化的方向可能并不是通常以为的 L1 L2 L3 这样，而“可能”就只是 L1 的进化，如果是后者，那么就会自然的在更高层阶的 L1 上爆发繁荣，而且“开始”一定是纯发币项目的此起彼伏，其实 meme 和 ICO 代币没有区别。这样来理解，那么今年 meme 的大繁荣，其实对应的就是 2017 年的以太坊 ICO 大繁荣，更大规模 meme 潮其实还没来临。

每一轮牛市爆发出来的“需求”，其实都已经潜在暗藏了下一轮牛市发动机。第一次牛市，比特币分叉币爆发，爆发出来的需求，就是发币需求。这种需求刺激着资本和人才转移向能解决这个问题的项目，以太坊和 Vitalik 横空出世，到了第二次牛市，智能合约 ICO 正好满足了这个需求。各路融资需求发现了新大陆，纷纷用这个模式发币融资。而太多的 ICO 项目，项目方分阶段销售代币又暗藏了新的需求，那就是减少人为因素，基于智能合约的去中心化应用逐渐完善，终于在第三次 DeFi 爆发。而很多超大市值项目的崩盘又暗藏了新的需求，不能让大资本掠夺大众的资金。

所以第四次牛市的需求就是“去 VC 化”，社区驱动项目从去年铭文就已经初见端倪了。而 Solana 作为平台，去年逐渐累积起来的“盈利杠杆”能量，在今年真正爆发，这个平台有千亿美金的盈利资本，其他平台怎么跟它相比？根本没有能力相比。加上今年去 VC 化大趋势，大规模外部流入资金是来自美股散户，自然涌现出 meme 大爆发。

加密进化的逻辑，现在的趋势是 L1 的进化，而不是 L1 L2 L3 这样的方向。一方面，现在所有的 L2 还在处于“训练轮”，另外第三极 Solana 正在真正崛起。 L1 L2 L3 这样的逻辑，是以太坊基金会和某些 VC 主导的叙事， VC 币用叙事和资本来吸引散户，但 VC 的叙事并不一定是正确的，加密进化的特点就是纯粹自由市场主导，每进化一个新的更高层级都带有随机性，无论从比特币分叉潮，还是 ICO 潮、 DeFi 潮都是。

3、如何在这种新牛市大背景下重新理解、重新认知 Ethscriptions ？

加密进化的逻辑，或许是 L1 的进化，而并不是 L1 L2 L3 这样的方向。当然这是我个人的观点。按照这个观点，或许 Ethscriptions / Facet 反而比 L2 更有优势。因为 Ethscriptions / Facet 本身就是 L1 资产和对应的全新生态，这也是 L1 生态的一部分，比如以太坊元宇宙，而以太坊铭文身份体系以后或许还能成为智能合约身份体系的补充，甚至替代。

区块链 L1 的进化，一方面指的是新进化出来的被大规模采用的 L1 ，就像今年牛市火爆的 Solana 作为 L1 成为比特币以太坊之后的第三极；另一方面指已经被大规模采用的 L1 本身的进化，这是 L1 的进化，而不是 L1 L2 L3 这样的方向。 Ethscriptions 是以太坊 L1 资产，其出现和进化本身也是 L1 的进化，这是符合加密进化逻辑的， Ethscriptions 是以太坊区块链 L1 的未来。

很可能今天引以为傲的 L2 ，将来会像历史上曾经风光过、但现在仅仅存在于传说中的很多超大型区块链项目那样烟消云散。一旦后来某一个技术打通了所有区块链，那么就不需要 L2 了，因为可能会有更好的 L1 ，而不同 L1 之间价值流通又是非常自由的。区块链的进化，其实并不是 L1 L2 L3 这样的方向，而就只是 L1 的进化。

Ethscriptions 代币交易成本远比以太坊主网的智能合约代币低，这难道不是 L1 的进化？以此形成的一种全新的“非智能合约生态”本身，也将是 L1 的进化。

另外，今年开始的新一轮大牛市，最大的特点就是“去 VC 化”，社区驱动项目将大放异彩。这非常有利于 Ethscriptions / Facet 铭文代币。

往往能突然起来的大市值 meme 币、社区币，就是以前不起眼的，人们看不上的。这是特别的强调， VC 币不会这样， VC 币往往开始就有宣发，开始就广为人知。以太坊 L2 太多了，分流了以太坊的资金流量和注意力流量，这样的分流，不符合加密进化的逻辑。 L2 们的四分五裂将造成以太坊本身最后被新的 L1 超越。 L2 们这种四分五裂本身，竟然再次改写了加密历史，变成了出乎所有人意料之外的历史，并不是 Vitalik 和以太坊基金会、 VC 们合谋预想的那样的结果。

没有人可以预知未来，不然人类世界就没有意思了。正是因为无法预料，随机性，才有意思。加密进化的方向也会遵循这种随机性，沿着比特币以太坊 solana 这个方向进化，而不是比特币极大、以太坊极大。

亚洲基金只关注网络和协议或许是错的。亚洲项目方不善于基础设施的原创，即使搞基础设施也是东拼西凑，或者在别人基础上的，没有意义。亚洲项目方特别善于在西方基础上的“再发扬光大”，比如以前的矿业大亨、矿机巨头、交易所巨头，反而可以做到世界最大，以后的去中心化应用，我想可能也会有新的某个方向的世界最大。去中心化应用，不仅仅是智能合约应用，还将会有大量的非智能合约应用。

从千万美金左右的小市值代币（注意，这里说的小市值不包括小于千万美金以下的，因为还没成长成型风险较高），到成为具有全世界影响力的大市值代币，是有一些规律的：

全球影响力的交易平台+低市值+猛烈暴涨（这个暴涨是发生在整体市场处于阶段性热度的顶峰期），是激活成为全世界大市值代币的三大法宝。其实历史上任何一个全世界大市值代币，都是满足了这三大法宝，没有满足这三大法宝的，无法成为遍布全世界的大市值代币，增长空间极其有限。

去年爆发的铭文代币，主要是国人玩家。现在更重要的是虹吸全世界玩家。

西方用户并不是反感国人元素的代币（最近出现了一些火热的 meme 币反而还特别强调中国概念），最主要原因就是交易平台不熟悉，全世界绝大多数人都是一样的，不会玩自己不熟悉的交易平台上的代币。在一个西方用户很熟悉的交易平台上，代币暴涨，没有人不愿意赚钱。但是市值已经很大了，上了大型交易所了，也没有人愿意去接盘了，别说老外不接盘，就是国人也不想接盘。如果一个币，是从西方用户不熟悉的交易平台起来的（这里说的起来，是指到市值 2 亿美金以上），基本上没有可能成为全世界大市值代币的可能性了，三大法宝就缺了一个，其他即使满足 2 个，也无法激活全世界。

精准的说，决定一个加密货币未来可能性的，是这个代币在起来的过程中的交易平台，主要是从千万美金市值到上亿美金市值这个过程的交易平台，这个交易平台决定了这个代币未来的可能性。上一轮牛市中，起来的代币比如波场，是通过币安起来的，即使都知道波场是国人币，如果不是币安（因为后来币安影响力遍布全球）那就不好说了。上一轮 DeFi 牛市中，起来的 SHIB 是通过 uniswap ， uniswap 的 AMM 机制加上 uniswap 本身就是全球化的去中心化交易平台，这是一个最基础的基础，如果 SHIB 是其他交易平台就不一定到数百亿美金市值了。

在加密领域，很少人有长时间的投资观念，大多数都是追逐短期利益，今天这个明天那个，都是纯粹短期利益驱动，所以对于散户也好，或者 VC 也好，项目方也好，真正能赚到大钱的肯定还是长期心态的交集群体，这一定是极少数的，极少数散户、 VC 、项目方能走过一个牛熊周期。能赚到大钱的，都是认知胆识和幸运。

反复的洗盘，痛苦的历程，才可能是最好的投资。身心也得到了历练。

在币圈，其实核心就是一个“信”字。对于个人来说，信，就像埋下种子，自然会有收获。不信，就没有埋下种子，自然不会有收获。种瓜得瓜种豆得豆，这是自然法则。对于加密货币来说，信的人多了，也就形成了共识。何一说因为她相信币安，所以当初买了很多 BNB 。上一个牛市，其实很多人很早就听说过 SHIB ，但不信的人太多，认为那是土狗，根本瞧不上。

任何一个项目，能持续发展的，无论是比特币，还是新出来的小 meme 币，无论大市值的，还是小市值的，都要经历不同的阶段，每一个阶段都会有不同阶段天花板，越过了那个阶段的天花板，市值就上升一个层级。每上升一个层级，就是要冲出它当时所限的那个圈，这就是破茧成蝶的过程。

eths 的价值目前还没被市场广泛认同。铭文期待第三波整体爆发，在第三波中， eths 将破茧成蝶。

现在，英伟达市值已经超越苹果，再稍微涨一点就超越微软了，也就是成为全球市值第一的科技公司了。这意味着人类科技将从互联网时代迈向一个更高层阶，即人工智能时代。加密与 AI ，将打开未来之门。

拥抱新趋势，拥抱新牛市！
