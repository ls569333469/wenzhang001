作者：momo，ChainCatcher

近日，多AI智能体调度平台Questflow宣布完成650万美元种子轮融资，由CyberFund（Lido联创旗下机构）领投，Delphi Labs、Systemic Ventures（以太坊联创Joseph Lubin支持）、Animoca Brands、HashKey Capital、 ElizaOS等头部机构及项目方参投，并获得Aptos、Coinbase、Virtuals Protocol等生态资助。

去年7月，Questflow还曾获得奇绩创坛、PAKA的150万美元天使轮融资。

除了获得头部机构和项目方投资支持外，近期Questflow还与Circle、Coinbase、Google、Near、CoinGecko等Web2与Web3顶级平台陆续达成战略合作。

为何Questflow获得头部机构和项目方青睐？其多AI智能体调度平台解决了哪些问题？在AI与区块链融合的浪潮中，Questflow如何卡位AI赛道？

AI Agent 时代，工作流将被重构

AI Agent的崛起正重塑传统的工作模式，人与AI Agent的协作或将成为未来工作常态。

对个人工作者而言，AI Agent将成为得力的"数字助手"，处理日程管理、邮件筛选、会议记录等重复性、流程化的基础工作。个人工作者的生产力因此得以释放，从而能够专注于更具创造性和战略性的高阶任务。

AI Agent 还将成为企业的“数字员工”，帮助企业降本增效。企业需要建立一个AI Agent池，部署财务、客服、数据分析等多个专用Agent，供员工协同调度。员工只需提出需求，意图驱动的自动化便能调动Agent高效执行，员工只需要审核关键内容。

但针对 AI Agent 带来的工作流革命，当前市场上并没有成熟的企业服务方案。

尽管市面上已有ChatGPT、DeepSeek、Midjourney 等AI工具执行特定任务，但每个模型都有自己的用户界面、支付结构和 API 语法，用户体验非常割裂。

此外，企业需求千差万别，现有的通用AI工具预计也将难以完全适配特定业务场景。对于大部分没有技术基础的企业员工而言，未来如何调度操作多个AI Agent同样面临着痛点。

在人与AI Agent协作的时代，如何帮助企业定制化AI Agent功能，并统一协调多AI Agent协作，处理跨部门、跨场景的复杂任务，将面临着庞大的市场需求。

甲子光年智库报告预测，到2026年60%的企业将部署AI Agent，到2027年，40%的企业服务将由AI Agent组合交付。

这一趋势下，Questflow致力于打造一个灵活、可组合的多AI智能体调度平台，让AI Agent可以像员工一样协作，帮助个人和企业适应新的工作流模式。

Questflow 如何打造多智能体协作的“智能中枢”？

Questflow相当于人与多个AI智能体协作过程中的“智能中枢”。基于MAOP（Multi-Agent Orchestration Protocol，多智能体编排协议）核心协议，Questflow 能理解意图，协调包含多类型的AI Agent采取行动，并通过链上支付来让AI Agent根据任务结果和使用量等指标来获得奖励。

在帮助工作者自动化重复性流程的同时，Questflow还在关键节点保留人工干预权，实现“高效 + 可控”的工作流协作模式。

目前Questflow基于MAOP协议的TARS，就是一个多Agent协作的智能中枢。

用户可通过TARS提出需求，由其协调多个AI Agent高效协同，完成复杂任务的 Agent to Agent 集群调度，确保工作流无缝衔接、高效且准确。

例如，用户每天需要浏览GitHub、Reddit 等AI论坛，并整理出一份 AI Alpha 项目列表。用户可以通过TARS调度GitHub Agent、Reddit Agent去完成一个Agent to Agent的调度，这个过程不需要输入代码。后续这个负责AI Alpha的集群就能每天帮用户完成自动化的整理分析，而无需其手动搜集。

TARS还分享了三个日常典型用例。比如市场分析师可以使用 TARS自动化收集 AI 新闻和趋势，从 GitHub Agent、HackerNews Agent、ProductHunt Agent 等的协作中获取最新信息；内容创作者可以通过 TARS 智能中枢自动化视频分发，在 YouTube Agent、Instagram Agent 和 TikTok Agent的协作下，在社媒上发布内容；以及市场营销团队可以通过 TARS 创建和管理多平台的内容日历，包含自动更新和提醒的多Agent交互协作体验。

一些流程相对清晰和固定的基础工作，用户几乎都可基于TARS的Agent to Agent协议来完成。

TARS 还内置了支付、Agent钱包和自动结算机制，允许任何一个或者多个协作的AI Agent根据工作去完成收、付、存等支付和结算能力。比如用户可以通过USDC等稳定币按需付费，无需月度订阅。

TARS之所以能在不同任务场景中的灵活性和高效性，离不开Questflow的多AI代理调度协议及其接入的多维度AI模型堆栈，使其覆盖多维度的AI协同能力，其包括但不限于：

视频生成模型：Veo3, Zora, Runway, Kelin,Jimeng等；

图片生成模型：GPT-4o, Flux, Stable Diffusion, MidJourney, Google Imagen4, Artbreeder, Deep dream等

Deep search模型：ChatGPT, Gemini 2.5 pro, Claulde, Qwen等

Questflow优势在于保证了各个AI模型间的无缝衔接，来适配多任务的复杂场景。同时，GPT-4o等大语言模型让用户只需通过简单地“提需求”来处理工作。用户无需重复切换和登录不同AI平台，通过Questflow平台的统一界面、钱包和单次操作即可调用。

如果说MAOP是协调多智能体的“智慧中心”，那么 Questflow Developer Platform（QDP，Questflow 开发者平台） 则是推动构建强大劳动力市场的“动力引擎”。

QDP 致力于赋能开发者，提供模块化 SDK、自然语言驱动的零代码开发工具，以及高效透明的链上结算能力，实现开发、调度与结算的无缝衔接。开发者无需处理底层技术，即可快速将 API 封装为 AI Agent，并通过编排调度构建 AI 代理群组以执行复杂工作流，同时支持采用稳定币USDC按次付费、收益分成等灵活的变现模式。

随着平台上的AI Agent模型越来越庞大，如果质量不过关同样影响用户体验，因此如何保证AI Agent的质量同样重要。

为此，Questflow还推出了“Agent Benchmark”，基于多维度评估体系（成本/质量/速度）生成动态排行榜，为用户推荐最优Agent组合，并支持稳定币即时结算测试费用。

通过MAOP、QDP和Benchmark的协同，Questflow正在构建去中心化的AI生产力网络，让智能体真正成为可组合、可交易的生产要素。

与 Coinbase、Circle 顶级平台共建，Questflow 的增长潜力

Questflow正通过与Coinbase、Circle等顶级平台的战略合作，构建AI Agent时代的关键基础设施。

据官方信息，Questflow已与多个领域的头部平台建立合作关系，包括交易所（Coinbase、OKX、Gate）、稳定币（Circle）、数据分析（MongoDB、CoinGecko）、AI Agent平台（Virtuals、Yield）、Web3手机（Jambo）、 Web2 企业（Google）等。

以Coinbase的合作为例，Questflow与其开发者生态展开了深度合作。Questflow利用Coinbase Developer Platform（CDP）的钱包 API，为AI智能体提供链上资产管理和结算体系。Questflow的MAOP协议也集成了CDP的AgentKit智能体供生态用户调用。

在企业集成AI Agent 的浪潮下，Questflow拥有极高的市场天花板。它不只是功能型工具，而是生态级平台，正在撬动两个万亿级市场的交汇点：全球企业自动化服务市场和去中心化金融基础设施。

目前Questflow核心协议及产品已经得到了头部机构的认可。当大多数AI项目还在比拼单点技术时，Questflow通过与Circle、Coinbase等龙头项目生态绑定，完成了从技术协议到商业生态的初步实践。未来有望从Web3领域进一步拓展到更庞大的Web2生态。

此外，Questflow的团队基因也为长期的产品化和商业化落地提供了支撑。 随着AI Agent网络的持续扩大，Questflow有望成为AI时代的App Store，掌管着AI Agent的流量与经济的分发。
