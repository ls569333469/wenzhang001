一、IP 行业的百年历史：从迪士尼到泡泡玛特

如果要追溯现代 IP 商业的源头，迪士尼一定是绕不开的案例。1928 年，米奇老鼠第一次登上银幕，这只黑白短片里的小老鼠并不复杂，却成了全球IP赛道的起点。迪士尼从一开始就抓住了 IP 赛道的关键点：米老鼠不仅仅是简单可爱的角色，而是一种可以不断生息的“数字资产”。核心抓对了，那么围绕IP展开的迪士尼商业模式就会变得无比清晰：

i. 先用动画和电影塑造角色，建立文化认知，进行文化传播；

ii. 再通过图书、音乐、玩具等周边，把角色从荧幕带到生活中，与用户建立“感情链接”；

iii. 最终用主题乐园和真人演绎，把虚拟角色延伸为沉浸式体验。

这条商业路径奠定了现代 IP 产业的基本范式：从故事到符号，再到IP授权，再到动漫宇宙的世界观搭建。在接下来的几十年里，迪士尼不断用这一套模式扩张：米老鼠、唐老鸭、白雪公主、狮子王、冰雪奇缘……这些角色与IP不仅存在于荧幕、玩具店、游乐园里，他们已经深深地印在了我们的脑海，成为了我们不可或缺的记忆中的一部分。

相信聪明的你已经发现了，自己创造IP固然好，但好IP不是想创造就能创造的，艺术创作需要天时，地利，人和。这时迪士尼的股东就想到了一个好主意：我有那么多钱，为什么不去买呢？于是接下来，迪士尼通过并购扩展了自己的“IP 联邦”：收购了皮克斯、漫威、星球大战和福克斯，直接囊括了大量的超级英雄与宇宙叙事。到今天，迪士尼已经成为一家以 IP 为核心资产 的全球娱乐帝国。

然而，西方有迪士尼，东方也有东方的动漫王国。在遥远的东亚，日本动漫产业疯狂崛起。日本的 IP 成长路径更“草根”。从手冢治虫的《铁臂阿童木》到后来的《灌篮高手》《海贼王》，再到如今的二次元文化，日本的 IP 并不是由像迪士尼这样的某个超级公司垄断打造，而是依靠 作者、出版社、电视台、玩具商 共同组成的产业链条。日本IP产业的独特之处在于同人文化。每年两次的 Comic Market（俗称 Comiket），会有上万创作者自发基于已有 IP 进行二次创作，出版同人志。严格来说，这是法律灰色地带，但行业里形成了一种默契：只要同人创作不触及商业大规模盈利，原作者一般不会追究。这种“默契”让二次创作反而成为了原作的免费宣传。粉丝通过二次创作扩展了世界观，形成了更强的文化归属感。比如我小时候最喜欢《Fate》系列，从同人，到动漫再到游戏，Typemoon疯狂变现，虚渊玄也成为一代宗师。

我们再把视角拉到最近，Popmart的突然崛起，似乎让中国IP产业看到了希望。如果说迪士尼代表了“工业化叙事”，日本代表了“社区参与”，那么中国的泡泡玛特，则展示了一条全新的路径：消费创新驱动的潮玩 IP。

泡泡玛特的逻辑与迪士尼完全不同。它不依赖大电影、大故事，而是通过“盲盒”这种消费形式，把小众角色推向大众。像 Molly、Dimoo、LABUBU 这些角色，单独看没有宏大叙事，更谈不上迪士尼式的宏大世界观。但通过盲盒经济，它们迅速破圈，成为了一代年轻人的社交符号。这里面真正的创新在于：大幅度地降低了 IP 消费门槛。你不需要买电影票，不需要买几十美元的手办，只要几十块钱，就能拥有一个精致的潮玩。再加上“开盲盒”的不确定性和收藏乐趣，消费者的情绪被瞬间点燃。这种模式让“小 IP”也能规模化变现。泡泡玛特不需要下一个米老鼠，它只要不断推出新角色，就能让粉丝在“收集”和“社交”中形成循环消费。但缺点也很明显：没有持续性。如果没有持续性，那么就需要大量的创作者进行创新，这就引出了下一个问题：在这些模式下，创作者的处境是怎样的？

二、创作者的困境

在 IP 行业的繁荣背后，创作者其实一直处在被动地位。无论是音乐人、插画师，还是 YouTuber、潮玩设计师，他们的故事高度相似：创作价值被低估、权益保护不足、过度依赖平台。

1. 收益分配：创作者总是拿到最少的

以音乐行业为例。Spotify 每次播放给音乐人带来的收入大约是 0.003 ~ 0.005 美元。这意味着，一首歌要被播放 100 万次，音乐人才有可能拿到 3000~5000 美元。可问题是，这些收入还要继续分成：给唱片公司、发行方、经纪公司。最后真正到创作者手里的，往往不足 20%。YouTube 同样如此。YouTuber 平均 1000 次观看大约能赚 1~3 美元，但其中 45% 被 YouTube 抽走。头部创作者能靠流量活得不错，但试问头部博主又有多少个呢？绝大多数人只能挣点零花钱。潮玩行业的创作者也面临类似问题。很多设计师辛苦打造了受欢迎的角色，但缺乏渠道与资本，无法独立规模化，即便和泡泡玛特合作，分成比例也极其有限，真正的利润大头仍然在平台手里。

2. 版权确权：原创与盗用难以区分

确权是创作者的第二大难题。在传统模式下，确权必须依赖版权局登记、合同或律师函。但这个过程繁琐、昂贵，很多独立创作者根本无力承担。而互联网让盗版的成本接近零。插画师原创的角色很快就会被山寨成周边商品；摄影师拍的照片被爬虫抓取，流传在各种图库网站；更复杂的是，AI 模型开始未经许可抓取艺术家的作品风格，生成新的“类原创内容”，却不给任何回报。结果就是，创作者的权益极难保障。而对于小创作者来说，即便打官司，成本将远远高于收益，因此大多数人只能忍气吞声。

3. 平台依赖：算法决定一切

第三个困境是对平台的过度依赖。在 Web2 世界里，创作者和粉丝之间的关系，实际上是被平台“垄断”的。首先，作品能不能被推荐，完全取决于平台算法。第二，广告、打赏、付费订阅全都需要经过平台结算。第三，一个 IP 就算在 A 平台火了，换到 B 平台之前仍然需要斟酌，因为如果你不是顶天立地的IP，通常不会得到 B 平台的扶持。可以看到，创作者的命运其实掌握在平台的黑箱里，算法权重调整，可能让一个创作者的收入瞬间腰斩。潮玩设计师的处境也类似。即使设计出爆款角色，如果没有像泡泡玛特这样的渠道和供应链，也难以商业化，最终创作者只能接受“被平台雇佣”的命运。

三、AI 时代的 IP 竞争格局

如果说过去是“公司驱动 IP”“社区驱动 IP”“消费驱动 IP”的不同阶段，那么进入 AI 时代之后，IP赛道又会是什么样的一种竞争格局呢？现在我们知道，AI的诞生导致的：创作门槛的降低、供给数量的爆炸、确权与分润的复杂化，都会让 IP 赛道变得前所未有地拥挤和激烈。

让我们从供给端变化， 所有权问题，AI生态下的IP以及护城河四个层面来拆解整个业态。

1. 供给爆炸：AI 让 IP 成本接近于零

AI 出现之后，创作门槛骤然下降：AI制图（如 Midjourney、Stable Diffusion）可以在几秒钟生成一套角色设计；AI写文（如 ChatGPT、Claude）可以帮助用户快速搭建世界观和人物关系；AI制作音、视频则能让音乐和动画生产成本急剧下降。这意味着：IP 不再是稀缺品，供给端爆炸是不可避免的。即，如果过去一年全球能诞生几千个原创 IP，那么在 AI 驱动下，这个数字可能轻松膨胀到百万级。我们要知道，当供给过剩时，注意力和版权才是稀缺资源。

2. 所有权争议：AI 生成内容究竟归谁？

AI 带来的另一个麻烦，是归属权问题。传统 IP 的确权逻辑很清晰：完成创作+登记，那么你就获得所有权。但 AI 的参与让这个逻辑变得模糊。试想一下，如果艺术家用 Stable Diffusion 生成了一张插画，这张图的版权算谁的？艺术家？模型开发者？还是训练数据的原作者？如果音乐人用 AI 辅助生成旋律，再自己加工，这首歌的归属是“原创”还是“衍生”？如果一个用户上传提示词，AI 直接生成了完整角色，那么这个角色的版权又算谁的？

在现实中，很多 AI 公司直接规避责任，声明“用户生成内容归用户所有”。但问题在于：训练数据本身往往未经许可。例如，很多艺术家抗议自己的作品被用于训练模型，最终生成了“仿品”，却完全没有获得报酬。这种争议已经开始进入司法层面。例如，美国已有 AI 图像公司因涉嫌侵犯艺术家版权而被起诉。未来几年，类似案例只会越来越多。

当微观问题很难被解决的时候，我们需要跳出框架看全局。

3. 在AI生态中，IP的定义将被重构

当AI让 “混合创作” 变成常态，IP 将不再是“静态作品”，而是“动态生态”，它像一个开源项目，任何人都可以在原作基础上迭代，产出新的分支。这是一把双刃剑，优势是能激发创作活力，让 IP 保持生命力；风险是原作者的权利和收益可能被稀释。所以未来的 IP 赛道的商业竞争，核心将从“创作能力”转向“生态治理能力”。谁能建立一套透明的规则，既鼓励混合创作，又保证原作者收益，谁就能赢得创作者和粉丝的支持。

4. 新的护城河：确权、合理分润与社区

综合来看，AI 时代的 IP 赛道将呈现以下竞争逻辑：
i.  确权能力：谁能最快、最低成本地为创作者提供确权工具，谁就能吸引更多内容入驻。

ii. 分润机制： 在混合创作与二次创作盛行的时代，能否透明、公平地分配收益，是 IP 基础设施能否成功的关键。

iii. 社区驱动力：供给已经不是问题，真正的关键点在于“粉丝与创作者的参与”。能建立活跃社区、形成文化共识的平台，才能拥有谈论“护城河”的资格。

可以看到，在这个格局下，传统的迪士尼、泡泡玛特模式将显得笨重，新的竞争者必须以基础设施的形式出现，这就给出了弯道超车的机会，这也为 Camp Network 的叙事铺垫好了舞台。

四、Camp Network：链上 IP 基础设施的范式尝试

让我们一起来看看Camp Network 给出的答案，它想做 IP 世界的“操作系统”。

1. 商业模式：全栈式 IP 基础设施

作为一个 Layer1，Camp能为整个 IP 生命周期提供全栈式支持。它的目标是在链上实现一条完整的价值链：

i. IP 注册与确权：创作者在 Camp 上注册作品，立即生成链上凭证，保证原创性和归属权。

ii. IP 授权与分润：通过智能合约定义 IP 的使用范围与收益分配并自动结算，不再依赖传统机构。

iii. AI 重混与衍生创作：提供原生的 AI 基础设施，允许在合法框架下进行二次创作。

iv. 代币化与交易：IP 可以在链上直接代币化，形成可交易的资产。

v. 跨生态流通：无论是 Web3 项目还是 Web2 的大 IP，都能通过 Camp 的协议桥接，进入链上世界。

2. 核心组件：四大模块

为了支撑这套模式，Camp 搭建了四个关键组件：

i. Remaster：法律授权框架

用链上合约固化 IP 授权条款，让使用范围和分润比例透明可追踪，解决传统版权合同复     杂、执行成本高的问题。

ii.mAItrix：AI 混合创作基础设施

为创作者和开发者提供二次创作工具，在合法合约的前提下，允许粉丝、社区对已有 IP 进行改编、扩展。

iii. Origin：IP 代币化模块

将 IP 以 NFT 的形式铸造在链上。

iv. Attribution：协议层归属与分润为每一次 IP 使用和交易提供透明的分润追踪。

确保原创者、二创者、持有者之间形成长期利益绑定。

3. 团队背景与融资

Camp Network 的团队来自 Web3 基础设施 + 内容产业 的复合背景。一方面，他们熟悉链上合约、协议设计和代币经济；另一方面，他们有在游戏、娱乐、IP 授权领域的深厚经验。

目前，Camp 已经完成了 3 轮融资，总额约 3000 万美元，投资方包括：1kx（知名加密基金，早期支持过 Lens、Celestia 等项目）、Blockchain Capital（老牌加密基金）、OKX Ventures、Maven 11

4. 生态系统的繁荣

Camp 目前还处在 主网上线前阶段，但它的生态系统已经展现出超预期的繁荣：有120+ 项目 已经在测试网构建；150 万+ IP 在测试网上铸造；它们持有 KOR Protocol 股份（合作 IP 包括《黑镜》、deadmau5、Imogen Heap 等），并且也已接入 Mimi & Neko 这样的 Web2 IP，下载量超过 50 亿。

生态领域涵盖：AI dApp（智能体与重混工具）；NFT 基础设施（IP 链上确权）；DeFi（IP 资产化后的流动性支持）；游戏（基于 IP 的链游）以及钱包与授权协议（降低用户进入门槛）

五、CAMP Tokenomics 设计预测

对于任何一个基础设施级别的公链或协议的讨论，最终都会回到一个核心问题：代币如何捕获价值？

那么接下来，笔者斗胆假设自己是Camp创始人，来设计一遍tokenomics，供大家参考：

1. 设计逻辑：IP 活动驱动的内生需求

CAMP的代币经济逻辑，我认为必须具备的核心功能有两个：

i. IP 注册与确权：每一个 IP 上链，都需要消耗或质押 CAMP。

ii.授权与分润：在 Camp 上进行 IP 授权，需要通过 CAMP 支付 Gas 或手续费，并且
分润可以用 CAMP 进行结算，创作者、二创用户和token持有者之间形成循环流动。

2. 价值锚定：Gas + 分润

CAMP必须同时具备 使用属性 + 分红属性：每一笔 IP 注册、授权、分润都要用 CAMP；部分手续费用于销毁 CAMP，保证稀缺性，部分收益进入奖励池，分配给质押者和创作者。这三类需求叠加，会让 CAMP的流动性形成稳固的内生市场，这样的设计使得 CAMP的价值捕获能力比传统的治理token更强。

3. Tokenomics细化

有了框架之后，我们再把Tokenomics细化。

首先，设立内容发布质押机制：

i.创作者发布内容时质押一定 token（可退），避免垃圾内容；内容产生调用、分润后可额外奖励 token。remix 使用费用统一用 token 结算：

ii.每次调用别人的内容、或 remix 某段素材，都会触发链上付费，用 token 支付，分配给所有 remix 路径中的上游创作者。内容信用等级 → 提高收益倍率 / token 回报比率：

iii.内容被频繁使用、产生收益高，其作者的链上“内容权重”上升，可获得更高比例奖励、参与协议治理、获得下一轮优质内容推荐资格。

第二，使得 token 与平台使用权限挂钩：如果想要大批量调用内容、训练模型的商业用户，需持有并锁仓 CAMP，形成付费门槛和流动性池锁仓模型。

最后，是协议回购机制：协议抽取 remix、商用中的 protocol fee 定期回购或注入 remix 激励池，从而形成 flywheel：内容越多 → remix 越多 → 商用调用越多 → 收益越多 → 回购越多 → 激励越多 → 内容越多…....
至此， tokenomics将变得没有死角，覆盖协调激励、支付、调用、质押、治理五个角色。

4. 举例说明：假如笔者是一个作曲家，他能得到什么？

我上传一段原创旋律片段，允许非商用remix、商用分润，结果发生了意料之中的结果：

i. 某用户用 Merv 把它转为 Lofi

ii. 某漫画创作者把它嵌入剧情配乐

iii.某广告公司剪进了品牌宣传片

与此同时，我能在后台看到他每一条 remix 的路径和每一段 remix 带来的收益，以及这段旋律被多少人协作引用，最终我获得了以下权益：

i. 220个 CAMP+ 37 USDC 分润

ii. 内容信用分数上升，未来分润倍率更高

iii. remix 图谱上自动建立路径资产，持续流量收益

六、总结：CAMP的投资价值

经过以上分析，相信读者对Camp network的价值与逻辑已经有深入了解了，我们最后来探讨一下终极问题，即这个项目的Token是否具备投资价值？

Camp network的确切准了一个非常强劲的赛道，拥有AI+IP概念的它给予了投资者相当大的想象空间，这也是它能大量融资的原因之一。在理想化状态下，拥有资源的Camp团队一旦进行创作者激励，并利用tokenomics将业务带入正循环，或许真能成为下一个龙头，但这也是目前IP赛道最大的问题：业务落地难度相当大。

首先，IP 的商业化周期很长，从确权到授权再到真正产生收益，往往需要几年时间；第二，不同国家对版权保护的法律差异很大，如何处理合规问题是一个巨大的挑战，如果不能迅速占领优质市场，很可能被竞争对手弯道超车；第三，创作者有巨大的迁移成本和学习成本，Camp需要有强有力的激励和引导措施；最后，Camp 的生态如何平衡“二创活力”和“版权保护”？这是最模糊，也是最核心的治理挑战。另一方面，最近看到了团队“先交钱再领空投”的骚操作，以及大量“女巫”测试网用户的行为，笔者需要对团队在Web3领域的运营经验打个问号。在估值水平上，同赛道的Story FDV高达59亿，流通市值17亿，可以看到目前市场给予IP赛道龙头的估值非常高，再综合考虑团队、市场状况等因素。
