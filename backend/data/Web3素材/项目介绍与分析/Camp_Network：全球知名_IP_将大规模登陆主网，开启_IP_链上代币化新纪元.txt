标题: Camp Network：全球知名 IP 将大规模登陆主网，开启 IP 链上代币化新纪元
链接: https://www.chaincatcher.com/article/2206245
发布时间: 2025-09-17

==================================================

自治 IP Layer1 Camp Network 宣布，其新上线的主网将迎来全球 IP 的大规模接入。在早期与 KOR Protocol 和 Minto 达成合作的基础上，Camp正进一步拓展至娱乐、体育、游戏和音乐等多个领域，将全球知名IP引入其平台。

值得注意的合作伙伴包括：

KOR Protocol ：Camp Network 收购 KOR Protocol 股份后，基于 KOR 的全球特许经营权和艺术家（如 Netflix 的《黑镜》、Imogen Heap、deadmau5、Richie Hawtin、Disclosure 和 Beatport 相关计划）都可使用 Camp 的溯源与版税基础设施，实现更透明的版权许可和自动化的支付流程。
Chalk Line：Chalk Line 与 Nickelodeon、NFL、迪士尼、漫威、WWE、NCAA、MTA 等众多知名品牌合作，打造了一系列经典 IP。Chalk Line 正与 Camp 支持的 REMASTER 合作，整合下一波新兴全球 IP，并利用区块链技术优化授权流程。
Minto：日本最大的 IP 公司之一，旗下拥有热门动画《咪咪与猫咪》系列，通过 REMASTER 平台加入 Camp。通过 Camp，粉丝们参与了一项由人工智能驱动的共同创作活动，获胜者可以通过 BitBrand 的数字壁纸将他们的作品变现。Minto 的角色在 LINE 和微信平台上的下载量已超过 50 亿次，曝光量超过 600 亿次。
Flappy Bird：这款手机游戏定义了超休闲游戏，在不到一年的时间内就积累了超过 1 亿粉丝和玩家社区，并成为有史以来最具标志性和最持久的手机 IP 之一。
Rhuna x UNTOLD 音乐节：Camp 和 Rhuna 携手合作，以 UNTOLD 音乐节为起点，展示 Web3 如何变革大型文化活动。UNTOLD 音乐节是全球第三大音乐节，每年吸引超过 50 万名观众，并邀请 Post Malone 和 Martin Garrix 等艺人献艺演出。
All Access：目前在亚洲和澳大利亚拥有 50 多个现场音乐节 IP（包括海上最大的音乐节 Its The Ship），每年吸引 200 万参与者。借助 Camp ，All Access 可将娱乐和文化 IP 代币化。
Moonbirds：Web3世界最具传奇色彩的NFT系列之一，包含1万只“小鸟”（birbs），已飞入收藏品、时尚等多个领域，总交易量超过36万ETH。。
拉丁美洲体育 IP：包括阿根廷的贝尔格拉诺竞技俱乐部（Club Atlético Belgrano）和秘鲁的水晶体育队（Sporting Cristal）。这两家俱乐部是拉丁美洲最具标志性的代表，不仅文化根基深厚，还拥有庞大的粉丝群体。

传统的版权许可框架并未为AI和数字分发时代做好准备。Camp以默认可编程的权属、版税和再创作基础设施，取代落后系统所带来的摩擦，让全球品牌更容易扩展IP，也让粉丝更安全地参与其中。

KOR Protocol创始人Inder Phull表示：“AI扩展了IP的可能性，但只有具备溯源与版权管理能力的网络才能安全地承载这些创新。Camp提供了这缺失的一层，KOR很高兴能将我们的艺术家与合作伙伴带入这一新篇章。”

随着主网上线，Camp正在释放知识产权的新用途，并接入新一波全球娱乐、体育、游戏和音乐IP——为权利、许可和货币化机制深度融入创作生态的未来铺平道路。


关于 Camp Network

Camp Network 是一个面向 IP 与 AI 未来的自主知识产权层（ Autonomous IP Layer ）。作为一条 Layer 1 区块链， Camp 正在开创溯源证明协议（ Pro of of Provenance Protocol ），在执行层直接嵌入 IP 注册、授权与版税分配，同时优化面向 AI agent 的工作流程。用户可以将任何形式的 IP 代币化、微调并部署 AI agent ，并将其链上化以供更广泛的生态使用。
