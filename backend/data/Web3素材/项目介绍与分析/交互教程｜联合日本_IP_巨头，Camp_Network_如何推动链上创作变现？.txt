近日，自治 IP Layer 1 区块链 Camp Network 联合日本顶级 IP 公司 Minto 推出全球共创计划，邀请 Web2 和 AI 创作者参与“ Mimi & Neko ” IP 的二次创作，并参与评选。获胜的 IP 作品将有机会在多个数字和电子商务渠道中获得变现机会。

Minto 的参与和 Camp Network 为创作者提供的变现机会，吸引了社区的广泛关注和热议。

本文将简要梳理此次合作概况以及 CAMP × Minto IP 创作大赛的交互教程。

联合日本 IP 巨头 Minto ，推动链上创作变现

Minto 是一家总部位于东京的创意工作室和 IP 公司，专注于创建、管理和许可原创角色 IP ，活跃在 Telegram 、 LINE 和社交媒体等数字优先平台上。 Minto 的 GIF 印象超过 600 亿次，贴纸下载超过50亿次，特别受到全球 Z 世代和年轻千禧一代的欢迎。

而 Camp Network 是一个自主 IP 层，旨在推动 IP 和 AI 的未来。作为一个 Layer -1区块链， Camp 正在开创“来源证明协议”，将 IP 注册、许可和版税分配直接嵌入执行层，同时优化以代理驱动的工作流程。用户可以对任何形式的 IP 进行代币化，微调和部署 AI 代理，并在链上对这些代理进行代币化，以便更广泛的生态系统使用。

Camp Network 提到，当前的 IP 许可环境未能满足创作者的需求， Camp Network 旨在通过在链上简化合规和变现框架，重新定义 Web2 许可流程，从而在时间、资源和成本上实现显著效率提升。

此次活动， Camp Network 不仅联合 Minto ，吸引更多活动全球 Z 世代和年轻千禧一代参与创作，还与 IP 许可引擎 REMASTER 合作，让创作者可以无缝管理、许可和变现他们的提交，所有的版税和所有权条款均在链上透明处理。

Camp Network 表示，此次与 Minto 、 REMASTER 达成战略合作，旨在为创作者解锁新的经济机会，并为全球 IP 许可设定新的标准。

CAMP × Minto IP 创作大赛交互教程

1、注册 Remaster 账户

进入 Remaster 注册页。 按照提示输入邮箱并验证，设置 PIN 密码。

2、下载 Minto 官方素材包

点击该链接进入 “Opportunities”页面，点击“Download Style Guide” → 仔细阅读协议条款 → 勾选同意并输入前面设置的PIN密码 → 创建专属签名并点击保存→ 自动下载 “Minto IP Kit素材包。

3、设计作品

点击链接进入Wide Worlds 平台。可以选择提示词或者自定义的描述，点击创建。等待创建后选择你喜欢的图片，并下载图片。

4、上传作品至 Remaster

点击链接进入Remaster的“Assets”提交板块。点击Add Assets → 上传作品并为其命名→ 点击保存。

5、提交正式提案

点击提案链接填写Camp Network支持的钱包地址（用于版税结算），关联已上传的作品文件。确认提交后，添加留言并点击发送，吸引你的潜在买家关注你的作品，

6、最终检查

点击链接再次进入提案查看页面，状态为Draft Submitted则提交成功。

7、等待审核结果

Minto 团队将对所有提交作品进行审核。若作品入选，将通过你注册的电子邮箱联系你，完成最终授权协议拟定在内的后续流程。
