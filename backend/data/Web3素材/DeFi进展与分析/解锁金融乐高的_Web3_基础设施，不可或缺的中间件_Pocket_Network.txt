DeFi 趋势已经转变为狂热，紧随其后的是以用户为中心的趋势，比如 NFT。当我们猜测加密朋克和追求天文数字收益时，以太坊正在达到其扩展极限，替代链正在努力追赶。我们正被 MEV 和成功的 DeFi 项目及其廉价山寨产品所推动的短期投机所吞噬。

2017 年的最后一个周期是以大局主题的名义进行的，比如 fat Protocol 理论和比特币作为硬货币替代品的作用。我们认为当前的周期更加微观化，因为我们已经变得过于关注金融应用的微观细节。

2016 年，Joel mongro 以他 Fat Protocol 论文开创了先例，掀起了智能合约层的狂潮。

2021 年，所有人都在关注 Tarun Chitra 以及他关于 CFMM 各个可能细节的数学驱动的论文。

宏观和微观的焦点都很重要，但是从宏观到微观的摆动似乎是一种过度补偿。这就是为什么我们建议将宏观与微观联系起来，并寻找中间的基础。

大约一年以来，Zee Prime 一直在问：可以改善和扩展 DeFi 和 Web3 的基础技术是什么？现在最有影响力的加密货币垂直投资是什么？我们的结论是，现在是我们需要改善基础设施的时候了。

正如 USV 所言，我们并不是在呼吁“基础设施阶段”，这只是一个神话。但是我们认为 DeFi 应用程序已经领先于基础架构，现在基础架构需要迎头赶上。

最终用户应用程序（DeFi 服务器）跳得太远了，现在基础设施需要赶上最终用户的需求（可扩展性问题，糟糕的用户体验等）。

从高昂的 gas 费用和失败的交易导致非巨鲸用户无法进入“加密曼哈顿”中定价，这显然需要更好的基础设施。但真正的威胁要微妙得多。即使我们接受这些费用作为抵抗真正审查制度的溢价，但当大多数 dapp 在中心化基础机构上运行时，我们真正支付的是什么费用呢？

DeFi 势不可挡，将引领未来十年的超金融化运动。但是我们错过了将小众应用程序和以前全局之间的联系。我们认为，如果我们希望在不损害加密运动的某些核心价值的情况下向前发展，我们需要改进基础技术。货币乐高积木应该由基础设施乐高积木提供动力。

什么是中间件？

开源软件产品供应商 Red Hat 提出了以下一般定义：

中间件是一种软件，它为操作系统之外的应用程序提供通用服务和功能。数据管理、应用程序服务、消息传递、身份验证和 API 管理通常都由中间件处理。中间件可以帮助开发者更有效地构建应用程序。它的作用就像应用程序、数据和用户之间的结缔组织。

这正是现在加密货币所缺乏的——一种坚固的胶水，其原理与其他加密货币相同。这使得现有的区块链操作系统能够升级到更高水平。

问题不在基础层或应用程序级别上。大多数问题来自于两者之间的摩擦；当您按下应用程序中的按钮，期望进行实际的链上操作。考虑一下那些可怕的“缺乏 gas”的消息，或者因为某个节点不同步而导致 tx 不能立即出现在 Etherscan 上，或者由于待处理，而导致 tx 不能立即显示成功。

加密中间件项目有一个很好的机会，通过调整经济激励，例如插入代币来集成。假设所提供的服务是有价值的，那么产生的价值将被引导到基于代币的激励机制。未来的 Web3 基础架构可能是一个跨越不同代币驱动网络复杂的 3D 系统。

目前，我们受限于分层定义基础架构或“堆栈”。我们讨论 L1 和 L2。未来的堆栈将不会被限制为两层。未来是由许多不同的乐高积木的灵活堆叠而成。

我们将这些模块称为中间件，每个模块都为实际的最终用户用例提供微服务。欢迎使用可组合的基础架构乐高。

中间件从内到外蚕食加密货币

我们在通用软件开发的背景下讨论了中间件，但是什么是用于加密货币的中间件呢？

中间件一次涵盖了 dapp 所需的所有服务，而大多数用户并不知道这些服务。有点像 dapp。预言机就是一个例子，它是一个插件解决方案，可以为应用程序提供所需的应用程序数据。更奇特的例子包括 Blockswap.network 代币化验证器及其在不同 PoS 网络上的现金流。

为了使 Blockswap 构建可靠的产品，它需要链上的数据。为此，它可以反过来依赖 Pocket Network 作为去中心化的数据来源。除此之外，Blockswap 的产品可以集成到不同的 dapp 中，例如提供收益。

因此，中间件意味着所有这些解决方案不必面对消费者，因为它们集成到 dapp 中，基本上是加密经济的 B2B 方面。如果您以为复杂的应用程序只是一堆“智能合约+区块链”，那么您需要更新您的愿景。

“中间件”技术堆栈的简化示例

一旦市场意识到对关键基础设施组件的需求，允许存在实际使用情况，Chainlink 的热潮只是一个即将到来的信号。预言机已经成为第一波主要的浪潮，现在其他人也将随之而来。

为了更好地理解中间件的未来，我们应该考虑到 Web3 不太可能成为一种整体技术。“区块链互联网”将不会被以太坊、Polkadot 或 Cosmos 独占。

Web3 可以是自发出现的产物，而不是自上而下的设计。我们想象不同的软件松散地捆绑在一起，从而自上而下地创建了 Web3。未来是灵活的。未来是可插入和可组合的东西。中间件使支持 Web3 的基础架构乐高的存在成为可能。

去中心化的互联网既不是自上而下的，也不是自下而上的，而是从中间连接起来的。在 Zee Prime，我们相信 Web3 的未来将与中间件联系在一起。

为了更好地说明加密中间件的情况，我们将在下面更详细地讨论 Pocket Network。

Pocket Network

Dapp 所需的通用中间件服务之一是 Pocket Network。

Pocket （或 Pokt）是一个去中心化的区块链网络，其将需求方的开发者和应用程序与供应方区块链全节点的运营商进行匹配。

Pokt 的目标是通过激励运行完整的节点来成为区块链数据供应商，从而创建一个与区块链无关的数据市场。这个很小的激励周期具有积极的结果，即可以保护去中心化的基础架构，同时可以访问链上数据。

所有不同的 dapp、分析工具、钱包、投资者、交易所等都需要来自区块链的数据。这些数据包括地址的历史或当前余额、智能合约事件日志、大幅削减等等。

客户通过向 Pokt Network 发送 API 请求或中继器（按照 Pokt 的说法）来获取数据，Pokt Network 将请求路由到整个节点（正在请求数据的那个特定区块链）的随机运算符。Pokt 削减了不提供正确数据并且也没有保留任何数据的节点操作员。

为了获得所需的数据，客户需要投入一定数量的 POKT。这种新颖的“单项服务”设计使您可以通过稀释来逐步付款。Pokt 正在定义一种使用代币为即插即用的 Web3 解决方案付款的新方式。

Pokt 是将跨越不同链条的关键中间件。随着我们进一步走向从中心化到去中心化金融的过渡，实际的基础设施必须保持去中心化。我们相信 Pokt 可以做到这一点。

未来的金融机构类似于技术提供商。例如，他们将运行支持底层基础架构的节点。因此，未来的金融体系更新兴、自下而上，而不是由中央政府强加。Pokt 正在将去中心化即服务（Daas）出售给未来金融基础设施的主要参与者。

以太坊的基础层是栈中唯一去中心化的部分。网络、DNS、存储和客户端层尚未去中心化。Pokt 使我们每天 (想要) 使用的应用程序的网络层真正具有抗审查性。

Pokt 采用独特的方法解决链上数据可用性和区块链抗审查性的问题，并以中心化架构挑战竞争对手。

在 Pokt 中，工作以 5 人一组的形式分布在节点之间，从而实现了集体规模经济，而无需使用强大的机器。其他一些去中心化替代方案的主要问题是，工作无法在节点之间共享，并且每个数据提供者都需要具有大量备份。

Pokt 提出了一种高效的解决方案，因为它是去中心化的。

为了真正将“De”融入到 DeFi 中，并使 Web3 的主题在技术上得以实现，我们需要一个功能齐全的去中心化堆栈（例如 ETH > SIA > HNS/ENS > POKT），以及使这些事情更容易构建的工具（例如 WEB3API)。

“去中心化”vs 去中心化

区块链最重要且被低估的好处之一是冗余。在当今过度优化的经济中，冗余并不被视为一种品质。但是，如果我们正在建立一个新的金融体系，我们应该避免过度优化。冗余层是一种保护和安全功能。

比特币建立在激励冗余的基础上。比特币的冗余是一种确保网络安全的质量。Pokt 还通过让节点运行获利来刺激冗余。

但不仅如此。通过设计，节点运营商的激增也会降低数据的成本。Pokt 解决了在宏观层面上保证冗余，同时又在单个节点运行程序层面上消除了对冗余的需求。

Pokt 是基于其用户托管由 POKT 支付的各种区块链的完整节点而建立的。每一个数据的中继器都会产生 POKT 代币，这些代币会支付给执行这些中继器的节点操作员。

我们需要一种服务，当人们深入研究项目并不断刷新其余额时，它提供可扩展的基础结构。每次刷新都是多个数据请求。实际使用会产生大量数据和价值。Pokt 定位为通过不信任协议中继器所有这些数据来捕获在应用程序层上创建的值。

通过消除对中心化实体来协调整个节点的需求，与自己运行的 dApp 相比，Pokt 降低了基础架构的成本。这是一种通过本地加密经济设计和集体规模经济实现的唯一解决方案。

Pokt 很重要，因为目前的 Web3 基础设施很昂贵，侵犯了用户的隐私，并且最终实现中心化。这是昂贵的，因为常规的完整节点并没有优化查询数据的效率，而是针对 P2P 网络中的弹性进行了优化。我们需要原生的 Web3 解决方案来优化成本。

目前的基础设施不能保证隐私，因为集中的基础设施提供商为经过它们的请求保留了每一个元数据，这意味着整个系统最终不会受到审查的影响。Pokt 完全消除了这一点，这就是为什么它是重要的中间件组件的原因。

当然，尤其是在 BSC 蓬勃发展的时期，Web3 更具讽刺意味。像 BSC 这样的中心化服务是否会取代去中心化服务？BSC 风格的网络可以被认为是一种“包装的”区块链。人们可以从一个中心化交易所的舒适性中体验到去中心化的暗示。

每个应用程序都需要可扩展的基础架构，而 Pokt 提供了一种更便宜、更私有且不受审查限制的替代方案。试想一下，如果政府机构命令一个中心化的节点提供商停止服务（例如下一个中心化的 Twitter），或者单方面决定提高价格（仅仅因为他们有这个能力），将会发生什么。

在 2020 年 11 月上旬的 Infura 中断期间，Pokt 已经证明了其可靠性以及此功能的重要性。

Pokt 是访问多链的一个接口。可以把它看作区块链基础架构的 Uniswap。在接下来的一两年中，将在 Pokt 上构建抽象层，让开发者可以更轻松地同时构建多个链。

例如，目前 BTC，ETH，DOT 上的“发送 TX ”有所不同。一个人需要使用其应用程序中的每个 SDK 构造 3 个不同的“发送 TX”，以进行跨链应用程序。想象一下将每次读写抽象到只需要构造一种类型的 tx 并指向将要到达的链的点，这可以基于 Pokt 构建。

Pokt 的经济学

至此，我们认为中间件可以为应用程序、节点操作员和协议本身创造很多价值。但是作为投资者，我们也必须问：中间件能 否 创造护城河？如果可以，如何创造？我们可以在 Pokt 这样的中间件解决方案上进行盈利投资吗？

在此阶段使用或购买 POKT(代币) 是对区块链数据需求增长的实际抵押。Pokt 提供的服务将在成熟时实现商品化。即使在现阶段价格也很重要，Pokt 希望以去中心化的方式以最好的价格提供最佳服务。在商品市场上构筑护城河是困难的。

除了低廉的数据外，Pokt 的防御能力还取决于网络效应和类似 Uniswap 或以太坊的品牌。我们还可以争辩说，以太坊的状态转换服务最终可以商品化，但是我们还没有成熟到看到这种假设能够实现的程度。去中心化的区块链数据提供商有一天可能会成为一个热门市场。

Web3 代币模型似乎固有地包括货币溢价和部落忠诚度。在某种程度上，它们都依赖于积极的加密经济飞轮。POKT 也是如此。随着越来越多的节点运营商加入，越来越多的开发者将使用去中心化的区块链数据开发杀手级应用，对 POKT 的需求预计将会增长。

当 Pokt 变得更具流动性时，加密经济飞轮将变得更有流动性，一些投机者将转变为用户，反之亦然。Pokt 用户将对其服务感到非常满意，以至于他们将其视为成功的投机者。如果您相信 DeFi 只会从这里开始增长，那么您应该假设区块链数据的 TAM 也会随之增长。

Pokt 成为区块链数据的 DEX，而 DEX 的流动性至关重要。流动性对于任何市场都是一个护城河。数据买家寻求最大的流动性，数据卖家则去订单流最多的地方。

每个协议都需要 Pokt。无论是 Polkadot 还是 Solana，每个生态系统都希望构建和集成 Pokt 或类似 Pokt 的解决方案。Pokt 本身可以是跨越多个链的流体中间件的第一个实例。

尽管网络还处于起步阶段，但节点的增长却非常可观。如果我们将 OTC 市场中 POKT 代币价格的上涨因素考虑在内，我们可以看到加密经济的飞轮开始旋转。建立强大的生态系统需要一点反射性。

但增加中继器将使飞轮机构的曲线更陡。基于过去 30 天的快速计算：

每个中继器的奖励 = 0.01 POKT

当前场外交易价格 = 25c

每天平均中继器 = ~5m

30 天网络收益 = 37.5 万美元

这对于处于“预生产阶段”的网络来说很不错。给您一个概念：在同一时期，Terra 的收入为 798,315 美元，0x 的收入为 809,104 美元，PoolTogether 的收入为 255,246 美元，Loopring 的收入为 97218 美元。

随着 Pokt 用户体验的提高，将会有更多的中继器。人们对新的仪表板版本的期望很高。如果一切顺利，仪表板将成为一个真正易于使用的产品。单击 3 次，您将获得一个端点。

Pokt 如何成为更便宜的解决方案？抵押 POKT 而不是支付 AWS 的账单。使用更多的中继器和更多的节点，数据将变得更便宜。预计在未来几年中，每个中继器的价格最终将以稳定在一个数量级。

Pokt 是一种当今更便宜的解决方案。通过 Pokt，开发者可以将其基础架构转变为可产生收益的资产。开发者不再向中心化解决方案支付 50 美元 / 月的费用，而只需购买 500 美元 POKT 并进行抵押即可。在使用该协议的几个月内，其成本基本接近 0 美元。

这种较高的前期成本将通过传统模式（例如每月付款直到支付 POKT 之前的费用）或 Web3 模型 (例如借贷) 来减轻。（这是 wPOKT 通过允许它与可组合的 DeFi 集成而大有帮助的地方。）

这种通过抵押的新颖支付方式可能会成为采用过程中潜在的阻力，但是，如果 Pokt 成功，我们可能已经找到一种有效的方式，可以将各种 Web3 中间件基础设施与代币连接起来。

 

在技术方面

总之，我们认为基础架构乐高积木将变得很有价值，因为它们：

为刺手的技术问题提供 10 倍更好的解决方案（例如，高昂的成本、易用性、抗审查制度等）

促进博弈和价值创造

提高现有应用程序的效率

支持构建新的应用程序

在用户体验本身之前创造价值（并获取价值）

激励关键的基础设施提供商根据生态系统的长期目标和价值采取行动和组织（去中心化）

中间件解释

Pocket Network 很有可能成为基础设施组成不可或缺的部分，因为它是一种即插即用的解决方案，能够激励去中心化，并为 dapp 和协议提供有价值的服务。

Pokt 是对应用程序开发者的一项投资，就像支付服务器费用一样。抵押代币获取数据是一项投资，可以将开发人员的基础设施变成一种资产。这是一种访问有价值服务的新颖模式。

Pokt 的长期目标是提供最便宜的链上数据。在中期，它可能不得不通过调整每个中继器的价格来平衡 POKT 的飞轮，以确保应用程序的可预测成本。

Pokt 在 BlockSwap Network、Api3、Web3API （是的，这是两个不同的项目，书呆子最不擅长品牌推广）、use、KALE 等少数技术能力强的团队中被有意义地采用而感到鼓舞。

到 2021 年底，随着 DeFi 跨链化程度的提高，我们将看到基础设施的乐高主题以一种更为微妙的方式发挥作用。
