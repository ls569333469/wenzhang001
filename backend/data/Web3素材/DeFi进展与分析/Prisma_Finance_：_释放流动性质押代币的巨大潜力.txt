导读：**Prisma Finance是一项专注于释放以太坊流动质押代币（LSTs）的全部潜力的新型DeFi原生。通过Prisma，用户可以使用流动质押代币作为抵押，铸造全抵押稳定币（acUSD）。这一稳定币将在Curve和Convex Finance上得到激励，为用户提供交易费用、CRV、CVX和PRISMA等额外收益。

Prisma的代码基于Liquity，具有完全不可变性，旨在创建一个强大的协议和真正去中心化的稳定币，其灵活的抵押参数吸引了那些希望充分发挥其流动质押代币潜力的用户。Prisma DAO将负责参数、发行和协议费用的管理。该项目获得了Curve Finance、Convex Finance、FRAX Finance等多位行业顶尖创始人和机构的支持。

 

概述

 

Prisma 是一种新的 DeFi 协议，专注于释放以太坊流动性质押代币（LST）的全部潜力。

Prisma 允许用户铸造一种由流动性质押代币完全抵押的稳定币（acUSD）。该稳定币将在 Curve 和 Convex Finance 上得到激励，从而创建一个高效的资本飞轮，用户可以在以太坊质押奖励之外获得交易费、CRV、CVX 和 PRISMA。

Prisma 的代码库完全不可变，基于 Liquity，以创建一个强大的协议和真正去中心化的稳定币，具有有利且灵活的抵押参数，使其对于那些希望在没有其他稳定币风险的情况下充分利用 LST 的人来说具有吸引力。Prisma DAO 将负责参数、排放和协议费用。

当前状况

 

以太坊流动性质押代币（LST）市场近年来增长迅速，目前市值为 180 亿美元，约占以太坊整个市场价值的 10%，根据 DeFiLlama 的数据，最近成为 TVL 最大的 DeFi 类别它是 DeFi 中最大的潜在市场。

 
实用性

 

Prisma 允许用户使用以下任何一种 LST 铸造 Prisma 原生的超额抵押稳定币（acUSD），为流动性质押 ETH 代币持有者提供无与伦比的资本效率。在以太坊质押奖励的帮助下，由 LST 保证的贷款会自动偿还。

通过添加 Curve 池，用户可以将其稳定币质押，然后以 CRV 和 CVX 的形式获得更多奖励，协议将通过参与 Curve 战争大力激励这一点。

 

Liquity 和 Prisma

 

Prisma 的代码库基于 Liquity。我们尽力尊重他们的精神，我们坚信这体现了 DeFi 的最佳品质：不变性、稳健性和去中心化。我们还希望 Prisma 独具特色，因此我们在治理层面增加了关于抵押品、参数等方面的灵活性。通过使用 veTokenomics，Prisma 持有者将对协议有更多的控制权。

PRISMA 使用 veToken 模型来控制协议的几个方面：

稳定性池；

新抵押品的池参数；

协议费用；

排放（以及哪些抵押品应该获得它们）。

治理参与者还可以激励铸造 acUSD 或更改他们选择的抵押品上的铸造和借款费用，目的是激励 LST 协议参与 Prisma 的治理。vePRISMA 持有者还可以选择用 PRISMA 发行激励任何 LP 代币。
