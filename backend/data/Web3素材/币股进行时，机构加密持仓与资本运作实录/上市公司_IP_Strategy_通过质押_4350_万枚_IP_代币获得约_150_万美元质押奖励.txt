标题: 上市公司 IP Strategy 通过质押 4350 万枚 IP 代币获得约 150 万美元质押奖励
链接: https://www.chaincatcher.com/article/2210279
发布时间: 2025-10-03

==================================================

ChainCatcher 消息，据 GlobeNewswire 报道，纳斯达克上市公司 IP Strategy 宣布已开始在 Story Network 上推出验证功能并支持直接质押 IP 代币。

该公司还披露截至目前已质押 4,350 万枚解锁 IP 代币，并获得了近 16.5 万枚 IP 代币质押奖励，价值约合 150 万美元。
