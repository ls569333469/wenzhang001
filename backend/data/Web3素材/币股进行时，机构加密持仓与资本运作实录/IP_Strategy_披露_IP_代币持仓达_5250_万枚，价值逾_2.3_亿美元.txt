标题: IP Strategy 披露 IP 代币持仓达 5250 万枚，价值逾 2.3 亿美元
链接: https://www.chaincatcher.com/article/2219237
发布时间: 2025-11-11

==================================================

ChainCatcher 消息，据 GlobeNewswire 报道，纳斯达克上市公司 IP Strategy 披露 IP 代币持仓量已达 5,250 万枚，价值超 2.3 亿美元。

此外，该公司还宣布与 Crypto.com 达成合作，后者将为其数字资产财库提供执行、托管、场外交易和质押服务。
