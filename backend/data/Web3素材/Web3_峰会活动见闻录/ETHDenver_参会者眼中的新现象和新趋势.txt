标题: ETHDenver 参会者眼中的新现象和新趋势
链接: https://www.chaincatcher.com/article/2088779
发布时间: 2023-03-07

==================================================

采访：Will

整理：Claudia，深潮 TechFlow

 

参加完 ETHDenver 的 Will 老师发出如此感叹，作为资深加密资料收集整理控，勤奋的 Will 老师再次卷了起来，在活动期间采访了 75 位参会者，试图群描 Denver 现场新鲜出炉的参会感想。

对于开发者和大部分 Builder 来说，整个会场一洗牛市的低沉，能量和生机在交谈中不断熵增，对于入圈不久的新人和学生来说，现场的氛围打开了眼界；更有乐观者对于「中国崛起」的叙事有了百分之百的预期，很多项目有大量华人的身影，分布在项目的各个环节；但对于很多投资人来说，新的玩法叙事，包括技术突破都尚未涌现。

不论如何，大多数参与者仍然对新项目有着积极的预期，AI，ZK 等宠儿仍然占据了较大的视线。不管新的叙事有没有出现，ETHDenver 中涌现的对于行业的热情和能量已经重于黄金。深潮 TechFlow 综合 Will 老师的采访，整理出以下内容，一起跨越时空，回归 Denver 现场的汹涌。

 

初夏虎

 

参加 Denver 大会活动感受：挺好的，一起来逛的老婆说：这生态，已经大到灭不掉了。我不太看好那些依赖技术的东西，其中大多数 95% 的东西都会失败，只有 5% 的东西有可能成功，但我们无法确定哪些是那 5%，只能一个一个地了解，判断它们属于以下三类：

1）金融服务，比如 LSD 借贷等；

2）数据服务，例如 API 方式和开发工具；

3）游戏。

我最看好金融领域，数据也有一些机会，但数量有限。对游戏则持悲观态度，Web2 进去是天方夜谭。

 

匿名 Z 某基金投资人

 

1）对个体来说，除非和项目方或创始人关系特别好，否则信息差太大了。因此，如果只从事一级市场，那样就太不划算了，除非你具备非常优秀的美国本科计算机专业背景并且非常努力；

2）在项目叙述方面，没有特别新的内容，大部分都是开发者工具，不是以太坊的核心层级，而是基于以太坊的工具。因此，很难从经济角度捕捉到价值，能够捕捉到的只是比较旧的内容；

3）整体而言，华人生态的质量有所提高，比 2019 年的熊市时期要好很多。但是，华人仍然缺乏话语权，需要靠外国的头部机构来带动；

4）依旧觉得在应用层上的大规模采用还为时过早；

5）当年是"卧槽，这东西牛逼"。现在是“这东西听起来牛逼，但是已经有很牛逼的项目了，行不行不知道”。包括 MEV，LSD，ZK 和中间件都是这种感觉，赛道太拥挤了。在去中心化执行层面，已经涌现出 3-4 个项目。在 API 和安全领域，也是这种感觉，听起来有点审美疲劳；

6）互联网是一个纵向的领域，主要是连接用户。而 Web3 的底层是一个横向的领域，大家都在铺设基础设施，竞争非常激烈。在同一个层面上，大家都知道彼此，但是哪个更好还不确定。在过去，我们可以直接梭哈，但现在不行了。

 

Jenks Filecoin 开发者

 

参加 Denver 大会活动感受：感觉还不错。身为项目方，我见到了很多 builder，其中只有 20 个项目获得了 grant。大会吸引了众多项目方前来，主要集中在 EVM 领域，他们借此机会发布新项目，并组织了一些早上的 lighting talk 来介绍各自项目的最新进展。

2.观点：

1）我认为 ZK 很有前途，很火，也在学习中关注它；

2）分布式赛道是一个转折点，如果企业能跟上叙事的步伐，将会有更好的发展；

3）ETH 基金会没做太多事情，也没推出什么活动。

4）个人认为，ETH 开创了先例，但它是否能够成功还不确定。比特币是一种承诺，而 ETH 发行后，需要不断迭代才能解决主流问题，因此无法作为一个很好的参照。从技术方面来看，以太坊能够提供高效解决方案，解决许多问题，而从经济学角度来看，BTC 解决了信任问题，但是其成本非常高昂。组织也想让更多人使用 BTC，但 ETH 则价格便宜，能够解决许多问题。最可怕的是，它不需要依赖国家，可以达到人类协调，因此是一种革命性的工具，就像个人电脑、印刷和文字一样。
