ChainCatcher 消息，Base 协议负责人 Jesse Pollak 在 X 平台发布华语推文：Base 属于我们每一个人。

据悉他在专访中披露了 Base 的五个战略方向，以在 2025 年打造 Base builder 主场，包括：

Base 将构建一个开发者平台；
将所有链上复杂性抽象，构建加密钱包；
Base 还将培育生态系统和应用程序；
Base 将培育深厚的资本市场，让 Base 成为生态链经济的中心；
进一步去中心化并继续扩张。
